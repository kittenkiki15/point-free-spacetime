# A-0008: 実験における時空の領域を独立に与える

| 項目 | 値 |
| --- | --- |
| 状態 | 作業上 |
| 層 | 実験 |
| 依存する ID | [D-0003](../definitions/D-0003.md) |
| 関係する予想・結果 | なし |
| 初出 | [2026-09-28 第 08 回](../summaries/2026-09-28_08_observation-as-limit.md) |

## 主張

実験における時空（[D-0003](../definitions/D-0003.md)）の領域と、その包含・有界性は、再構成の対象である観測の局在を使わずに、独立に与えられる。具体的には、観測者 $`O`$ の時空の部分 $`M_O`$ の開集合を領域とし、包含は集合の包含、有界性は距離 $`d_O`$ での有界性とする。

## 採用の理由

局在（[D-0008](../definitions/D-0008.md)）を実験における時空の領域で添字づけるとき、循環を避けるために要る（第 08 回。PR #12 のレビューの指摘）。二つの時空を名前で分けるだけでは、この独立性は保証されない。

## 注意

- 第 13 回に、領域の与え方を $`M_O`$ の開集合として決め、状態を「未定」から「作業上」にした。$`M_O`$ は較正（[A-0010](A-0010.md)）で定まり、観測の局在を使わない。
- 領域は観測者 $`O`$ に依存する。観測者の取り替えで領域がどう移るかは、整合条件（[D-0003](../definitions/D-0003.md) の未解決の点）の問いである。

## 未解決の点

- 開集合のすべてを領域とするか、実験で意味を持つ領域の族（因果的に凸な集合、有界な集合など）に限るか。限る場合、その族は一般に任意の合併で閉じないので、膨張（[D-0011](../definitions/D-0011.md)）が作用する領域の族と、必要な結びについての閉性を併せて決める（PR #28 のレビュー）。

## 履歴

- 第 08 回：循環を避けるための未解決の条件として挙げた。
- 第 10 回：前提の候補として登録した（状態は未定）。
- 第 13 回：領域を $`M_O`$ の開集合、有界性を $`d_O`$ での有界性として中身を決め、作業上にした（ユーザーの判断）。
