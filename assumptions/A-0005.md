## 目的

- 同じプロトコルの各観測について、資源の予算を、許容される設定の全体で一様に抑える。極限を取る族に一様な上界を課すと、極限として現れる観測量（層 2）が、どの資源を抑えるかによって選ばれる（第 08 回の「族全体に課す資源の条件」の軸）（[G-0005](../goals/G-0005.md)）。
  - 各実験を有限にする [D-0001](../definitions/D-0001.md) とは役目が別である。

## 完了の条件

[Q-0005](../questions/Q-0005.md)（コンパクト性を課す対象）と [Q-0006](../questions/Q-0006.md)（「一様に有界」の範囲）が解決したら、状態を「採用」にできる。代わりの前提（プロトコルをまたぐ共通の上限、実験全体の上限）との比較は Q-0006 で行い、別の択一の組にするかどうかもそこで決める。第 44 回に、両方の結論を下の主張・採用の理由・注意に反映した（択一の組は登録しない。下の注意）。

## 主張

族の上での実験の有限性のうち、同じプロトコルの各観測の資源の予算が一様に有界であることを、予算の座標の有界性として課す（各実験の有限性は、[D-0001](../definitions/D-0001.md) の定義で課す）。

プロトコル $`π`$ が予算を指定する資源の種類を $`J_π`$ 個とする。予算は設定の一部として記録する（[A-0004](A-0004.md) の 1）ので、設定の空間 $`X_π ⊆ ℝ^{n_π}`$（[D-0003](../definitions/D-0003.md)）の座標のうち $`J_π`$ 個が予算の座標である。これを $`b_π = (b_{π,1}, …, b_{π,J_π}) : X_π → [0, ∞)^{J_π}`$ と書く（座標への射影なので連続である）。このとき、各プロトコルの各資源について、1 回の観測の予算は、設定によらず一様に有界である。

```math
∀π\; ∀j ∈ \{1, …, J_π\}\; ∃B_{π,j} ≥ 0\; ∀x ∈ X_π :\; b_{π,j}(x) ≤ B_{π,j}
```

これは [A-0004](A-0004.md) の 3（消費量の有界性）と対になる形である。量化の順序から、上界 $`B_{π,j}`$ は $`π`$ と $`j`$ だけで決まり、設定と実験に依らない。したがって、プロトコル $`π`$ に従う任意の有限な実験 $`e`$ の各観測の設定 $`x_i`$ について、$`b_{π,j}(x_i) ≤ B_{π,j}`$ が成り立つ。

この前提は、次を述べない（下の注意の「範囲は各プロトコルの中」）。

- 予算でない設定の座標（雑音の大きさ、角度など）の値域の条件。
- プロトコルの間に共通の上界（例えば、プロトコル $`π_k`$ の予算が常に $`k`$ なら、各プロトコルでは有界だが、全体では有界でない。PR #42 のレビュー）。
- 観測の回数にわたる上界（各観測の予算の和は、観測の回数 $`N_e`$（[D-0001](../definitions/D-0001.md)）に上限がないので、一様に有界とは限らない。例えば、毎回 1 単位の予算なら、和は $`N_e`$ になる。PR #42・#46 のレビュー）と、実験全体の資源の上界。

## 採用の理由

資源の条件を「特に限定せず、実験パラメータの値域とする」というユーザーの提案（第 09 回。「実験パラメータ」は第 20 回に「設定」に改めた語）を、予算の座標の値域の条件として述べたものである。当初は、設定の空間のすべての座標の値域のコンパクト性として述べていたが、第 44 回に、次の理由で、予算の座標だけの有界性に改めた（[Q-0005](../questions/Q-0005.md)。第 37 回のユーザーの提案を受けて、第 44 回にユーザーと合意した）。

- **有界性で足りる**：この前提の目的（同じプロトコルの各観測の予算を一様に抑える）には、予算の座標の値域の有界性で足りる。コンパクト性（閉じていること）を加えて使う項目は、第 44 回の時点でない（設定の列の極限が $`X_π`$ の中にあることを使う定義・前提・予想・結果はない）。
- **予算の座標だけで足りる**：抑えたいのは資源の予算なので、ほかの座標には条件を課さない（前提を最小にする方針）。消費量の有界性（[A-0004](A-0004.md) の 3）が資源の消費量の座標だけに課すのと対になる。
- **座標の取り替え**：予算の座標は、観測者の基準の時計と物差し（[A-0010](A-0010.md)）などで読む資源の量で、取り替えとして許すのは単位の換算（正の定数倍）である。正の定数倍は、予算の非負性と予算 0 の意味を保ち、有界性も保つ（原点のずれは、予算を負にし得て、予算 0 の意味も変え得るので許さない。PR #60 のレビュー）。予算でない座標は、この前提の対象でないので、その取り替えは条件に影響しない。

## 注意

- [D-0001](../definitions/D-0001.md) との区別（目的は第 34 回にユーザーと確認した。第 37 回に「目的」の節へ移した）：有限な実験だけを許す（期間と、操作・観測の回数を有限にする）のは、D-0001 の定義の役目である（エネルギーなどの資源の有限性は D-0001 からは従わない。D-0001 の未解決の点。PR #47 のレビュー）。この前提と [A-0004](A-0004.md) が抑えるのは、同じプロトコルの各観測の予算（この前提）と消費量（A-0004 の 3）である。各実験が有限でも、族全体で資源が一様に有界とは限らず（例：待ち時間がいくらでも長い実験の族）、その極限には理想化された観測量が現れ得る（[調査 08](../surveys/2026-09-28_08_observation-as-limit.md) の 1.2・1.3 節）。
- **予算を指定する資源の種類**：どの資源の予算を指定するか（$`J_π`$）は、プロトコルに任せる（A-0004 の消費量の種類 $`K_π`$ と同じ扱い。[Q-0010](../questions/Q-0010.md) の第 34 回の決定）。$`J_π = 0`$ なら、この前提は空になる。予算の上界が必要になる結果では、その結果の仮定として、どの資源の予算を指定するかを書く。第 08 回の「有界にする資源」の軸（時空の領域、エネルギー、操作の回数など）は、この前提の下で、プロトコルがどの資源を予算として指定するか、という形にまとまる。体系を分ける軸として択一の組に登録することはしない（第 44 回。[Q-0005](../questions/Q-0005.md)）。
- **コンパクト性を課さないこと**：予算の値域が閉じている必要はない。理想化の値を設定の範囲に含めない扱い（[A-0006](A-0006.md) の注意の 3）では、値域が閉じないことがあるが、有界性とは食い違わない。設定の列の極限は $`X_π`$ の中にあるとは限らない。境界の設定値を理想化した模型の設定として扱うかは、前提では決めず、理想化の再現の予想の論点とする（[T-0032](../tasks/T-0032.md)。第 46 回）。設定の列の収束する部分列が必要になったときは、プロトコルを固定した有限次元の空間 $`X_π ⊆ ℝ^{n_π}`$ で、列の座標がすべて有界なら、閉包 $`\overline{X_π}`$ の中に極限を持つ部分列がある（ボルツァーノ–ワイエルシュトラスの定理）。予算の座標だけが有界な場合や、プロトコルをまたいで次元が増える列では、この結論は得られない（PR #51 のレビュー。[Q-0005](../questions/Q-0005.md) の (c)）。
- **一般の座標の取り替え**：設定の空間 $`X_π`$ から新しい座標の像への同相写像による一般の取り替えでは、値域の有界性もコンパクト性も保たれない（例：$`X = [0, 1]^2 \setminus \{(0, 0)\}`$ は両座標の値域がコンパクトだが、同相な取り替え $`(x, y) ↦ (x, 1/(x + y))`$ の第二座標は有界でない。ほかの座標を混ぜる取り替え $`(b, u) ↦ (b + u, u)`$ は、$`[0, 1] × [0, ∞)`$ の第一座標を予算とすると、一様連続でも予算の有界性を保たない。PR #51 のレビュー）。この前提は、予算の座標を、資源の量の読みとして単位の換算の範囲で固定して述べるので、このような取り替えは許さない。
- **範囲は各プロトコルの中（第 44 回。[Q-0006](../questions/Q-0006.md)、ユーザーと合意）**：
  1. プロトコルをまたぐ共通の上界は置かない。層 2 では、理想化した観測量を、プロトコルを取り替えていく族の極限として得ることがある。共通の上界を前提にすると、そのうち、ある資源の予算を際限なく増やしていく族（待ち時間や操作の回数の予算をいくらでも大きくする族など）の極限を禁じてしまう。予算を固定したままの族（共通の設定・結果の空間の上の $`p_k(1 \mid x) = s(kx)`$ のように、予算と無関係に応答が鋭くなる族）は、共通の上界があっても禁じられない。どの族に予算の増加が伴うかは、プロトコルがどの資源を予算として指定するかによる。族に一様な上界が要る場面は、特定の族の条件として書く（[D-0005](../definitions/D-0005.md) の族。族の条件は [T-0006](../tasks/T-0006.md) で扱う）。[C-0007](../conjectures/C-0007.md) の上限 $`Λ`$ は、可能な実験の装置の占有範囲の上限で、この前提の予算の上界からは従わず、C-0007 の詳細化で別に扱う。
  2. 観測の回数の上限 $`N_e ≤ N_π`$ は課さない。同じプロトコルで観測の回数を増やすことは、統計を推定する基本の手続きで、回数の上限を課すと、回数を増やす族がプロトコルを取り替える族になってしまう。各実験の有限性は D-0001 で課している。
  3. 実験全体の資源の上界は置かないので、観測の外の操作の資源と、観測を行わない実験（$`N_e = 0`$）の資源の、実験単位の記録は、この前提には要らない。必要になったときは、実験全体の記録として定める（[Q-0010](../questions/Q-0010.md) の第 34 回の決定の 2）。
  4. 代わりの前提（プロトコルをまたぐ共通の上界、実験全体の上界）は、今は置かないので、択一の組には登録しない。必要になったら、前提ではなく族の条件として述べるかを含めて検討する。
