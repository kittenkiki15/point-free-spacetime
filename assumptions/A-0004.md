## 目的

- 資源の予算を設定の座標に、実際の消費量を結果の座標に含め、資源の条件を設定と結果の空間の条件として述べられるようにする。どの資源を抑えるかという制約を、実験の形式化の中に置く（[G-0005](../goals/G-0005.md)）。
  - 予算は [A-0005](A-0005.md) の値域の条件で、消費量はこの前提の 3 で、プロトコルごとに一様に抑える。予算を座標に含めないと、値域の条件だけでは資源を抑えられない（注意の例）。
## 完了の条件

## 主張

各観測の資源（操作回数、時間、エネルギーなど）について、次のように記録する。

1. **予算は設定**：各観測に割り当てる資源の量（事前に決める予算・上限）を、その観測の設定の一部として記録する。
2. **消費量は結果**：各観測で実際に消費した資源の量を、その観測の結果の一部として記録する。プロトコル $`π`$ が記録を指定する資源の種類を $`K_π`$ 個とし、結果の空間 $`Y_π`$（[D-0001](../definitions/D-0001.md)）の上の消費量の座標を、ボレル可測な写像 $`r_π = (r_{π,1}, …, r_{π,K_π}) : Y_π → [0, ∞)^{K_π}`$ と書く。
3. **消費量の有界性**：各プロトコルの各資源について、1 回の観測の消費量の記録は、結果によらず一様に有界である。

```math
∀π\; ∀k ∈ \{1, …, K_π\}\; ∃R_{π,k} ≥ 0\; ∀y ∈ Y_π :\; r_{π,k}(y) ≤ R_{π,k}
```

3 から、プロトコル $`π`$ に従う任意の有限な実験 $`e`$（その全体を $`E_π`$ と書く。観測の回数 $`N_e`$、結果の族 $`(y_i)_{i=1}^{N_e}`$。[D-0001](../definitions/D-0001.md)）の各観測について、次が従う。

```math
∀π\; ∀k ∈ \{1, …, K_π\}\; ∃R_{π,k} ≥ 0\; ∀e ∈ E_π\; ∀i ∈ \{1, …, N_e\} :\; r_{π,k}(y_i) ≤ R_{π,k}
```

量化の順序から、上界 $`R_{π,k}`$ は $`π`$ と $`k`$ だけで決まり、設定・結果・実験 $`e`$ に依らない。ただし、$`r_{π,k}(y)`$ は、その実験の観測者の基準の時計と物差し（[A-0010](A-0010.md)）で読んだ記録の値である。3 は、同じ物理過程の消費量を別の観測者が読んだ値（時間やエネルギーは観測者によって異なる）の上界までは述べない。

3 は 1 回の観測ごとの上界で、観測の回数にわたる上界は述べない。例えば、各観測の消費量の記録の和 $`\sum_{i=1}^{N_e} r_{π,k}(y_i)`$ は、$`N_e`$ に依らない上界を持つとは限らない（毎回 $`r_{π,k} = c > 0`$ なら和は $`N_e c`$）。なお、実験全体の消費量はまだ定めていない。実験全体の消費量がこの和に等しいか（加法性）、和以下か（劣加法性）は仮定しない（未解決の点の Q-0010 で扱う）。

## 採用の理由

予算を設定として記録しておけば、設定の空間 $`X`$（[D-0003](../definitions/D-0003.md)。この前提の下で、設定から作る）の座標に予算が含まれるので、設定の値域の条件（[A-0005](A-0005.md)）だけで、1 回の観測の予算を、プロトコルごとに、許容される設定全体で一様に抑えられる（プロトコルの間に共通の上限と、観測の回数にわたる実験全体の上限は従わない。PR #42 のレビュー）（ユーザーの認識。第 09 回の PR #21 のレビューの際に明確化）。

実際の消費量は、適応的・確率的な操作では、その回の結果に依存しうる（例：成功するまで繰り返す操作の繰り返しの回数）。観測の前に決まる設定とは限らないので、結果として記録する（第 34 回に [Q-0009](../questions/Q-0009.md) でユーザーと合意）。消費量の有界性は、「上限に達したら打ち切る」のような、プロトコルの記述や装置の実現に依存する言い方を避け、記録だけで述べる最小の形（3）で置いた（ユーザーの判断）。記録の上で予算を守ること（同じ資源について予算と消費量の両方を指定した場合に、その資源の消費量の座標 $`r_{π,k}`$ と予算の座標 $`b_{π,j}`$（[A-0005](A-0005.md)）の添字を対応させて、$`r_{π,k}(y_i) ≤ b_{π,j}(x_i)`$。予算と消費量の種類の数 $`J_π`$・$`K_π`$ は独立にプロトコルが指定するので、対応する資源がない場合は定まらない）は、プロトコルの記述に依存する条件なので課さない。なお、これを実現した設定・結果の組だけに課しても、3 は従わない（3 は実現しない結果を含むすべての $`y ∈ Y_π`$ について述べる。PR #46 のレビュー）。

## 注意

- 定義の順序：この前提は設定と結果について述べ、結果の空間は [D-0001](../definitions/D-0001.md) のものを使う。$`X`$ は D-0003 でその設定から作るので、この前提は D-0003 に依存しない（D-0003 がこの前提に依存する）。
- 予算を座標に含めず、設定 $`x`$ から決まる量として別に扱うと、値域がコンパクトでも資源が一様に有界とは限らない（$`x → 0`$ で操作回数が際限なく増えるプロトコルなど）。
- 記録する資源の種類（第 34 回に [Q-0010](../questions/Q-0010.md) で決めた）：どの資源の消費量を記録するか（$`K_π`$）は、プロトコルに任せる。$`K_π = 0`$ なら 3 は空になる。消費量の上界が必要になる結果では、その結果の仮定として、どの資源を記録するかを書く。
- 実験全体の消費量（第 34 回に Q-0010 で決めた）：今は定めない。必要になったときは、各観測の消費量の和との関係を仮定するのではなく、実験全体の記録として定める。

## 未解決の点

- [Q-0010](../questions/Q-0010.md)：記録する資源の範囲
- 消費量の記録の観測者への依存（第 34 回。ユーザーの指摘。[T-0024](../tasks/T-0024.md) で扱う）：3 の上界は、その実験の観測者の基準（[A-0010](A-0010.md)）で読んだ記録についてのもので、時間やエネルギーのように観測者によって値の異なる資源では、別の観測者が読んだ値の上界までは述べない。観測者の取り替え（[A-0014](A-0014.md)・[A-0015](A-0015.md)）の下で、資源の上界をどう比べるか（例：固有時で読む、装置の静止系で読む）を決める。
- [Q-0009](../questions/Q-0009.md)：設定に含める資源の量は、予算か実際の消費量か
- どの資源が他の資源の上限を従属的に抑えるか（第 44 回。ユーザーの問い）：ユーザーの直観は、記録の情報量が最も本質的な資源だというもの。通常の物理学には、条件付きで、エネルギーと大きさの側が情報量や操作の回数を抑える関係がある（参考例。適用の条件を省いて、任意の実験の資源の関係として読まない）：Bekenstein の上限 $`S ≤ 2πk_B R E/(ħc)`$（半径 $`R`$ の領域に収まる、エネルギー $`E`$ の系のエントロピー）、Margolus–Levitin の定理（基底エネルギーから測った平均エネルギーが $`E`$ の系が、直交する状態に移るのに要る時間の下限 $`πħ/(2E)`$）、ランダウアーの原理（温度 $`T`$ の熱浴の下で、等確率で未知の 1 ビットを決まった状態にリセットするときに、熱浴へ散逸する平均の熱の下限 $`k_B T \ln\,2`$。既知のビットのリセットには、この下限は掛からない。記録すること自体は原理的に可逆にできる（Bennett））。どれも、使えるエネルギーなどの上限から情報量や操作の回数の上限へ向かう関係で、情報量の上限でエネルギーを抑えることはできない（1 ビットの結果を得るのに、いくらでもエネルギーを使える）。なお、この前提と [A-0005](A-0005.md) は各観測の予算と消費量の上界しか置かず、実験全体で使えるエネルギーの上界も置かないので、これらの関係を当てはめても、実験全体のビット数の上界は今の前提からは従わない。一方、このプロジェクトでは、時間と長さは層 1 では観測者の時計と物差しの読み（[A-0010](A-0010.md)）で、エネルギーの記録は時計と物差し以外の測定器の読みである。前者の観測者によらない物理量としての意味は時空を構成した後に付き、後者を層 1 でどう解釈するか（装置が何を測るかのモデルが要るか。[Q-0008](../questions/Q-0008.md) と同じ型の問題）は決めていない。記録の情報量は、観測者の座標を使わずに記録から定める方法を検討できるので、構成の順序の上では最も基本的な資源の候補になる（ただし、有限な記録に実数値が含まれるだけでは、符号化にも分布にも依らない情報量は定まらない。どの情報量を選ぶかと、それに要る追加のデータは [T-0029](../tasks/T-0029.md) に書いた）（点なし位相の「有限の観測で確かめられる性質」を「有限の情報で確かめられる性質」と読む見方とも合う）。Bekenstein・Margolus–Levitin・Landauer の型の関係は、時空を構成した後に、適用の条件とあわせて予想として述べる候補とする（Claude の見立て。ホログラフィー原理や Bousso の共変エントロピー上限との関係は、記憶による見立てで、文献で確かめていない）。資源を一つの量に換算する場合の候補としては [T-0029](../tasks/T-0029.md) の「$`R(N)`$ の量の形」で扱う。今の主張（資源の種類を限らない予算・消費量の座標）は、情報量（記録の容量など）を資源の一つとして扱うことを、すでに許している。
