## 主張

各観測の資源（操作回数、時間、エネルギーなど）について、次のように記録する。

1. **予算は設定**：各観測に割り当てる資源の量（事前に決める予算・上限）を、その観測の設定の一部として記録する。
2. **消費量は結果**：各観測で実際に消費した資源の量を、その観測の結果の一部として記録する。プロトコル $`π`$ が記録を指定する資源の種類を $`K_π`$ 個とし、結果の空間 $`Y_π`$（[D-0001](../definitions/D-0001.md)）の上の消費量の座標を、ボレル可測な写像 $`r_π = (r_{π,1}, …, r_{π,K_π}) : Y_π → [0, ∞)^{K_π}`$ と書く。
3. **消費量の有界性**：各プロトコルの各資源について、1 回の観測の消費量の記録は、結果によらず一様に有界である。

```math
∀π\; ∀k ∈ \{1, …, K_π\}\; ∃R_{π,k} ≥ 0\; ∀y ∈ Y_π :\; r_{π,k}(y) ≤ R_{π,k}
```

3 から、プロトコル $`π`$ に従う任意の有限な実験 $`e`$（観測の回数 $`N_e`$、結果の族 $`(y_i)_{i=1}^{N_e}`$。[D-0001](../definitions/D-0001.md)）の各観測について、次が従う。

```math
∀π\; ∀k ∈ \{1, …, K_π\}\; ∃R_{π,k} ≥ 0\; ∀e\; ∀i ∈ \{1, …, N_e\} :\; r_{π,k}(y_i) ≤ R_{π,k}
```

量化の順序から、上界 $`R_{π,k}`$ は $`π`$ と $`k`$ だけで決まり、設定・結果・実験 $`e`$ に依らない。ただし、$`r_{π,k}(y)`$ は、その実験の観測者の基準の時計と物差し（[A-0010](A-0010.md)）で読んだ記録の値である。3 は、同じ物理過程の消費量を別の観測者が読んだ値（時間やエネルギーは観測者によって異なる）の上界までは述べない。

3 は 1 回の観測ごとの上界で、観測の回数にわたる上界は述べない。例えば、各観測の消費量の記録の和 $`\sum_{i=1}^{N_e} r_{π,k}(y_i)`$ は、$`N_e`$ に依らない上界を持つとは限らない（毎回 $`r_{π,k} = c > 0`$ なら和は $`N_e c`$）。なお、実験全体の消費量はまだ定めていない。実験全体の消費量がこの和に等しいか（加法性）、和以下か（劣加法性）は仮定しない（未解決の点の Q-0010 で扱う）。

## 採用の理由

予算を設定として記録しておけば、設定の空間 $`X`$（[D-0003](../definitions/D-0003.md)。この前提の下で、設定から作る）の座標に予算が含まれるので、設定の値域の条件（[A-0005](A-0005.md)）だけで、1 回の観測の予算を、プロトコルごとに、許容される設定全体で一様に抑えられる（プロトコルの間に共通の上限と、観測の回数にわたる実験全体の上限は従わない。PR #42 のレビュー）（ユーザーの認識。第 09 回の PR #21 のレビューの際に明確化）。

実際の消費量は、適応的・確率的な操作では、その回の結果に依存しうる（例：成功するまで繰り返す操作の繰り返しの回数）。観測の前に決まる設定とは限らないので、結果として記録する（第 34 回に [Q-0009](../questions/Q-0009.md) でユーザーと合意）。消費量の有界性は、「上限に達したら打ち切る」のような、プロトコルの記述や装置の実現に依存する言い方を避け、記録だけで述べる最小の形（3）で置いた（ユーザーの判断）。記録の上で予算を守ること（$`r_{π,k}(y_i) ≤ b_{π,k}(x_i)`$。$`b_{π,k}`$ は設定の予算の座標）は、3 より強いので課さない（課せば、A-0005 と合わせて 3 が従う）。

## 注意

- 定義の順序：この前提は設定と結果について述べ、結果の空間は [D-0001](../definitions/D-0001.md) のものを使う。$`X`$ は D-0003 でその設定から作るので、この前提は D-0003 に依存しない（D-0003 がこの前提に依存する）。
- 予算を座標に含めず、設定 $`x`$ から決まる量として別に扱うと、値域がコンパクトでも資源が一様に有界とは限らない（$`x → 0`$ で操作回数が際限なく増えるプロトコルなど）。
