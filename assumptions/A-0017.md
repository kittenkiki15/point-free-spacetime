## 主張

実際の実験の各プロトコル $`π`$ について、次が成り立つ。

1. **結果の空間の形**：結果の空間（[D-0001](../definitions/D-0001.md)）は、有限集合 $`F_π`$ を添字とする、連続体の部分の直和である。

```math
Y_π = ⨆_{a ∈ F_π} C_{π,a}, \qquad C_{π,a} ⊆ ℝ^{m_{π,a}}
```

ここで $`C_{π,a}`$ は、$`m_{π,a} ≥ 1`$ なら正のルベーグ測度を持つボレル集合、$`m_{π,a} = 0`$ なら一点である。$`Y_π`$ が有限集合（デジタルの記録）の場合は、すべての $`m_{π,a}`$ が 0 の場合に当たる。有限集合と連続体の直積 $`F_π × C_π`$ は、すべての $`C_{π,a}`$ が等しい場合に当たる。

2. **結果の統計は密度を持つ**：各設定 $`x ∈ X_π`$ の結果の統計 $`p_π(\,\cdot \mid x)`$（[D-0004](../definitions/D-0004.md)）は、$`Y_π`$ の上の「$`F_π`$ の数え上げの測度とルベーグ測度の積」について絶対連続である。つまり、密度 $`q_π(a, z \mid x)`$ があって、各 $`a ∈ F_π`$ と可測集合 $`B ⊆ C_{π,a}`$ について次が成り立つ（$`m_{π,a} = 0`$ の成分では、右辺は $`q_π(a \mid x)`$ とする）。

```math
p_π(\{a\} × B \mid x) = \int_B q_π(a, z \mid x)\, dz
```

有限集合の成分には条件を課さない。量子ビットの測定で結果が確定する場合（$`F_π`$ の上の δ 分布）も許す。

## 採用の理由

実際の装置の統計は、雑音のために、連続体の部分では滑らかになる（第 33 回のユーザーの提案）。連続体の上の δ 分布（雑音のない針の読みなど、決定論的な古典力学の模型）や、設定について不連続な統計（雑音のない閾値の装置など）は理想化であり、実際の実験の応答関数の、設定ごとの弱収束の極限としてだけ現れる（下の注意）。有限集合の記録と、有限集合と連続体を組み合わせた記録は、量子ビットの測定などで現に使うので許す（ユーザーの判断）。

## 注意

- 理想化した模型（連続体の上の δ 分布や、不連続な統計）は、この前提の対象ではない。実際の実験の応答関数の列 $`p_{π_k}`$ が、各設定 $`x`$ で弱収束する極限としてだけ扱う。極限は実際の実験ではなく、極限（可能な実験）の側に属する。極限の不連続点での値は、極限の列が決める（例：$`p_k(1 \mid x) = s(kx)`$（$`s`$ はシグモイド関数）の極限は、$`x = 0`$ で $`s(0) = 1/2`$ になる）。
- 「密度を持つ」より強い条件（密度の連続性や微分可能性）は課さない。弱位相での連続性（[A-0006](A-0006.md)）と極限の議論には、これで足りる。
- 結果が可算無限個になる記録（光子の数え上げなど）は、有限集合に含めていない。実際の装置は計数の上限を持つ（[A-0005](A-0005.md) の有界性とも合う）ので、有限集合で足りるとした。
- 密度を持つ統計に限っても、弱位相と全変動の位相は一致しない（例：$`[0, 2π]`$ の上の密度 $`1 + \sin(y/x)`$ は、$`x → 0`$ で一様分布に弱収束するが、全変動では収束しない）。
