# 前提の一覧

本プロジェクトの前提（仮定）とその候補を、1 件 1 ファイル（`A-NNNN.md`）で管理します。書式は [`_template.md`](_template.md) のとおりです。

- 前提は、定義でも予想でもなく、議論の土台とする主張です。採用したものだけでなく、作業上のものと未定の候補も、状態を付けて載せます。前提を変えて得られる体系を比べることも、本プロジェクトの方針です（第 08 回）。
- 前提を定理として導けるかを問うものは、予想として別に登録します（例：[C-0004](../conjectures/C-0004.md)）。
- 前提の種類（物理的・方法論的・数学的な技術上の前提など）の欄は設けません。立場によって判断が分かれうるためです（第 10 回のユーザーの判断）。

## 状態

| 状態 | 意味 |
| --- | --- |
| 採用 | ユーザーと合意し、以後の議論の土台にするもの |
| 作業上 | 暫定的に使うが、未解決の指定が残るもの |
| 未定 | 必要なことは分かっているが、中身が決まっていないもの |
| 廃止 | 使わなくなったもの（ファイルは残し、理由を履歴に書く） |

## 層

[`framework.md`](../framework.md) の構成の層（実験 → 観測量 → 観測量の時空 → 可能な実験 → 可能な観測量 → 点なし時空）のどれに属するかを書きます。

## 依存関係

各ファイルの「依存する ID」から、[`framework.md`](../framework.md) の依存関係の図を `python3 tools/deps_graph.py` で生成します。「関係する予想・結果」には、この項目に依存する予想・結果の ID を書きます（予想・結果のファイルの「依存する ID」と一致することを、`tools/tests/test_framework.py` で検査します）。
