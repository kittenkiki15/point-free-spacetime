## 主張

観測者 $`O`$ の時計と物差しで定まる、実験における時空のうち時空の部分 $`M`$ の上の距離を $`d_O`$ とする（例えば、$`O`$ の静止系の座標 $`(t, 𝐱)`$ で $`d_O = \max(c \left| Δt \right|, \left| Δ𝐱 \right|)`$）。ある $`0 < ℓ ≤ Λ`$ があって、すべての $`x ∈ M`$ について次が成り立つ。

```math
B_ℓ(x) ⊆ \mathrm{occ}(x) ⊆ B_Λ(x)
```

ここで $`B_r(x)`$ は $`d_O`$ の開球、$`\mathrm{occ}`$ は装置の占める領域（[D-0011](../definitions/D-0011.md)）である。

$`\mathrm{occ}(x)`$ は、設定値が $`x`$ の許容された実験の占める領域の**合併**である（[D-0011](../definitions/D-0011.md)）。したがって、下限 $`ℓ`$ は「設定値が $`x`$ の実験を全部合わせると、少なくとも半径 $`ℓ`$ の球を占めうる」ことを表し、個々の装置を $`ℓ`$ より小さくできないことは意味しない（例えば、半径 1 の球を占める実験と、任意に小さい球を占める実験の両方を許しても、$`\mathrm{occ}(x) = B_1(x)`$ となりうる）。個々の装置の最小の大きさを主張するには、実験ごとの占める領域 $`\mathrm{occ}(e)`$ に別の条件を課す。上限 $`Λ`$ は、観測者 $`O`$ の距離で、すべての設定値に一様な上限があることを表す（各 $`\mathrm{occ}(x)`$ が有界であることより強い。例えば $`ℝ`$ で $`\mathrm{occ}(x) = B_{1 + \left| x \right|}(x)`$ は、各領域は有界だが一様な上限はない）。これは装置の**占有範囲**についての仮定である。大きな装置でも測定位置を細かく識別できる可能性があるので、占める領域の下限だけからは、分解能の下限（$`ℓ`$ より細かい分解能は操作的に使えないこと）は従わない。分解能への含意には、追加の条件（例えば、実験の結果が装置の占める領域全体を単位としてしか区別されないこと）が要る。

## 採用の理由

- 第 05 回の C-0001 の主張 1 で、「$`ℓ`$ より細かい分解能は操作的に使えない」という物理の仮定を別に置く必要があるとした。候補 A（[D-0011](../definitions/D-0011.md)）では、膨張を装置の占める領域から作るので、この膨張の尺度に効くのは占める領域の上下限である。そこで、占める領域についての仮定を前提として置いた（第 12 回）。分解能についての仮定とは別のもので、両者を結ぶには上の追加の条件が要る。
- 数学の側では、$`(M, d_O)`$ が直径が $`Λ`$ より大きい長さ空間で、$`Λ < 2ℓ`$ なら、膨張 $`N_{\mathrm{occ}}`$ の余白付きの包含は補間的でないと見込まれる（[C-0001](../conjectures/C-0001.md) の主張 2）。直径が小さい空間では成り立たない（例えば、直径が $`ℓ`$ 未満なら $`\mathrm{occ}(x) = M`$ が上下限を満たし、膨張は冪等で補間的になる）。

## 注意

- この前提は、物理から導くことを目指す（[C-0007](../conjectures/C-0007.md) の目標）。それまでは作業上の前提として扱う。
- $`d_O`$ は観測者 $`O`$ に依存する。ポアンカレ共変な $`\mathrm{occ}`$ では、有界性（上限 $`Λ`$）と両立しないと見込まれる（[C-0008](../conjectures/C-0008.md)）。
- 上限 $`Λ`$ を課さないと、例えば $`\mathrm{occ}(x) = M`$ で余白付きの包含は補間的になり、最小の尺度は補間性の破れとして現れない。

## 未解決の点

- 距離 $`d_O`$ の選び方（時間と空間の尺度の比 $`c`$、最大値の距離か、ほかの距離か）。
- $`ℓ`$ と $`Λ`$ の比の条件（$`Λ < 2ℓ`$ は十分条件の候補で、物理的に自然かどうかは未検討）。
- $`\mathrm{occ}`$ を観測者ごとの族 $`\mathrm{occ}_O`$ にする場合の、族の共変性の条件（[C-0008](../conjectures/C-0008.md)）。
