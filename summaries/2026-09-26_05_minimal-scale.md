## 要約

NEXT.md のタスク 1「物理からのアプローチの調査：最小の長さと、操作的な領域の構造」を扱った。第 04 回の後にユーザーが示した方針（ユークリッド空間にこだわらず、量子重力・量子ブラックホール・量子情報・エンタングルメントの観点を含める）に沿って、おもちゃのモデルを多角的に検討した。

この回は、前半を `/clear` 後の新しいチャットで、後半を第 04 回のチャットで行った（ユーザーが前半の内容を後半のチャットに貼り付けて続けた）。対話ログは両方の記録を合わせて作った。前半より前（2026-09-26 02:04 UTC）に始めて中断した試みの記録は含めていない。

1. 最小の尺度の入れ方を、**型 I（小さすぎる領域を捨てる）**と**型 II（「分けられる」という関係の側に尺度を入れる）**に分けた。おもちゃのモデルの候補 A〜G（ユークリッドの球、因果集合、因果的に閉じた領域、余白の下限、エンタングルメントのエントロピー、非可換な空間、ホログラフィー）を、6 つの観点（物理的な動機、ローレンツ不変性、点なし位相との相性、答えの鋭さ、検証の手段、エンタングルメント）で比べた。
2. ユーザーと相談して、案 D（領域を外から切り離すための余白に下限がある）を中心に、E（エンタングルメント）と C（因果的な閉包）を比較対象にすることにした。
3. 案 D を、膨張 $`N`$（領域を操作的に区別できないところまで広げる操作）による余白付きの包含 $`a ◁ b \iff N\,a ≤ b`$ として定式化した。長さ空間の $`ℓ`$ 近傍による膨張のような仮定の下では、最小の尺度があることは、$`◁`$ が補間的でない（$`N ∘ N ≰ N`$）ことにあたる（一般には一致しない。PR #9 のレビューで反例の指摘を受け、C-0001 に注意として記録した）。型 I と型 II は、膨張と収縮の随伴 $`N ⊣ E`$ の二つの面になっている。
4. 文献を調べ、数学の部分は既知と確認した（劣位代数の補間性と推移性の対応、数理形態学の随伴）。物理学の側では、Connes–van Suijlekom がプランク長を動機に許容関係を非可換幾何で扱っていること、Vakarelov の接触代数による点なしの時空論、Casini と Cegła–Jadczyk の因果論理、van der Schaaf のアトムによる試み（位相が失われる）を確認した。
5. Lean の命題を、既知の結果の形式化と明記して結果 R-0006〜R-0008 に登録し、物理学的な新規性を整理して予想 C-0001 を立てた。優先度はユーザーと相談して「高」とし、Issue #8 を作った。

## 得られた結果（検証済み）

### 型 I の分配律の破れ

$`ℝ`$ で $`ℓ = 1`$ のとき、冪集合の上の膨張の像、すなわち半径 $`ℓ`$ の開区間の合併として書ける開集合（長さ 2 以上の成分だけからなる開集合）の束では、$`a = (0, 3)`$、$`b = (-1, 1.5)`$、$`c = (1, 4)`$ について $`a ∧ (b ∨ c) = (0, 3)`$、$`(a ∧ b) ∨ (a ∧ c) = (1, 3)`$ となり、分配律が破れる。分数による厳密な計算で確かめた（スクリプトは作業用のもので、リポジトリには入れていない。結果としても登録していない）。開集合のフレームの上の膨張の像（長さ 2 を超える成分からなる開集合）で考えると $`a ∧ c = ∅`$ となるが、分配律はやはり破れる（PR #9 のレビューで指摘を受けて区別した。[調査メモ](../surveys/2026-09-26_05_subordination.md) の 1 節）。

### 文献で確認したこと

- derudder2020 の 4 節：劣位代数が (S8)（補間性）を満たすことと、対応する到達関係が推移的であることは同値（既知の結果として紹介）。
- heijmans1990 の 2.3 節：膨張と収縮を完備束上の随伴として定義し、随伴の下側は膨張、上側は収縮になる（命題 2.5）。オープニングは続編で扱う。
- connes2022 の序論：時空の幾何は分解能のため有限の精度でしか決められず、プランク長で理解が破綻すると予想されることを、許容関係 $`d(x, y) < ε`$ を考える動機として明示している。
- casini2002：一般の時空で、因果的に閉じた部分集合の束は完備なオーソモジュラ束になる。ミンコフスキー時空では cegla1977 が先に示した。
- vanderschaaf2024 の 9.3 節：プランクスケールをフレームのアトムで表すと、フレームは冪集合に同型になり、位相的な構造が失われる。

## 新しい予想

- [C-0001](../conjectures/C-0001.md)：最小の尺度は、余白付きの包含の補間性の破れとして点なしに表せる。確度は中、重要度は高、検証費用は高、優先度は高（ユーザーと相談して決定）。主張は 4 つ。
  1. 定式化：長さ空間の $`ℓ`$ 近傍による膨張では、正の尺度があることを $`N_ℓ ∘ N_ℓ ≰ N_ℓ`$ として表せる。一様な余白による近接関係は補間的で、コンパクトな閉包を持つ領域では「十分内側にある」関係と一致する。
  2. 物理的内容：DFR の局在の限界から得られる「操作的に切り離せる」関係は、この型になる。
  3. 離散化との区別：フレームは連続なままでよい。
  4. ローレンツ共変で局所的な膨張は、最小の尺度を入れられない。
- 物理学的な新規性（見立て）：最小の長さと離散性の区別を点なしの構造で与えること、領域の代数の側で最小の長さを表すこと（Connes–van Suijlekom は関数の代数の側）、厳密な定義のない「局在の限界」に定式化を与えること、ローレンツ共変性・局所性・最小の尺度の緊張関係を膨張の性質として明示すること。

## 未解決の論点
