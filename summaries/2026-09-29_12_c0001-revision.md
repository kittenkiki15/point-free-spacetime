## 決定事項

- **C-0001 の分割**（ユーザーの判断。Claude の提案による）
  - 旧主張 1・3（数学）は C-0001 に残した。
  - 旧主張 2（物理的内容）は C-0007 に移した。
  - 旧主張 4（ポアンカレ共変性と有界性）は C-0008 に移した。第 06 回の観測者ごとの族の案も、C-0008 に入れた。
- **「区別」の書き直し**（ユーザーの判断）：候補 A を採った。
  - 候補 A は、実験が領域に「収まる」ことの二つの読み方（設定値が属する、装置の占める領域が含まれる）のずれを、膨張として表すものである。
  - 候補 B（「操作的に切り離せる」ことで余白付きの包含を定める、split property 型）は、「A の $`\mathrm{occ}`$ を物理から決める方法の一つ」として C-0007 の中で扱う。
- **優先度**（ユーザーと相談）
  - C-0007 は高とした。
  - C-0001 は中とした（第 05 回は高）。
  - C-0008 は中とした。
  - 予想の検証を始めるとき（ロードマップの T-0008）に、予想全件の優先度を見直す。
- **A-0009 の状態**：少なくともレビューが済んで次のセッションが始まるまでは、「作業上」とする。
- **T-0001 の手がかりの残り**（第 07 回からの検討課題：橋渡し、局所性の候補、観測する側とされる側の対称性）は、T-0009（再構成）に移した。

## 得られた結果（検証済み）

- なし。
- 次の包含は定義から直ちに従う。結果としては登録していない。
  - 局在（D-0008）の $`𝒪(R)`$ を、設定の読みで定めたものを $`𝒪_{\mathrm{set}}`$、占有の読み（実験ごとの占める領域で判定する）で定めたものを $`𝒪_{\mathrm{occ}}`$ とする。
  - このとき $`𝒪_{\mathrm{occ}}(R) ⊆ 𝒪_{\mathrm{set}}(R) ⊆ 𝒪_{\mathrm{occ}}(N_{\mathrm{occ}}\,R)`$ が成り立つ（D-0011 の注意）。

## 新しい予想

- [C-0007](../conjectures/C-0007.md)（[Issue #8](https://github.com/kittenkiki15/point-free-spacetime/issues/8)）：局在の限界から、装置の占める領域の上下限が導かれる。
  - 目標の ID は A-0009。
  - 確度は中・重要度は高・検証費用は高。
- [C-0008](../conjectures/C-0008.md)（[Issue #9](https://github.com/kittenkiki15/point-free-spacetime/issues/9)）：ポアンカレ共変な装置の占める領域は有界にできない。
  - 確度は高・重要度は中・検証費用は中。
  - 主張 1（点の場合）は、証明の筋が立っている（見立て）。$`\mathrm{occ}(x)`$ は $`x`$ を固定するローレンツ変換で不変で、$`x`$ 以外の点の軌道は有界でない。
- [C-0001](../conjectures/C-0001.md)（改訂）に、主張 2（挟まれた膨張）を加えた（Claude の提案）。
  - 主張の内容：直径が $`Λ`$ より大きい長さ空間で、$`N_ℓ ≤ N ≤ N_Λ`$ かつ $`Λ < 2ℓ`$ なら、余白付きの包含は補間的でない。
  - 証明の筋（見立て）：小さな球 $`a = B_ε(x)`$ について、$`N(N\,a) ⊇ B_{2ℓ+ε}(x)`$ と $`N\,a ⊆ B_{Λ+ε}(x)`$ を比べる。

## 未解決の論点

- 装置の占める領域の下限 $`ℓ`$ だけからは、補間性の破れを保証できない（例えば $`\mathrm{occ}(x) = M`$ では補間的になる）。C-0001 の主張 2 の証明では、一様な上限 $`Λ`$ も仮定する（上限は補間性の破れの必要条件ではない。例えば $`ℝ`$ で $`\mathrm{occ}(x) = (x - 1, ∞)`$ は一様な上限を持たないが、補間性は破れる。PR #27 のレビュー）。DFR の局在の限界は $`ℓ`$ の根拠になりうるが、$`Λ < 2ℓ`$ となる物理的な理由は、まだない（C-0007 の詳細化の論点。この条件は不要かもしれない）。
- $`\mathrm{occ}`$ を観測者ごとの族にするときの共変性の条件（A-0009・C-0008）。
- 装置の占める領域の判定と、許容された実験の全体の合併とするか、実験ごとの族とするか（D-0011 の未解決の点）。
- 装置の占める領域による膨張と余白付きの包含が、観測における時空にどう移るか（ロードマップの T-0009）。
