各セッションの内容を整理したものです。ファイル名は [`logs/`](../logs/) の対話ログと同じです。

## 書式

```markdown
# YYYY-MM-DD 第 NN 回: <話題>

- 対話ログ: [logs/YYYY-MM-DD_NN_<話題>.md](../logs/YYYY-MM-DD_NN_<話題>.md)
```
