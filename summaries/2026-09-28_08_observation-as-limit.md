## 決定事項

- **本プロジェクトの方針**（ユーザー）：構想は数学基礎論のような位置づけで、唯一の正しい時空の再構成を探すのではなく、前提や制約を変えて得られる体系を比べる。
- **観測の作業上の定義**（ユーザーの提案に Claude が賛成し、定式化の方向にユーザーが同意）：観測は、有限な実験の族による近似の極限として定義する。局在は、族にわたる実験の領域が共通の有界な領域に収まることで定める。定義の案は、全観測の集合 $`𝒪`$ と、$`R`$ に収まる近似族が存在する観測の集合 $`𝒪(R)`$（調査メモの 1.2 節）。観測が局在するとは、ある有界な $`R`$ について $`𝒪(R)`$ に属すること。実験から何を対応させるか、共通の値域、極限の位相、族に課す資源の条件を指定して、初めて定義になる（PR のレビューの指摘）。
- **体系を分けるパラメータ**：有界にする資源、極限の位相、因果律を課すか（調査メモの 1.3 節）。
- 第 07 回の主張 2'（局在の特徴づけ）は、定義に置き換わる。残る中身は、主張 1'（実験における時空の領域の性質が $`𝒪(R)`$ の性質にどう反映されるか）と、$`R ↦ 𝒪(R)`$ から観測における時空の局在を再構成できるか、である。
- 数式で、定義済みでない関数名は `\mathrm` で書く（`docs/math-guide.md`）。
- 読んだ論文の arXiv 版の PDF を、非公開リポジトリの `papers/` に置いた（7 件）。

## 得られた結果（検証済み）

この回は文献調査で、新しい定理や数値実験の結果はない（結果 R-NNNN の登録なし）。原典または二次文献で確かめた主な事実は次のとおり（詳細と出典は調査メモ）。

- **局在と測定**（halvorson2001rs、原典）：局所代数を「その領域で測れる観測量」と読むのが標準の解釈である。Halvorson が引用する完全な Reeh–Schlieder の定理（真空の巡回性）の証明では、領域の時間方向の広がりを使う（巡回性の一般的な必要条件ではない）。この巡回性の証明に微視的因果律は要らない（真空の分離性を導くには微視的因果律を使う）。点に固定して結び付いた量で、局在していながらその領域で測れないものの例は見つかっていない、と著者は論じている。
- **split property と核型性**（fewster2016、原典。元の論文は未入手）：核型性の条件（局所的な分配関数の増え方の制限）から、余白のある包含 $`O_1 ⋐ O_2`$ で split property が従う（Buchholz–D'Antoni–Fredenhagen 1987）。第 07 回・第 08 回の前半で「Buchholz–D'Antoni–Longo」と書いたのは誤りで、訂正した。
- **distal split**（dantoni1987 は fewster2016 による、naaijkens2012 は原典）
  - 指数関数的な質量スペクトル $`m_r = (2d_0)^{-1}\log(r+1)`$ の模型では、核型性が成り立たず、半径の差が分離の距離 $`d(r)`$（$`d_0 ≤ d(r) ≤ 2d_0`$）を超えるときは split property が成り立ち、$`d(r)`$ より小さいときは成り立たない（$`d(r)`$ は split が成り立つ半径の差の下限。ちょうど $`d(r)`$ のときは未確認）。分離の距離の逆数は、局所的に正規な平衡状態が存在する最高温度と同じ程度である。
  - toric code の錐について、Naaijkens は Haag 双対性と distal split を示した（distal split は I 型因子を明示的に構成して示した）。余白があれば、内側の錐の代数と外側の錐の補集合の代数について、正規な積状態が存在する（そのような状態では、この組で Bell の不等式は破れない）。余白がなければ（$`Λ_1 = Λ_2`$）、内側の錐の代数と補集合の代数の間の 1 コピーあたりのもつれが無限になる、と Naaijkens は先行研究を引いて述べている（状態などの正確な条件は未確認）。
- **最小の余白と共変性**（fewster2016 の 4 節、元の論文 fewster2015 は未入手。morinelli2018 は原典）：局所共変性（異なる背景時空の上の理論を比べる）、局所準同値性、時間スライス性の下では、球と微分同相な集合について、分離の距離は 0 か ∞ に限られ、distal split から split が従う（ポアンカレ共変性だけからではない）。円周上の微分同相共変な網では、split property が自動的に成り立つ。
- **局所的な Noether の定理**（fewster2016 による。元の論文は未入手）：split property と大域的なゲージ対称性から、対称性の局所的な実装が得られ、その生成子は保存する局所的なカレントをぼかしたものと解釈できる（Doplicher–Longo 1983）。逆に、入れ替え（flip）が余白の中で内部的に実装できれば、包含は split である（D'Antoni–Longo 1983、Doplicher–Longo 1984）。途中の報告では、抽象的な Noether の定理を Buchholz–Doplicher–Longo 1986 の結果としたが、Fewster がこの箇所で引くのは Doplicher–Longo 1983 で、訂正した（Buchholz–Doplicher–Longo 1986 は、幾何的な対称性の局所的な実装の文献として引かれている）。
- **巨視的な観測量**（landsman2005、原典。hepp1972 は未入手）：対称化して平均した観測量は、交換子が $`1/N`$ の程度で 0 に近づき、極限で可換になって超選択セクターを区別する。この巨視的な観測量による超選択セクターは、系の数を無限にする極限で現れる（Landsman の「有限の系には超選択則は存在しない」は、単純な C* 代数の非同値な既約表現という意味に限った言明）。Hepp は、装置を互いに素な純粋状態を持つ無限の系とし、全体の状態が互いに素な状態の混合になることを測定とみなした。時間発展が自己同型なら互いに素であることは保たれるので、これには無限の時間の極限が要る（有限の装置でも、系の縮約状態は有限の時間で混合状態になりうるので、これとは区別する）。
- **電荷の非局在化**（buchholz2001、原典）：古典論では電荷の台を鋭く局在させられるが、量子電磁力学では真空偏極のため、電荷の台を定義できない。
- **幾何学的論理**（spitters2014、原典）：ℕ・ℤ・ℚ は幾何学的論理で一意に特徴づけられるが、ℝ・ℂ はそうできない。代数的場の量子論の網を関手の圏の中の C* 代数とみなし、内部のゲルファント・スペクトル（ロケール）を構成する試みがある。

## 新しい予想

登録していない。見立て（未検証）は次のとおり。予想として登録するかは、次回以降にユーザーと相談する。

- **制約と性質の対応**（調査メモの 8 節の表）：族にわたって有界にする資源（時空の領域、系の大きさなど）と、現れる性質（局在、巨視的な平均からなる可換な極限代数など。装置の古典性との関係は未検証）が対応する。実験のエネルギーの上限と、理論の性質である核型性・split property との対応は、別の条件で、未検証である（PR のレビューの指摘）。
- **C-0001 の主張 2 の模型**：distal split は、「最小の余白」（余白付きの包含が補間的でないこと）の具体的な物理の模型の候補である（distal split だけからは補間的でないことは従わず、領域の族を定めて別に示す必要がある。PR のレビューの指摘）。最小の尺度 $`d_0`$ は理論の状態密度から決まる。一方、異なる背景時空を比べる局所共変性（時間スライス性と局所準同値性と合わせたもの）の下では、球と微分同相な集合について分離の距離は 0 か ∞ に限られ、distal split（分離の距離が有限）を仮定すれば、元の局所代数の網では split の正の閾値が残らない。C-0001 の最小の余白は、許す領域の族とそこで定める関係にも依存するので、適用には両者を結ぶ追加の条件が要る（PR のレビューの指摘）。最小の尺度と共変性の関係（C-0001 の主張 4 の論点）を見直す手掛かりになる。
- **保存則**：包含 $`R_1 ⊂ R_2`$ について、$`R_1 ⊗ R_1`$ の上の flip が $`R_2 ⊗ R_2`$ の内部自己同型で実装できること ⇔ split（巡回的で分離的なベクトルの存在などの追加の条件の下で。同じ代数の二つのコピーについての定理なので、一般に同型でない系と装置の入れ替えにはそのまま適用できない）、split と大域的な対称性 ⇒ 対称性の局所的な実装（その生成子を保存する局所的なカレントのぼかしと読むのは、追加の仮定を要する解釈）、という既知の鎖が、ユーザーの問い（極限と結び付けた場合の保存則）の手掛かりになる。ただし、全体の力学の連続的な対称性は入力として別に要る。
- **連続的な値と極限**：連続的な値をとる結果（ℝ に値をとる観測）は、有限個の結果を記録する実験の族の極限で初めて現れ、論理の側では点なしの空間として現れる。記録する結果の値と、対応する作用素のスペクトルは区別する（二つの結果を持つ POVM の効果でも、スペクトルは連続になりうる。PR のレビューの指摘）。
