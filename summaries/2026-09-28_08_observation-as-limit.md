1. **ユーザーのコメント**（第 07 回のまとめを読んで）
   - **構想の位置づけ**：唯一の正しい時空の再構成方法があるとは考えていない。構想は、数学における数学基礎論のような位置づけである。「観測」や「実験」の形式化に様々な前提や制約を課し、異なる特徴を持った物理の体系を相対的に比べることを期待している。
   - **観測の定義**：「実験の有限性」を制約として課すなら、すべての観測は、有限な実験の族による近似の極限としてしか定義できない。それは非局在の観測量（無限スピン鎖の例など）も含む。観測が局在する条件は、族にわたる実験パラメータ全体の集合が有界であること、などが考えられる。
   - **保存則**：観測を極限と結び付けて定義すれば、何らかの保存則が出る可能性はあるか。

## 決定事項

- **観測の作業上の定義**（ユーザーの提案に Claude が賛成し、定式化の方向にユーザーが同意）：観測は、有限な実験の族による近似の極限として定義する。局在は、族にわたる実験の領域が共通の有界な領域に収まることで定める。定義の形は $`𝒪(R)`$（調査メモの 1.2 節）。
- **体系を分けるパラメータ**：有界にする資源、極限の位相、因果律を課すか（調査メモの 1.3 節）。

## 得られた結果（検証済み）

この回は文献調査で、新しい定理や数値実験の結果はない（結果 R-NNNN の登録なし）。原典または二次文献で確かめた主な事実は次のとおり（詳細と出典は調査メモ）。

- **局在と測定**（halvorson2001rs、原典）：局所代数を「その領域で測れる観測量」と読むのが標準の解釈である。完全な Reeh–Schlieder の定理には領域の時間方向の広がりが要り、微視的因果律は要らない。点に固定して結び付いた量で、局在していながらその領域で測れないものの例は見つかっていない、と著者は論じている。
- **split property と核型性**（fewster2016、原典。元の論文は未入手）：核型性の条件（局所的な分配関数の増え方の制限）から、余白のある包含 $`O_1 ⋐ O_2`$ で split property が従う（Buchholz–D'Antoni–Fredenhagen 1987）。第 07 回・第 08 回の前半で「Buchholz–D'Antoni–Longo」と書いたのは誤りで、訂正した。
- **distal split**（dantoni1987 は fewster2016 による、naaijkens2012 は原典）
  - 指数関数的な質量スペクトル $`m_r = (2d_0)^{-1}\log(r+1)`$ の模型では、核型性が成り立たず、半径の差が分離の距離 $`d(r)`$（$`d_0 ≤ d(r) ≤ 2d_0`$）以上のときだけ split property が成り立つ。分離の距離の逆数は、局所的に正規な平衡状態が存在する最高温度と同じ程度である。
  - toric code の錐では、Haag 双対性から distal split が従う。余白があれば Bell の不等式を破らない積状態があり、余白がなければ 1 コピーあたりのもつれが無限になる。
- **最小の余白と共変性**（fewster2016 の 4 節、元の論文 fewster2015 は未入手。morinelli2018 は原典）：局所共変性、局所準同値性、時間スライス性の下では、分離の距離は 0 か ∞ に限られ、distal split から split が従う。円周上の微分同相共変な網では、split property が自動的に成り立つ。
- **局所的な Noether の定理**（fewster2016 による。元の論文は未入手）：split property と大域的なゲージ対称性から、対称性の局所的な実装が得られ、その生成子は保存する局所的なカレントをぼかしたものと解釈できる（Doplicher–Longo 1983）。逆に、入れ替え（flip）が余白の中で内部的に実装できれば、包含は split である（D'Antoni–Longo 1983、Doplicher–Longo 1984）。途中の報告では、抽象的な Noether の定理を Buchholz–Doplicher–Longo 1986 の結果としたが、Fewster がこの箇所で引くのは Doplicher–Longo 1983 で、訂正した（Buchholz–Doplicher–Longo 1986 は、幾何的な対称性の局所的な実装の文献として引かれている）。
- **巨視的な観測量**（landsman2005、原典。hepp1972 は未入手）：対称化して平均した観測量は、交換子が $`1/N`$ の程度で 0 に近づき、極限で可換になって超選択セクターを区別する。有限の系には超選択則は存在しない。測定による純粋状態から混合状態への移行は、無限に大きな装置と無限の時間の極限でだけ起こる（Hepp）。
- **電荷の非局在化**（buchholz2001、原典）：古典論では電荷の台を鋭く局在させられるが、量子電磁力学では真空偏極のため、電荷の台を定義できない。
- **幾何学的論理**（spitters2014、原典）：ℕ・ℤ・ℚ は幾何学的論理で一意に特徴づけられるが、ℝ・ℂ はそうできない。代数的場の量子論の網を関手の圏の中の C* 代数とみなし、内部のゲルファント・スペクトル（ロケール）を構成する試みがある。

## 新しい予想

登録していない。見立て（未検証）は次のとおり。予想として登録するかは、次回以降にユーザーと相談する。

- **制約と性質の対応**（調査メモの 8 節の表）：族にわたって有界にする資源（時空の領域、エネルギー、系の大きさ）と、現れる性質（局在、split property と最小の余白、巨視的な観測量と古典性）が対応する。
- **C-0001 の主張 2 の模型**：distal split は、「最小の余白」（余白付きの包含が補間的でないこと）の具体的な物理の模型になる。最小の尺度 $`d_0`$ はエネルギーの側（状態密度）から決まる。一方、大きな共変性（尺度変換、微分同相、時間スライス性と局所準同値性）の下では最小の余白は消える。最小の尺度と共変性の関係（C-0001 の主張 4 の論点）を見直す手掛かりになる。
- **保存則**：入れ替え（flip）が余白の中で内部的であること ⇔ split、split と大域的な対称性 ⇒ 保存量の局所化、という既知の鎖が、ユーザーの問い（極限と結び付けた場合の保存則）の手掛かりになる。ただし、全体の力学の連続的な対称性は入力として別に要る。
- **連続的な値と極限**：連続スペクトル（ℝ に値をとる観測）は、有限な実験の族の極限で初めて現れ、論理の側では点なしの空間として現れる。
