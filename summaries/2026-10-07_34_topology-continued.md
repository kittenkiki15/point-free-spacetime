## 要約

T-0004「設定の空間と、結果の統計の空間の位相」の続きを行った。最初に Q-0002（可能な実験の状態の集合の位相）の案を出したが、ユーザーの提案で、Q を層の順に検討することにした。層 4 の Q-0002〜Q-0004 を T-0010 に移し、層 1 の Q-0009（資源の量は予算か実際の消費量か）を解決した。最後に、各項目の検討の目的と完了の条件を明確にするタスク T-0028 を加えた。

**Q-0002 の案と、層の順の検討（ユーザーの提案）**
- Claude は、状態の集合に弱 * 位相を制限した位相を入れる案を出した。古典の結果の空間では、$`C_b(Y)`$ の状態としての弱 * 位相が、$`\mathrm{Prob}(Y)`$ の弱位相（Q-0001）と一致する。
- ユーザーは、判断の材料が足りないと考えた。Q-0002 は層 4（可能な実験）の論点なので、層 2・3 を先に扱うことを提案した。各 Q をどの層の問題かで整理し、層の順に検討したい、とも提案した。
- Claude の整理：Q-0002〜Q-0004 の親の D-0014 は層 1 に登録されているが、中身（装置の物理モデルとしての C* 代数とその状態）は層 4 に当たる。層は、親の層ではなく、論点の中身で決めることにした。

**Q-0009：資源の量は予算か実際の消費量か**
- Claude の案：予算を設定に、実際の消費量を結果に記録し、「割り当てた量を超えて使わない（上限で打ち切る）」を A-0004 に加える。
- ユーザーの確認を受けて区別した：この条件から従うのは 1 回の観測ごとの上界で、実験全体の観測の回数 $`N_e`$ に依らない上界ではない。
- ユーザーは、プロトコルの記述や装置の実現に依存しない最小の仮定を求めた。Claude は、記録だけで述べる条件（消費量の座標の値域の有界性）を出した。ユーザーが、それと同値な資源ごとの式を提案した。
- ユーザーの指摘を受けて、二つの言い過ぎを直した。
  - 「上界は観測者に依らない」：式から言えるのは、上界が $`π`$ と $`k`$ だけで決まることまでである。記録は、その実験の観測者の基準（A-0010）で読んだ値で、観測者によらない物理量の上界ではない。
  - 「実験全体の消費量」を各観測の和とするのは、加法性を黙って仮定していた。今は、実験全体の消費量を定めない。

**資源の条件の目的（ユーザーの確認）**
- 有限な実験だけを許す（期間と、操作・観測の回数を有限にする）のは、D-0001 の役目である（第 08 回のユーザーの見解）。エネルギーなどの資源の有限性は D-0001 からは従わず、別の論点である（第 35 回の PR #47 のレビューで直した。D-0001 の未解決の点に記録した）。
- A-0004・A-0005 は、同じプロトコルについて、各観測の予算と消費量を一様に抑えるためのものである（プロトコルをまたぐ上界と、実験全体の上界は従わない。PR #46 のレビューで限定した）（第 08 回の「族全体に課す資源の条件」の軸と、第 09 回のユーザーの提案）。各実験が有限でも、族全体で資源が一様に有界とは限らない。

**各項目の目的の明確化（ユーザーの提案）**
- 上の議論で、各項目の目的がログや調査メモに埋もれていることが分かった。各項目に「目的」と「完了の条件（アウトプット）」の欄を設けるタスク T-0028 を加えた。
- ユーザーの提案で、結果（R）にも、予想と同様の完了の条件を記録する。後で条件が覆ったときに、見直しの要る結果を確かめるためである。

## 決定事項

- Q には「層」の欄を設け、論点の中身で決める。一覧と [framework.md](../framework.md) の層別の表にも Q の列を加えた。Q は層の順に（下の層から）検討する（ユーザーの提案）。
- 層 4 の [Q-0002](../questions/Q-0002.md)〜[Q-0004](../questions/Q-0004.md) を、[T-0004](../tasks/T-0004.md) から [T-0010](../tasks/T-0010.md) に移した。T-0004 には層 1 の Q を残し、順序は Q-0009 → Q-0010 → Q-0005 → Q-0006 と Q-0007 → Q-0008 にした。
- [Q-0009](../questions/Q-0009.md) を解決にした（ユーザーと合意）。[A-0004](../assumptions/A-0004.md) の題名を「資源の量を設定と結果に含める」に改め、主張を次の三つにした。
  1. 予算は設定として記録する。
  2. 実際の消費量は結果として記録する（消費量の座標 $`r_π : Y_π → [0, ∞)^{K_π}`$）。
  3. 消費量の有界性（式は次。ユーザーの提案の形）。

```math
∀π\; ∀k ∈ \{1, …, K_π\}\; ∃R_{π,k} ≥ 0\; ∀y ∈ Y_π :\; r_{π,k}(y) ≤ R_{π,k}
```

- [A-0005](../assumptions/A-0005.md) が抑えるのは予算であると言い換え、この前提の目的（D-0001 の有限性との区別）を注意に明記した。
- A-0004 の残りの論点を [Q-0010](../questions/Q-0010.md)「記録する資源の範囲」に移し、次を決めた（ユーザーと合意）。
  - 記録する資源の種類はプロトコルに任せる。消費量の上界が必要な結果では、その仮定として書く。
  - 実験全体の消費量は今は定めない。必要になったら、和との関係を仮定せず、実験全体の記録として定める。
  - 観測の外の資源と実験全体の上界は [Q-0006](../questions/Q-0006.md) に、消費量の記録の観測者への依存は A-0004 の未解決の点（[T-0024](../tasks/T-0024.md)）に移した。
- 新しいタスク [T-0028](../tasks/T-0028.md)「各項目の検討の目的と完了の条件の明確化」を加えた。T-0004 の残りの Q の前に、少なくとも層 1 の項目まで行う（ユーザーと合意）。
