## 主張

半順序集合 $`L`$ 上の写像 $`N`$（膨張）と $`E`$（収縮）が随伴（$`N\,a ≤ b \iff a ≤ E\,b`$）をなすとき、オープニング $`N ∘ E`$ の不動点（$`N(E\,b) = b`$ となる $`b`$）は、ちょうど $`N`$ の像の元である。

## 検証

- 自然言語の証明：不動点なら $`b = N(E\,b)`$ は $`N`$ の像にある。逆に $`b = N\,a`$ なら、随伴の一般的な性質 $`N ∘ E ∘ N = N`$ から $`N(E\,b) = b`$。
- Lean：[`lean/PointFreeSpacetime/Tolerance.lean`](../lean/PointFreeSpacetime/Tolerance.lean) の `PointFreeSpacetime.opening_fixed_iff_mem_range`（Mathlib の `GaloisConnection.l_u_l_eq_l` を使う）。
- **既知である**：随伴（ガロア接続）の一般的な性質であり、数理形態学では膨張と収縮を完備束上の随伴として扱う（heijmans1990 の 2.3 節）。

## 形式化の確認

- Lean では `[PartialOrder α]` と `GaloisConnection N E` について述べた。主張と同じ一般性である。

## 意義

**（見立て）** 最小の尺度の入れ方の型 I（小さすぎる領域を捨てる。残る領域は $`N`$ の像で、分配律が破れうる）と型 II（余白に下限を置く。R-0007）が、同じ随伴 $`N ⊣ E`$ の二つの面であることを示す。
