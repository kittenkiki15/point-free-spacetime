# R-0004: 平行性の不等式 (f±) ならば共役

## 主張

$`L`$ を最小元 $`0`$ を持つ交わり半束（たとえばフレーム）とし、写像 $`f, g : L → L`$ が $`f(0) = 0`$、$`g(0) = 0`$ と、次の不等式 (f±) を満たすとする。

```math
f(U) ∧ V ≤ f(U ∧ g(V)), \qquad g(V) ∧ U ≤ g(V ∧ f(U))
```

このとき、Jónsson–Tarski の共役の条件が成り立つ。

```math
f(U) ∧ V = 0 \iff U ∧ g(V) = 0
```

特に、heunen2026 の平行な順序付きロケールでは、$`f = ↟`$、$`g = ↡`$ として $`↟U ∧ V = ∅ \iff U ∧ ↡V = ∅`$（heunen2026 の命題 3.10）が従う。

## 検証

- 自然言語の証明：$`f(U) ∧ V = 0`$ なら、(f±) の 2 本目から $`U ∧ g(V) ≤ g(V ∧ f(U)) = g(0) = 0`$。逆に $`U ∧ g(V) = 0`$ なら、1 本目から $`f(U) ∧ V ≤ f(U ∧ g(V)) = f(0) = 0`$。補元も分配律も使わない。
- Lean：[`lean/PointFreeSpacetime/Conjugate.lean`](../lean/PointFreeSpacetime/Conjugate.lean) の `PointFreeSpacetime.conjugate_of_fpm`。
- テスト：[`sim/tests/test_conjugate.py`](../sim/tests/test_conjugate.py) の `test_f_pm_implies_conjugate_on_small_lattices`（元が 8 個以下のいくつかの有限分配束で、結びを保つ閉包作用素の組を総当たり）。Lean の証明があるので、テストは補助的な確認である。

## 形式化の確認

- Lean では `[SemilatticeInf L] [OrderBot L]` のもとで、任意の写像 `f g : L → L` について述べた。主張と同じ一般性であり、フレームや閉包作用素であることは仮定していない。
- heunen2026 の命題 3.10 への適用には、$`↟∅ = ∅`$、$`↡∅ = ∅`$（たとえば (c-∨) の空の結びの場合）と (f±)（平行性から従う、heunen2026 の補題 3.7）が必要で、これらは形式化していない。

## 意義

平行性（(f±)）が、時制論理の最小体系 Kt の点なし版にあたることの一方向。逆が成り立たないこと（R-0005）とあわせて、Kt の点なし版とみなすべきなのは共役ではなく (f±) だと判断した（第 04 回にユーザーと合意）。
