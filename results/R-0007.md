## 主張

順序集合（たとえばフレーム）$`L`$ 上の単調な写像 $`N`$ について（膨張、すなわち結びを保つ写像は、その特例である）、$`a ◁ b \iff N\,a ≤ b`$ と定める。このとき、次は同値である。

- $`◁`$ は補間的である：$`N\,a ≤ b`$ ならば、ある $`c`$ で $`N\,a ≤ c`$ かつ $`N\,c ≤ b`$。
- すべての $`a`$ で $`N(N\,a) ≤ N\,a`$。

## 検証

- 自然言語の証明：補間的なら、$`b = N\,a`$ に対する $`c`$ をとって $`N(N\,a) ≤ N\,c ≤ N\,a`$。逆に $`N(N\,a) ≤ N\,a`$ なら $`c = N\,a`$ とすればよい。
- Lean：[`lean/PointFreeSpacetime/Tolerance.lean`](../lean/PointFreeSpacetime/Tolerance.lean) の `PointFreeSpacetime.margin_interpolates_iff`。
- **既知の事実の言い直しと考える**：同じ主張を明示した文献は見つけていないが、証明は数行で、R-0006 と随伴の一般論を順序集合の言葉で述べ直したものにあたる。新しい数学的な結果とはみなさない。

## 形式化の確認

- Lean では `[Preorder α]` と単調な `N : α → α` について述べた。主張と同じ一般性である。
- 点の場合との関係：$`N\,a`$ を $`a`$ の $`T`$ 近傍とすると $`◁`$ は R-0006 のものと一致する（Lean の `marginSub_iff_image_subset`）。このとき $`N ∘ N`$ は $`T`$ の合成による近傍にあたる。

## 意義

この結果は、余白付きの包含が補間的かどうかを、$`N ∘ N ≤ N`$ という点を使わない条件で判定できることを述べるだけである。補間性の破れと「最小の尺度」の関係は、一般には一致しない（予想 [C-0001](../conjectures/C-0001.md) の「注意」）。**（見立て）** 長さ空間の $`ℓ`$ 近傍による膨張のような仮定の下では、補間性の破れを最小の尺度の指標として使える。C-0001 の数学的な土台である。
