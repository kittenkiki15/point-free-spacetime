## 主張

次の空間と事後分布の族では、族は確定的だが、$`P_n(U) → 1`$ となる開集合の全体 $`F`$ は完全素フィルターでなく、点を定めない。

- 空間：$`S = [0, 1)`$ に、開集合を $`[0, a)`$（$`0 ≤ a ≤ 1`$）だけとする位相を入れる。この空間は $`T_0`$ でソバーだが、ハウスドルフでもコンパクトでもない。
- 事前分布：点 $`θ_k = 1 - 1/k`$（$`k ≥ 2`$）に正の重み $`w_k`$（和は 1）を置く離散分布とする。
- 観測モデル：成功確率 $`θ`$ の試行とし、データは $`n`$ 回続けて成功だったとする。
- 事後分布：$`P_n(\{θ_k\}) ∝ w_k θ_k^{\,n}`$ とする。

## 検証

自然言語の証明。

- **位相であること**：$`[0, a_i)`$ の任意の和は $`[0, \sup a_i)`$、有限の交わりは $`[0, \min a_i)`$ である。
- **ソバーであること**：空でない閉集合は $`[a, 1)`$ の形で、点 $`a`$ の閉包に等しい。したがって、空でない既約な閉集合は、ただ一つの生成点を持つ。
- **確定的であること**：
  - $`a < 1`$ を固定し、$`θ_K ≥ a`$ となる $`K`$ を取る。$`[0, a)`$ に入る $`θ_k`$ はすべて $`θ_k < θ_K`$ を満たす。
  - $`M > K`$ を一つ取ると、次が成り立つ。

```math
P_n([0, a)) = \frac{\sum_{θ_k < a} w_k θ_k^{\,n}}{\sum_k w_k θ_k^{\,n}} ≤ \frac{θ_K^{\,n}}{w_M θ_M^{\,n}} → 0 \quad (n → ∞)
```

  - 一方、$`P_n([0, 1)) = 1`$ である。開集合はこの二種類だけなので、族は確定的である。
- **完全素でないこと**：
  - $`F = \{[0, 1)\}`$ である。
  - $`[0, 1) = ⋃_{a < 1} [0, a)`$ だが、どの $`[0, a)`$ も $`F`$ に属さない。
- **測度について**：離散分布なので、事後分布は τ 加法的である。

## 形式化の確認

Lean では形式化していない。確定性は、すべての開集合について確かめた（開集合が $`[0, a)`$ の形に限られるため）。

## 意義

- データが示す「真の値」$`θ = 1`$ がモデルの空間 $`S`$ に含まれない場合（モデルの誤指定）に、事後分布が空間の「端」へ逃げ、極限が点にならない例である。
- 空間がソバーで測度が τ 加法的でも、ハウスドルフでなければ、観測の極限（状態推定の極限）が点にならないことがある。**（見立て）** 因果構造などから作る時空の位相はハウスドルフでないことが多いので、点なしの時空の議論に関わる可能性がある。
