## 主張

完備ブール代数 $`L`$（をフレームとみなしたロケール）の点は、$`L`$ のアトムと一対一に対応する。
アトム $`a`$ には上集合 $`↑a = \{b : a ≤ b\}`$ を対応させ、逆に点 $`x`$ には、R-0001 で対応する素元 $`p`$ の否定 $`¬p`$ を対応させる。このとき $`x = ↑(¬p)`$ である。

## 検証

- Lean：[`lean/PointFreeSpacetime/BooleanPoints.lean`](../lean/PointFreeSpacetime/BooleanPoints.lean) の `PointFreeSpacetime.ptEquivAtom`（型 `PT L ≃ {a : L // IsAtom a}`）。点がアトムの上集合であることは `apply_iff_ptEquivAtom_le`。途中の段は `IsPrimeElement.isCoatom`（素元は余アトム）と `atomPt`（アトムから作る点）。
- 依存する公理は Lean の標準の 3 つだけである（第 03 回に確認）。

## 形式化の確認

- 完備ブール代数は Mathlib の `CompleteBooleanAlgebra`、アトムは Mathlib の `IsAtom` を使った。点の表し方は R-0001 と同じ。
- アトムから作る点が**任意の**結び（空の結びを含む）について完全素であることは、`atomPt` がフレーム準同型であること（`map_sSup'`）として検証されている。
