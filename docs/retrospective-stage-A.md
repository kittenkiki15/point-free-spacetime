### 1.3 物理学への寄与の評価（Claude のたたき台）

第 04 回のユーザーの方針では、価値の主軸は**物理学への寄与**（厳密な定義のない物理の概念や主張に、数学的な定式化を与えることなど）にある。その基準で見ると、次のように評価する。

- **今の時点で主張できる寄与は、まだない**。新しい定理も、既知の物理の主張の新しい導出もない。結果 9 件は、どれも既知の結果の形式化か、文献の確認である。
- **寄与の候補は、定義の水準にある**。観測量を「実際の実験の可算な族の極限」として定め（D-0005）、主体の間の一致を予測分布の相互絶対連続性（A-0007）で置く構成は、Le Cam の実験の理論、Blackwell–Dubins、QBism、AQFT の局所性を一つの枠に並べる試みとして、文献の中でまとまった形では見ていない（ただし、新しさの系統的な文献調査はしていない。見立て）。この組み合わせが寄与になるかは、それを使って何かを示せるかで決まる。
- **最も物理に近い問い**は、最小の長さ（C-0001・C-0007・C-0008）と、観測者の取り替えの群が較正の普遍性から決まるか（C-0009・C-0011）である。後者は、相対性理論の群を、操作的な前提から導く既存の研究（ローレンツ群の導出の系譜）と比べる必要があり、まだ比べていない。
- **注意すべき傾向**：第 06 回以降の 22 回のうち、予想の検証に充てた回はない。調査と定義の精密化が、そのたびに新しい区別と論点を生み、未解決の点が増え続けている（[`roadmap.md`](../roadmap.md) の論点の割り当て）。定義が固まるまで検証を待つと、検証に入れないおそれがある。

**ユーザーのコメント**（第 28 回）

- 概念の区別が、段階 B 以降の成果しだいで「厳密な定義のない物理の概念や主張に、数学的な定式化を与えること」に役立つことを期待する。特に、「最小の尺度」の定式化が、関係する予想（C-0001・C-0007・C-0008）の解決に寄与するかに注目している。
  - Claude の補足：効くかどうかが分かるのは、段階 B の後の T-0008 である（段階 B のうち、最小の尺度に直接つながるのは T-0007（局在）だけ）。効きそうな点の見立ては二つある。(1) C-0008 の共変性との緊張は、「実際の装置は有限で、可能な装置の族が共変」という実際と可能の区別（D-0002）でほどける可能性がある。(2) 較正の段階 2（揺らぎを持つ較正。D-0013）は「占める領域」をぼかすので、A-0009 の上下限の述べ方を変えうる。T-0008 に入るときに、「区別によって主張がどう変わったか」を評価の観点として書いておく。
- 「定義の広さ」（どれだけ広い概念を含むか）と「予想の強さ」（どれだけ広い概念について強い主張が言えるか）は、トレードオフの関係にある。定義の妥当さの検討に時間をかけることは、予想の検証と同じくらい重要であり、今後もその重み付けで作業のバランスを取りたい。

### 2.2 フレームワークの骨組みは、先行研究の地図に役立ったか

ユーザーの質問（第 28 回）：フレームワークの骨組みは、先行研究の地図を作るための文献調査で役立ったか。各文献の結果を位置づけ、比較する枠組みとして有用だったか。

Claude の評価：半分ほど役立った。

- 役立った点：調査メモの「プロジェクトへのつながり」の節で、毎回「どの層の、どの定義・前提に効くか」という同じ問いで文献を位置づけた（Le Cam の弱位相 → D-0005、Blackwell–Dubins・QBism → A-0007、量子コム → D-0001、量子参照系 → D-0013 など）。分野の違う文献を同じ物差しで並べられたので、第 25 回の判断（(a)・(b) と較正の段階）では、T-0019 の群 A・B・C をまたいで比べられた。
- 足りない点：
  - 位置づけが「文献をこちらの枠にはめる」向きに偏り、文献どうしを直接比べる作業は少なかった。
  - 層 3〜6（時空の側）は空いていて、時空の側の文献（T-0017）は地図に載っていない。
  - 地図が一枚になっておらず、調査メモ、定義・前提の未解決の点、ロードマップに散らばっている（「文献 × 層」の対応表がない）。

### 2.3 先行研究の地図の、公開するサーベイとしての価値

ユーザーの質問（第 28 回）：先行研究の地図は、オープンソースでネット上に公開するサーベイとして価値があるか。このリポジトリを公開する意義の一つになっているか。

Claude の評価：価値はあり、公開の意義の一つになっている。

- 強み：原典で仮定と結論まで確かめている。Le Cam の統計理論、QBism、代数的場の量子論、量子コム、量子参照系、因果的非分離性を、一つの問い（観測から時空へ）で横断する資料は少ない。日本語でこの範囲をまとめたものは、さらに少ないと考える（系統的には調べていない）。
- 弱み：セッション単位で書いていて、テーマから引けない。レビュー対応の限定が積み重なって、文章が重い。
- 価値を上げる方法：テーマ別の索引（テーマ → 調査メモの節）と、テーマごとの短い要約を置く（4 節の外部の読者向けの入口で扱う）。
- 公開の意義としては、サーベイと並んで、「人と AI の研究の過程を、対話ログとレビューごと残した記録」もほかにない価値である。

## 3. 今後改善した方がよい点

### 3.1 定義と予想のバランスの運用（Claude の提案。第 28 回）

- **定義の作業を、仕える予想と結びつける**：定義を改めるときは、どの予想のための改定かを記録する。予想につながらない精密化は、後に回す。
- **定義の妥当さも検証の形にする**：「この定義は既知の例 X を含む」「反例 Y を除く」といった例と反例の確認を、小さな結果として登録する。定義の作業も「検証」として数えられる。

### 3.2 管理の仕組みの切り出し

ユーザーの提案（第 28 回）：フレームワークと、それに基づく管理の仕組みは、ほかのテーマの研究でも生かせる。仕組みだけを抽出して、別リポジトリで公開することを検討している。

Claude の意見：賛成する。

- 分野によらず使える部分：`CLAUDE.md` のセッションの運用（1 セッション 1 タスク、終え方の手順）、ID と状態で管理する定義・前提・予想・結果、依存関係の図と整合性の検査、択一の組と体系、割り当て漏れの検査、見直しの手順（[`review-procedure.md`](review-procedure.md)）、指摘を「誤り・食い違い」と「詳細化の論点」に分けるクロスモデルレビュー、伏せ字つきの対話ログの書き出し、数式の書き方。
- 切り出すときの注意：
  - 層の名前や ID の種類は、今はこのプロジェクトに合わせてコードに書いてある。設定ファイルに出す。
  - 使ったのはまだこの 1 件だけである。クロスモデルレビューの往復の多さ（1 PR に 5〜15 回）や API の費用（第 26 回の 429。原因はクレジットの不足）などの実情を書き添える。
  - `redactions.txt` の中身など、非公開のものを入れない。
- 時期：今すぐ v0 として出し、このリポジトリを実例として参照する形でもよい。段階 B で仕組みが規模に耐えるかを見てからのほうが、手直しは少ない。
