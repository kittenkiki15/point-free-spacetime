### 3.2.1 レビューの質の分析（ユーザーの問いを受けて）

ユーザーの問い：予想（C）についての指摘に、主張から本質的に外れたものが多くないか。差分だけを見るので、仮定と結論を別々に見て、その関係を無視していないか。

- **レビューに渡しているもの**：第 42 回の改善の前の `codex-review.yml` は、PR のタイトルと本文、`git diff`（変更行の前後 3 行）、`CLAUDE.md`・`docs/math-guide.md` をモデルに渡していた。変更したファイルの全文、参照先の定義・前提、前の回のレビューと返信は渡していなかった。
- **T-0028 の PR で起きたこと**：#52〜#55 は、主に各ファイルの「目的」「完了の条件」の節を書き換えた（第 39 回の C-0004 の注意・詳細化の論点の追加などを除く）。そのため、主張を変えなかったファイルでは、同じファイルの「主張」がレビューから見えない。レビュー自身も、ほぼ毎回「主張の本文は差分にないため、判断を保留」と書いている（#46 でも 5 回中 4 回）。次の三つは、これが原因の一つと考えられる（Claude の見立て。改善の後のレビューと比べて確かめる）。
  - **主張を見ない指摘**：A-0017 の参照測度の非原子性は、主張に書いてあるのに 3 回続けて指摘された（#52）。C-0012 の「可能な実験は実際には行われない」も、D-0002 の本文を見れば判断できた（#54）。
  - **一度に一部しか挙がらない**：レビューは前の回の指摘と返信を知らずに、毎回 PR の全体の差分を新しく見る。そのため、各回で別の一部が挙がり、1〜2 件ずつの小出しになると考えられる。直した箇所の周りの新しい文が次の回の対象になり、同じ論点を少しずつ強めていく往復にもなる（#52 の A-0016 は 3 回）。

- **改善の候補**（`.github/codex/` の変更は、`main` にマージした後の PR から効く）：
  - (r1) 変更した D・A・C・R・Q・T のファイルは、差分に加えて、head の版の全文を（合計の上限の内で。省いたファイルは明示する）プロンプトに入れる。
