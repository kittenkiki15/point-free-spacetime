## 主張

Doplicher–Fredenhagen–Roberts の局在の限界（`doplicher1995`）と、実験に使える資源（エネルギーなど）の上限から、装置の占める領域 $`\mathrm{occ}`$（[D-0011](../definitions/D-0011.md)）について、上下限の前提 [A-0009](../assumptions/A-0009.md)（ある $`0 < ℓ ≤ Λ`$ で $`B_ℓ(x) ⊆ \mathrm{occ}(x) ⊆ B_Λ(x)`$）が、物理のモデルの帰結として導かれる。さらに、得られる $`ℓ`$ と $`Λ`$ は $`Λ < 2ℓ`$ を満たし、膨張 $`N_{\mathrm{occ}}`$ の余白付きの包含は補間的でない（[C-0001](C-0001.md) の主張 2 を経由する）。

## 注意

- DFR の不確定性関係は事象の局在についての制約であり、split property（Doplicher–Longo）それ自体は、局在に要るエネルギーや余白の下限を与えない。局在の限界から装置の大きさへ移るためのモデル（例えば、余白を狭めるほど増える資源、つまりエネルギーやエンタングルメントの量と、その上限）を置くことが、検証の課題になる。
- この予想の目標は、装置の**占有範囲**の上下限（A-0009）を物理から導くことである。それによって得られるのは膨張 $`N_{\mathrm{occ}}`$ の余白付きの包含の補間性の破れであり、**操作上の最小の分解能**（$`ℓ`$ より細かい分解能は操作的に使えないこと）とは区別する。占有範囲の下限から分解能の下限は従わない（[A-0009](../assumptions/A-0009.md) の主張の説明）。最小の分解能まで主張するには、例えば、実験の結果が装置の占める領域全体を単位としてしか区別されない、という別の条件が要る。
- 補間性の破れだけでは、最小の尺度があることにはならない（[C-0001](C-0001.md) の「注意」）。そのため、この予想では、物理から得る $`\mathrm{occ}`$ が長さ空間の近傍に挟まれる形（A-0009）になることを主張する。

## 詳細化の論点

- **候補 B（操作的な切り離し）**：$`a ◁ b`$ を「$`a`$ の実験で状態を準備しても、$`b`$ の外側の観測量の統計を変えない」（局所的な準備可能性、split property 型）と定める案がある。これは、$`\mathrm{occ}`$ を物理から決める方法の一つとして、この予想の中で扱う（第 12 回にユーザーと合意）。この定め方で得る関係が膨張から来るか（結びを保つか）は自明でない。
- distal split（dantoni1987、naaijkens2012）は、最小の余白の具体的な模型の候補である。ただし、distal split だけからは補間的でないことは従わないので、同心球などの領域の族を定めて示す必要がある。最小の尺度 $`d_0`$ は理論の状態密度から決まる（実験のエネルギーの上限との対応は未検証）。
- 「資源の上限」を、実験パラメータの値域のコンパクト性（[A-0005](../assumptions/A-0005.md)）の言葉で述べるか。
- 実験ごとの占める領域、測定の分解能、球による下限（A-0009）を区別し、どの条件からどの結論を導くかを指定する。DFR の局在の制約は座標ごとの不確定性の形なので、距離 $`d_O`$ の球の包含への対応も定める必要がある（PR #27 のレビュー）。
- C-0001 の主張 2 の条件 $`Λ < 2ℓ`$ は、不要かもしれない（C-0001 の詳細化の論点。PR #27 のレビュー）。不要なら、補間性の破れに要る物理的な条件は、一様な上限 $`Λ`$ があることだけになる。T-0008 で C-0001 を確かめてから、この予想で $`Λ < 2ℓ`$ を求める方針を見直す。
- 局在の限界と上限 $`Λ`$ の関係：DFR の限界は下限 $`ℓ`$ の根拠になりうるが、上限 $`Λ`$ が $`2ℓ`$ より小さくなる理由は、今のところない。

## 背景

- 第 05 回の C-0001 の主張 2（物理的内容）を、第 12 回に候補 A の言葉で書き直して分けた。
- DFR の局在の限界の原典（`doplicher1995` の 2 節）は、第 06 回に確認した。split property と distal split は、第 08 回に fewster2016 のレビューで概要を確認した（原典は未入手。ロードマップの T-0014）。

## 物理学的な新規性（見立て）

- **「局在の限界」という厳密な定義のない物理の主張に、数学的な定式化を与える**。DFR の不確定性関係は、測定と重力崩壊の仮定に基づくオーダー評価であり、それが領域の構造にどう効くかは定式化されていない。この予想は、それを装置の占める領域の下限として述べ、補間性の破れに結びつける。

## 評価の根拠

- 確度（中）：下限 $`ℓ`$ は DFR の限界から得られる見込みがあるが、上限 $`Λ < 2ℓ`$ の根拠は今のところない。物理のモデル化しだいで成否が変わりうる。
- 重要度（高）：成り立てば、最小の長さの点なしの定式化という、本プロジェクトの物理的な主軸に直接の成果を与える。
- 検証費用（高）：DFR と split property の文献の読み込みと、物理のモデル化が必要である。

## 検証の方針

1. DFR の 2 節と split property（Doplicher–Longo）の文献を調べ、装置の占める領域の下限を与える議論を取り出す。
2. 候補 B（操作的な切り離し）から $`\mathrm{occ}`$ を定める方法を検討する。第 06 回の調査メモの 6.4 節の言い換え（DFR の許される状態の制限から、実現できる結合領域の族を定める）も検討する。
3. 上限 $`Λ`$ の物理的な意味（装置の有界性）と、$`Λ < 2ℓ`$ が成り立つかを検討する。成り立たない場合は、C-0001 の主張 2 の条件を弱められるかを調べる。
