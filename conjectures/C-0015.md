## 目的

- 有限の精度の観測を鋭くしていった統計の極限が「点」に集中するかを、点を前提にせずに述べる（[T-0032](../tasks/T-0032.md) の方針の 2 と、点の型の予想）。連続体の上の δ 分布を理想として置くと、点を先取りすることになる（第 45 回のユーザーの懸念）。この予想は、点が現れる条件を、開集合（有限の精度の命題）と統計だけで述べ、標準の意味論ではそれが δ 分布への弱収束と一致することを確かめる（[G-0003](../goals/G-0003.md)）。
  - 現段階の条件 (C) は、開集合と統計のほかに、指定した距離（一様構造）も使う。フレームだけによる定式化は、詳細化の論点（(C) の点なしの言葉での形）で扱う（第 48 回。PR #70 のレビュー）。
- 成り立てば、層 3・6 で点なしの空間から点が現れる条件（点なし時空の主題）を、統計の側から問う足場になる（[G-0004](../goals/G-0004.md)）。

## 完了の条件

統計を与える対象はボレル確率測度とし、点なしの条件は有限の精度の集中の条件 (C) とする（第 48 回にユーザーと決めた。付値に移すかは詳細化の論点に残す）。検証の形は紙の証明とする。主張の (1)・(2) は標準的な議論（ポルトマントーの定理など）で示す。(3) は、(a)〜(c) の同値の証明と、質量が逃げる列の例で確かめる。(C) を一様ロケールの言葉で述べ直すことは、詳細化の論点として別に扱う。(1)・(2) は Lean で形式化する候補である。

## 主張

結果の空間 $`Y`$（[A-0017](../assumptions/A-0017.md) の形。成分への分解 $`Y = ⨆_{a ∈ F_Y} C_a`$ まで含めて）と、[C-0014](C-0014.md) の定義 1 の拡張した結果の空間 $`K = ⨆_a K_a`$（各成分の参照測度の台の閉包）を考える。$`K`$ には、同じ成分 $`K_a ⊆ ℝ^{m_a}`$ の点の間では $`d(x, y) = \min(1, \lVert x - y \rVert)`$（ユークリッド距離を 1 で打ち切ったもの）、異なる成分の点の間では $`d(x, y) = 1`$ とおいた距離 $`d`$ を入れる（打ち切らないと、成分をまたぐ三角不等式が成り立たないことがある。PR #70 のレビュー）。これは $`K`$ の直和の位相を与える。各 $`K_a`$ は $`ℝ^{m_a}`$ の閉集合で、距離が 1 未満の点は同じ成分にあるので、$`(K, d)`$ は完備な距離空間である。

統計の列は、$`K`$ の上の任意のボレル確率測度の列 $`ν_k ∈ \mathrm{Prob}(K)`$（$`k ∈ ℕ`$）とする。これは任意の測度の列についての数学的な主張であり（第 48 回のユーザーの判断）、実験の統計の列（C-0014 のプロトコルの列の、ある設定 $`x`$ での値 $`ν_k = ι(p_{π_k}(\,\cdot \mid x))`$。各項は密度を持つ）は、その特別な場合である。$`K`$ の開集合のフレーム $`𝒪(K)`$（点なしの言葉では、有限の精度で確かめられる命題の代数）の部分集合

```math
F = \{\, U ∈ 𝒪(K) : \liminf_{k → ∞} ν_k(U) = 1 \,\}
```

を考える。$`F`$ は、統計の列が「最終的にほぼ確実に成り立つ」と言える命題の全体である。

1. $`F`$ は $`𝒪(K)`$ のフィルターである（上に閉じ、$`ν_k(U ∩ V) ≥ ν_k(U) + ν_k(V) - 1`$ から有限の交わりで閉じ、$`ν_k(∅) = 0`$ なので空集合を含まない）。
2. 点 $`y ∈ K`$ について、$`ν_k`$ が $`δ_y`$ に弱収束することと、$`y`$ の近傍のフィルター $`N(y)`$ が $`F`$ に含まれることは同値である（ポルトマントーの定理による）。ただし、$`F`$ 自体が点（完全素フィルター）になるとは限らない（例：$`K = [0, 1]`$ で $`ν_k = δ_{1/(k+2)}`$ は $`δ_0`$ に弱収束するが、$`(0, 1] ∈ F`$ で、$`(0, 1] = ⋃_{n ≥ 1} (1/n, 1]`$ のどの項も $`F`$ に入らない）。
3. 「統計が点に集中する」を「$`F`$ が完全素フィルターを含む」と定める。このとき、次の三つは同値である。
   - (a) $`F`$ が完全素フィルターを含む。
   - (b) **（有限の精度の集中の条件 (C)）** どの精度 $`ε > 0`$ についても、直径が $`ε`$ 未満の開集合で $`F`$ に入るものがある。
   - (c) ある（ただ一つの）点 $`y ∈ K`$ について、$`ν_k`$ が $`δ_y`$ に弱収束する。

   緊密性に当たる条件は、別には要らない（無限遠へ逃げる列は (C) を満たさない）。

## 主張についての注意

- (a) と (c) の同値は、距離化可能な空間がソバー（sober）であること（$`𝒪(K)`$ の完全素フィルターは近傍のフィルター $`N(y)`$ に限られる）と、(2) から従う。$`y`$ がただ一つであることは、ハウスドルフ性から従う。
- (b) から (c) の証明の筋（Claude の案）：直径が $`1/n`$ 未満の $`U_n ∈ F`$ をとる。$`F`$ はフィルターなので、どの有限個の交わりも空でなく、各 $`U_1 ∩ ⋯ ∩ U_n`$ から点を選ぶとコーシー列になる。$`K`$ の完備性からその極限 $`y`$ があり、$`y`$ のどの近傍も十分先の $`U_n`$ を含むので、$`N(y) ⊆ F`$ となる。点の選び方には可算選択公理を使う（数学的な主張なので許す。構成的な形にするかは詳細化の論点）。(c) から (b) は、$`y`$ を中心とする半径 $`ε/3`$ の開球をとればよい。
- 例：
  - 無限遠へ逃げる列：$`Y = K = ℝ`$ で $`ν_k = δ_k`$、または密度を持つ $`(k, k + 1)`$ の上の一様分布。直径 1 未満のどの開集合でも $`\liminf ν_k = 0`$ なので、(C) を満たさず、点に集中しない。
  - 境界へ逃げる列：$`Y = (0, 1)`$、$`K = [0, 1]`$ で $`ν_k = δ_{1/(k+2)}`$、または密度を持つ $`(1/(k+2),\, 2/(k+2))`$ の上の一様分布。$`K`$ の上では (C) を満たし、点 $`0 ∈ K`$ に集中する。$`𝒪(Y)`$ の上で同じ $`F`$ を考えると、(C) は満たすが、完全素フィルターを含まない。$`Y`$ が完備でないからで、境界へ逃げる問題は完備化の問題である。$`F`$ を $`𝒪(Y)`$ ではなく $`𝒪(K)`$ の上で定めるのはこのためで（第 48 回にユーザーと決めた）、$`K`$ は $`Y`$ の参照測度の台の完備化に当たる。
- (C) は、フレーム $`𝒪(K)`$ だけでなく、距離（一様構造）を使う。ただし、$`K`$ の位相を与える完備な距離ならどれを使っても、(C) は (c) と同値なので、(C) の成否は完備な距離の選び方によらない。完備でない $`Y`$ の上では、距離の選び方で変わり得る（C-0014 の PR #69 のレビューの、境界を貼り合わせた距離の例）。

## 詳細化の論点

- 主張の対象の範囲（PR #69 のレビューの詳細化の論点）：第 48 回に、任意の測度の列についての数学的な主張として残すことにした（ユーザーの判断）。実験の統計の列は特別な場合として扱い、例には密度を持つ列も併記した。
- 統計を与える対象：ボレル確率測度のままにするか、フレームの上の付値（valuation）に移すか。点を持たないフレームでも述べるには、付値が自然である（[T-0032](../tasks/T-0032.md) の「較正とトポスの見方」の 2）。
- 条件の候補の形：第 48 回に、(3) の条件を有限の精度の集中の条件 (C)（コーシー性）とした（ユーザーが了承）。緊密性に当たる条件は別には要らない。
- (C) の点なしの言葉での形：(C) は距離（一様構造）を使う。一様ロケール（uniform locale）の正則なコーシー・フィルター（regular Cauchy filter）が完備化の点に対応するという結果（Banaschewski–Pultr。Claude の記憶によるもので、文献で確かめる）を使えば、点を先取りせずに述べられる見込みである。フレームのほかに、どの一様構造を与えるか（記録から決まるか）を決める。
- (b) から (c) の証明の可算選択公理を、構成的な形に置き換えるかは、[Q-0018](../questions/Q-0018.md)（実無限と選択公理の扱い）に移した（第 51 回）。
- 主張の 3 は、空間全体のフレームが点を十分に持つ（spatial）かどうかで述べる形は採らない（spatial でなくても一部の点への集中はあり得る。第 45 回。PR #62 のレビュー）。
- 以下は、第 46 回に [Q-0007](../questions/Q-0007.md) から [T-0032](../tasks/T-0032.md) に仮置きし、第 47 回にこの予想に移した論点である（本文は移す前のまま）。
- 理想化の前後で比べる事象（第 33 回。PR #42 のレビューの詳細化の論点）：弱収束は、任意の可測な結果の事象の確率の収束までは保証しない（例：$`N(0, σ_k^2) → δ_0`$ でも、事象 $`[0, ∞)`$ の確率は各 $`k`$ で $`1/2`$、極限では 1）。閾値の判定などの後処理を理想化の前後で比べるときに、どの事象の確率に収束を求めるか（例：極限の分布の連続集合に限る）を決める。
- 境界へ逃げる質量の扱いは、[C-0014](C-0014.md) の結果の空間の拡張（$`K`$）と同じ問題の別の面である。拡張した空間では点に集中しても、元の $`Y`$ では集中しないことがある。

## 背景

第 45 回のユーザーの懸念（「連続体の上の δ 分布を扱えるようにする」は点あり時空を前提にしているように読める）と、結果の空間の意味を意味論として読む提案から、点の型の予想の案を立てた（T-0032）。第 47 回に、Claude の案（4 件）をユーザーが了承して登録した。

- 確度：高（第 48 回に中から改めた）。(1)・(2) は標準的な議論で示せる見込みで（Claude の確認による。(2) の例は確かめた）、(3) は、条件を (C) と定めたことで、完備な距離空間の標準的な議論に帰着した（主張についての注意の証明の筋。紙の証明で確かめる）。

## 検証の方針
