## 主張

時空の領域をフレーム $`L`$（開集合の束）で表し、膨張 $`N : L → L`$（[D-0009](../definitions/D-0009.md)）の余白付きの包含 $`a ◁ b \iff N\,a ≤ b`$（[D-0010](../definitions/D-0010.md)）を考える。

1. **（尺度 $`ℓ`$ の近傍）** $`ℓ > 0`$ とする。距離空間 $`(X, d)`$ が**長さ空間**（2 点間の距離が、それらを結ぶ道の長さの下限に等しい）で、直径が $`ℓ`$ より大きいとき、開 $`ℓ`$ 近傍による膨張 $`N_ℓ\,U = \{y : d(x, y) < ℓ \text{ となる } x ∈ U \text{ がある}\}`$ は $`N_ℓ ∘ N_ℓ = N_{2ℓ} ≰ N_ℓ`$ を満たし、余白付きの包含 $`◁_ℓ`$ は補間的でない。これは**固定した $`ℓ`$ の関係の性質**である（通常の $`ℝ`$ でも、任意に小さい $`ℓ`$ について同じことが成り立つ）。したがって、**操作上の最小の尺度**があると言うには、「$`ℓ`$ より細かい分解能（$`δ < ℓ`$ の $`N_δ`$）は操作的に使えない」という物理の仮定を別に置く必要がある（第 12 回に、候補 A の言葉で、装置の占める領域の上下限の前提 [A-0009](../assumptions/A-0009.md) を置いた。これは占有範囲の仮定で、分解能の仮定そのものではない。占める領域の下限から分解能の下限を導くには、追加の条件が要る）。分解能についてのこの仮定の下で、最小の尺度 $`ℓ`$ があることを、使える膨張 $`N_ℓ`$ の余白付きの包含 $`◁_ℓ`$ が補間的でないこととして表す（一般の膨張では両者は一致しない。下の「注意」を参照）。また、$`δ ≤ ℓ/2`$ で $`N_δ ∘ N_δ ≤ N_ℓ`$ が成り立つので、「ある $`ℓ > 0`$ で $`a ◁_ℓ b`$」として得られる関係（一様な余白による近接関係）は補間的である。この関係は、$`a`$ の閉包がコンパクトなら、閉包の包含 $`\overline{a} ⊆ b`$（点なし位相の「十分内側にある」関係）と一致するが、一般にはそれより強い。
2. **（挟まれた膨張）** 1 の長さ空間で、$`0 < ℓ ≤ Λ`$ とする。膨張 $`N`$ がすべての開集合 $`U`$ で $`N_ℓ\,U ⊆ N\,U ⊆ N_Λ\,U`$ を満たし、$`Λ < 2ℓ`$ で、空間の直径が $`Λ`$ より大きければ、$`◁_N`$ は補間的でない。これは、装置の占める領域の上下限（[A-0009](../assumptions/A-0009.md)）の下で、[D-0011](../definitions/D-0011.md) の膨張に 1 の結論が移ることを表す（A-0009 は、この予想の仮定には使わない。仮定は上の挟み込みの条件だけである）。
3. **（離散化との区別）** 1・2 の構造では、フレーム $`L`$ は連続な時空の開集合フレームのまま（空間的で、アトムを持たない）でよい。したがって、「最小の尺度がある」ことと「時空が離散的である（フレームがアトムで生成される）」ことは、点なしの枠組みで区別できる。

### 注意（補間性の破れと最小の尺度は、一般には一致しない）

PR #9 のクロスモデルレビューで指摘された反例である。

- $`ℝ`$ で $`T(x, y)`$ を「$`x = y`$ または $`\left| x - y \right| = 1`$」とすると、$`T`$ による膨張は結びを保ち、補間性も破れるが、距離 1 未満の異なる点は区別できる。補間性の破れだけでは、最小の尺度があることにはならない。
- 超距離空間（$`d(x, z) ≤ \max(d(x, y), d(y, z))`$）では、$`d(x, y) < ℓ`$ は推移的なので、正の尺度 $`ℓ`$ があっても補間性は破れない（見立て：階層的に離散的な空間では、尺度が補間性の破れとして現れない）。
- $`ℝ`$ で $`U = ⋃_{n ≥ 2} (n, n + 1/4)`$、$`V = ⋃_{n ≥ 2} (n - 1/n, n + 1/2)`$ とすると、$`\overline{U} ⊆ V`$ だが、$`N_ℓ\,U ⊆ V`$ となる一様な $`ℓ > 0`$ はない。一様な余白による近接関係は、コンパクト性などの条件がないと「十分内側にある」関係と一致しない。

したがって主張 1・2 は、長さ空間の $`ℓ`$ 近傍による膨張と、それに挟まれた膨張に限って述べる。物理から得られる膨張がこの型であるかは、[C-0007](C-0007.md) で確かめる。

## 詳細化の論点

- 点なし版：1・2 を、長さ空間の近傍の代わりに、フレームと膨張の族（尺度 $`ℓ`$ で添字づけた膨張 $`N_ℓ`$ で、$`N_ℓ ∘ N_{ℓ'} = N_{ℓ + ℓ'}`$ を満たすものなど）で述べ直す。
- 主張 2 の条件 $`Λ < 2ℓ`$ は不要かもしれない（PR #27 のレビュー）。補間的なら $`N ∘ N ≤ N`$（[R-0007](../results/R-0007.md)）なので、すべての $`k ≥ 1`$ で $`N^k\,a ≤ N\,a`$ となる。一方、$`N ≥ N_ℓ`$ から長さ空間では $`N^k\,B_ε(x) ⊇ B_{kℓ+ε}(x)`$ で、$`N\,B_ε(x) ⊆ B_{Λ+ε}(x)`$ である。距離が $`Λ + ε`$ 以上の点 $`y`$ があれば、十分大きな $`k`$ で矛盾する。この筋が正しければ、直径が $`Λ`$ より大きい長さ空間では、一様な上限 $`Λ`$ があるだけで（$`Λ`$ と $`ℓ`$ の比によらず）補間性が破れる。ロードマップの T-0008 で確かめる。

## 背景

- 第 05 回に、最小の尺度の入れ方を型 I（小さすぎる領域を捨てる）と型 II（余白に下限を置く）に分け、型 II（案 D）を深掘りした。型 I と型 II は同じ随伴 $`N ⊣ E`$ の二つの面である（[R-0008](../results/R-0008.md)）。
- 数学の部分（[R-0006](../results/R-0006.md)〜[R-0008](../results/R-0008.md)）は既知である（劣位代数の補間性と推移性、数理形態学の随伴）。
- 第 12 回に、第 05 回の C-0001 を三つに分けた（ユーザーの判断）。数学の部分（旧主張 1・3）をこの予想に残し、物理的内容（旧主張 2）を [C-0007](C-0007.md) に、ポアンカレ共変性と有界性（旧主張 4）を [C-0008](C-0008.md) に移した。主張 2（挟まれた膨張）は、候補 A（[D-0011](../definitions/D-0011.md)）に合わせて第 12 回に加えた。
- van der Schaaf（`vanderschaaf2024` の 9.3 節）は、プランクスケールをアトムで表そうとして、位相が失われる（離散化する）ことを示した。Connes–van Suijlekom（`connes2022`）は、許容関係 $`d(x, y) < ε`$ を作用素系で扱っている。
- 詳細は [調査メモ](../surveys/2026-09-26_05_subordination.md) の 4 節。

## 物理学的な新規性（見立て）

- **正の尺度を持つ膨張と離散性の区別を、点なしの構造として与える**（主張 3）。これを「最小の長さ」と呼べるのは、分解能を制限する追加の条件（[A-0009](../assumptions/A-0009.md) の主張の説明）が成り立つ場合である。先行研究では、点なしの枠組みでプランクスケールを表そうとすると離散化していた（van der Schaaf）。
- **正の尺度を持つ膨張と、その補間性の破れを、領域の代数の側で表す**（主張 1・2）。Connes–van Suijlekom は関数の代数（作用素系）の側で扱っており、両者の対応は非可換な時空とのつながりを与えうる。
- 数学の内容は、一様空間や長さ空間の標準的な事実に近いと見込まれる。物理学への寄与は、[C-0007](C-0007.md) で物理から膨張を得たときに生じる。

## 評価の根拠

- 確度（高）：主張 1 は、長さ空間では $`N_ℓ ∘ N_ℓ = N_{2ℓ}`$ となることから従う見込みである。主張 2 は、$`a`$ を小さな開球 $`B_ε(x)`$ に取ると、$`N(N\,a) ⊇ N_ℓ(N_ℓ\,a) = B_{2ℓ + ε}(x)`$ と $`N\,a ⊆ B_{Λ + ε}(x)`$ から、距離が $`Λ + ε`$ 以上 $`2ℓ + ε`$ 未満の点があれば従う（長さ空間の中間値の性質で取れる見込み。証明の筋の段階）。主張 3 は定義から近い。
- 重要度（中）：C-0007・C-0008 の数学的な土台である。単独では既知の事実に近い。
- 検証費用（低）：第 27 回の棚卸しから、検証費用は自然言語の証明について評価する（検証方法の Lean での形式化は別に数え、それを含めると中程度。第 26 回までは Lean を含めて中と評価していた。PR #50 のレビュー）。主張 1・3 は初等的で、主張 2 も詳細化の論点の筋（$`Λ < 2ℓ`$ が不要）が正しければ、自然言語の証明は 1 セッション程度で済む見込みである。この見積もりは、詳細化の論点の別の筋が正しいことを条件にしている。T-0008 で、$`Λ + ε`$ と $`2ℓ + ε`$ の間の点を使わずに主張 2 を示す論証と、要る空間・尺度の条件を明示する（PR #50 のレビューの詳細化の論点）。
