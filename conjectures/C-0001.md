## 主張

時空の領域をフレーム $`L`$（開集合の束）で表し、「領域を、操作的に区別できないところまで広げる」操作を、結びを保ち増大的な写像（膨張）$`N : L → L`$ で表す。余白付きの包含を $`a ◁ b \iff N\,a ≤ b`$ と定める（[R-0007](../results/R-0007.md)）。

1. **（定式化）** $`ℓ > 0`$ とする。距離空間 $`(X, d)`$ が**長さ空間**（2 点間の距離が、それらを結ぶ道の長さの下限に等しい）で、直径が $`ℓ`$ より大きいとき、開 $`ℓ`$ 近傍による膨張 $`N_ℓ\,U = \{y : d(x, y) < ℓ \text{ となる } x ∈ U \text{ がある}\}`$ は $`N_ℓ ∘ N_ℓ = N_{2ℓ} ≰ N_ℓ`$ を満たし、余白付きの包含 $`◁_ℓ`$ は補間的でない。これは**固定した $`ℓ`$ の関係の性質**である（通常の $`ℝ`$ でも、任意に小さい $`ℓ`$ について同じことが成り立つ）。したがって、**操作上の最小の尺度**があると言うには、「$`ℓ`$ より細かい分解能（$`δ < ℓ`$ の $`N_δ`$）は操作的に使えない」という物理の仮定を別に置く必要がある。この仮定の下で、最小の尺度 $`ℓ`$ があることを、使える膨張 $`N_ℓ`$ の余白付きの包含 $`◁_ℓ`$ が補間的でないこととして表す（一般の膨張では両者は一致しない。下の「注意」を参照）。また、$`δ ≤ ℓ/2`$ で $`N_δ ∘ N_δ ≤ N_ℓ`$ が成り立つので、「ある $`ℓ > 0`$ で $`a ◁_ℓ b`$」として得られる関係（一様な余白による近接関係）は補間的である。この関係は、$`a`$ の閉包がコンパクトなら、閉包の包含 $`\overline{a} ⊆ b`$（点なし位相の「十分内側にある」関係）と一致するが、一般にはそれより強い。
2. **（物理的内容）** Doplicher–Fredenhagen–Roberts の局在の限界（`doplicher1995`）から、「領域を外から操作的に切り離せる」という関係を定義でき、それは 1 の型の補間的でない関係になる。ただし、DFR の不確定性関係は事象の局在についての制約であり、split property（Doplicher–Longo）それ自体は、局在に要るエネルギーや余白の下限を与えない。したがって、これらを手掛かりに膨張 $`N`$ を構成できるかを検討する必要がある。そのためには、測定の局在の限界から領域の余白へ移るためのモデル（たとえば、余白を狭めるほど増える資源、つまりエネルギーやエンタングルメントの量と、その上限）を置くことが、検証の課題になる。
3. **（離散化との区別）** 1 の構造では、フレーム $`L`$ は連続な時空の開集合フレームのまま（空間的で、アトムを持たない）でよい。したがって、「最小の尺度がある」ことと「時空が離散的である（フレームがアトムで生成される）」ことは、点なしの枠組みで区別できる。
4. **（ポアンカレ共変性と有界性）** 空間の次元が 1 以上のミンコフスキー時空で、ポアンカレ変換と可換で（共変）、有界な領域を有界な領域に移す膨張 $`N`$ は、恒等写像になり、補間性を破れない（最小の尺度を入れられない）。したがって、ポアンカレ共変（ローレンツ変換と並進の両方と可換）な最小の尺度は、この有界性の条件を満たさない膨張としてしか入らない。並進との可換性は外せない（たとえば、原点を中心とする 2 倍の拡大 $`U ↦ U ∪ 2U`$ は、結びを保ち、増大的で、有界な領域を有界な領域に移し、ローレンツ変換と可換だが、恒等写像ではない。PR #9 のレビューの指摘による）。ここでの「有界な領域を有界な領域に移す」は、物理的な局所性（微視的因果律など）を定義したものではなく、両者の対応は別の検証課題とする。空間の次元が 0（時間 1 次元だけ）の場合は、ブーストがないので成り立たない（時間軸上の $`ℓ`$ 近傍が反例になる）。

### 注意（補間性の破れと最小の尺度は、一般には一致しない）

PR #9 のクロスモデルレビューで指摘された反例である。

- $`ℝ`$ で $`T(x, y)`$ を「$`x = y`$ または $`\left| x - y \right| = 1`$」とすると、$`T`$ による膨張は結びを保ち、補間性も破れるが、距離 1 未満の異なる点は区別できる。補間性の破れだけでは、最小の尺度があることにはならない。
- 超距離空間（$`d(x, z) ≤ \max(d(x, y), d(y, z))`$）では、$`d(x, y) < ℓ`$ は推移的なので、正の尺度 $`ℓ`$ があっても補間性は破れない（見立て：階層的に離散的な空間では、尺度が補間性の破れとして現れない）。
- $`ℝ`$ で $`U = ⋃_{n ≥ 2} (n, n + 1/4)`$、$`V = ⋃_{n ≥ 2} (n - 1/n, n + 1/2)`$ とすると、$`\overline{U} ⊆ V`$ だが、$`N_ℓ\,U ⊆ V`$ となる一様な $`ℓ > 0`$ はない。一様な余白による近接関係は、コンパクト性などの条件がないと「十分内側にある」関係と一致しない。

したがって主張 1 は、長さ空間の $`ℓ`$ 近傍による膨張に限って述べる。主張 2 では、DFR の局在の限界から得られる膨張が、長さ空間の近傍に相当する性質（途中の点を取れること）を持つかを確かめる必要がある。

## 背景

- 第 05 回に、最小の尺度の入れ方を型 I（小さすぎる領域を捨てる）と型 II（余白に下限を置く）に分け、型 II（案 D）を深掘りした。型 I と型 II は同じ随伴 $`N ⊣ E`$ の二つの面である（[R-0008](../results/R-0008.md)）。
- 数学の部分（[R-0006](../results/R-0006.md)〜[R-0008](../results/R-0008.md)）は既知である（劣位代数の補間性と推移性、数理形態学の随伴）。
- 物理学の側では、Connes–van Suijlekom（`connes2022`）が、プランク長を動機として、許容関係 $`d(x, y) < ε`$ を非可換幾何（作用素系）で扱っている。Vakarelov（`vakarelov2020`）は接触代数で点なしの時空論を展開しているが、最小の尺度は扱っていない。van der Schaaf（`vanderschaaf2024` の 9.3 節）は、プランクスケールをアトムで表そうとして、位相が失われる（離散化する）ことを示した。
- 詳細は [調査メモ](../surveys/2026-09-26_05_subordination.md) の 4 節。

## 物理学的な新規性（見立て）

- **最小の長さと離散性の区別を、点なしの構造として与える**（主張 3）。先行研究では、点なしの枠組みでプランクスケールを表そうとすると離散化していた（van der Schaaf）。
- **最小の長さを、領域の代数の側で表す**（主張 1）。Connes–van Suijlekom は関数の代数（作用素系）の側で扱っており、両者の対応は非可換な時空とのつながりを与えうる。
- **「局在の限界」という厳密な定義のない物理の主張に、数学的な定式化を与える**（主張 2）。DFR の不確定性関係は、測定と重力崩壊の仮定に基づくオーダー評価であり、それが領域の構造にどう効くかは定式化されていない。
- **ポアンカレ共変性・有界性・最小の尺度の緊張関係を、膨張の性質として明示する**（主張 4）。因果集合理論で知られているとされる非局所性（未確認）の、点なし版にあたる可能性がある。ただし、有界性の条件と物理的な局所性の対応は、まだ検証していない。
  - 第 06 回の調査（[調査メモ](../surveys/2026-09-26_06_minimal-length-covariance.md)）で、非局所性の文献（`bombelli2009`、`sorkin2007`）を確認した。主張 4 は「単一の不変な関係」の no-go 定理として既知の型に属し、新規性は点なしの形に言い直すことにとどまりそうである（ユーザーも同意）。観測者ごとの族と赤外の尺度を入れた形への見直しを、[NEXT.md](../NEXT.md) のタスク 1 で行う。

## 評価の根拠

- 確度（中）：主張 1 と 3 は、長さ空間（ユークリッド空間を含む）の $`ℓ`$ 近傍による膨張で成り立つと見込まれる（一様空間の標準的な事実に近い）。ただし、補間性の破れと最小の尺度は一般には一致しないので（注意）、主張 2 で物理から得られる膨張が長さ空間型であるかが鍵になる。主張 4 は、点の関係 $`T`$ から作る膨張については簡単に示せる見込みである（ローレンツ不変で有界な集合は一点だけなので、局所的で共変な $`T`$ は恒等関係になる）。主張 2 は、物理のモデル化しだいで成否が変わりうる。
- 重要度（高）：成り立てば、最小の長さの点なしの定式化という、本プロジェクトの物理的な主軸に直接の成果を与える。主張 4 は、ポアンカレ共変な最小の尺度の扱いに制約を与える。
- 検証費用（高）：主張 1・3・4 の数学的な部分は数日程度（Lean を含む）。主張 2 は、DFR と split property の文献の読み込みと、物理のモデル化が必要である。

## 検証の方針

1. 主張 4 の点の場合を、自然言語で証明し、Lean で形式化する（ローレンツ群の作用が必要なので、2 次元ミンコフスキー時空から始める）。
2. 主張 1 と 3 を、ユークリッド空間の $`ℓ`$ 近傍による膨張で示す。点なし版（任意のフレームと膨張の族）の定式化を考える。
3. 主張 2 のために、DFR の 2 節と split property（Doplicher–Longo）の文献を調べ、「操作的に切り離せる」関係を定義する。
4. Connes–van Suijlekom の作用素系との対応を調べる。
