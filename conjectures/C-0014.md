## 目的

理想化した応答（設定について不連続な閾値の応答など）を、前提で保証するのではなく、実際の実験の応答関数の列の極限として得られるかを確かめる（[T-0032](../tasks/T-0032.md) の方針の 2。第 46 回に [A-0017](../assumptions/A-0017.md)・[A-0006](../assumptions/A-0006.md) から「理想化を極限として扱えるようにする」書き方を外した）。成り立てば、極限として得られる応答の範囲が、前提を置かずに特定され、扱うべき物理モデル（閾値の装置など）が扱えることと、扱えない模型（$`𝟙_ℚ`$ のような応答）がどれかが分かる。成り立たなければ、前提を見直す材料になる。

## 完了の条件

先に、下の詳細化の論点のうち、結果の空間の拡張（$`K_π`$ の取り方）と、極限を取る列の取り方（共通の空間を持つ列、延長の実験）を決める。検証の形は紙の証明とする。主張の (1) は、距離化可能な空間の間の各点極限についての古典的な結果（ルベーグ–ハウスドルフの定理の型）を当てはめる形で、(2a) は、ベール第 1 級の写像を連続な写像の各点極限として表す定理を、密度を持つ統計に値をとる連続な写像で近似できるように延ばす形で示す。(2b) は、C-0018 を仮定した紙の証明とする。文献の定理を使う場合は、仮定（値の空間の凸性・可分性など）が満たされることを確かめる。

## 主張

### 定義（第 47 回にユーザーの依頼で加えた）

標準の意味論（[A-0017](../assumptions/A-0017.md) の位相。第 46 回）で、設定の空間 $`X ⊆ ℝ^n`$（[D-0003](../definitions/D-0003.md)。部分空間の位相）と結果の空間 $`Y`$ を固定する。結果の空間は、集合としてだけでなく、成分への分解まで含めて固定する。

```math
Y = ⨆_{a ∈ F} C_a, \qquad C_a ⊆ ℝ^{m_a}, \qquad λ = ⨁_{a ∈ F} λ_a
```

$`λ_a`$ は、$`m_a ≥ 1`$ なら $`C_a`$ に制限した $`m_a`$ 次元のルベーグ測度、$`m_a = 0`$ なら一点の上の重さ 1 の測度である（A-0017 の参照測度。参照測度はこの分解で決まるので、集合 $`Y`$ だけでは決まらない。分解まで共通なら、参照測度も共通になる）。

1. **拡張した結果の空間 $`K`$**：

```math
K_a = \overline{\{\, y ∈ ℝ^{m_a} : \text{$y$ のどの開近傍 $U$ についても } λ_a(U ∩ C_a) > 0 \,\}}^{\,ℝ^{m_a}}, \qquad K = ⨆_{a ∈ F} K_a
```

   各 $`K_a`$ に $`ℝ^{m_a}`$ の部分空間の位相、$`K`$ にその直和の位相を入れる。$`K_a`$ は $`ℝ^{m_a}`$ の閉集合なので、$`K`$ はポーランド空間（可分で完備に距離化できる空間）である。$`K`$ は参照測度の台の閉包で、$`Y`$ に境界の点を加える一方、$`Y`$ に属する測度 0 の部分（孤立点だけでなく、例えば $`C = [0, 1] ∪ (2 + \text{カントール集合})`$ の後半のような孤立点を持たない零測度の部分も）を除き得る（PR #69 のレビュー）。
2. **値の空間 $`\mathrm{Prob}(K)`$**：$`K`$ の上のボレル確率測度の全体に、弱位相（写像 $`μ ↦ \int_K g\, dμ`$（$`g ∈ C_b(K)`$）をすべて連続にする最も粗い位相）を入れたもの。列については

```math
μ_k → μ \;\;\Longleftrightarrow\;\; \int_K g\, dμ_k → \int_K g\, dμ \quad (∀ g ∈ C_b(K))
```

   である。$`K`$ がポーランド空間なので、$`\mathrm{Prob}(K)`$ もレヴィ–プロホロフ距離で距離化できるポーランド空間である。
3. **埋め込み $`ι`$**：$`λ`$ について密度を持つ $`μ ∈ \mathrm{Prob}(Y)`$ を、$`K`$ のボレル集合 $`B`$ について $`ι(μ)(B) := μ(B ∩ Y)`$ とおいて、$`\mathrm{Prob}(K)`$ の元とみなす（$`λ`$ の台の外は測度 0 なので、$`μ`$ の質量は $`K ∩ Y`$ に乗る）。
4. **応答の空間**：$`X`$ から $`\mathrm{Prob}(K)`$ への写像の全体 $`\mathrm{Prob}(K)^X`$ に、各点収束の位相（積位相）を入れたもの。列については

```math
q_k → q \;\;\Longleftrightarrow\;\; ∀ x ∈ X :\; q_k(x) → q(x) \quad (\mathrm{Prob}(K) \text{ の弱位相で})
```

   である。応答 $`q`$ は値の空間 $`\mathrm{Prob}(K)`$ の元ではなく、応答の空間の元である。
5. **実際の実験の応答の候補**：[A-0006](../assumptions/A-0006.md) と A-0017 を満たす応答（を $`ι`$ で写したもの）の全体。

```math
R(X, Y) = \{\, ι ∘ p \mid p : X → \mathrm{Prob}(Y) \text{ は連続},\; ∀ x ∈ X :\; p(x) ≪ λ \,\}
```

6. **点列閉包**：$`R(X, Y)`$ の列の極限として得られる応答の全体。

```math
\mathrm{Scl}(X, Y) := \{\, q ∈ \mathrm{Prob}(K)^X \mid ∃ (p_k)_{k ∈ ℕ} ⊆ R(X, Y) :\; p_k → q \,\}
```

7. **理想化した応答**：点列閉包のうち、$`R(X, Y)`$ に属さないもの。

```math
\mathrm{Ideal}(X, Y) := \mathrm{Scl}(X, Y) \setminus R(X, Y)
```

8. **実効的な点列閉包**：有限の規則で生成されるプロトコルの列の極限として得られる応答の全体。

```math
\mathrm{Scl}_{\mathrm{eff}}(X, Y) := \{\, q ∈ \mathrm{Prob}(K)^X \mid ∃ M :\; M \text{ は } k \text{ からプロトコル } π_k \text{ の記述を出力する機械（A-0018 の制約を満たす）で、} ι ∘ p_{π_k} → q \,\}
```

   存在を主張するのは、有限の対象である機械 $`M`$ だけである。列は $`M`$ が段階ごとに一つずつ出力するもので、どの段階でも出力済みの部分は有限である（[A-0001](../assumptions/A-0001.md) の (b) の可能的無限と、[A-0018](../assumptions/A-0018.md) の延長の読み方）。収束 $`ι ∘ p_{π_k} → q`$ は、各設定 $`x`$ と各 $`ε > 0`$ について、十分大きな有限の $`k`$ で距離が $`ε`$ 以内になる、という意味で、収束のモジュラス（どの $`k`$ から $`ε`$ 以内になるかを与える関数）の計算可能性は求めない（近似する応答が一様に計算可能な場合には、モジュラスの計算可能性を求めると極限は計算可能で連続になり、理想化した応答は得られない。下の詳細化の論点）。$`M`$ が計算するのはプロトコルの記述で、応答関数 $`p_{π_k}`$ は自然が決めるものであり、この定義は応答の計算可能性を課さない（PR #69 のレビュー）。

注意：理想化した応答の全体は、積位相の閉包ではなく、列の極限の全体（点列閉包）で定める。積位相の閉包はネット（有向族）の極限を含み、連続写像の閉包は大きくなりすぎる（値の空間が弧状連結なら写像の全体になる）。

### 主張の本文

上の $`X`$・$`Y`$ を設定と結果の空間に持つプロトコルの列 $`(π_k)`$ と、その応答関数（[D-0004](../definitions/D-0004.md)）の列 $`p_k := p_{π_k}`$ を考える。各 $`p_k`$ は [A-0006](../assumptions/A-0006.md)（弱位相についての連続性）と A-0017（密度）を満たすとする。プロトコルを一つに固定すると応答関数は一つなので、極限を考えるには、プロトコルを取り替える列が要る（第 47 回）。

1. **（含まれる側）** 点列閉包の元はベール第 1 級（開集合の逆像が $`F_σ`$ 集合）の写像である：$`\mathrm{Scl}(X, Y) ⊆ B_1(X, \mathrm{Prob}(K))`$。特に、プロトコルの列の応答 $`ι ∘ p_k`$ が各設定で収束するとき、極限 $`q`$ はベール第 1 級である。$`q`$ は列 $`(π_k)`$ によって決まる（異なる列が同じ $`q`$ を与えることもある）。$`q`$ が $`\mathrm{Ideal}(X, Y)`$ に属するなら、$`R(X, Y)`$ に属さないので、どのプロトコルの応答関数でもない（定数の列の極限はそのプロトコルの応答関数自身で、$`\mathrm{Scl}(X, Y)`$ は $`R(X, Y)`$ を含む。PR #69 のレビュー）。
2. **（尽くす側）**（(1) と (2a) は、実無限の列を量化する $`\mathrm{Scl}(X, Y)`$ についての数学的な命題で、物理的な存在は述べない。第 37 回に、物理学の実践で $`ℝ`$ を使うことを認めたのと同じ扱いである。物理的な主張は (2b) で述べる。第 47 回）
   - (2a)（数学的な形）$`B_1(X, \mathrm{Prob}(K)) ⊆ \mathrm{Scl}(X, Y)`$。すなわち、ベール第 1 級の写像 $`q : X → \mathrm{Prob}(K)`$ は、どれも $`R(X, Y)`$ の列の極限として得られる。(1) と合わせて $`\mathrm{Scl}(X, Y) = B_1(X, \mathrm{Prob}(K))`$ となる。これは、プロトコルの存在を述べない、写像の全体についての主張である。
   - (2b)（プロトコルについての形）実効的なベール第 1 級の写像（実効的に $`Σ^0_2`$ 可測な写像）$`q : X → \mathrm{Prob}(K)`$ のうち、各設定で $`λ`$ について密度を持つ計算可能な連続な写像 $`q_k : X → \mathrm{Prob}(Y)`$ の、一様に計算可能な列の各点極限（$`ι ∘ q_k → q`$）として表せるものは、$`\mathrm{Scl}_{\mathrm{eff}}(X, Y)`$ に属する。ここで、[C-0018](C-0018.md) を構成的な形（近似するプロトコルの記述を、近似したい応答の計算の手順と精度から、計算で求める手順がある）で仮定し、$`X`$ が実効的に与えられたコンパクト集合の増大列 $`C_k`$ で覆われるとする（$`C_k`$ の上で $`q_k`$ に $`1/k`$ 以内で近いプロトコルの記述を、その手順で計算する。列は計算されるので、選択公理は要らない）。逆向きの包含（$`\mathrm{Scl}_{\mathrm{eff}}`$ の元が実効的なベール第 1 級であること）は、今の定義からは従わない。$`M`$ が計算するのは記述だけで、応答は計算可能とは限らない（例：一定のプロトコルに、極限計算可能でない確率の二値の応答が対応すれば、その定数列の極限は実効的なベール第 1 級でない。PR #69 のレビュー）。逆向きを述べるには、使う応答が一様に計算可能であるなどの条件を加える（下の詳細化の論点）。

例えば、$`Y = \{0, 1\}`$ で、閾値の応答 $`q(1 \mid x) = 𝟙_{x ≥ 0}`$ はベール第 1 級で、計算可能な連続な写像の一様に計算可能な列（シグモイドの列 $`s(kx)`$ の極限は $`x = 0`$ で $`1/2`$ になるが、$`s(kx + \sqrt{k})`$ のように中心をずらした列を使えば、$`x = 0`$ で 1、$`x < 0`$ で 0 になる）の極限なので、(2b) で得られる（この列は計算可能な収束のモジュラスを持たない）。$`q(1 \mid x) = 𝟙_ℚ(x)`$ はベール第 1 級でないので、(1) によって得られない。連続体の成分では、極限は $`K`$ の点の δ 分布（雑音のない針の読み）も含み得る。

## 詳細化の論点

- 収束の意味：各設定ごとの、結果の確率測度の弱収束に指定した。一様収束では、連続な応答の極限は連続なので、閾値の応答は得られない（第 45 回。PR #62 のレビュー）。閾値を除いた領域での一様収束など、別の収束も比べるか。
- 以下は、第 46 回に [Q-0007](../questions/Q-0007.md) と A-0017 から [T-0032](../tasks/T-0032.md) に仮置きし、第 47 回にこの予想に移した論点である（本文は移す前のまま）。
- 極限で表せる不連続な応答の範囲（A-0017 の未解決の点から。第 33 回。PR #42 のレビューの詳細化の論点）：連続な応答関数の設定ごとの極限として得られる不連続な応答は限られる。例えば $`X = [0, 1]`$、$`Y = \{0, 1\}`$ で $`p(1 \mid x) = 𝟙_{ℚ}(x)`$ は、連続関数の各点極限（ベール第 1 級の関数）にならないので、極限としても得られない。どの不連続な模型を極限として扱いたいかと、それで足りるかを確かめる。
- 理想化した極限のための結果の空間の拡張（第 33 回。PR #42 のレビューの詳細化の論点）：$`C_{π,a}`$ が開集合だと、境界の δ 分布は $`\mathrm{Prob}(Y_π)`$ の中の弱極限にならない（例：$`(0, 1)`$ の上の密度 $`n\,𝟙_{(0, 1/n)}`$ は、ℝ の上では $`δ_0`$ に弱収束するが、$`\mathrm{Prob}((0, 1))`$ では弱極限を持たない）。理想化の際に結果の空間を（閉包などへ）拡張する条件を決める。
- どの点の δ 分布まで理想化として必要か（第 33 回。PR #42 のレビューの詳細化の論点）：$`C_{π,a}`$ がルベーグ測度 0 の孤立点を含むと（例：$`C = [0, 1] ∪ \{2\}`$）、密度を持つ分布はその点に質量を持たず、$`𝟙_{\{2\}}`$ が $`C`$ の上で連続なので、$`δ_2`$ に弱収束できない。すべての点の δ 分布を対象にするなら、参照測度の台と $`C_{π,a}`$ の関係（例：$`C_{π,a}`$ を開集合の閉包に限る）も決める。
- 境界の設定値の扱い（第 44 回。PR #60 のレビューの詳細化の論点）：[A-0005](../assumptions/A-0005.md) は予算の値域が閉じていることを求めないので、設定の列が範囲の境界（$`X_π`$ の外）へ近づくことがある。この極限は、[A-0017](../assumptions/A-0017.md) の極限（共通の空間の各設定を固定した、応答関数の列の弱極限）とは別の操作である。境界の設定値を、理想化した模型の設定として含めるために、設定の空間の拡張や写像を定めるかを、理想化の前後で比べる事象とあわせて決める。
- 列の取り方：極限を考える列は、設定の空間と結果の空間が共通のものに限る（空間の違う列を写す方法は [Q-0008](../questions/Q-0008.md)。層 4 で決める）。実際の実験は全体で有限個（[A-0001](../assumptions/A-0001.md)）なので、無限の列には延長の実験の応答関数が要る（[T-0029](../tasks/T-0029.md)・[T-0031](../tasks/T-0031.md)）。主張は、応答関数の列が与えられた後の数学的な主張として述べた。
- 極限の統計を可能な装置で実現できるか（A-0017 の未解決の点。[T-0010](../tasks/T-0010.md)）とは区別する。
- 実無限と有限の立場（第 47 回。ユーザーの指摘）：$`\mathrm{Scl}(X, Y)`$ の定義の「$`∃ (p_k)_{k ∈ ℕ}`$」は、完結した無限の列（実無限）を量化しており、A-0001 の有限の立場（実際の実験は有限個で、主張は有限の場合と $`N → ∞`$ の漸近（可能的無限）に限る）の外にある。また、(2b) を C-0018 の存在の形から示すと、各 $`k`$ のプロトコルを選ぶのに可算選択公理が要る。存在が選択公理でしか保証されない列は、それを作る手順を持たないので、物理的に存在するとは見なせない。そこで、物理的な主張は、有限の機械 $`M`$ で生成される列の $`\mathrm{Scl}_{\mathrm{eff}}`$ について述べ（(2b)）、$`\mathrm{Scl}`$ は数学的な道具として残す（(1)・(2a)）。極限 $`q`$ そのものは、どちらの場合も物理的に存在する装置の応答ではなく、理想化（可能な実験の候補）である。
- 収束のモジュラス（第 47 回。ユーザーの問い）：近似する応答が一様に計算可能なとき、モジュラスの計算可能性を求めると、極限は計算可能になり（応答の一様な計算可能性がなければ、この結論は出ない。計算可能でない定数の応答の定数列は計算可能なモジュラスを持つが、極限は計算可能でない。PR #69 のレビュー）、計算可能解析（TTE）の基本定理（計算可能な関数は連続）によって連続になる。したがって、理想化した応答は得られない。逆に、計算可能な列の各点極限が不連続なら、その列は計算可能なモジュラスを持たない（古典的には、各点収束する列には $`x`$ と $`ε`$ に十分大きな $`k`$ を対応させるモジュラスの関数がいつでもあるが、極限が不連続なら、それは $`x`$ について不連続で、計算できない）。TTE は「計算可能な列なら計算可能なモジュラスを持つ」を導かず、むしろ極限の操作 $`\lim`$ は計算できない操作の代表である（ワイラウフの還元の理論）。ヘヴィサイド関数（閾値の関数）は $`\lim`$ で計算できる、極限計算可能な関数の典型例である。物理的な読み：モジュラスがないことは、どの有限の段階でも、極限にどれだけ近づいたかを記録から精度つきで保証できないことに当たり、理想化した応答が実際の実験の応答ではない（極限としての候補にとどまる）ことの計算論的な表現になる（Claude の見立て）。
- 極限計算可能性と実効的なベール第 1 級（(2b) の主張の形）：極限計算可能な関数は、実効的に $`Σ^0_2`$ 可測な関数と一致する、という結果がある（Brattka の実効的なボレル可測性の研究。Claude の記憶によるもので、文献で確かめる）。(2b) で得られる $`q`$ は、任意のベール第 1 級の写像（(2a)）より狭い。両者の差を確かめる。
- A-0018 の多項式時間の制約：延長のプロトコルの記述は多項式時間で列挙する必要があるが、計算に時間がかかる場合は、次のプロトコルが計算されるまで同じプロトコルを繰り返せば列挙を遅らせられ、繰り返しを含む列の極限は元の列の極限と同じなので、極限の範囲は狭まらない見込みである（Claude の見立て）。資源の増え方の制約（A-0018 の 2）との関係は別に確かめる。
- (2b) の逆向きの包含と応答の計算可能性（PR #69 のレビュー）：$`\mathrm{Scl}_{\mathrm{eff}}`$ を実効的なベール第 1 級の写像の全体と一致させるには、列の応答 $`p_{π_k}`$ が一様に計算可能である（あるいは計算可能な写像に、$`k`$ について一様な精度で近い）ことを、定義か仮定に加える必要がある。その条件を置くか、置くなら $`\mathrm{Scl}_{\mathrm{eff}}`$ の定義に入れるかを決める。
- 値の空間の違い（PR #69 のレビュー）：C-0018 が近似するのは、各設定で密度を持つ $`\mathrm{Prob}(Y)`$ に値をとる応答で、(2b) の極限 $`q`$ は $`\mathrm{Prob}(K)`$ に値をとる。(2b) は、近似の列 $`q_k`$ を $`\mathrm{Prob}(Y)`$ に値をとる密度つきの写像に限って述べた。$`\mathrm{Prob}(K)`$ の計算可能な測度（境界の δ 分布など）を、密度つきの $`\mathrm{Prob}(Y)`$ の測度で実効的に近似する補題を置けば、(2b) を $`\mathrm{Prob}(K)`$ に値をとる計算可能な写像の列から述べられる。
- 実効的なコンパクト被覆（PR #69 のレビューの詳細化の論点）：(2b) の構成には、$`X`$ の σ コンパクト性だけでなく、実効的に与えられたコンパクト被覆が要る。C-0018 の「コンパクト集合の記述」の表現と合わせて決める。
- A-0018 の制約の判定（PR #69 のレビューの詳細化の論点）：$`\mathrm{Scl}_{\mathrm{eff}}`$ の「A-0018 の制約を満たす機械」を、プロトコルの記述を出す機械だけで判定するのか、A-0018 の資源の累積量 $`R(N)`$ を持つ実験の延長まで含めて判定するのかを、A-0018 と [T-0031](../tasks/T-0031.md)・[T-0029](../tasks/T-0029.md) の詳細化で決める。
- 極限が連続になる物理的な前提（第 47 回。択一の組の候補）：TTE からは出ないが、「すべてのプロトコルに共通の雑音の下限がある（すべての応答関数が、プロトコルによらない同じ度合いで連続である。同程度連続性）」という前提を置けば、同程度連続な関数の列の各点極限は設定について連続なので、閾値の応答のような設定について不連続な応答は、極限としても近似できない。ただし、$`\mathrm{Ideal}(X, Y)`$ が空になるわけではない（例：$`X = [0, 1]`$、$`Y = [0, 1]`$ で、設定に依存しない密度 $`k\,𝟙_{(0, 1/k)}`$ の応答の列は同程度連続だが、極限の $`δ_0`$ は密度を持たず $`R(X, Y)`$ に属さない。PR #69 のレビュー）。特異な測度（δ 分布など）の極限まで除くには、別の条件が要る。根拠の候補は、熱雑音、量子的な揺らぎ（読みの精度の限界）、資源の上限による精度の限界である。今の体系は、[A-0006](../assumptions/A-0006.md) の注意の 2 で同程度連続性を課さず、[A-0005](../assumptions/A-0005.md)・A-0018 でもプロトコルをまたぐ資源の共通の上界を置かない（第 44 回）ので、理想化はあり得る。この前提を置く体系と置かない体系を、択一の組の候補とした（[assumptions/README.md](../assumptions/README.md) の「択一の組の候補」。ユーザーの判断）。「閾値の装置は、極限としても物理的に意味のある理想化なのか、純粋に数学的な虚構なのか」は、前提ではなく問いとして扱う。
- (2b) の σ コンパクト性：$`X`$ が σ コンパクトでないと、コンパクト集合の増大列で $`X`$ を覆えず、各設定での収束を保証できない。D-0003 の設定の空間で σ コンパクト性を仮定してよいか（閉集合や開集合なら成り立つ）。
