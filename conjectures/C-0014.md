## 目的

理想化した応答（設定について不連続な閾値の応答など）を、前提で保証するのではなく、実際の実験の応答関数の列の極限として得られるかを確かめる（[T-0032](../tasks/T-0032.md) の方針の 2。第 46 回に [A-0017](../assumptions/A-0017.md)・[A-0006](../assumptions/A-0006.md) から「理想化を極限として扱えるようにする」書き方を外した）。成り立てば、極限として得られる応答の範囲が、前提を置かずに特定され、扱うべき物理モデル（閾値の装置など）が扱えることと、扱えない模型（$`𝟙_ℚ`$ のような応答）がどれかが分かる。成り立たなければ、前提を見直す材料になる。

## 完了の条件

先に、下の詳細化の論点のうち、結果の空間の拡張（$`K_π`$ の取り方）と、極限を取る列の取り方（共通の空間を持つ列、延長の実験）を決める。検証の形は紙の証明とする。主張の (1) は、距離化可能な空間の間の各点極限についての古典的な結果（ルベーグ–ハウスドルフの定理の型）を当てはめる形で、(2a) は、ベール第 1 級の写像を連続な写像の各点極限として表す定理を、密度を持つ統計に値をとる連続な写像で近似できるように延ばす形で示す。(2b) は、C-0018 を仮定した紙の証明とする。文献の定理を使う場合は、仮定（値の空間の凸性・可分性など）が満たされることを確かめる。

## 主張

標準の意味論（[A-0017](../assumptions/A-0017.md) の位相。第 46 回）で、設定の空間 $`X ⊆ ℝ^n`$（[D-0003](../definitions/D-0003.md)）と結果の空間 $`Y`$（A-0017 の形）を固定する。結果の空間は、集合としてだけでなく、成分への分解 $`Y = ⨆_{a ∈ F} C_a`$ と各成分の次元 $`m_a`$ まで含めて固定する。A-0017 の参照測度は、この分解で決まる（各成分の上の $`m_a`$ 次元のルベーグ測度の直和）ので、分解まで共通なら、参照測度 $`λ`$ も共通になる（第 47 回。参照測度はプロトコルが結果の空間をどう指定するかに依存するので、集合 $`Y`$ だけでは決まらない）。$`λ`$ の台の、各成分の $`ℝ^{m_a}`$ の中での閉包の直和を $`K`$ とし、密度を持つ統計を $`K`$ の上の確率測度とみなす。

この $`X`$・$`Y`$ を設定と結果の空間に持つプロトコルの列 $`(π_k)`$ と、その応答関数（[D-0004](../definitions/D-0004.md)）の列 $`p_k := p_{π_k}`$ を考える。各 $`p_k`$ は [A-0006](../assumptions/A-0006.md)（弱位相についての連続性）と A-0017（密度）を満たすとする。プロトコルを一つに固定すると応答関数は一つなので、極限を考えるには、プロトコルを取り替える列が要る（第 47 回）。

1. **（含まれる側）** 列 $`p_k`$ が、各設定 $`x`$ で $`\mathrm{Prob}(K)`$ の弱位相について収束するとき、極限 $`q : X → \mathrm{Prob}(K)`$ はベール第 1 級（開集合の逆像が $`F_σ`$ 集合）の写像である。$`q`$ は列 $`(π_k)`$ によって決まり（異なる列が同じ $`q`$ を与えることもある）、どのプロトコルの応答関数でもない。
2. **（尽くす側）**
   - (2a)（数学的な形）ベール第 1 級の写像 $`q : X → \mathrm{Prob}(K)`$ は、どれも、各設定で $`λ`$ について密度を持つ連続な写像 $`X → \mathrm{Prob}(Y)`$ の列の、各設定での弱収束の極限として得られる。これは、プロトコルの存在を述べない、写像の全体についての主張である。
   - (2b)（プロトコルについての形）[C-0018](C-0018.md)（計算可能な連続な応答は、延長で使えるプロトコルの応答で近似できる）を仮定し、$`X`$ が σ コンパクトであるとする。このとき、各設定で密度を持つ計算可能な連続な写像の列 $`q_k`$ の各設定での弱収束の極限 $`q`$ は、延長で使えるプロトコルの列 $`(π_k)`$ の応答関数 $`p_{π_k}`$ の、各設定での弱収束の極限として得られる（$`X`$ を覆うコンパクト集合の増大列 $`C_k`$ をとり、$`C_k`$ の上で $`q_k`$ に $`1/k`$ 以内で近い $`p_{π_k}`$ を C-0018 で選ぶ）。

例えば、$`Y = \{0, 1\}`$ で、閾値の応答 $`q(1 \mid x) = 𝟙_{x ≥ 0}`$ はベール第 1 級で、計算可能な連続な写像の列（シグモイドの列 $`s(kx)`$ の極限は $`x = 0`$ で $`1/2`$ になるが、$`s(kx + \sqrt{k})`$ のように中心をずらした列を使えば、$`x = 0`$ で 1、$`x < 0`$ で 0 になる）の極限なので、(2b) で得られる。$`q(1 \mid x) = 𝟙_ℚ(x)`$ はベール第 1 級でないので、(1) によって得られない。連続体の成分では、極限は $`K`$ の点の δ 分布（雑音のない針の読み）も含み得る。

## 詳細化の論点

- 収束の意味：各設定ごとの、結果の確率測度の弱収束に指定した。一様収束では、連続な応答の極限は連続なので、閾値の応答は得られない（第 45 回。PR #62 のレビュー）。閾値を除いた領域での一様収束など、別の収束も比べるか。
- 以下は、第 46 回に [Q-0007](../questions/Q-0007.md) と A-0017 から [T-0032](../tasks/T-0032.md) に仮置きし、第 47 回にこの予想に移した論点である（本文は移す前のまま）。
- 極限で表せる不連続な応答の範囲（A-0017 の未解決の点から。第 33 回。PR #42 のレビューの詳細化の論点）：連続な応答関数の設定ごとの極限として得られる不連続な応答は限られる。例えば $`X = [0, 1]`$、$`Y = \{0, 1\}`$ で $`p(1 \mid x) = 𝟙_{ℚ}(x)`$ は、連続関数の各点極限（ベール第 1 級の関数）にならないので、極限としても得られない。どの不連続な模型を極限として扱いたいかと、それで足りるかを確かめる。
- 理想化した極限のための結果の空間の拡張（第 33 回。PR #42 のレビューの詳細化の論点）：$`C_{π,a}`$ が開集合だと、境界の δ 分布は $`\mathrm{Prob}(Y_π)`$ の中の弱極限にならない（例：$`(0, 1)`$ の上の密度 $`n\,𝟙_{(0, 1/n)}`$ は、ℝ の上では $`δ_0`$ に弱収束するが、$`\mathrm{Prob}((0, 1))`$ では弱極限を持たない）。理想化の際に結果の空間を（閉包などへ）拡張する条件を決める。
- どの点の δ 分布まで理想化として必要か（第 33 回。PR #42 のレビューの詳細化の論点）：$`C_{π,a}`$ がルベーグ測度 0 の孤立点を含むと（例：$`C = [0, 1] ∪ \{2\}`$）、密度を持つ分布はその点に質量を持たず、$`𝟙_{\{2\}}`$ が $`C`$ の上で連続なので、$`δ_2`$ に弱収束できない。すべての点の δ 分布を対象にするなら、参照測度の台と $`C_{π,a}`$ の関係（例：$`C_{π,a}`$ を開集合の閉包に限る）も決める。
- 境界の設定値の扱い（第 44 回。PR #60 のレビューの詳細化の論点）：[A-0005](../assumptions/A-0005.md) は予算の値域が閉じていることを求めないので、設定の列が範囲の境界（$`X_π`$ の外）へ近づくことがある。この極限は、[A-0017](../assumptions/A-0017.md) の極限（共通の空間の各設定を固定した、応答関数の列の弱極限）とは別の操作である。境界の設定値を、理想化した模型の設定として含めるために、設定の空間の拡張や写像を定めるかを、理想化の前後で比べる事象とあわせて決める。
- 列の取り方：極限を考える列は、設定の空間と結果の空間が共通のものに限る（空間の違う列を写す方法は [Q-0008](../questions/Q-0008.md)。層 4 で決める）。実際の実験は全体で有限個（[A-0001](../assumptions/A-0001.md)）なので、無限の列には延長の実験の応答関数が要る（[T-0029](../tasks/T-0029.md)・[T-0031](../tasks/T-0031.md)）。主張は、応答関数の列が与えられた後の数学的な主張として述べた。
- 極限の統計を可能な装置で実現できるか（A-0017 の未解決の点。[T-0010](../tasks/T-0010.md)）とは区別する。
- (2a) と (2b) の範囲の差（第 47 回）：延長の列 $`(π_k)`$ は [A-0018](../assumptions/A-0018.md) の制約（プロトコルの記述を多項式時間で列挙できること）を満たす必要があるので、(2b) で得られる $`q`$ は、計算可能な写像の、実効的な列の極限（計算可能解析の極限計算可能性に当たるもの）に限られる見込みで、任意のベール第 1 級の写像（(2a)）より狭い可能性がある。両者の差と、A-0018 の下で (2b) の列 $`q_k`$ に要る一様な計算可能性を確かめる。
- (2b) の σ コンパクト性：$`X`$ が σ コンパクトでないと、コンパクト集合の増大列で $`X`$ を覆えず、各設定での収束を保証できない。D-0003 の設定の空間で σ コンパクト性を仮定してよいか（閉集合や開集合なら成り立つ）。

## 背景

第 45 回のユーザーの問題提起（実験の層の前提に、理想の物理モデルを扱えるようにするための前提が混ざっており、結論を先取りしやすい）を受けて、第 46 回に A-0017・A-0006 から理想化の保証を外し、理想化の再現を予想として確かめることにした（T-0032）。第 47 回に、Claude の案（4 件）をユーザーが了承して登録した。

## 評価の根拠

- 確度：高。(1) は、距離化可能な空間から距離化可能な空間への連続写像の各点極限がベール第 1 級であるという古典的な結果の当てはめである（Claude の記憶による。文献で確かめる）。(2) も、値の空間が凸な場合の古典的な結果に近いが、近似する応答に A-0017 の密度の条件を課すので、確かめが要る。
- 重要度：中。前提から外した理想化を、どこまで取り戻せるかを示す。点なしの見方の中心の問いは [C-0015](C-0015.md) の側にある。
- 検証費用：中。結果の空間が有限集合なら、ほぼ古典的な結果のままである。連続体の成分と $`K`$ の取り方に手間がかかる。

## 検証の方針

結果の空間が有限集合の場合から始め（$`\mathrm{Prob}(Y)`$ は単体で、古典的な結果がそのまま使える見込み）、連続体の成分に広げる。(2) では、ベール第 1 級の写像を連続な写像の各点極限で表したうえで、各段階の統計を小さな雑音で畳み込んで密度を持たせ、雑音を 0 に近づける。文献（ルベーグ–ハウスドルフの定理、ベールの関数の分類）を確かめる。
