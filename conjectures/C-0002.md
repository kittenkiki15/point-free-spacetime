## 主張

第 08 回の調査メモの 1.4 節（作業上の定義の改訂案）の枠組みで考える。

- 有限な実験の族の $`n`$ 番目までのデータによる事後分布を $`P_n`$ とする。$`P_n`$ は、推定の対象（状態の空間など）である空間 $`S`$ の上の確率分布（ボレル確率測度）である。$`S`$ を空間的でないロケールとする場合は、$`P_n`$ として正規化された付値（valuation。開要素に 0 以上 1 以下の値を割り当て、$`P_n(⊥) = 0`$、$`P_n(⊤) = 1`$ を満たし、単調で、有限の交わりと結びについてのモジュラー則 $`P_n(U ∧ V) + P_n(U ∨ V) = P_n(U) + P_n(V)`$ を満たし、有向な結びと交換するもの。$`P_n(⊥) = 0`$ がないと $`F`$ が空要素を含んでフィルターにならない。モジュラー則から $`P_n(U ∧ V) ≥ P_n(U) + P_n(V) - 1`$ が従うので、フィルターの議論はロケールでも成り立つ）を採る案がある。その場合の定義と必要な性質は、主張 2 の検討課題とする（PR のレビューの指摘）。
- $`S`$ の開集合 $`U`$ のうち、$`P_n(U) → 1`$ となるものの全体を $`F`$ とする。
- $`P_n(U ∩ V) ≥ P_n(U) + P_n(V) - 1`$ なので、$`F`$ は有限の交わりで閉じ、上にも閉じたフィルターである。

$`F`$ が完全素フィルター（任意の結び $`⋁_i U_i`$ が $`F`$ に属すれば、ある $`U_i`$ が $`F`$ に属する）であるとき、$`F`$ はロケールの点を定める。これを「族の極限が点に収束する」ことの点なしの言い方の一つとする。

以下の「点にならない」は、この $`F`$ についての意味（$`F`$ が完全素にならない）に限る。ほかの収束の概念では点に収束することがある（PR のレビューの指摘）。たとえば下の Dieudonné 測度 $`μ`$ を一定の列 $`P_n = μ`$ とすると、$`F`$ は完全素でないが、$`[0, ω_1]`$ の上の連続関数 $`f`$ は $`ω_1`$ の手前で最終的に $`f(ω_1)`$ に等しいので $`∫ f\,dμ = f(ω_1)`$ となり、連続関数による弱収束の意味では $`δ_{ω_1}`$ に収束する。どの収束の概念で観測を定めるかは、第 08 回の調査メモの 1.4 節 (3) のとおり未解決である。

$`S`$ を状態の空間とするなら、$`F`$ が完全素のときに定まるのは状態の点で、以下の主張はまず**状態推定の極限**についての主張である。それが族の極限に対応する観測（第 08 回の調査メモの $`𝒪`$ の元）の何に当たるかは、観測量も含めた空間と対応を定義するまで未指定で、橋渡しは今後の課題とする（PR のレビューの指摘）。

主張は次のとおりである。

1. **（素であること）** 族が**確定的**である、つまりすべての開集合 $`U`$ について $`P_n(U)`$ が 0 か 1 に収束するなら、$`F`$ は素フィルターである（$`U ∪ V ∈ F`$ なら $`U ∈ F`$ または $`V ∈ F`$）。
2. **（点にならない例）** 確定的な族でも、$`F`$ が完全素にならず、点を定めない例がある。
   - 正則でない（τ 加法的でない）測度を許せば、例はすでにある（PR のレビューの指摘）。下の Dieudonné 測度を $`S = [0, ω_1)`$ に制限して $`P_n = μ`$ とすると、族は確定的である。$`S = ⋃_{α < ω_1} [0, α)`$ だが、各 $`[0, α)`$ の測度は 0 なので、$`F`$ は完全素でない。主張 3 の後に挙げる $`[0, ω_1]`$ の例も、正則でない測度による例である。
   - ハウスドルフでない空間では、τ 加法的な測度でも例がある（第 09 回の PR の対応中に Claude が構成した）。$`S = [0, 1)`$ に、開集合を $`[0, a)`$（$`0 ≤ a ≤ 1`$）だけとする位相を入れる。この空間は $`T_0`$ でソバーだが（空でない閉集合 $`[a, 1)`$ は点 $`a`$ の閉包）、ハウスドルフでもコンパクトでもない。
     - 固定した事前分布からの事後分布の例：事前分布を、点 $`θ_k = 1 - 1/k`$（$`k ≥ 2`$）に正の重み $`w_k`$ を置く離散分布とする。観測モデルを「成功確率 $`θ`$ の試行」とし、データが $`n`$ 回続けて成功だったとする。事後分布は $`P_n(\{θ_k\}) ∝ w_k θ_k^{\,n}`$ となる（離散分布なので τ 加法的）。$`a < 1`$ を固定し、$`θ_K ≥ a`$ となる $`K`$ を取ると、$`[0, a)`$ に入る $`θ_k`$ はすべて $`θ_k < θ_K`$ を満たす。$`M > K`$ について $`P_n([0, a)) ≤ θ_K^{\,n} / (w_M θ_M^{\,n}) → 0`$（$`n → ∞`$）である。一方 $`P_n([0, 1)) = 1`$ である。したがって族は確定的で、$`F = \{[0, 1)\}`$ となる。$`[0, 1) = ⋃_{a < 1} [0, a)`$ のどの $`[0, a)`$ も $`F`$ に属さないので、$`F`$ は完全素でない。
     - 解釈（見立て）：データが示す「真の値」$`θ = 1`$ がモデルの空間 $`S`$ に含まれない場合（モデルの誤指定）に当たる。事後分布は $`S`$ の「端」へ逃げ、点としての極限を持たない。
     - はじめに挙げた点に集中した分布の列 $`P_n = δ_{1 - 1/n}`$ は、確率測度の列としては同じ現象を示すが、固定した事前分布からの事後分布にはなれない（ベイズ更新の事後分布は、前の事後分布に対して絶対連続である。PR のレビューの指摘）。そのため、上の事後分布の例に置き換えた。
   - 残る問いは三つある。
     - ハウスドルフ空間の上の Radon 測度で例があるか（下の主張 3 は、ないと見込む）。
     - $`S`$ が空間的でないロケールの場合（$`P_n`$ を付値とする。定義は検討課題）。
     - 確定性の条件を弱めた場合（基本開集合だけについて確定的とする、など）。
3. **（点になる条件）** $`S`$ がハウスドルフ空間で、各 $`P_n`$ が Radon 測度（コンパクト集合で内側から近似できる、τ 加法的な測度）なら、確定的な族の $`F`$ は完全素で、点を定める。空間のコンパクト性は要らない見込みである。
   - 第 09 回の PR のレビューで、次の議論が示された。$`U = ⋃_i U_i ∈ F`$ で、どの $`U_i`$ も $`F`$ に属さない（確定性から $`P_n(U_i) → 0`$）とする。τ 加法性から、$`U_i`$ を可算個に絞って並べ、最初の $`k`$ 個の和を $`V_k`$ とすると、各 $`n`$ で $`P_n(V_k) → P_n(U)`$（$`k → ∞`$）、各 $`k`$ で $`P_n(V_k) → 0`$（$`n → ∞`$）となる。そこで $`n_j`$ と $`k_j`$ を交互に選び、ブロックごとの和を偶数番目だけ集めた開集合 $`W`$ の確率が振動することを示して、確定性に反すると結論する。
   - ただし、この議論には穴がある（Claude の確認）。ブロックの和は開集合どうしの和なので、互いに重なりうる。ある $`P_{n_j}`$ の確率を担うブロック以外のブロックが、重なりによって同じ確率を拾うことがあり、$`W`$ の確率が振動するとは限らない。実際、主張 2 のハウスドルフでない例では、$`U_i`$ が増大列で互いに大きく重なり、結論が成り立たない。
   - ハウスドルフ空間の上の Radon 測度なら、各ブロックの確率を担うコンパクト集合を取り、それらを互いに交わらない開集合で分離して $`W`$ を作れば、議論が通る見込みである（見立て）。ただし、ハウスドルフ性だけでは、可算個のコンパクト集合を一斉に互いに交わらない開集合で分離できるとは限らない（たとえば $`[0, 1]`$ の $`\{0\}`$ と $`\{1/j\}`$）。コンパクト集合の選び方で、必要な分離と各 $`P_{n_j}`$ の確率の制御を同時に保証する手順は、未確立の課題である（PR のレビューの指摘）。
   - ソバー空間（ハウスドルフ空間はソバー）では、開集合の完全素フィルターは点と一対一に対応するので、$`F`$ は点を定める。
   - 正則性（τ 加法性）の条件は外せない（PR のレビューの指摘）。$`S = [0, ω_1]`$（最初の非可算順序数までの順序位相。コンパクト・ハウスドルフ）の上の Dieudonné 測度 $`μ`$（ボレル集合が $`ω_1`$ の中の閉非有界集合を含めば 1、そうでなければ 0）を取り、$`P_n = μ`$ とすると、族は確定的である。しかし、開集合 $`[0, ω_1)`$ は $`F`$ に属するのに、それを覆う $`[0, α)`$（$`α < ω_1`$）はどれも $`F`$ に属さない。この測度は τ 加法的でない。

主張 1 は下の「背景」に示す短い議論で成り立つと見込まれる。主張 2 は、ハウスドルフでない空間の例で成り立つ（例の確認は簡単だが、改めて検証する）。主張 3（ハウスドルフ空間の上の Radon 測度の場合）と、主張 2 の残る問いが検証の対象である。

## 背景

第 09 回に、ユーザーから作業上の定義についての提案があった。

- 有限な実験に確率分布を対応させる（ベイズ推定の描像）。
- 有限な実験の族の極限で、分布が適当な意味で「一点」に収束する。その点が、族の極限に対応する観測である。

Claude は、この収束を点なしの言い方にすると上の $`F`$ になり、$`F`$ が完全素でない場合がありうると補足した。ユーザーの合意を得て、予想として登録した（調査メモの 1.4 節の (3)）。

確定性の条件は、自明な場合を除くために置く。分布が集中しない族（たとえば $`S = [0, 1]`$ の上で $`P_n`$ がずっと一様分布のまま）では、$`[0, 1]`$ を確率が 1 未満の小さな区間の和で覆えるので、$`F`$ は自明に完全素でない。これは「推定が終わらない」場合で、ここで問いたい「極限が点にならない」場合とは区別する。

主張 1 の根拠は次のとおりである。$`U ∪ V ∈ F`$ で、$`U`$ と $`V`$ がどちらも $`F`$ に属さないとする。確定性から $`P_n(U) → 0`$、$`P_n(V) → 0`$ となり、$`P_n(U ∪ V) ≤ P_n(U) + P_n(V) → 0`$ となって矛盾する。

登録時には、主張 2 の候補として次の見込みを挙げていた（見立て。この族は確定的でなく、主張 2 の例にはならない）。$`S = [0, 1)`$ の上で $`P_n`$ を $`1 - 1/n`$ に集中した分布とすると、$`(1 - ε, 1)`$ の形の開集合はすべて $`F`$ に属する。一方、$`S = ⋃_{k ≥ 2} [0, 1 - 1/k)`$（$`[0, 1 - 1/k)`$ は $`S`$ の相対位相で開集合）と覆ったとき、どの $`[0, 1 - 1/k)`$ も $`F`$ に属さない。ただし、この族はすべての開集合について確定的とは限らない。たとえば、$`1 - 1/n`$ の形の点を一つおきに含む開集合では、確率が振動する。そのため、確定性の条件の置き方を含めて検討が要る。

さらに、すべての開集合について確定的という条件は、かなり強い（見立て）。たとえば距離空間で、点に集中した分布 $`P_n = δ_{x_n}`$ の族を考え、点 $`x_n`$ が互いに異なり、ある点 $`x`$ に収束するとする。このとき、$`x_n`$ を一つおきに含む開集合（各点の小さな近傍の和）を作れるので、族は確定的でない。確定的になるのは、点の列が最終的に一定になる場合などに限られそうである。確定性の条件を、基本開集合だけについて課すなど、弱めた形を検討する必要がある。

## 評価の根拠

- **確度：中。**
  - 第 09 回の PR のレビューと対応を経て、見込みが変わった。主張 2 は、正則でない測度の例と、ハウスドルフでない空間の例で成り立つ。主張 3 は、ハウスドルフ空間の上の Radon 測度について、コンパクト性なしに成り立つ見込みである（分離を使った議論の検証は今後）。
  - 確定性の条件はかなり強く、その置き方で主張 2・3 の成否が変わる。
- **重要度：中。**
  - 成り立てば、点なしの空間で観測を扱う動機の一つ（「極限が点にならない観測がある」）を、作業上の定義から直接に与える。
  - 主張 3 の見込みの修正により、「点になること」に効くのはコンパクト性ではなく、空間の分離性（ハウスドルフ性）、測度の正則性（τ 加法性）、確定性の条件だと分かった。因果構造などから作る時空の位相は、ハウスドルフでないことが多いので、主張 2 のハウスドルフでない例は、点なしの時空の議論に直接関わる可能性がある（見立て）。実験パラメータの値域のコンパクト性（第 09 回のユーザーの提案）との結び付きは、登録時に考えたほど直接ではない（状態の空間 $`S`$ と $`X`$ の対応も未指定である）。
- **検証費用：中。** 主張 1〜3 は、測度論と点なし位相（ロケールの上の測度・付値）の既知の結果の組み合わせで示せる見込みである。文献の確認と、確定性の条件の調整が要る。

1. 主張 1 を自然言語で証明し、確定性の条件の定義を固める（開集合全体について確定的とするか、基本開集合についてだけ確定的とするか）。
2. 主張 3 の議論（τ 加法性、コンパクト集合の分離、対角線論法）を詳しく書き、検証する。主張 2 のハウスドルフでない例も改めて検証する。必要なら Lean で形式化する。
3. 主張 2 の残る問い（空間的でないロケール、確定性の条件を弱めた場合）を検討する。どれを先に進めるかは、ユーザーと相談する。ロケールの上の付値の文献を確認する。
4. 物理の側の意味を検討する。たとえば、量子論の状態の空間（無限次元）で、推定の族が点に収束しない例が自然に現れるか。
5. 必要なら、主張 1 などを Lean で形式化する。
