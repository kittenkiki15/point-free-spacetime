## 目的

プロトコルの応答関数の集合が十分に豊富であること（どんな応答を実現する装置が作れるか）を、前提ではなく予想として確かめる（第 47 回のユーザーの提案）。応答関数はプロトコルの記述で自由に決められるものではなく、自然が決めるものなので、豊富さは物理的な主張である。成り立てば、[C-0014](C-0014.md) の (2b)（密度つきの計算可能な写像の、一様に計算可能な列の極限として表せる写像が、有限の機械で生成されるプロトコルの列の極限として得られる）の前提が満たされ、その範囲の理想化を、物理的に作れる装置の言葉で述べられる。任意のベール第 1 級の写像（C-0014 の (2a)）に対する物理的なプロトコルの列は、この予想からは保証されない（PR #69 のレビュー）。

## 完了の条件

先に、下の詳細化の論点のうち、「計算可能」の意味（計算可能解析の、どの表現での計算可能性か）と、装置の構成に使う部品（読みの雑音、計算機、乱数源、出力の雑音）を、どこまで前提にするかを決める。検証の形は、部品の存在を仮定として明記したうえで、近似するプロトコルを構成する紙の証明とする。部品の存在そのものが前提に当たるなら、その前提を置くか（オプショナルの前提とするか）をユーザーと相談する。

## 主張

設定の空間 $`X ⊆ ℝ^n`$（[D-0003](../definitions/D-0003.md)）と結果の空間 $`Y`$（[A-0017](../assumptions/A-0017.md) の形。成分への分解 $`Y = ⨆_{a ∈ F} C_a`$ と各成分の次元 $`m_a`$ まで含めて）を固定する。[A-0001](../assumptions/A-0001.md) の延長で使えるプロトコル（[A-0018](../assumptions/A-0018.md) の制約を満たすもの）のうち、設定と結果の空間がこの $`X`$・$`Y`$ であるものの応答関数（[D-0004](../definitions/D-0004.md)）の全体を $`R_{\mathrm{prot}}(X, Y)`$ とする（[C-0014](C-0014.md) の $`R(X, Y)`$（条件を満たす写像の全体）とは別のもので、実在しうるプロトコルの応答関数だけの集合である。PR #69 のレビュー）。

このとき、計算可能な（計算可能解析の意味で）連続な応答 $`q : X → \mathrm{Prob}(Y)`$ で、各設定で A-0017 の参照測度について密度を持つものは、どれも $`R_{\mathrm{prot}}(X, Y)`$ の元で近似できる。すなわち、任意のコンパクト集合 $`C ⊆ X`$ と $`ε > 0`$ について、$`C`$ の上で、拡張した結果の空間 $`K`$（C-0014 の定義 1）の距離から作る $`\mathrm{Prob}(K)`$ のレヴィ–プロホロフ距離で、$`ι ∘ p_π`$ と $`ι ∘ q`$ の距離が一様に $`ε`$ 以内になる（$`Y`$ の位相を与えるだけの距離では、埋め込み $`ι`$ の後の誤差を抑えられないので、$`K`$ の距離を $`Y`$ に制限したものを使う。例：$`Y = (0, 1) ∪ (2, 3)`$ で境界の 0 と 2 を貼り合わせた距離では、0 の近くと 2 の近くの測度が近いとされるが、$`K`$ ではそれぞれ $`δ_0`$ と $`δ_2`$ に収束する。PR #69 のレビュー）応答関数 $`p_π ∈ R_{\mathrm{prot}}(X, Y)`$ を持つプロトコル $`π`$ がある（延長のプロトコルの応答にも A-0006・A-0017 が当てはまるなら、C-0014 の集合については $`ι ∘ p_π ∈ R(X, Y)`$ である。延長への当てはめは [T-0029](../tasks/T-0029.md)・[T-0031](../tasks/T-0031.md) で決める。PR #69 のレビュー）。さらに、そのプロトコルの記述は、$`q`$ を計算する手順、$`C`$ の記述、$`ε`$ から、計算で求められる（構成的な形。第 47 回。近似の列を、選択公理によらず計算で作れるようにするため。[C-0014](C-0014.md) の (2b)）。

厳密な一致ではなく近似の形にするのは、設定の読みが有限の精度なので、応答を厳密に指定することは求められないためである。

## 詳細化の論点

- 根拠となる構成（Claude の案）：設定 $`x`$ を雑音のある読みとして計算機に取り込み、$`q`$ を計算し、乱数で結果を出し、小さな雑音を加えて密度を持たせるプロトコル。読みの雑音で応答は連続になり、出力の雑音で密度を持つ。雑音を小さくすると $`q`$ に近づく。部品（雑音のある読み、計算機、乱数源、出力の雑音）が装置として使えることを、どこまで前提にするかを決める。
- 乱数源：真の乱数を使うプロトコルの扱い（[C-0004](C-0004.md) の第 38 回の議論）と合わせる。疑似乱数で足りるか。
- 「計算可能」の意味：計算可能解析の表現（実数の名前の与え方）と、$`\mathrm{Prob}(Y)`$ の上の計算可能性の定め方。A-0018 のプロトコルの列挙の条件（多項式時間）と整合させる。C-0014 の (2b) のため、拡張した結果の空間 $`K`$・$`\mathrm{Prob}(K)`$ と埋め込み $`ι`$ の実効的な表現もあわせて決める（PR #69 の第 2 回のレビュー）。
- 近似の位相：コンパクト集合の上の一様な近似で足りるか、$`X`$ 全体での近似を求めるか。
- 物理的なチャーチ–チューリングの提唱の、実験の側の類比である（Claude の見立て）。その方面の議論と比べる。
- 計算可能でない応答や、密度を持たない応答は、この予想の対象外である（後者は A-0017 の外）。

## 背景

第 47 回に、[C-0014](C-0014.md) の (2) を確かめるには、近似に使う応答関数が実際にプロトコルとして存在すること（応答関数の集合の豊富さ）が要る、とユーザーが指摘した。Claude がその豊富さを予想の形にし（実際の実験は有限個なので、延長で使えるプロトコルについて述べる）、ユーザーが優先度「中」で登録を決めた。

## 評価の根拠

- 確度：中。部品が使えるなら、構成はほぼ標準的である。部品の存在をどこまで前提にするかで、主張の強さが変わる。
- 重要度：中。C-0014 の (2) の前提になり、理想化の範囲を物理的に作れる装置で述べる足場になる。
- 検証費用：中。

## 検証の方針

上の構成を、部品の存在を仮定として明記して書き、近似の誤差を見積もる。数値実験で、具体的な応答（閾値の近くで急に変わる応答など）について、雑音の大きさと近似の誤差の関係を確かめることもできる。
