## 目的

設定と結果の空間に位相空間を割り当てること（意味論）を取り替えると、得られる物理法則が変わる、というユーザーの予想（第 45 回。[T-0032](../tasks/T-0032.md) の「結果の空間の意味論」の依存の型）を、具体的な一組の意味論で確かめる。全称の主張（どの取り替えでも変わる）は強すぎる（同相な取り替えでは法則の形を保てる。PR #62 のレビュー）ので、同型な意味論は同じものとして扱い、差が現れる組を一つ指定する。成り立てば、「閾値の応答は理想化である」という主張が、前提ではなく意味論の選択に依ることが示され、意味論の型の予想の最初の例になる。

## 完了の条件

検証の形は紙の証明とする。主張の 1〜4 を示し、二つの意味論が同相でない（同型な意味論ではない）ことを確かめる。証明の前に、下の詳細化の論点のうち、ストーン空間の意味論で記録の読みをどう符号化するか（読みの桁の列の取り方）と、二つの意味論の間で何を固定するか（記録の構文、応答の与え方）を決める。

## 主張

設定を一つの実数の読み $`x ∈ [-1, 1]`$ とし、結果を $`\{0, 1\}`$ とする閾値の装置の応答 $`p(1 \mid x) = 𝟙_{x ≥ 0}`$ を考える。

1. **標準の意味論**（設定の空間に $`ℝ`$ の部分空間の位相を入れる。[D-0003](../definitions/D-0003.md)・[A-0017](../assumptions/A-0017.md) の当面の選択）では、この応答は $`x = 0`$ で不連続なので、[A-0006](../assumptions/A-0006.md) を満たさず、実際の実験の応答には入らない（理想化である。極限としては [C-0014](C-0014.md) の型で得られる）。
2. **有限の精度の読みから作るストーン空間の意味論**では、設定を、読みを一桁ずつ確定させた列（例えば、符号の桁と二進の桁の列 $`(d_0, d_1, d_2, …) ∈ \{0, 1\}^ℕ`$。$`d_0`$ が符号を表す）とし、カントール空間の積位相を入れる。D-0003 の設定の空間（実数の組の集合）に収めるには、カントール空間を、$`ℝ`$ の中の中央 3 分の 1 のカントール集合 $`𝒞 ⊆ [0, 1]`$ に同相に埋め込み、設定の空間を $`𝒞`$（部分空間の位相）とする（PR #69 のレビュー）。この意味論で、応答 $`p'(1 \mid d) = d_0`$ を考える。「$`d_0 = 1`$」は開かつ閉の集合なので、$`p'`$ は連続で、A-0006（この意味論での連続性）を満たす。
3. **二つの応答の関係**：読みの列から実数への写像（$`d_0 = 1`$ なら $`h(d) = \sum_{i ≥ 1} d_i 2^{-i}`$、$`d_0 = 0`$ なら $`h(d) = -\bigl(1 - \sum_{i ≥ 1} d_i 2^{-i}\bigr)`$ とおく連続な全射 $`h : 𝒞 → [-1, 1]`$。$`𝒞`$ とカントール空間を同一視する）で比べると、$`x ≠ 0`$ では $`p'`$ は $`p`$ と一致する（$`p'(1 \mid d) = p(1 \mid h(d))`$）。しかし、$`x = 0`$ には二つの読みの列（$`d_0 = 0`$ で残りがすべて 1、$`d_0 = 1`$ で残りがすべて 0）が対応し、$`p'`$ はそこで二つの値をとる。したがって、$`p'`$ は $`p`$ の $`h`$ による引き戻しではない。実際、$`𝒞`$ の上の連続な応答で、各実数のすべての名前に同じ値を与えるものは、$`[-1, 1]`$ の上の連続な応答に降りるので、閾値の応答 $`p`$ にはなれない（PR #69 のレビュー）。
4. **結論の形**：二つの意味論は同相でない（$`[-1, 1]`$ は連結で、$`𝒞`$ は完全不連結）。予想の主張は、「標準の意味論で理想化とされる閾値の応答に、$`x ≠ 0`$ で一致する応答 $`p'`$ が、ストーン空間の意味論では連続になり、A-0006 を満たす」ことである。これは同じ応答 $`p`$ の扱いが変わるという主張ではなく、閾値の振る舞いを、標準の意味論では理想化としてしか書けず、ストーン空間の意味論では（$`x = 0`$ の名前の区別を伴う）連続な別の模型として書ける、という主張である。
5. **プロトコルの存在との区別**：連続性は A-0006 を満たすための条件で、$`p'`$ を応答関数とするプロトコルが存在することの十分条件ではない。そのようなプロトコルが存在するか（設定の読みの桁を、名前の区別まで含めて記録できる装置があるか）は、[C-0018](C-0018.md) の型の問いとして別に扱う（PR #69 のレビュー）。

## 詳細化の論点

- 記録の読みの符号化：符号付きの二進展開のほかに、冗長な桁（$`\{-1, 0, 1\}`$ の桁）を使う符号化では、$`x = 0`$ の近くの扱いが変わる。どの符号化を「有限の精度の読み」とするかは、記録の構文（[T-0031](../tasks/T-0031.md) の記録の集合）とあわせて決める。
- 二つの意味論の間で固定するもの：記録の構文、許すモデルの範囲、命題の対応づけ（第 45 回。PR #62 のレビュー。T-0032 の詳細化の論点）。特に、A-0017 の位相を固定した体系と、それを変えた体系を区別する。
- 結果の空間の側の意味論の取り替え（設定の側だけでなく）の例も挙げるか。
- 物理法則との対応：ここで比べているのは「応答が A-0006 を満たすか」で、物理法則そのものではない。意味論で妥当な命題と物理法則の対応は、設定・応答・統計を含むモデルを定めてから検討する（T-0032）。

## 背景
