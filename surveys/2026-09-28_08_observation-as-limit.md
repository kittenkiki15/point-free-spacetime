# 観測を「有限な実験の族の極限」として定義するための先行研究

- 作成: 2026-09-28 第 08 回（[まとめ](../summaries/2026-09-28_08_observation-as-limit.md)）

- 前提: 第 07 回の「実験における時空」と「観測における時空」の区別（[まとめ](../summaries/2026-09-27_07_observation-and-experiment.md)）

第 08 回では、観測と実験の作業上の定義を決めるために、先行研究を原典で確かめた。ユーザーと合意した方針（観測は有限な実験の族の極限として定義し、制約の選び方で体系を比べる）に沿って、作業上の定義（1 節）と、文献から分かったこと（2〜7 節）を整理する。

「見立て」と書いたものは、Claude の未検証の解釈である。原典が入手できず、二次文献（レビュー論文の要約や参考文献欄）で確かめたものは、その旨を書く。

## 1. 作業上の定義（第 08 回の案）

### 1.1 方針

- 本プロジェクトの構想は、数学基礎論のような位置づけで考える（ユーザーの方針）。「唯一の正しい時空の再構成」を探すのではなく、「観測」や「実験」の形式化に様々な前提や制約を課し、得られる体系の特徴を比べる。
- 先例として、点なし位相の成り立ちがある。「有限の観測で確かめられる性質」という制約から、有限の連言と任意の選言だけを許す幾何学的論理（geometric logic）と、その代数であるフレーム（ロケール）が決まる（Vickers *Topology via Logic*。原典は未入手で、記憶による。未確認）。本プロジェクトは、同じ「制約 → 論理・代数の形 → 空間の概念」の流れを、物理の観測・実験に広げることを目指す。

### 1.2 定義の形

「実験の有限性」を制約として課すと、観測は、有限な実験の族による近似の極限としてしか定義できない（ユーザーの見解）。これを次の形で書く。

```math
𝒪(R) := \{\, R \text{ に収まる有限な実験の族の極限として得られる観測 } \,\}
```

- $`R`$ は、実験における時空の有界な領域である（観測における時空の領域ではない）。
- 有限な実験：実験における時空の有限な世界線の区間の中で、有限回の操作を行い、有限個の結果を読み出すもの。使える資源（エネルギーなど）にも上限がある。
- 族：有限な実験の列（または有向族）。族にわたって、どの資源の上限を共通にするか（有界にするか）を、パラメータとして選ぶ。

この定義の性質（定義から直ちに従うもの）：

- **循環を避けられる。** 添字 $`R`$ は実験における時空の領域なので、観測における時空の局在を先取りしない（PR #12 のレビューの指摘に対応する）。
- **単調性（isotony）。** $`R ⊆ R'`$ ならば $`𝒪(R) ⊆ 𝒪(R')`$。代数的場の量子論で局所代数の単調性を「$`O_1`$ での実験は $`O_2`$ での実験でもある」と操作的に正当化する議論（halvorson2001rs の 6 節など）と同じ形である。
- **局在しない観測も含む。** 族の実験の領域に共通の上限がなければ、極限は局在しない観測になりうる（無限スピン鎖の平均磁化など）。局在は、「族にわたる実験の領域が共通の有界な $`R`$ に収まる」という条件として現れる（ユーザーの提案）。

### 1.3 パラメータ（体系を分ける軸）

| 軸 | 選択肢の例 | 対応しそうな性質（見立て。2〜6 節の文献で一部を確認） |
| --- | --- | --- |
| 有界にする資源 | 時空の領域、エネルギー（温度）、操作の回数・結果の個数、系の大きさ | 局在、核型性・split property、離散的な値、巨視的な観測量 |
| 極限の位相 | ノルム（状態にわたって一様）、弱い（状態ごと） | 準局所的な観測量、無限遠の観測量（observables at infinity） |
| 因果律 | 課す（空間的に離れた実験は互いに影響しない）、課さない | 可換性、局所的な Noether の定理の前提 |

注意：

- 有限の実験では「すべての状態で一様に収束する」ことも確かめられないので、極限の位相の選び方そのものが制約になる。
- エネルギーの上限は、装置のエネルギーの予算、状態のエネルギーの期待値の上限、状態のスペクトルの厳密な上限のどれかで条件が異なる（PR #12 のレビューの提案。未整理）。
- 第 07 回の主張 1'（橋渡し）は、この定義では「$`R`$ の性質（互いに空間的に離れている、など）が $`𝒪(R)`$ の性質（互いに可換である、など）にどう反映されるか」と、「$`R ↦ 𝒪(R)`$ から観測における時空の局在を再構成できるか」に移る。主張 2'（特徴づけ）は、定義に置き換わる。

## 2. 局在を「測れること」で定義する：Halvorson 2001（halvorson2001rs）

原典（arXiv 版）で確認した。

- Reeh–Schlieder の定理の帰結（3 節）：真空は局所代数について巡回的かつ分離的である。そのため、局所的な個数演算子は存在しない。局所代数は III 型である。
- Reeh–Schlieder の定理が相対論的な因果律と矛盾するように見えるのは、局所的な操作を「物理的な擾乱」とだけ見るためで、選択的な操作と非選択的な操作を区別すれば、直ちには矛盾しない（3 節。Clifton–Halvorson 2000 を参照している）。
- 完全な Reeh–Schlieder の定理には、領域が時間方向の広がりを持つことが必要である（脚注）。一方、証明に微視的因果律（microcausality）は要らない（5 節）。
- 局所代数 $`R(G)`$ を「$`G`$ の中で測れる観測量」と読む操作的な解釈が標準で、この解釈の下では Newton–Wigner の局在は一般化された微視的因果律を満たさないことが問題になる（6 節）。
- 局在の二つの意味（6 節）：点に固定して結び付いた量（fixedly-localized。場の強さなど）と、値として位置をとる量（variably-localized。重心など）。後者は、局在していても局所的に測れないことがある。一方、前者の意味で局在していながら、その領域で測れない量の例は見つかっていない、と著者は論じている。

本プロジェクトへの示唆（見立て）：

- 「局在 = その領域の実験で測れる」とする 1.2 節の定義は、Halvorson が擁護する標準的な解釈と同じ向きである。
- 重心のような「値として位置をとる量」は、観測における時空の局在ではなく、観測の値が実験における時空の点を表す、という別の役割を持つ。二つの時空の区別と合わせて整理する余地がある。

## 3. 資源の有界性と split property：核型性と distal split

### 3.1 核型性から split property へ（fewster2016 による）

原典（buchholz1986nuclear、buchholz1987universal）は未入手で、Fewster のレビュー（fewster2016、arXiv 版）で確かめた。

- split property：$`O_1 ⋐ O_2`$（$`O_1`$ の閉包が $`O_2`$ に含まれ、間に「余白（collar）」がある）とき、$`R(O_1) ⊂ R(O_2)`$ の間に I 型因子が挟まる。これは、$`O_1`$ とその外側の $`O_2`$ の因果的な補集合とで、準備と測定を独立に行える（W* 統計的独立性。任意の正規状態の組を積の形で合わせられる）ことを意味する。
- 核型性（nuclearity）の条件：写像 $`Ξ_{O,β}(A) = e^{-βH} A Ω`$ が核型で、その核型ノルムが $`\left\| Ξ_{O,β} \right\|_1 ≤ e^{(β_0/β)^n}`$（$`β → 0^+`$）を満たすこと。$`\left\| Ξ_{O,β} \right\|_1`$ は「局所的な分配関数」の役を果たし、与えられた距離とエネルギーの尺度で使える状態の空間の大きさを表す、と Fewster は説明している。
- Buchholz–D'Antoni–Fredenhagen（1987）は、この条件から split property を示した（fewster2016 の定理 2.1）。前回（第 07 回・第 08 回の前半）に「Buchholz–D'Antoni–Longo」と書いたのは誤りで、ここで訂正する。
- Fewster は、split property、核型性、量子エネルギー不等式（QEI）を、いずれも不確定性原理の表れと見ている。split property で余白が要ることは、鋭い局在の喪失を表す、としている（5 節）。
- 局所代数そのものは、多くの理論で超有限な III₁ 型因子で、同型を除いて一意に決まる。理論の違いは局所代数どうしの関係の中にある、と Fewster はまとめている。

### 3.2 distal split（dantoni1987、naaijkens2012）

dantoni1987 の原典は未入手で、fewster2016 の要約で確かめた。

- 質量スペクトル $`m_r = (2d_0)^{-1} \log(r+1)`$（指数関数的に多くの場。Hagedorn 型の状態密度）を持つ模型では、十分高い温度で分配関数が発散し、核型性が成り立たない。
- この模型でも、半径の差が「分離の距離」$`d(r)`$ 以上の同心球（の依存領域）の間では split property が成り立つ。$`d_0 ≤ d(r) ≤ 2d_0`$ である（dantoni1987 の定理 4.3）。分離の距離の逆数は、局所的に正規な平衡状態が存在する最高温度と同じ程度である。
- 格子の模型では、naaijkens2012（原典で確認）が toric code の錐について、Haag 双対性から distal split（錐 $`Λ_1 ≪ Λ_2`$ の境界が十分離れていれば split）を示している。
  - 境界が十分離れていれば、正規な積状態が存在し、$`R_{Λ_1}`$ と $`R_{Λ_2}`$ の組で Bell の不等式は破れない。
  - $`Λ_1 = Λ_2`$ とすると最大に相関し、1 コピーあたりのもつれ（one-copy entanglement）は無限になる。
  - 必要な境界の距離は小さく（格子間隔 1 程度で足りることが多い）、錐をわずかにずらすだけで、もつれの性質が大きく変わる。

### 3.3 最小の余白と共変性の衝突（fewster2016 の 4 節、morinelli2018）

- fewster2016 の 4 節（fewster2015 の結果の紹介。fewster2015 の原典は未入手）：局所共変な理論で、状態空間が局所準同値性（local quasiequivalence）を満たし、時間スライス性を仮定すると、
  - 空間の尺度変換から、一様な分離の距離 $`d_0`$ があれば $`d_0 = 0`$（つまり split）になる。
  - 球と微分同相な集合について、分離の距離は 0 か ∞ に限られる。つまり、この仮定の下では distal split から split が従う。
  - 物理的には、分離の距離が 0 でないことは臨界温度の存在に対応する。膨張する計量（インフレーション）が温度を冷やすことと合わせると、時間スライス性と局所準同値性が矛盾する。dantoni1987 の模型は、これらの仮定のどれかと両立しないと考えられる、と Fewster は述べている。
- morinelli2018（原典で確認）：円周上の、微分同相群について共変な場の網では、split property が自動的に成り立つ。2 次元ミンコフスキー時空では成り立たない反例がある。

本プロジェクトへの示唆（見立て）：

- distal split は、C-0001 の主張 2（最小の余白。余白付きの包含が補間的でないこと）の、具体的な物理の模型になる。最小の尺度 $`d_0`$ は、理論の状態密度（エネルギーの側の資源）から決まる。
- 一方、3.3 節の結果は、「最小の余白」が大きな共変性（尺度変換、微分同相、時間スライス性と局所準同値性の組）と両立しにくいことを示している。C-0001 の見直しで、最小の尺度と共変性の関係（第 06 回の主張 4 の論点）を考えるときの、重要な先行研究である。
- 1.3 節の軸で言えば、「エネルギーを有界にするか」と「どの共変性を課すか」の組み合わせで、最小の余白の有無が分かれる。

## 4. 対称性・保存則と余白：局所的な Noether の定理

原典（dantoni1983、doplicher1983、doplicher1984、buchholz1986noether）は未入手で、fewster2016 の 2 節の要約で確かめた。

- split な包含と大域的なゲージ対称性（内部対称性）があると、$`O_1 ⋐ O_2`$ について、$`R(O_2)`$ の中のユニタリ $`W(g)`$ で、$`R(O_1)`$ の上では対称性と一致し、$`R(O_2)'`$ には自明に作用するものが得られる。その生成子は、保存する局所的なカレントを適当にぼかしたものと解釈でき、ラグランジアンを仮定しない、抽象的な Noether の定理になる（Fewster はこの箇所で doplicher1983 を引いている）。
- 同様の考えで、適当な修正の下で、幾何的な対称性（時空の対称性）の局所的な実装も構成できる（buchholz1986noether など。Fewster の要約による）。
- 第 08 回の途中の報告では、抽象的な Noether の定理を「Buchholz–Doplicher–Longo 1986」の結果としたが、fewster2016 が内部対称性についてこの箇所で引いているのは doplicher1983 で、buchholz1986noether は幾何的な対称性の局所的な実装の文献として引かれている。ここで訂正する。
- 逆向きの結果：$`R_1 ⊂ R_2`$ で、$`R_1 ⊗ R_1`$ の上の入れ替え（flip）$`A ⊗ B ↦ B ⊗ A`$ が $`R_2 ⊗ R_2`$ の内部自己同型で実装できれば（と、巡回的で分離的なベクトルの存在などの条件の下で）、包含は split である。逆に split なら flip は内部的である（dantoni1983、doplicher1984）。
- D'Antoni–Longo は、この考えで自由スカラー場の split property を示した。二つの独立な場の SO(2) 回転（$`π/2`$ の回転が入れ替えを与える）の Noether カレントを局所的にぼかして、入れ替えを局所的に実装する。

本プロジェクトへの示唆（見立て）：

- 第 08 回の前半でユーザーが問うた「観測を極限と結び付けて定義すると、保存則は出るか」には、次の既知の鎖が手掛かりになる。
  - 入れ替えの対称性が（余白の中で）内部的に実装できること ⇔ split（余白による独立性）。
  - split と大域的な対称性 ⇒ 保存量の局所化（局所的な Noether の定理）。
- ただし、全体の力学の連続的な対称性は入力として別に要る。入れ替えの対称性だけから保存則が出るわけではない（第 07 回の結論は変わらない）。
- 「観測する側と観測される側の入れ替え」を、系と装置の二つの同型なコピーの flip とみなせば、flip が余白の中で内部的であることが「観測者と対象を局所的に取り替えられる」ことに当たる、と読める可能性がある（見立て。系と装置は一般に同型でないので、そのままは当てはまらない）。

## 5. 極限で現れる古典性：巨視的な観測量と Hepp の結果（landsman2005）

landsman2005（arXiv 版）の 6.1 節と 6.6 節を原典で確かめた。hepp1972 の原典は未入手。

- $`N`$ 個の同じ系の、対称化して平均した観測量（巨視的な観測量）は、交換子が $`1/N`$ の程度で 0 に近づき、$`N → ∞`$ で可換になる（$`1/N`$ が $`ħ`$ の役を果たし、$`N`$ 倍した交換子は極限で Poisson 括弧になる）。C* 代数の連続な場を通して、極限は 1 個の系の状態空間上の連続関数の代数 $`C(S(A_1))`$ になる。
- この巨視的な観測量は、極限の系の超選択セクター（superselection sector）を区別する大域的な電荷の役を果たす。Landsman は、有限の系には超選択則は存在しない、とまとめている。
- Hepp（1972）の結果（Landsman の紹介による）：測定で純粋状態から混合状態への移行（波束の収縮）が起こるのは、無限に大きな装置と無限の時間の極限だけである。背景にある Hepp の補題：自己同型（時間発展）は、状態が互いに素（disjoint）であることを保つ。

本プロジェクトへの示唆（見立て）：

- 「観測 = 有限な実験の族の極限」という定義と整合する。系の大きさを有界にしない族の極限で、可換（古典的）な観測量が初めて現れる。
- 第 08 回の前半の見立て (iii)（観測する側と観測される側の対称性は有限の段階で成り立ち、極限で破れて、古典的な装置が現れる）の具体例になる。

## 6. 極限でも局在しない観測量：電荷（buchholz2001）

原典（arXiv 版）の序論で確かめた。

- 古典的な Maxwell 場と Klein–Gordon 場（または Dirac 場）の系では、電荷の台を鋭く局在させられる。
- 量子電磁力学では、真空偏極のため、電荷密度の高次のモーメントが Coulomb 場と同じ遅さでしか減衰しない（Swieca の議論とつながる）。そのため、電荷の台そのものを定義できない（電荷の量子的な非局在化）。

本プロジェクトへの示唆（見立て）：電荷は、族にわたる実験の領域を有界にできない「局在しない極限の観測量」の実例で、局所的な操作では変えられない量（保存量）が局在しない観測量として現れる、という第 08 回の前半の見立て (i) を支持する。

## 7. 観測の論理と点なしの空間：Spitters–Vickers–Wolters（spitters2014）

Vickers *Topology via Logic*（vickers1989）と Abramsky 1987 は入手できなかった（大学のサイト、nLab、SEP へのアクセスがプロキシで拒否された）。代わりに spitters2014（arXiv 版）を読んだ。

- 幾何学的論理の無限の選言を使うと、ℕ・ℤ・ℚ は同型を除いて一意に特徴づけられるが、ℝ と ℂ はそうできない（2 節）。ℝ は点なしの空間（ロケール）として扱うことになる。
- 代数的場の量子論の網 $`O ↦ A(O)`$ を、関手の圏 $`[K(M), \mathrm{Set}]`$ の中の C* 代数とみなし、その可換な部分代数の族を通して、内部のゲルファント・スペクトル（ロケール）を構成している（3.5 節）。$`A(O)`$ の自己共役元を「領域 $`O`$ で測れる観測量」と読み、その読みから単調性を仮定する、と述べている。
- 「開集合 = 有限の観測で確かめられる性質」という Vickers の元の動機は、この論文には書かれていない（未確認のまま）。

本プロジェクトへの示唆（見立て）：

- 「連続的な値（ℝ）は、有限の観測の論理では点の集合として一意に決まらず、点なしの空間として現れる」ことは、1.3 節の見立て「連続スペクトルは極限で初めて現れる」の論理の側での対応物になる。
- spitters2014 の 3.5 節は、「局所代数の網から点なしの空間を作る」という本プロジェクトの構想（第 07 回の構想 2）に近い先行研究である。ただし、そこで作られるのは状態空間（相空間）の側のロケールで、観測における時空ではない。
