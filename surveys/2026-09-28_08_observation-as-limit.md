## 1. 作業上の定義（第 08 回の案）

### 1.1 方針

- 本プロジェクトの構想は、数学基礎論のような位置づけで考える（ユーザーの方針）。「唯一の正しい時空の再構成」を探すのではなく、「観測」や「実験」の形式化に様々な前提や制約を課し、得られる体系の特徴を比べる。
- 先例として、点なし位相の成り立ちがある。「有限の観測で確かめられる性質」という制約から、有限の連言と任意の選言だけを許す命題的な幾何学的論理（geometric logic。一階の幾何学的論理では存在量化も許す）と、その代数であるフレーム（ロケール）が決まる（Vickers *Topology via Logic*。原典は未入手で、記憶による。未確認）。本プロジェクトは、同じ「制約 → 論理・代数の形 → 空間の概念」の流れを、物理の観測・実験に広げることを目指す。

### 1.2 定義の案

「実験の有限性」を制約として課すと、観測は、有限な実験の族による近似の極限としてしか定義できない（ユーザーの見解）。これを次の形で書く。

これはまだ**定義の案**で、定義として完成していない。次の四つを指定して、初めて $`𝒪(R)`$ が定義になる。

1. 有限な実験（有限回の操作と有限個の結果）から、何を対応させるか（結果の確率の割り当て、効果（effect）、観測量など）。
2. 異なる実験の結果を比べる、共通の値域・空間。
3. 極限を取る位相。
4. 族全体に課す資源の条件。

```math
𝒪 := \{\, \text{有限な実験の族の極限として得られる観測} \,\}
```

```math
𝒪(R) := \{\, o ∈ 𝒪 \mid o \text{ に収束する有限な実験の族で、すべての実験が } R \text{ に収まるものが存在する} \,\}
```

全観測の集合 $`𝒪`$ と、領域 $`R`$ の観測の集合 $`𝒪(R)`$ を分ける。一つの観測に、領域の外へ広がる近似族と、$`R`$ に収まる近似族の両方がありうるので、$`𝒪(R)`$ は「$`R`$ に収まる近似族が**存在する**」ことで定める。

- $`R`$ は、実験における時空の有界な領域である（観測における時空の領域ではない）。
- 有限な実験：有限の期間に、有界な範囲で、有限回の操作を行い、有限個の結果を読み出すもの（族全体に共通の上限がない場合でも、族の各実験はこの意味で有限とする）。使える資源（エネルギーなど）にも上限がある。実験を行う観測者の世界線の区間（実験の期間）と、複数の装置と操作が占める実験における時空の領域とは区別する。後者が有界な領域 $`R`$ に収まることを「$`R`$ に収まる」という（離れた装置を使う実験も含める）。
- 族：有限な実験の列（または有向族）。族にわたって、どの資源の上限を共通にするか（有界にするか）を、パラメータとして選ぶ。

上の四つを指定したときに期待される性質（見立て。単調性などは、指定のしかたによっては成り立たないこともありうる）：

- **循環を避けられる。** 添字 $`R`$ は実験における時空の領域なので、観測における時空の局在を先取りしない（PR #12 のレビューの指摘に対応する）。
- **単調性（isotony）。** $`R ⊆ R'`$ ならば $`𝒪(R) ⊆ 𝒪(R')`$。実験と族の許容条件（エネルギーの予算など）が $`R ⊆ R'`$ について単調で（$`R`$ で許される実験と族は $`R'`$ でも許される）、比べる空間と位相を $`R`$ によらず共通に取れば、$`R`$ に収まる族は $`R'`$ にも収まるので成り立つ。代数的場の量子論で局所代数の単調性を「$`O_1`$ での実験は $`O_2`$ での実験でもある」と操作的に正当化する議論（halvorson2001rs の 6 節など）と同じ形である。
- **局在しない観測も $`𝒪`$ に含みうる。** 観測 $`o ∈ 𝒪`$ が局在するとは、ある有界な $`R`$ について $`o ∈ 𝒪(R)`$ となること（$`R`$ に収まる近似族が存在すること）とする。どの有界な $`R`$ についてもそのような近似族がない観測は、$`𝒪`$ には入るが、どの $`𝒪(R)`$ にも入らない局在しない観測になる（無限スピン鎖の平均磁化など。ただし、準局所代数ではノルム収束しないので、表現と位相の指定が要る。たとえば全スピン上向きの積状態の GNS 表現では、平均磁化は強収束で単位作用素になり、局所代数に属する。非自明な極限になるのは、異なる磁化の状態を含む表現（それらの直和など）で、その表現の正規状態について弱い（強い）位相を使う場合である。全状態についての各点の収束とは区別し、$`𝒪(R)`$ の候補ごとに表現と位相を指定する）。局在の条件は、「族にわたる実験の領域が共通の有界な領域に収まる」というユーザーの提案を、近似族の存在の形にしたものである。 ただし、局在しない観測が現れるのは、近似族の領域がどの有界な領域にも共通して収まらない場合に限る。実験に使える時空全体が有界な領域 $`R_{\mathrm{all}}`$ に収まる体系（到達範囲が有限な観測者など）では、定義から、すべての観測が $`𝒪(R_{\mathrm{all}})`$ に属し、この局在の定義は自明になる（その場合は、より小さな領域についての局在を問う必要がある）。

## 2. 局在を「測れること」で定義する：Halvorson 2001（halvorson2001rs）

原典（arXiv 版）で確認した。

- Reeh–Schlieder の定理とその帰結（3 節）：真空は局所代数について巡回的かつ分離的である。個数演算子も真空を 0 に移す。個数演算子は非有界なので、局所代数に付随する（affiliated）と仮定して、その有界なスペクトル射影（0 以外の値に対応するもの。真空を 0 に移す）に分離性を適用すると、射影が 0 になって矛盾する。そのため、局所代数に付随する（0 でない）個数演算子は存在しない（Halvorson は「affiliated」の形で述べている）。
- 局所代数が III 型であることは、巡回性・分離性だけからは従わない別の結果として、Halvorson が紹介している（Araki 1964。原典は未確認）。
- Reeh–Schlieder の定理が相対論的な因果律と矛盾するように見えるのは、局所的な操作を「物理的な擾乱」とだけ見るためで、選択的な操作と非選択的な操作を区別すれば、直ちには矛盾しない（3 節。Clifton–Halvorson 2000 を参照している）。
- 完全な Reeh–Schlieder の定理（開いた時空領域の局所代数について、真空が巡回的であること）の証明では、領域が時間方向の広がりを持つこと（領域の中の作用素を、四つの独立な方向に少し並進しても領域の中に留まること）を使う（脚注）。これは引用先の定理の証明で使う仮定で、巡回性そのものの一般的な必要条件ではない（たとえば自由場では、時刻 0 の空間領域の場と共役運動量から作る代数を、その依存領域の局所代数と結び付けられる。Halvorson の脚注の正確な射程は未確認）。一方、この巡回性の証明に微視的因果律（microcausality）は要らない（5 節。すべての領域に同じ代数を割り当てる自明な例を挙げている）。真空が局所代数について分離的であることは、空間的に離れた領域の代数についての巡回性と微視的因果律を合わせて導く（すべての領域に $`B(ℋ)`$ を割り当てれば、真空は巡回的だが分離的ではない）。
- 局所代数 $`R(G)`$ を「$`G`$ の中で測れる観測量」と読む操作的な解釈が標準で、この解釈の下では Newton–Wigner の局在は一般化された微視的因果律を満たさないことが問題になる（6 節）。
- 局在の二つの意味（6 節）：点に固定して結び付いた量（fixedly-localized。場の強さなど）と、値として位置をとる量（variably-localized。重心など）。後者は、局在していても局所的に測れないことがある。一方、前者の意味で局在していながら、その領域で測れない量の例は見つかっていない、と著者は論じている。

本プロジェクトへの示唆（見立て）：

- 「局在 = その領域の実験で測れる」とする 1.2 節の定義は、Halvorson が擁護する標準的な解釈と同じ向きである。
- 重心のような「値として位置をとる量」は、観測における時空の局在ではなく、観測の値が実験における時空の点を表す、という別の役割を持つ。二つの時空の区別と合わせて整理する余地がある。

## 3. 資源の有界性と split property：核型性と distal split

### 3.1 核型性から split property へ（fewster2016 による）

原典（buchholz1986nuclear、buchholz1987universal）は未入手で、Fewster のレビュー（fewster2016、arXiv 版）で確かめた。

- split property：ミンコフスキー時空の有界な開領域 $`O_1`$、$`O_2`$ で $`O_1 ⋐ O_2`$（$`O_1`$ の閉包が $`O_2`$ に含まれ、間に「余白（collar）」がある。ミンコフスキー時空の有界な領域なので、閉包はコンパクトで、境界の間に正の距離がある）とき、$`R(O_1) ⊂ R(O_2)`$ の間に I 型因子が挟まる。これは、$`O_1`$ とその外側の $`O_2`$ の因果的な補集合とで、準備と測定を独立に行える（W* 統計的独立性。任意の正規状態の組を積の形で合わせられる）ことを意味する。
- 核型性（nuclearity）の条件：写像 $`Ξ_{O,β}(A) = e^{-βH} A Ω`$ が核型で、その核型ノルムが $`\left\| Ξ_{O,β} \right\|_1 ≤ e^{(β_0/β)^n}`$（$`β → 0^+`$）を満たすこと。$`\left\| Ξ_{O,β} \right\|_1`$ は「局所的な分配関数」の役を果たし、与えられた距離とエネルギーの尺度で使える状態の空間の大きさを表す、と Fewster は説明している。
- Buchholz–D'Antoni–Fredenhagen（1987）は、この条件から split property を示した（fewster2016 の定理 2.1）。前回（第 07 回・第 08 回の前半）に「Buchholz–D'Antoni–Longo」と書いたのは誤りで、ここで訂正する。
- Fewster は、split property、核型性、量子エネルギー不等式（QEI）を、いずれも不確定性原理の表れと見ている。split property で余白が要ることは、鋭い局在の喪失を表す、としている（5 節）。
- 局所代数そのものは、多くの理論で超有限な III₁ 型因子で、同型を除いて一意に決まる。理論の違いは局所代数どうしの関係の中にある、と Fewster はまとめている。

### 3.2 distal split（dantoni1987、naaijkens2012）

dantoni1987 の原典は未入手で、fewster2016 の要約で確かめた。

- 質量スペクトル $`m_r = (2d_0)^{-1} \log(r+1)`$（指数関数的に多くの場。Hagedorn 型の状態密度）を持つ模型では、十分高い温度で分配関数が発散し、核型性が成り立たない。
- この模型でも、半径の差が「分離の距離」$`d(r)`$ を超える同心球（の依存領域）の間では split property が成り立つ。$`d(r)`$ は、split が成り立つ半径の差の下限として定義される（split な包含の外側の領域を大きくしても split のままなので、下限を超えれば成り立つ）。$`d(r)`$ より小さい差では成り立たず、差がちょうど $`d(r)`$ の場合は未確認である。$`d_0 ≤ d(r) ≤ 2d_0`$ である（dantoni1987 の定理 4.3）。分離の距離の逆数は、局所的に正規な平衡状態が存在する最高温度と同じ程度である。
- 格子の模型では、naaijkens2012（原典で確認）が toric code の錐について、Haag 双対性と distal split（錐 $`Λ_1 ⊂ Λ_2`$ の境界が十分離れていれば、$`R_{Λ_1} ⊂ N ⊂ R_{Λ_2}`$ となる I 型因子 $`N`$ がある）を示している。distal split は、I 型因子 $`N`$ を明示的に構成して示している。Naaijkens は、distal split を Haag 双対性の帰結と位置づけて先行研究を引いているが、その依存関係は原典の引用先で未確認である（一般に、Haag 双対性だけから distal split が従うわけではない）。
  - distal split は、$`Λ_1`$ と $`Λ_2`$ の補集合の統計的な独立性と解釈できる。$`R_{Λ_1}`$ と $`R_{Λ_2}'`$（Haag 双対性から、$`Λ_2`$ の補集合の代数が生成するもの）の正規な状態の任意の組について、積の形の正規な状態が存在する。そのような積状態では、この二つの代数の組で Bell の不等式は破れない（すべての状態で破れないという意味ではない）。
  - $`Λ_1 = Λ_2`$ とすると、$`R_{Λ_1}`$ と補集合の代数は最大に相関し、1 コピーあたりのもつれ（one-copy entanglement）は無限になる（Naaijkens が引く先行研究による。状態などの正確な条件は未確認）。
  - 必要な境界の距離は小さく（格子間隔 1 程度で足りることが多い）、錐をわずかにずらすだけで、もつれの性質が大きく変わる。

### 3.3 最小の余白と共変性の衝突（fewster2016 の 4 節、morinelli2018）

- fewster2016 の 4 節（fewster2015 の結果の紹介。fewster2015 の原典は未入手）：局所共変な理論で、状態空間が局所準同値性（local quasiequivalence）を満たし、時間スライス性を仮定すると、
  - 議論は、局所共変性を使って**異なる背景時空（計量）の上の理論を比べる**ことによる。空間の微分同相 $`f`$（尺度変換 $`x ↦ x/λ`$ を含む）で写した領域どうしを、途中に膨張する計量（インフレーション）を挟んだ時空を通して比べ、分離の距離の不等式 $`d(S) ≤ κ\, d(f(S))`$ を得る。固定したミンコフスキー時空の上で理論が尺度変換の対称性を持つ、という仮定ではない。
  - 尺度変換の場合から、一様な分離の距離（すべての集合 $`S`$ で分離の距離 $`d(S)`$ が同じ値 $`δ ≥ 0`$ をとること）があれば $`δ = 0`$（つまり split）になる。ここでの $`δ`$ は、dantoni1987 の模型の尺度 $`d_0`$（$`d(r)`$ の下界）とは別の量である。
  - 球と微分同相な集合について、分離の距離は 0 か ∞ に限られる。つまり、この仮定の下では distal split から split が従う。
  - 物理的には、分離の距離が 0 でないことは臨界温度の存在に対応する。膨張する計量（インフレーション）が温度を冷やすことと合わせると、時間スライス性と局所準同値性が矛盾する。dantoni1987 の模型は、これらの仮定のどれかと両立しないと考えられる、と Fewster は述べている。
- morinelli2018（原典で確認）：円周上の、微分同相群について共変な場の網では、split property が自動的に成り立つ。2 次元ミンコフスキー時空では成り立たない反例がある。

本プロジェクトへの示唆（見立て）：

- distal split は、C-0001 の主張 2（最小の余白。余白付きの包含が補間的でないこと）の、具体的な物理の模型の候補である。ただし、distal split そのものは「十分離れた包含は split になる」という性質で、狭い余白で split が必ず成り立たないことや、split の関係が補間的でないことは、それだけでは従わない。dantoni1987 の模型で、同心球などの領域の族を定め、分離の距離が正であることを使って、split の関係が補間的でないことを示す必要がある（未検証。toric code の例にも、同じ結論を直ちには移せない）。最小の尺度 $`d_0`$ は、理論の状態密度から決まる。
- 一方、3.3 節の結果は、「最小の余白」が、異なる背景時空を比べる局所共変性（時間スライス性と局所準同値性と合わせたもの）や、円周上の微分同相共変性と両立しにくいことを示している。ポアンカレ共変性だけから正の分離の距離が排除されるわけではない（dantoni1987 の模型は、ミンコフスキー時空の理論である）。ただし、これは与えられた局所代数の網で split の正の閾値が残らない、という結果である。C-0001 の最小の余白は、実験で実現できる領域の族と、そこで定める関係にも依存する（たとえば、元の網が任意に狭い余白で split でも、許す領域を離散的に制限すれば、中間に許される領域がなく補間性は失われうる）。C-0001 に適用するには、許す領域の族と split の関係を結ぶ追加の条件が要る。そのうえで、C-0001 の見直しで、最小の尺度と共変性の関係（第 06 回の主張 4 の論点）を考えるときの、重要な先行研究である。
- 文献の結論として言えるのは、次の二つである。核型性（$`β → 0`$ にわたる局所的な状態密度への制約で、理論の性質）を仮定すれば split property が従う。状態密度の大きい模型では distal split の例がある。実験に使うエネルギーの上限（1.3 節の資源の軸）は、これとは別の条件で、核型性はそこから従わない。「実験の資源の上限と、どの共変性を課すかの組み合わせで、最小の余白の有無が分かれる」という対応は、未検証の見立てにとどまる。

## 4. 対称性・保存則と余白：局所的な Noether の定理

原典（dantoni1983、doplicher1983、doplicher1984、buchholz1986noether）は未入手で、fewster2016 の 2 節の要約で確かめた。

- split な包含と大域的なゲージ対称性（内部対称性）があると、$`O_1 ⋐ O_2`$ について、$`R(O_2)`$ の中のユニタリ $`W(g)`$ で、$`R(O_1)`$ の上では対称性と一致し、$`R(O_2)'`$ には自明に作用するものが得られる。Fewster はこの局所的な実装を、ラグランジアンを仮定しない、抽象的な Noether の定理と呼び、その生成子は保存する局所的なカレントを適当にぼかしたものと**解釈できる**、と述べている（この箇所で doplicher1983 を引いている）。定理として従うのは局所的な実装の存在までで、生成子とカレントの関係は、追加の仮定（カレントの存在など）を要する解釈である。原論文は未入手なので、その正確な射程は未確認である。
- 同様の考えで、適当な修正の下で、幾何的な対称性（時空の対称性）の局所的な実装も構成できる（buchholz1986noether など。Fewster の要約による）。
- 第 08 回の途中の報告では、抽象的な Noether の定理を「Buchholz–Doplicher–Longo 1986」の結果としたが、fewster2016 が内部対称性についてこの箇所で引いているのは doplicher1983 で、buchholz1986noether は幾何的な対称性の局所的な実装の文献として引かれている。ここで訂正する。
- 逆向きの結果：$`R_1 ⊂ R_2`$ で、$`R_1 ⊗ R_1`$ の上の入れ替え（flip）$`A ⊗ B ↦ B ⊗ A`$ が $`R_2 ⊗ R_2`$ の内部自己同型で実装できれば（と、巡回的で分離的なベクトルの存在などの条件の下で）、包含は split である。逆に split なら flip は内部的である（dantoni1983、doplicher1984）。
- D'Antoni–Longo は、この考えで自由スカラー場の split property を示した。二つの独立な場の SO(2) 回転の Noether カレントを局所的にぼかして、$`π/2`$ の回転を局所的に実装する。$`π/2`$ の回転は、場のレベルでは $`(φ_1, φ_2) ↦ (-φ_2, φ_1)`$ のような符号付きの入れ替えで、純粋な flip ではない。Fewster は、要点は $`1 ⊗ A ↦ A ⊗ 1`$ を引き起こすことにあり、上の議論は flip に限らず、より一般の自己同型でも成り立つ、と述べている（この回転の構成と、直前の flip の定理とは区別する）。

本プロジェクトへの示唆（見立て）：

- 第 08 回の前半でユーザーが問うた「観測を極限と結び付けて定義すると、保存則は出るか」には、次の既知の鎖が手掛かりになる。
  - 包含 $`R_1 ⊂ R_2`$ について、$`R_1 ⊗ R_1`$ の上の flip が $`R_2 ⊗ R_2`$ の内部自己同型で実装できること ⇔ 包含が split（余白による独立性）。ただし、巡回的で分離的なベクトルの存在などの追加の条件の下での同値である（上の 4 節の本文）。
  - split と大域的な対称性 ⇒ 対称性の局所的な実装（局所的な Noether の定理）。その生成子を保存量の局所化（カレントのぼかし）と読むのは解釈である。
- ただし、全体の力学の連続的な対称性は入力として別に要る。入れ替えの対称性だけから保存則が出るわけではない（第 07 回の結論は変わらない）。
- 「観測する側と観測される側の入れ替え」を、系と装置の二つの同型なコピーの flip とみなせば、flip が余白の中で内部的であることが「観測者と対象を局所的に取り替えられる」ことに当たる、と読める可能性がある（見立て。flip の定理は同じ代数の二つのコピーについてのもので、系と装置は一般に同型でないので、そのままは当てはまらない）。

## 5. 極限で現れる古典性：巨視的な観測量と Hepp の結果（landsman2005）

landsman2005（arXiv 版）の 6.1 節と 6.6 節を原典で確かめた。hepp1972 の原典は未入手。

- $`N`$ 個の同じ系の、対称化して平均した観測量（巨視的な観測量）は、交換子が $`1/N`$ の程度で 0 に近づき、$`N → ∞`$ で可換になる。$`1/N`$ が $`ħ`$ の役を果たし、適切な正則な観測量の部分代数の上では、$`N`$ 倍した交換子（landsman2005 の式 (6.42)・(6.43) の $`iN[A_N, A_N']`$。実数値の括弧としては係数と符号の取り方に注意）が、極限で Poisson 括弧になる。C* 代数の連続な場を通して、極限は 1 個の系の状態空間上の連続関数の代数 $`C(S(A_1))`$ になる（Poisson 括弧が定義されるのは、その中の滑らかな関数の部分代数の上である）。
- この巨視的な観測量は、極限の系の超選択セクター（superselection sector）を区別する大域的な電荷の役を果たす。Landsman は、有限の系には超選択則は存在しない、とまとめている。ただしこれは、単純な C* 代数の非同値な既約表現という伝統的な意味での超選択則についての言明で、Landsman も脚注でそう限定している。有限次元でも、許す観測量を電荷やパリティーと可換なものに制限すれば、超選択セクターを持てる。ここで言えるのは、巨視的な観測量による超選択セクターが、系の数を無限にする極限で現れる、ということである。
- Hepp（1972）の結果（Landsman の紹介による）：装置を、互いに素（disjoint）な純粋状態を持つ無限の量子系として理想化する。系と装置を合わせた全体の代数の上で、初めの純粋状態が、装置の成分が互いに素な状態（異なる超選択セクター）の重ね合わせになれば、全体の状態は、それらの状態の混合と一意に分解され、無知による解釈を許す。しかし Hepp の補題（自己同型は、状態が互いに素であることを保つ）から、時間発展が自己同型なら、有限の時間ではこれは起こらない。そのため無限の時間の極限が要る。
  - ここでの「混合」は、無限の装置を含む全体の代数の上の状態が、互いに素な状態の混合になることを指す。有限の装置でも、系と装置がもつれれば、系の縮約状態は有限の時間で混合状態になる。一方、閉じた全体系の純粋状態は、ユニタリな発展では純粋なままである。

本プロジェクトへの示唆（見立て）：

- 「観測 = 有限な実験の族の極限」という定義と整合する。系の大きさを有界にしない族の極限で、巨視的な平均からなる可換な極限代数が現れる（有限の量子系にも可換な観測量の代数はあるので、「可換な観測量が初めて現れる」のではなく、この構成の巨視的な平均が極限で互いに可換になる、ということである）。
- 第 08 回の前半の見立て (iii)（観測する側と観測される側の対称性は有限の段階で成り立ち、極限で破れて、古典的な装置が現れる）とは、「古典的な装置が極限で現れる」という点での類比にとどまる。入れ替えの作用を定義し、それが有限の段階で成り立ち、極限で破れることを示さない限り、対称性の破れの例とは言えない（未検証）。

## 6. 極限でも局在しない観測量：電荷（buchholz2001）

原典（arXiv 版）の序論で確かめた。

- 古典的な Maxwell 場と Klein–Gordon 場（または Dirac 場）の系では、電荷の台を鋭く局在させられる。
- 量子電磁力学では、真空偏極のため、電荷密度の高次のモーメントが Coulomb 場と同じ遅さでしか減衰しない（Swieca の議論とつながる）。そのため、電荷の台そのものを定義できない（電荷の量子的な非局在化）。

本プロジェクトへの示唆（見立て）：電荷は、族にわたる実験の領域を有界にできない「局在しない極限の観測量」の候補である。ただし buchholz2001 の結論は電荷密度の台についてのもので、そこから直ちに、全電荷が有界な $`R`$ の $`𝒪(R)`$ に属さないことは従わない。電荷密度の局在、全電荷という観測量、その測定のしかたを区別し、全電荷をどの代数・位相の極限として扱うかを別に検討する必要がある。そのうえで、局所的な操作では変えられない量（保存量）が局在しない観測量として現れる、という第 08 回の前半の見立て (i) を支持するかを調べる。

## 7. 観測の論理と点なしの空間：Spitters–Vickers–Wolters（spitters2014）

Vickers *Topology via Logic*（vickers1989）と Abramsky 1987 は入手できなかった（大学のサイト、nLab、SEP へのアクセスがプロキシで拒否された）。代わりに spitters2014（arXiv 版）を読んだ。

- 幾何学的論理の無限の選言を使うと、ℕ・ℤ・ℚ は同型を除いて一意に特徴づけられるが、ℝ と ℂ はそうできない（2 節）。ℝ は点なしの空間（ロケール）として扱うことになる。
- 代数的場の量子論の網 $`O ↦ A(O)`$ を、関手の圏 $`[K(M), \mathrm{Set}]`$ の中の C* 代数とみなし、その可換な部分代数の族を通して、内部のゲルファント・スペクトル（ロケール）を構成している（3.5 節）。$`A(O)`$ の自己共役元を「領域 $`O`$ で測れる観測量」と読み、その読みから単調性を仮定する、と述べている。
- 「開集合 = 有限の観測で確かめられる性質」という Vickers の元の動機は、この論文には書かれていない（未確認のまま）。

本プロジェクトへの示唆（見立て）：

- 「連続的な値（ℝ）は、有限の観測の論理では点の集合として一意に決まらず、点なしの空間として現れる」ことは、「連続的な値をとる結果は、有限個の結果を記録する実験の族の極限で初めて現れる」という見立ての、論理の側での対応物になりうる。ただし、ここで言う「連続」は**記録する結果の値**についてのもので、実験に対応する作用素のスペクトルとは区別する。たとえば $`L^2([0,1])`$ 上の乗算作用素 $`E f(x) = x f(x)`$ は、結果が二つの POVM $`\{E, I - E\}`$ の一方の効果（effect）だが、そのスペクトルは $`[0,1]`$ である。作用素のスペクトルについて同様のことを言うには、有限な実験に追加の条件（射影値測定に限る、など）が要る（未検討）。
- spitters2014 の 3.5 節は、「局所代数の網から点なしの空間を作る」という本プロジェクトの構想（第 07 回の構想 2）に近い先行研究である。ただし、そこで作られるのは、可換な部分代数から得るゲルファント・スペクトル（ロケール）で、一般に全状態空間ではない（たとえば $`ℂ^2`$ のスペクトルは 2 点だが、状態の全体は線分である）。観測における時空とも、直ちには同一視できない。
