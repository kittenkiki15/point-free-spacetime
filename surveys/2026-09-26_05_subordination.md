# 余白付きの包含・許容関係・数理形態学：最小の尺度の点なしの表し方

- 作成: 2026-09-26（第 05 回）
- 目的: 第 05 回のおもちゃのモデルの案 D（余白の下限）で出てきた命題が既知かを確かめ、許容関係・劣位代数と物理学の関係を調べて、本プロジェクトの新規性を見極める。

## 1. 第 05 回の出発点（まとめ）

最小の尺度を入れる方法を、二つの型に分けた。

- **型 I（領域の側を削る）**：小さすぎる領域を捨てる。ユークリッド空間で「半径 $`ℓ`$ 以上の球の合併」だけを残す場合、残る領域の束は分配律を満たさない（$`ℝ`$、$`ℓ = 1`$ で $`a = (0, 3)`$、$`b = (-1, 1.5)`$、$`c = (1, 4)`$ とすると $`a ∧ (b ∨ c) = (0, 3)`$、$`(a ∧ b) ∨ (a ∧ c) = (1, 3)`$。分数による厳密な計算で確認した）。
- **型 II（関係の側に尺度を入れる）**：領域の束はそのままにして、「$`a`$ は $`b`$ の中に余白を持って入っている」という関係 $`a ◁ b`$ を制限する。

膨張（dilation）$`N`$ を「領域を、操作的に区別できないところまで広げる」単調な写像とし、$`a ◁ b \iff N\,a ≤ b`$ と定めると、次が成り立つ（Lean で証明済み。[`Tolerance.lean`](../lean/PointFreeSpacetime/Tolerance.lean)）。

- **R-0006**：点の集合の上で、関係 $`T`$（「区別できないほど近い」）から $`a ◁ b`$（$`a`$ の $`T`$ 近傍が $`b`$ に含まれる）を作ると、$`◁`$ が**補間的**（$`a ◁ b`$ なら $`a ◁ c ◁ b`$ となる $`c`$ がある）であることと、$`T`$ が推移的であることは同値。
- **R-0007**：順序集合の上の単調な $`N`$ について、$`◁`$ が補間的であることと $`N(N\,a) ≤ N\,a`$ は同値（R-0006 の点なし版）。
- **R-0008**：$`N`$ が右随伴 $`E`$（収縮、erosion）を持つとき、オープニング $`N ∘ E`$ の不動点はちょうど $`N`$ の像。型 I と型 II は、同じ随伴 $`N ⊣ E`$ の二つの面である。

## 2. 数学の側：これらは既知である

### 劣位代数（subordination algebra）

- **derudder2020**（De Rudder–Hansoul–Stetenfeld, *Subordination algebras in modal logic*）：劣位代数は、ブール代数に関係 $`≺`$ を加えたもので、公理 (S1)〜(S4)（$`0 ≺ 0`$、$`1 ≺ 1`$、$`≺`$ が右で交わりに、左で結びに閉じる、単調性）を満たす。反射性 (S6) $`a ≺ b ⇒ a ≤ b`$、対称性 (S7) $`a ≺ b ⇒ ¬b ≺ ¬a`$ などを加えると接触代数になり、さらに完備性と補間性 (S8) を加えると de Vries 代数（コンパクト・ハウスドルフ空間と双対）になる。
- 同論文の 4 節は、「劣位代数が (S8)（補間性）を満たすことと、対応する到達関係が推移的であることは同値である」と述べ、Balbiani–Kikot（2012）と Bezhanishvili–Bezhanishvili–Santoli–Venema（2019）を参照している。**R-0006 は、この既知の結果の冪集合の場合にあたる。**
- 劣位代数は、双対性によって「閉じた関係を持つストーン空間」に対応する（Celani、Bezhanishvili ら。arXiv:2206.05711 なども参照。原典は未確認）。

### 数理形態学（mathematical morphology）

- **heijmans1990**（Heijmans–Ronse, *The algebraic basis of mathematical morphology I*）：完備束の上で、膨張と収縮を随伴の組として定義する（2.3 節、定義 2.2）。随伴の下側は結びを保つ膨張、上側は交わりを保つ収縮になる（命題 2.5）。オープニングとクロージングは続編（Part II）で扱うと述べている。
- **R-0008** は、随伴（ガロア接続）の一般的な性質 $`N ∘ E ∘ N = N`$ から直ちに従う（Mathlib の `GaloisConnection.l_u_l_eq_l`）。**既知である。**
- **R-0007** は証明が数行で、上の二つの事実を順序集合の言葉で述べ直したもの。同じ主張を明示した文献は見つけていないが、新しい数学的な結果とは考えない（見立て）。

## 3. 物理学の側：許容関係と劣位代数

### 許容関係（tolerance relation）

反射的で対称だが、推移的とは限らない関係。

- **Poincaré**（1894〜1902、『科学と仮説』）：観測される物理的連続体では、測定の分解能のため、A = B かつ B = C でも A ≠ C となりうる。「等しい」は「区別できない」の意味で、推移的でない（connes2022 の序論による紹介）。
- **zeeman1962**：Poincaré の考えを形式化し、「許容」（tolerance）と名付けた。視覚の幾何が目的だった（未入手）。
- **connes2022**（Connes–van Suijlekom, *Tolerance relations and operator systems*）：非可換幾何で、同値関係の商空間から $`C^*`$ 代数を作る方法を、許容関係に広げる。得られるのは $`C^*`$ 代数ではなく作用素系（operator system）である。例として、距離空間の $`d(x, y) < ε`$ と、物理の粗視化を挙げる。**序論で、時空の幾何は測定装置の分解能のため有限の精度でしか決められず、理論的にもプランク長で理解が破綻すると予想されることを、$`d(x, y) < ε`$ を考える動機として明示している。**
- **connes2021**（Connes–van Suijlekom, *Spectral truncations in noncommutative geometry and operator systems*）：運動量の紫外切断（ディラック作用素のスペクトルの打ち切り）と許容関係を、「有限の分解能での空間の近似」の二つの形として扱う。
- **dandrea2022**（D'Andrea–Landi–Lizzi, *Tolerance relations and quantization*）：許容関係の作用素系に、非結合的な積が自然に入ることを示し、空間の切断や正作用素値測度（POVM、ぼやけた測定）とのつながりを論じる。

### 劣位代数・接触代数と時空

- **vakarelov2020**（Vakarelov, *Point-free theories of space and time*）と「動的メレオトポロジー」の連作：Whitehead の点を使わない時空論を、接触代数と、領域の時間変化を扱う動的接触代数で定式化する（要旨による。本文は未読）。目標は本プロジェクトと同じ「点なしの時空」だが、相対論・量子論・最小の長さとの接続は見当たらない（見立て）。
- **casini2002**（Casini, *The logic of causally closed spacetime subsets*）：一般の時空で、「時間的に関係しない点の全体」を否定とすると、因果的に閉じた部分集合の束は完備なオーソモジュラ束になる。ミンコフスキー時空では **cegla1977**（Cegła–Jadczyk, CMP 57, 213）が先に示していた（casini2002 の参考文献 [4]）。2 次元ミンコフスキー時空で分配律が破れる例も図示している。第 05 回の案 C の直接の先行研究である。

### 点なしの枠組みでプランクスケールを扱った例

- **vanderschaaf2024**（博士論文）の 9.3 節は、プランクスケールの「分割できない領域」をフレームのアトムでモデル化することを検討している。アトムで生成されるフレームはブール代数、さらに冪集合に同型になり、離散的な因果集合に戻って「位相的な構造はすべて失われる」と結論している。より緩い条件（コンパクト元、代数的束など）は今後の課題としている。

## 4. 本プロジェクトの位置づけと物理学的な新規性（見立て）

先行研究は、次の三つの流れに分かれている。

| 流れ | 扱う側 | 最小の尺度 | 位相の連続性 |
| --- | --- | --- | --- |
| Connes–van Suijlekom（許容関係・作用素系） | 関数の代数（非可換幾何） | 許容関係 $`d < ε`$ として明示的に扱う | 保たれる（距離空間の上で考える） |
| Vakarelov（接触代数）、Casini（因果論理） | 領域の代数（点なし） | 扱わない | 保たれる |
| van der Schaaf 9.3 節（アトム） | 領域の代数（点なし） | 分割できない領域として扱う | 失われる（離散化する） |

案 D は、**最小の尺度を、点なしの領域の代数の側で、フレームを保ったまま表す**もので、上の三つのどれとも違う。具体的には次の点が新しいと考える。

1. **離散化との区別**：最小の尺度を「分割できない領域（アトム）」として入れると位相が失われる（van der Schaaf）。これに対して、「余白付きの包含の補間性の破れ」として入れると、領域のフレームは連続なまま（空間的なロケールのまま）で、最小の尺度を表せる。「最小の長さがある」ことと「時空が離散的である」ことを、点なしの枠組みで区別できる。
2. **分解能の二つの型の統一**：型 I（小さい領域を捨てる、分配律が破れる）と型 II（余白に下限を置く、ハイティング代数のまま）が、同じ随伴 $`N ⊣ E`$ の二つの面であることが、「最小の長さがあると論理は量子論理に近づくのか」という問いを、どちらの面を物理的に採るかという問いに言い換える。
3. **関数の側との対応**：同じ許容関係から、Connes–van Suijlekom の作用素系（非可換側）と、補間性のない劣位関係（点なし側）が作られる。両者の対応を調べることは、点なしの時空と非可換な時空（第 05 回の案 F）をつなぐ具体的な問いになる。
4. **ローレンツ版で非局所性が見える**：膨張 $`N`$ を「体積が $`λ_P^4`$ 以下の因果ダイヤモンド」で作ると、ダイヤモンドが光円錐に沿っていくらでも長くなるので、$`N`$ が非局所的になる。因果集合理論で知られている非局所性（未確認）が、点なしの枠組みでは $`N`$ の性質として具体的に現れる。

これらを予想 [C-0001](../conjectures/C-0001.md) にまとめた。
