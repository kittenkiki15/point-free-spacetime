## 2. 原典で確かめた内容

### 2.1 群 A：状態の族の比較

**`buscemi2012`**（有限の $`Θ`$、有限次元のヒルベルト空間）

- 量子統計モデル $`R = (Θ, H, ρ)`$ は、パラメータの有限集合 $`Θ`$ と、密度行列の族 $`(ρ_θ)`$ の組である（定義 4）。
- 情報の順序 $`R ⊃ S`$（定義 7）：任意の有限の判定の集合 $`X`$ と利得関数 $`ℓ : Θ × X → ℝ`$ について、POVM で最適化した期待利得が $`R`$ で $`S`$ 以上であること。判定は POVM の測定で、出力は古典的である。
- 統計的射（statistical morphism。定義 13）：入力の状態の空間を出力の状態の空間に写し、双対写像が「試験」（状態の空間の上で POVM と同じ確率を与える写像）を試験に写す線形写像。正写像より弱い概念である（注意 8）。
- 十分性（定義 19）：$`R ≻ S`$ は、$`σ_θ = E(ρ_θ)`$ となる CPTP 写像 $`E`$ があること。$`R ≻_m S`$ は、同じ等式を満たす統計的射があること。
- 定理 3（非可換の BSS 定理）：$`R ≻_m S ⇔ R ⊃ S`$。古典的な判定問題で比べた順序に対応するのは、CPTP 写像ではなく統計的射である。
- 命題 4（半古典の場合）：$`S`$ が可換（$`σ_θ`$ が互いに可換）なら、$`R ≻ S ⇔ R ⊃ S`$。
- 命題 5：$`R ≻ S`$ と、補助のモデル $`T`$ との合成について $`T × R ⊃ T × S`$ がすべての $`T`$ で成り立つことと、ある完全な（$`(\dim H')^2`$ 個の線形独立な状態を含む。定義 16）$`T`$ で成り立つことは、同値である。完全正値性は、補助の系との合成と結びつく（原典の注意）。

**`matsumoto2010`**（可分なヒルベルト空間、任意の $`Θ`$）

- 量子の判定（出力が量子系 $`H_D`$ の CPTP 写像）と、それに対する損失で、量子的な $`e`$-不足度 $`E ≥_{qe} F`$ を定める（4 節）。
- 定理 5（量子版の randomization criterion）：$`E ≥_{qe} F`$ は、すべての $`θ`$ で $`\| Λ(ρ_θ) - σ_θ \|_1 ≤ e_θ`$ となる CPTP 写像 $`Λ`$ があることと同値である。
- 古典的な判定（POVM、古典的な判定の空間）による不足度 $`E ≥_{ce} F`$ も定める（6 節）。定理 13：$`\dim H < ∞`$ で $`\{ρ_θ\}`$ がエルミート行列の全体を張るとき、$`E ≥_{c0,k} F`$ は、$`Γ(ρ_θ) = σ_θ`$ となる**正の**（完全正値とは限らない）トレースを保つ写像 $`Γ`$ があることと同値である。

### 2.2 群 B：チャネル・装置の比較

**`jencova2016`**（すべて有限次元）

- 入力の空間が同じチャネル $`Φ ∈ C(H, K)`$、$`Ψ ∈ C(H, K')`$ について、不足度を $`δ(Φ, Ψ) = \inf_{α} \| Φ - α ∘ Ψ \|_⋄`$（$`α`$ は $`K'`$ から $`K`$ へのチャネル。後処理）と定め、Le Cam 距離 $`Δ(Φ, Ψ) = \max\{δ(Φ, Ψ), δ(Ψ, Φ)\}`$ を定める（3 節。チャネルの上の前順序を与え、$`Δ`$ 自体は擬距離である）。
- 命題 4（補助系なし）：入力の空間の上のアンサンブルを通したときの識別の成功確率の比較は、「$`Φ`$ の後の任意の POVM に、$`Ψ`$ の後の POVM が近い」こと（チャネルに POVM をつないだ qc チャネルの比較）と同値である。$`Φ`$ が qc チャネル（出力が古典的）なら、この比較は $`δ(Φ, Ψ)`$ による比較と一致する（注意 3）。一般のチャネルでは、一致するとは限らない（PR #46 のレビューを受けて、必要条件のように読める書き方を改めた）。
- 定理 1（主定理）：$`δ(Φ, Ψ) ≤ ε`$ は、任意の有限次元の補助系 $`K_0`$ と、$`H ⊗ K_0`$ の上の任意のアンサンブル $`E`$ について、$`P_{\mathrm{succ}}((Φ ⊗ \mathrm{id})(E)) ≤ P_{\mathrm{succ}}((Ψ ⊗ \mathrm{id})(E)) + \frac{ε}{2} P_{\mathrm{succ}}(E)`$ が成り立つことと同値である。$`K_0 = K`$、要素が $`d_K^2`$ 個の等確率のアンサンブルに限ってよい。
- 系 1：補助系の状態を、$`B_h(K)`$ を張る有限個の状態に限ってよい（補助系と入力のもつれは要らず、補助系の状態を添字とする古典的な相関で足りる）。
- 定義 1・定理 3・定理 4：統計的実験 $`S`$、$`T`$ について、古典的な判定による不足度（定義 1）では、古典的な実験に対する Le Cam の randomization criterion（定理 3）が量子の実験では成り立たない（$`ε = 0`$ で、写す元の $`T`$ が古典的でも。原典が引く先行研究による）。定義 1 の $`S ⪰_{\mathrm{cl},ε} T`$ は、$`S`$ が $`T`$ の randomization で近似できるかを問うもので、反例で量子的なのは写す先の $`S`$ である。写す先が可換なら CPTP 写像があるという `buscemi2012` 命題 4 とは矛盾しない（PR #46 のレビューを受けて、写す元と写す先を明記した）。定理 4 は、補助系との合成による識別の成功確率で表した量子版の randomization criterion である。
- 系 3：チャネルの比較は、入力に完全な実験（情報的に完全な状態の族）を通した統計的実験の比較に帰着する。
- 結び：前処理（入力の側の処理）による比較、前処理と後処理の組合せ、入力と出力の相関を許す処理への拡張、無限次元への拡張は、今後の課題としている。

**`buscemi2016`**

- 古典的な通信路の「劣化可能」（後処理の通信路がある）と「雑音が少ない」（すべての入力の分布で条件付きエントロピーが小さい）の二つの順序を、量子チャネルに拡げる（定義 1〜4）。
- 統計的射（定義 5）：チャネル $`N`$ について、線形写像 $`L`$ が、出力の側の任意の POVM を $`N`$ の後の POVM で模倣できるとき、$`L`$ を $`N`$ の統計的射とよぶ。どこでも正でトレースを保つ写像 ⇒ 統計的射 ⇒ $`N`$ の値域の上で正でトレースを保つ、で、逆はいずれも成り立たない（注意 1）。
- 命題 1：入力が古典的な添字を持つアンサンブル（cq 通信路）について、条件付き最小エントロピー $`H_{\min}(U \mid R) = -\log P_{\mathrm{guess}}(U \mid R)`$ の比較（推測確率が大きいほど小さい）は、トレースを保つエルミートな統計的射 $`L`$ で $`N' = L ∘ N`$ と書けることと同値である。
- 系 1：$`N'`$ の出力が互いに可換なら、上の比較は CPTP 写像による劣化可能性と同値である。系 3（古典的な通信路）：$`H`$ を $`H_{\min}`$ に置き換えると、「雑音が少ない」は「劣化可能」と同値になる（$`H`$ のままでは同値でない例が知られている）。

### 2.3 群 C：漸近論（要旨と主定理の主張のみ）

**`kahn2009`**

- 要旨：$`n`$ 個の同じ $`d`$ 次元の系の状態 $`ρ^{⊗n}`$ のモデルは、$`n → ∞`$ で、平均が未知の古典的なガウス分布と、変位した熱平衡状態の調和振動子（量子的なガウス状態）の積のモデルに収束する（局所漸近正規性、LAN）。
- 定理 4.3：基準の状態 $`ρ_0`$ を、固有値が相異なり正である（$`μ_1 > μ_2 > ⋯ > μ_d > 0`$。式 (4.1)。忠実な状態）対角の状態とし、固有値の間隔を $`δ > 0`$ とする。その下で、局所的なパラメータ $`θ`$（$`ρ_{θ / \sqrt{n}}^{⊗ n}`$）の範囲で一様に、二つのモデルを互いに写す CPTP チャネル $`T_n`$、$`S_n`$ があり、誤差は $`O(n^{-ε})`$ である。特に、量子の Le Cam 距離が 0 に収束する（$`\lim_n Δ(Q_n, R_n) = 0`$）。

### 2.4 因果的非分離性

**`oreshkov2012`**

- 因果不等式：二人の課題（相手の乱数を当てる。どちらが当てるかを片方の乱数で決める）の成功確率は、次の三つの仮定の下で $`3/4`$ 以下である。
  - 因果構造（CS）：課題の主な事象が、半順序を持つ因果構造の中に位置づけられる。
  - 自由な選択（FC）：各乱数は、その因果的な未来の事象とだけ相関しうる。
  - 閉じた実験室（CL）：相手の乱数との相関は、その乱数が自分の系の入力より因果的に過去で生成された場合に限る。
- 局所的な量子力学：各当事者の操作は量子の instrument（CP 写像の族）で表される、とだけ仮定する。結果の同時確率は、Choi 行列の双線形の式 $`P(M^A_i, M^B_j) = \mathrm{Tr}[W (M^A_i ⊗ M^B_j)]`$ で与えられ（式 (3)）、過程行列 $`W`$ は正値性と正規化の条件（式 (4)・(5)）を満たす。この条件は、量子コムの条件の一部と同じで、コムが持つ因果順序の条件は課さない（原典の注意）。
- 2 者の因果的分離性（式 (6)）：$`W = q W^{B ≼ A} + (1 - q) W^{A ≼ B}`$（$`0 ≤ q ≤ 1`$。$`W^{A ≼ B}`$ は B から A への信号のない過程、つまり記憶を持つ通信路）と書けること。分離可能な過程は因果不等式を破れない。原典は、不等式を $`(2 + \sqrt{2})/4`$ まで破る過程行列の例を与える。
- 2 者の古典的な過程は、因果的に分離可能である（付録で証明。原典は 2 者を扱う）。ここでいう古典的な過程は、局所的な操作をポインタ基底で対角な CP 写像（古典的な遷移行列）に限ったときに得られる、ポインタ基底で対角な有効な過程行列で表される確率のことである。元の過程行列 $`W`$ そのものが因果的に分離可能になるという意味ではない（PR #46 のレビューを受けて区別した）。3 者以上では、局所的な操作が古典的でも因果不等式を破る過程がある（`oreshkov2016` が引く Baumeler–Feix–Wolf 2014。原典は未確認）。

**`araujo2015`**

- 3 者（第 3 の当事者 C の出力が自明）の因果的分離性を、二つの順序 $`A ≺ B ≺ C`$ と $`B ≺ A ≺ C`$ に合う過程の凸結合で定める（II 節の 3）。より多くの当事者や、前の当事者の操作が後の当事者の順序を決める場合（「古典的なスイッチ」）への一般化は自明でない、と注意している。
- 因果の証人（causal witness）を導入し、量子スイッチが因果的に非分離であることを示す。証人は、当事者の量子的な操作（instrument）を信頼することを前提とする。
- 一方、量子スイッチはどの因果不等式も破れない（VI 節の定理 4 による）。因果不等式は、装置に依存しない（device-independent）制約である。時空の重ね合わせによる例を含め、物理的な解釈が知られている因果的に非分離な過程はどれもこの類（非分離だが、因果的な相関しか生まない）に入る、と述べている。

**`oreshkov2016`**

- 因果的な過程（定義 II.3）：局所的な実験の上の厳密な半順序 $`κ`$（因果の配置）を値とする確率変数があり、各実験 $`A`$ について、$`A`$ の因果的な未来にない実験（因果的な過去か無関係な位置にあるもの）の結果と、それらとの因果の配置の同時分布が、$`A`$ の設定によらないこと（式 (2)。$`A`$ の設定が、過去や無関係な位置の結果へ影響しない）。この条件は、自由に選ぶ設定を条件として述べたものである。前の結果から決める適応的な設定は、選び方の規則を局所的な操作やプロトコルの中に含めて表し直して扱う。原典の条件を、適応的に選んだ設定の観測された分布にそのまま当てはめるものではない（例えば A の結果をそのまま B の設定にすると、観測された分布では A の結果が B の設定によらないとは言えない）（PR #46 のレビューを受けて、原典の式 (2) に沿って書き直し、適応的な設定の扱いを区別した）。順序は確率的で、前の操作に応じて後の順序が変わってよい（動的な因果順序）。
- 定理 II.2（標準の因果的な分解）：因果的な過程は、「最初の当事者 $`i`$ の過程」と「$`i`$ の設定と結果で条件付けた、残りの当事者の因果的な過程」の積の凸結合として、再帰的に書ける。
- 定義 III.1：多者の因果的分離性は、この分解の各項（条件付きの過程を含む）が量子の過程であること、として定める。ベルの局所性と状態の可分性の関係の類比である。
- 因果的（相関の水準）だが因果的に非分離な 3 者の過程の例（量子スイッチに基づくもの）を与える。また、因果的に分離可能でも、もつれた補助系を与えると非因果的になる過程がある。補助系で拡げても性質が保たれる「拡張可能に因果的に分離可能」（ECS）を定め、古典的に制御された量子回路で実現できる過程は ECS であることを示す（逆は予想）。

## 3. 群 A と群 B の対比（Claude の見立て）

### 3.1 比較の順序は、許す判定・操作の類で決まる

2 節の結果は、どれも「判定や操作の類を指定した課題での成績の比較」と「処理の写像の存在」との同値を述べる。違いは、許す課題の類と、それに対応する処理の類にある。

| 許す課題の類 | 対応する処理 | 文献 |
| --- | --- | --- |
| 古典的な判定（POVM）だけ、補助系なし | 統計的射（一般の場合）。有限次元で状態の族がエルミート行列の全体を張るときは、正でトレースを保つ写像（完全正値とは限らない。`matsumoto2010` 定理 13） | `buscemi2012` 定理 3、`matsumoto2010` 定理 13、`jencova2016` 命題 4、`buscemi2016` 命題 1 |
| 上と同じだが、比べられる側（出力）が可換 | CPTP 写像 | `buscemi2012` 命題 4、`buscemi2016` 系 1・3 |
| 量子の出力を持つ判定 | CPTP 写像 | `matsumoto2010` 定理 5 |
| 古典的な判定だが、補助系（完全な補助のモデル、または補助系との合成）を許す | CPTP 写像 | `buscemi2012` 命題 5、`jencova2016` 定理 1・系 1・定理 4 |

これは、[第 22 回の調査メモ](2026-10-01_22_combs-and-composites.md)の 3.1 節の判定基準（記述どうしの同等性は、許す後の操作の類 $`𝒯`$ で決まる）の、比較の順序についての具体例と読める。

### 3.2 (a) の立場との関係

- 補助系を許した比較（`jencova2016` 定理 1・系 1、`buscemi2012` 命題 5）でも、比べる量は識別の成功確率や期待利得で、どれも**古典的な記録の確率**である。補助系の状態を添字とする古典的な相関で足りる（`jencova2016` 系 1）。
- したがって、(a)（古典的な記録とモデルの組）の立場でも、許す実験の類に「補助系と合成した実験」（[D-0001](../definitions/D-0001.md) の複合のプロトコル $`π^M`$ の一種）を含め、さらに引用した定理が要求する補助系の状態・同時測定・入力のアンサンブル（`jencova2016` 定理 1・系 1 では、補助系 $`K_0 = K`$ と $`B_h(K)`$ を張る補助系の状態、出力と補助系の同時の識別。`buscemi2012` 命題 5 では完全な補助のモデル）を許す**場合に**、CPTP の水準でチャネル・装置を比べられる（PR #46 のレビューを受けて条件付きにした）。補助系を許さず、各装置の出力を単独で読み出す実験だけなら、得られる順序は統計的射の水準にとどまり、CPTP の後処理の有無は一般には決まらない。「補助系と合成した実験」を含めると判断する場合は、補助系に許す状態と、出力と補助系に許す同時測定を明示する。そうすれば、引用したチャネル比較の定理を適用できる範囲がはっきりする（PR #46 のレビューの詳細化の論点）。
- この意味で、「(a) で装置を比べるときに、どの実験の類を可能な実験に含めるか」が、比較の細かさを決める。これは、第 22 回の調査メモの 3.2 節の「部分の記述がトモグラフィーに足りない場合は合成性が失われる」という見立てと整合する。

### 3.3 状態の族の比較とチャネルの比較

- チャネルの比較は、入力に完全な実験を通した統計的実験の比較に帰着する（`jencova2016` 系 3）。逆に、入力を一部の状態の族に限った比較（統計的実験の比較）は、チャネルの比較より粗い。
- 本プロジェクトでは、可能な実験の装置のモデルを比べるときに、「設定の空間 $`X`$ の全体を入力とするチャネルとして比べる」か、「推定の対象 $`Θ`$ ごとの記録の分布の族として比べる」かを選ぶことになる。前者のうち、設定を古典的な入力とする cq チャネルとして比べるなら、入力の量子状態の情報的な完全性は定義には要らない。設定の背後にある量子入力のチャネルを、既知の準備状態から同定・比較したい場合に、情報的に完全な準備の族が要る（PR #46 のレビューを受けて分けた）。後者は [D-0005](../definitions/D-0005.md) の未解決の点（$`Θ`$ の読み方）と同じ論点である。
- 前処理による比較と、前処理と後処理の組合せ（`jencova2016` の結びでは今後の課題）は、設定の側の処理（設定の読み替え）を含む比較にあたる。本プロジェクトの実験の比較（模倣）には、こちらが要りうる（[第 17 回の調査メモ](2026-09-30_17_comparison-of-experiments.md)の 7.3 節のねじれ射の圏の候補と関係する）。

### 3.4 極限（D-0005）との関係

- 次の二つは、[D-0005](../definitions/D-0005.md) の極限の位相の候補（古典的な Le Cam の弱位相。第 18 回）の量子版の候補になる。二つは別のものである。
  - チャネルについて：`jencova2016` の不足度 $`δ(Φ, Ψ)`$（ダイヤモンドノルム）と、それを対称化した $`Δ(Φ, Ψ)`$。$`Δ`$ はチャネルの上では擬距離で（互いに後処理で得られる異なるチャネル、例えば恒等チャネルとユニタリ共役のチャネルでは 0 になる）、$`Δ = 0`$ で同一視した同値類の上で距離になる（PR #46 のレビューを受けて書き分けた）。
  - 状態の族について：`matsumoto2010` の量子的な不足度。方向を持ち、パラメータごとの誤差 $`e_θ`$ で表される。距離として使うには、誤差を $`θ`$ について一様にし（$`\sup_θ e_θ`$）、両方向の不足度の大きい方を取って対称化する定義を置く必要がある（PR #46 のレビューを受けて分けた）。
- 量子 LAN（`kahn2009` 定理 4.3）は、局所的なパラメータで添字づけた状態の族（量子の統計的実験）の列が、状態の族の量子的な Le Cam 距離（CPTP チャネルによる近似の誤差）の意味で、古典・量子のガウスのモデルに収束することを述べる。これは状態の族の距離であり、`jencova2016` のチャネルの不足度（ダイヤモンドノルム）とは別に定義される。二つを結ぶには、状態の族をチャネル（設定から状態への cq チャネルなど）として表したときに距離が一致する条件を示す必要があり、今は候補にとどまる（PR #46 のレビューを受けて分けた）。 具体的に調べる候補：$`Θ`$ が有限で共通なとき、各 $`θ`$ に $`ρ_θ`$（または $`σ_θ`$）を出力する cq チャネルとして表すと、後処理 $`α`$ を固定したときの差のダイヤモンドノルムは $`θ`$ ごとのトレースノルムの最大値になる、とされる（PR #46 のレビューの詳細化の論点。まだ確かめていない）。そうなら、状態の族の一様な不足度とチャネルの不足度が対応する。極限が古典の部分と量子の部分の積になる点は、フレームワークの要件（量子・古典・混成の実験を扱う）に合う例である。
- ただし、`jencova2016` と `buscemi2012` は有限次元を仮定し（`matsumoto2010` は可分なヒルベルト空間）、無限次元への拡張は `jencova2016` の結びで課題とされている。設定や結果が連続の場合（[A-0003](../assumptions/A-0003.md)）への適用には、この点を確かめる必要がある。

## 4. 因果的非分離性と第 23 回の段階 3（Claude の見立て）

### 4.1 二つの水準を分ける

- 原典は、二つの水準を区別している。
  - **相関の水準**（装置に依存しない）：設定と結果の確率の族が、確率的な因果順序（`oreshkov2016` の因果的な過程）で説明できるか。因果不等式で判定する。
  - **過程の水準**（当事者の量子的な操作を信頼する）：過程行列が、因果順序の決まった過程の凸結合（2 者）や、再帰的な分解（多者）で書けるか。因果の証人で判定する。
- 量子スイッチは、過程の水準では因果的に非分離だが、相関の水準では因果的である（`araujo2015` VI 節）。

### 4.2 (a) の立場への当てはめ

- (a) の立場で、許す操作を「設定を選び、古典的な結果を記録する」ことに限り、装置の量子的な特徴づけを前提にしなければ、比べるのは相関の水準である。この水準では、量子スイッチや時空の重ね合わせの例（`araujo2015` が挙げる、物理的な解釈を持つ例）の記録の分布は、確率的な因果順序で説明できる。
- 確率的な因果順序（`oreshkov2016` の定義 II.3）は、局所的な実験の上の厳密な半順序を値とする確率変数で、各実験の設定が、その因果的な未来にない実験の結果（と因果の配置）に影響しない条件を課す（自由に選ぶ設定についての条件で、適応的な設定は、選び方の規則をプロトコルに含めて表し直して扱う）。これは、[A-0016](../assumptions/A-0016.md)（観測の準備と登録の順序、適応的な設定での観測の間の順序）を、順序が確率的で動的な場合に拡げた形と読める。第 23 回の段階 2（確率的な較正）の、順序の部分の候補になる。
- 量子スイッチのような、相関の水準では因果的で過程の水準でだけ非分離な過程を段階 3 の候補にする場合、それが問題になるのは、可能な実験の層のモデルで装置の量子的な操作（instrument）を特徴づけ、それを信頼する場合である。つまり、許す後続の操作の類 $`𝒯`$ に、量子的な操作の特徴づけを含める場合である。一方、因果不等式を破る過程（`oreshkov2012` の例など）は、操作を信頼しない相関の水準でも確率的な因果順序を否定する。こちらと段階 3 との関係は、別に検討する。なお、因果順序が否定されることから、事象に位置を割り当てられないことが直ちに従うわけではない（PR #46 のレビューを受けて限定した）。これは、[第 23 回の調査メモ](2026-10-02_23_quantum-clocks-and-frames.md)の 3.2 節の「段階 3 に含めるための追加の条件」の候補になる。
- 2 者の古典的な過程は因果的に分離可能であり（`oreshkov2012`）、古典的に制御された量子回路は ECS である（`oreshkov2016`）。3 者以上の古典的な過程一般には、前者は成り立たない（局所的な操作が古典的でも非因果的な過程がある）。ここで整合するのは、古典的に制御された回路として組み立てられた実験の場合である。実際の実験が古典的な記録と古典的な制御（[D-0001](../definitions/D-0001.md) の適応的な設定）で組み立てられていることは、この意味で、確率的な因果順序による記述と整合する。
- ただし、`oreshkov2016` の例のように、因果的に分離可能でも、もつれた補助系を与えると非因果的になる過程がある。補助系との合成を可能な実験に含めるか（3.2 節と同じ論点）によって、どの水準の因果性を要求するかが変わる。
