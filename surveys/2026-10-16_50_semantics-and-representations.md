## 2. 文献で確かめた内容（第 1 部）

### 2.1 表現と許容性

- **表現**（representation）：カントール空間・ベール空間など（名前の空間 $`Σ^ω`$）から集合 $`X`$ への部分的な全射 $`δ :\subseteq Σ^ω → X`$。$`δ(q) = x`$ のとき、$`q`$ を $`x`$ の名前（name）と呼ぶ。関数 $`f : X → Y`$ の実現（realizer）は、名前を名前に写す関数 $`F`$ で $`δ_Y ∘ F = f ∘ δ_X`$ を満たすもの（`kreitz1985`。後続の文献の説明による）。
- **許容性**（admissibility。Kreitz–Weihrauch）：表現が連続で、連続な表現のうちで連続な帰着について最大であること（任意の連続な $`δ' :\subseteq Σ^ω → X`$ について、$`δ' = δ ∘ G`$ となる連続な $`G`$ があること）。「合理的な表現」の基準として提案された（後続の文献の説明による）。
- **許容的な表現での実現可能性**（`schroder2002` の要旨）：許容的な表現の間では、部分関数が連続に実現できることと、点列連続であることが一致する。許容的な表現を持つ空間は、点列化が qcb₀ 空間であるもの（後続の文献による引用）。
- **実数の二進表現は許容的でない**（`weihrauch2000` の定理 4.1.13 の 6。後続の文献での引用による）：$`[0, 1]`$ の二進表現は連続な全射だが許容的でなく、例えば $`x ↦ 3x`$（$`[0, 1/3]`$ の上）に連続な実現がない。符号付きの桁（$`\{-1, 0, 1\}`$）の表現、有理数の列の表現は許容的である。

### 2.2 実効的なボレル可測性と、極限の次数

- `brattka2005`：ボレル可測性の定義を実効化し、計算可能な距離空間の上のボレル可測な関数について、Kreitz–Weihrauch の表現定理を一般化した（要旨）。極限計算可能な関数が実効的に $`Σ^0_2`$ 可測な関数と一致することは、`brattka2011` での引用で確かめた。
- `brattka2011`：多価関数のワイラウフ帰着（Weihrauch reducibility）の次数を調べ、LPO を並列化したものが極限計算可能な関数について完全であることを示した（要旨）。$`\lim`$ の次数そのものの記述は、本文を読んで確かめる。

## 3. プロジェクトへの当てはめ（Claude の見立て）

### 3.1 C-0016 の写像 $`h`$ は許容的でない

[C-0016](../conjectures/C-0016.md) の $`h : 𝒞 → [-1, 1]`$（符号の桁と二進の桁）は、二進表現の符号付きの版である。C-0016 の詳細化の論点に書いた $`g(d) = \sum_{i ≥ 0} 2^{-(i+1)} d_i - 1/3`$ で確かめられる：$`g`$ は名前の空間からの連続写像で、$`d = 0101⋯`$ で 0 をとり、その任意の近傍に正と負の値が現れる。$`g = h ∘ G`$ となる連続な $`G`$ があれば、$`G(d)`$ の符号の桁 $`G(d)_0`$ は $`d = 0101⋯`$ の近傍で一定になるが、$`g > 0`$ の点では 1、$`g < 0`$ の点では 0 でなければならないので矛盾する。したがって $`h`$ は許容的でない（2.1 節の定理 4.1.13 の 6 と同じ型の理由。$`0`$ に二つの名前があること自体は理由ではない）。

### 3.2 表現を取り替えても、$`[-1, 1]`$ の上の応答の連続性は変わらない

表現 $`δ`$ で連続に実現できる $`f : X → \{0, 1\}`$ は、$`f ∘ δ`$ が連続なもの、すなわち $`δ`$ の終位相（商位相）で連続なものである。$`h`$ はコンパクト空間からハウスドルフ空間への連続な全射なので商写像であり、終位相は $`[-1, 1]`$ の通常の位相に一致する。したがって、

- 閾値の応答 $`p(1 \mid x) = 𝟙_{x ≥ 0}`$ は、$`h`$ でも（許容的な表現と同じく）連続に実現できない。
- $`p'(1 \mid d) = d_0`$ は、0 の二つの名前に異なる値を与えるので、$`[-1, 1]`$ の上の関数の実現ではない（名前の上の関数で、外延的でない）。

つまり、「表現の選び方」は $`[-1, 1]`$ の上の関数のうち何が連続かを変えない（許容的でない $`h`$ を選んでも、終位相は同じ）。C-0016 の二つの意味論の違いは、表現の選び方ではなく、設定の空間そのものを $`[-1, 1]`$ から名前の空間 $`𝒞`$ に取り替えたこと（記録をそのまま設定とすること）にある。これは C-0016 の主張の 4（同じ応答 $`p`$ の扱いが変わるのではなく、別の模型 $`p'`$ との比較である）と整合する。

### 3.3 「意味論」の扱いへの含み（決めるための材料）

- 第 49 回の Claude の案（意味論を記録から設定への対応（表現）の選び方から述べる）は、3.2 節のとおり、設定の空間の上の応答の連続性を変えない。表現から述べるなら、比べる対象は「名前の空間の上の模型（記録の模型）」と「設定の空間の上の模型（その商）」になり、意味論の違いは、名前の上の応答が商に降りるか（外延的か）の違いとして現れる。
- この見方では、閾値の振る舞いの問いは「記録の区別（0 の二つの名前）を物理的な設定の区別として認めるか」に置き換わる。これは C-0018 の型の問い（その区別を記録できる装置があるか）と結びつく。
- 位相の割り当て（設定の空間に何を置くか）として述べる見方は、2 部（幾何学的論理）で調べる位相的意味論・ロケールの見方と合う。二つの見方の関係（名前の空間の位相と、そこから作る命題の代数）は、2 部の後にまとめる。
