## 2. 文献で確かめた内容（第 1 部）

### 2.1 表現と許容性

- **表現**（representation）：カントール空間・ベール空間など（名前の空間 $`Σ^ω`$）から集合 $`X`$ への部分的な全射 $`δ :\subseteq Σ^ω → X`$。$`δ(q) = x`$ のとき、$`q`$ を $`x`$ の名前（name）と呼ぶ。関数 $`f : X → Y`$ の実現（realizer）は、名前を名前に写す関数 $`F`$ で $`δ_Y ∘ F = f ∘ δ_X`$ を満たすもの（`kreitz1985`。後続の文献の説明による）。
- **許容性**（admissibility。Kreitz–Weihrauch）：表現が連続で、連続な表現のうちで連続な帰着について最大であること（任意の連続な $`δ' :\subseteq Σ^ω → X`$ について、$`δ' = δ ∘ G`$ となる連続な $`G`$ があること）。「合理的な表現」の基準として提案された（後続の文献の説明による）。
- **許容的な表現での実現可能性**（`schroder2002` の要旨）：許容的な表現の間では、部分関数が連続に実現できることと、点列連続であることが一致する。許容的な表現を持つ空間は、点列化が qcb₀ 空間であるもの（後続の文献による引用）。
- **実数の二進表現は許容的でない**（`weihrauch2000` の定理 4.1.13 の 6。後続の文献での引用による）：$`[0, 1]`$ の二進表現は連続な全射だが許容的でなく、例えば $`x ↦ 3x`$（$`[0, 1/3]`$ の上）に連続な実現がない。符号付きの桁（$`\{-1, 0, 1\}`$）の表現、有理数の列の表現は許容的である。

### 2.2 実効的なボレル可測性と、極限の次数

- `brattka2005`：ボレル可測性の定義を実効化し、計算可能な距離空間の上のボレル可測な関数について、Kreitz–Weihrauch の表現定理を一般化した（要旨）。極限計算可能な関数が実効的に $`Σ^0_2`$ 可測な関数と一致することは、`brattka2011` での引用で確かめた。
- `brattka2011`：多価関数のワイラウフ帰着（Weihrauch reducibility）の次数を調べ、LPO を並列化したものが極限計算可能な関数について完全であることを示した（要旨）。$`\lim`$ の次数そのものの記述は、本文を読んで確かめる。

### 2.3 確率測度の空間の表現

- `schroder2007`：確率測度の空間の許容的な表現を与える（題名と、後続の文献での引用による）。内容は本文で確かめる。

## 3. プロジェクトへの当てはめ（Claude の見立て）

### 3.1 C-0016 の写像 $`h`$ は許容的でない

[C-0016](../conjectures/C-0016.md) の $`h : 𝒞 → [-1, 1]`$（符号の桁と二進の桁）は、二進表現の符号付きの版である。C-0016 の詳細化の論点に書いた $`g(d) = \sum_{i ≥ 0} 2^{-(i+1)} d_i - 1/3`$ で確かめられる：$`g`$ は名前の空間からの連続写像で、$`d = 0101⋯`$ で 0 をとり、その任意の近傍に正と負の値が現れる。$`g = h ∘ G`$ となる連続な $`G`$ があれば、$`G(d)`$ の符号の桁 $`G(d)_0`$ は $`d = 0101⋯`$ の近傍で一定になるが、$`g > 0`$ の点では 1、$`g < 0`$ の点では 0 でなければならないので矛盾する。したがって $`h`$ は許容的でない（2.1 節の定理 4.1.13 の 6 と同じ型の理由。$`0`$ に二つの名前があること自体は理由ではない）。

### 3.2 表現を取り替えても、$`[-1, 1]`$ の上の応答の連続性は変わらない

表現 $`δ`$ で連続に実現できる $`f : X → \{0, 1\}`$ は、$`f ∘ δ`$ が連続なもの、すなわち $`δ`$ の終位相（商位相）で連続なものである。$`h`$ はコンパクト空間からハウスドルフ空間への連続な全射なので商写像であり、終位相は $`[-1, 1]`$ の通常の位相に一致する。したがって、

- 閾値の応答 $`p(1 \mid x) = 𝟙_{x ≥ 0}`$ は、$`h`$ でも（許容的な表現と同じく）連続に実現できない。
- $`p'(1 \mid d) = d_0`$ は、0 の二つの名前に異なる値を与えるので、$`[-1, 1]`$ の上の関数の実現ではない（名前の上の関数で、外延的でない）。

つまり、「表現の選び方」は $`[-1, 1]`$ の上の関数のうち何が連続かを変えない（許容的でない $`h`$ を選んでも、終位相は同じ）。C-0016 の二つの意味論の違いは、表現の選び方ではなく、設定の空間そのものを $`[-1, 1]`$ から名前の空間 $`𝒞`$ に取り替えたこと（記録をそのまま設定とすること）にある。これは C-0016 の主張の 4（同じ応答 $`p`$ の扱いが変わるのではなく、別の模型 $`p'`$ との比較である）と整合する。

### 3.3 「意味論」の扱いへの含み（決めるための材料）

- 第 49 回の Claude の案（意味論を記録から設定への対応（表現）の選び方から述べる）は、3.2 節のとおり、設定の空間の上の応答の連続性を変えない。表現から述べるなら、比べる対象は「名前の空間の上の模型（記録の模型）」と「設定の空間の上の模型（その商）」になり、意味論の違いは、名前の上の応答が商に降りるか（外延的か）の違いとして現れる。
- この見方では、閾値の振る舞いの問いは「記録の区別（0 の二つの名前）を物理的な設定の区別として認めるか」に置き換わる。これは C-0018 の型の問い（その区別を記録できる装置があるか）と結びつく。
- 位相の割り当て（設定の空間に何を置くか）として述べる見方は、2 部（幾何学的論理）で調べる位相的意味論・ロケールの見方と合う。二つの見方の関係（名前の空間の位相と、そこから作る命題の代数）は、2 部の後にまとめる。

## 5. 文献で確かめた内容（第 2 部）

### 5.1 幾何学的論理と、有限の観測の論理

- `vickers1989`：ロケールの見方から位相を導入し、動機を「有限の観測で確かめられる命題」の論理に置く（出版元の説明）。中心の構成は**位相系**（topological system）$`(X, ⊨, A)`$：集合 $`X`$、フレーム $`A`$、その間の充足関係 $`⊨`$（条件つき）の三つ組で、これを幾何学的論理（有限の観測の論理）と結びつける（後続の文献の説明）。本プロジェクトの「有限の精度の命題」と、記録（$`X`$ の側）と命題（$`A`$ の側）を分けて充足関係で結ぶ形が、そのまま近い。
- `abramsky1991`：ストーン双対を使って、領域理論の意味論（型を領域、項をその元）と、型を命題的な理論、項をプログラム論理で公理化した性質の集まりとして読む見方を結び、二つの解釈が互いのストーン双対であることを示す。下の論理は幾何学的で、式は観測可能な性質（過程の実行についての有限の情報で確かめられる性質）を表す（要旨）。

### 5.2 完全性と点の有無

- 命題的な幾何学的理論は、生成元と関係で与えたフレーム（分類ロケール）を持ち、ロケールの点は理論のモデルに当たる。幾何学的論理には、集合値のモデルについての通常の意味の完全性定理は一般にはない（nLab・Vickers の講義資料の説明）。フレームの中のモデル（ロケール）まで許せば、リンデンバウム代数そのものがモデルになる。
- **コヒーレントなロケールは空間的**（spatial）である。これは、コヒーレントなトポスが十分な点を持つというドリーニュの完全性定理の特別な場合で、ローヴェアはドリーニュの定理がゲーデル–ヘンキンの完全性定理の変種であることを示した（nLab の説明）。十分な点を持つトポスは、集合値のモデルについての完全性を持つ幾何学的理論に当たる（後続の文献の説明）。
- 点を持たないが自明でないロケールがある。例：自然数から実数への全射のロケール（そのような全射はないので点を持たないが、自明でない開部分を多く持つ。Johnstone『Elephant』の C1.2 の例 1.2.8。nLab の説明）。

### 5.3 位相的意味論

- `mckinsey1944`：様相論理 S4 は、自己稠密な可分距離空間のどれについても完全で、特に実数直線について完全である。直観主義命題論理は、開集合の代数（ハイティング代数）の位相的な表現によって位相的に完全である（タルスキが 1930 年代に示した）。McKinsey–Tarski は、直観主義論理から S4 へのゲーデルの翻訳が忠実であることも示した（後続の文献での引用による）。

### 5.4 一様ロケールと完備化

- `banaschewski1996`：一様フレーム（の一般化の近接フレーム）の**正則なコーシー・フィルター**を「コーシー点」と呼び、完備化が一意に存在すること、コーシー点の空間（コーシー・スペクトル）が完備化の通常のスペクトル（点の空間）と一致することを示した（要旨）。点なしの設定では正則なコーシー・フィルターが乏しいことがあり、それに頼らない「完全にコーシーな」準同型の考え方も後に導入された（Banaschewski–Pultr 1997 の要旨。未登録）。

## 6. プロジェクトへの当てはめ（第 2 部。Claude の見立て）

### 6.1 C-0017 の二つの主張の位置

- C-0017 の主張の 1（ロケールまで許せば、妥当な命題と導ける命題は一致する）は、5.2 節のとおり、リンデンバウム代数がモデルになることからほぼ定義どおりに従う。新しい中身は少ない。
- 主張の 2（点のモデルに限る場合）は、記録から作るフレームが空間的か、という問いになる。5.2 節のとおり、コヒーレントな（有限の観測の命題が有限の交わりで閉じ、コンパクトな元で生成される）理論なら空間的で、完全性はドリーニュ・ゲーデルの型の定理として成り立つ。記録が有限の精度の命題だけからなる場合、生成されるフレームがコヒーレントになる条件を探すのが、主張の 2 を具体化する道である。
- 一方、全射のロケールのように、整合的なのに点を持たない理論もある。記録の構文から作った理論がそうなるなら、点のモデルだけの意味論では、その理論の帰結を区別できない。これは C-0015 の「点が現れる条件」と同じ型の問いである。

### 6.2 「意味論」の扱い（第 1 部と合わせて）

- 第 1 部（3.2 節）では、表現の選び方は設定の空間の上で何が連続かを変えず、C-0016 の差は設定の空間そのものを取り替えたことにある、と見た。第 2 部の見方では、これは**命題の代数（フレーム）を取り替えた**ことに当たる：標準の意味論は $`𝒪([-1, 1])`$、ストーン空間の意味論は $`𝒪(𝒞)`$（ストーン双対では、ブール代数としての桁の命題の代数）で、後者には「$`d_0 = 1`$」という開かつ閉の命題がある。
- したがって、本プロジェクトの「意味論」は、Vickers の位相系の形で、**記録の集合と、有限の観測の命題の代数（フレーム）と、その間の充足関係**として述べるのが、第 1 部・第 2 部の両方と合う見込みである。位相の割り当て（命題の代数の選択）と、表現（記録から点への対応）は、この三つ組の別々の成分として扱える。
- C-0016 の問い（閾値を連続な模型として書けるか）は、「記録の区別（0 の二つの名前）に当たる命題を、命題の代数に入れるか」と言い換えられる。C-0017 の問いは、その命題の代数が点を十分に持つかである。
