## 2. Blackwell–Dubins の定理（`blackwell1962`）

### 2.1 設定と定理

- **設定**：各 $`i`$ で可測空間 $`(X_i, 𝔅_i)`$ を取り、その無限積 $`(X, 𝔅)`$ の上の σ 加法的な確率を考える（原典は、すべての確率を可算加法的とする）。$`X_i`$ は任意の可測空間でよく、有限集合に限らない。
- **予測的**（predictive）：確率 $`P`$ が予測的であるとは、各 $`n`$ で、過去 $`x_1, …, x_n`$ が与えられたときの将来 $`X_{n+1} × ⋯`$ の条件付き分布 $`P^n`$ が存在することをいう（通常の三つの性質を満たす関数として）。原典は、この仮定は穏やかで、知られている自然な確率はすべて満たすとし、予測的な確率に絶対連続な確率も予測的であると注記する。
- **距離**：同じ σ 加法族の上の二つの確率の距離 $`ρ(μ_1, μ_2)`$ は、事象 $`D`$ にわたる $`\left| μ_1(D) - μ_2(D) \right|`$ の上限（全変動距離）である。
- **主定理**：$`P`$ が予測的で、$`Q`$ が $`P`$ に絶対連続であるとする。このとき、$`P`$ についての将来の条件付き分布 $`P^n`$ の各版に対して、$`Q`$ についての条件付き分布 $`Q^n`$ の版で、次を満たすものがある。$`Q`$ 確率 0 の履歴を除いて、$`ρ(P^n(x_1, …, x_n), Q^n(x_1, …, x_n))`$ は $`n → ∞`$ で 0 に収束する。
- **証明の筋**：$`Q`$ の $`P`$ に対する密度 $`q`$ を取り、過去で条件付けた密度 $`q_n`$ との比 $`d_n = q / q_n`$ を考える。マルチンゲールの収束定理（少し一般化した形。原典の定理 2）から、$`d_n → 1`$ が $`Q`$ についてほとんど確実に言える。これから距離の評価が従う。

### 2.2 原典の解釈と注意

- **解釈**（5 節）：二人の意見 $`P, Q`$ が「$`P(D) > 0 ⇔ Q(D) > 0`$」という点だけで一致していれば、二人はともに、十分多くの観測の後には意見が近いままになると確信する。「近い」は、すべての事象 $`E`$ について確率の差が $`ε`$ 以下で、$`ε`$ は $`E`$ によらない。
- **交換可能な場合**（5 節。Savage の指摘として紹介）：$`P, Q`$ が、パラメータを固定すると独立同分布になる観測の、事前分布 $`p, q`$ による混合なら、$`P`$ と $`Q`$ の絶対連続性の関係は、$`p`$ と $`q`$ の関係とちょうど同じである（原典はこの主張の証明を載せておらず、パラメータの取り方も明示していない。パラメータから観測の分布への写像が単射であることを暗に仮定していると読むべきである。単射でなければ、例えば異なるパラメータが同じ分布を表すとき、互いに特異な事前分布から同じ予測分布が得られる）。
- **注意**（6 節）：過去で条件付けた分布は一致しても、条件付けない将来の分布 $`P(n)`$（最初の $`n`$ 個を捨てた分布）は一致しなくてよい。二つの異なる成功確率の独立なコイン投げの、異なる重みによる混合 $`P, Q`$ は、互いに絶対連続だが、$`P(n) = P`$ と $`Q(n) = Q`$ はいつまでも離れている。

### 2.3 二次文献による補足

- **絶対連続性の必要性**（`pomatto2014`、命題 1）：$`Ω = \{0, 1\}^∞`$ で、$`P`$ がすべての有限の履歴に正の確率を与えるとき、$`P`$ が $`Q`$ に併合する（merge）なら $`Q ≪ P`$ である。
- **σ 加法性は外せない**（同、例 1）：有限加法的な確率では、絶対連続でも一致しない例がある。
- `pomatto2014` の定理 1 は、原典の結論を確率収束の形で述べている。原典は、$`Q`$ についてほとんど確実な収束である。

## 3. 事後一致性

### 3.1 Doob の定理（`miller2018`、`diaconis1986`）

- **仮定**（`miller2018` の仮定 2.1）：標本の空間とパラメータの空間 $`Θ`$ が、完備可分距離空間のボレル部分集合である。$`θ ↦ P_θ`$ が可測で単射である（識別可能）。データはパラメータを与えると独立同分布である。
- **結論**（`miller2018` の定理 2.4）：事前分布 $`Π`$ について確率 1 の集合 $`Θ_1`$ があり、各 $`θ_1 ∈ Θ_1`$ で事後分布は一致的である。つまり、$`P_{θ_1}`$ に従う独立同分布のデータについてほとんど確実に、$`θ_1`$ の任意の近傍の事後確率が 1 に収束する。
- 例外の集合は、主体自身の事前分布で測って零の集合なので、主体ごとに異なりうる。`diaconis1986` の付録 A（系 A.2）も、弱位相での形で同じ結論を証明している。

### 3.2 Schwartz の定理（`choi2008`、`kleijn2019`）

- **KL 台**（`choi2008` の定義 2.1）：$`θ_0`$ が事前分布 $`Π`$ の KL 台に入るとは、すべての $`ε > 0`$ で $`Π(\{ θ : K(θ_0, θ) < ε \}) > 0`$ となることをいう。$`K`$ はカルバック–ライブラー情報量である。
- **定理**（`kleijn2019` の定理 1.1）：モデルがヘリンガー距離について全有界で、$`P_0`$ が事前分布の KL 台に入るとする。このとき事後分布は、$`P_0`$ に従う独立同分布のデータについてほとんど確実に、ヘリンガー距離の意味で $`P_0`$ に集中する。
- `choi2008` の定理 3.7 は、KL 台の条件と、一様に一致的な検定の存在から一致性を導く、元の形を述べている。

### 3.3 不一致の例と、有限次元の場合（`diaconis1986`）

- **有限次元の滑らかな族**（1 節）：$`(θ, μ)`$ が一致的であることと、$`θ`$ が事前分布 $`μ`$ の台に入ることは同値である。論文は条件を詳しく述べず、Freedman 1963 と Schwartz 1965 を引く。識別可能性などの正則性の条件が前提と読むべきである（例えば $`P_θ`$ をベルヌーイ分布 $`\mathrm{Bernoulli}(θ^2)`$ とし、事前分布を $`θ = ±1/2`$ に半分ずつ置くと、真の値 $`1/2`$ は台に入るが、二点をデータで区別できないので事後分布は真の値に集中しない。PR #31 のレビューの例）。5.1 節の設定は、情報的に完全な測定で識別可能なので、この条件を満たす。
- **無限次元での反例**（1 節）：Freedman 1963 は、正の整数の上の分布で、真の分布（幾何分布）の任意の開近傍に正の確率を置くのに、事後分布が別の幾何分布に集中する事前分布を作った。位相的な意味（第 1 類の集合）では、一致的な組は例外的である（Freedman 1965）。
- **位置の問題**（1 節の定理 2）：誤差の分布に対称化したディリクレ事前分布（コーシーの基底測度）を置くと、ある対称な誤差の密度の下で、ベイズ推定量が $`±γ`$ の間で振動して一致しない。

## 4. 一致性と、弱位相での主体の間の一致（`diaconis1986` の 3 節と付録 A）

- **弱位相での併合**：確率の列 $`α_n, β_n`$ が弱位相で併合（merge weak-star）するとは、$`R(α, α) = 0`$ を満たす弱位相で連続なすべての関数 $`R`$ について、$`R(α_n, β_n) → 0`$ となることをいう（付録 A の (A.3)）。
- **予測分布**：$`P_{μ n} = \int Q_θ^∞\, μ_n(dθ)`$ は、事前分布 $`μ`$ の主体が $`n`$ 個のデータを見た後に持つ、将来全体の予測分布である。
- **定理 A.1**：$`θ ↦ Q_θ`$ が単射でボレル可測なら、次の三つは同値である。(i) 事後分布 $`μ_n`$ が一致的である（すべての $`θ`$ で）。(ii) すべての事前分布 $`ν`$ について、$`P_ν`$ 確率 1 で、第 1 の主体が $`θ`$ を正しく推定する。(iii) すべての $`ν`$ について、$`μ_n`$ と $`ν_n`$ が $`P_ν`$ 確率 1 で弱位相で併合する。さらに $`θ ↦ Q_θ`$ が連続で連続な逆写像を持てば、(i) は次とも同値である。(iv) すべての $`ν`$ について、予測分布 $`P_{μ n}`$ と $`P_{ν n}`$ が $`P_ν`$ 確率 1 で弱位相で併合する。
- 本文の定理 3 は、この (i) と (iv) の同値を述べたものである。連続性の条件は外せない（付録 A の注意 (3)・(4) に反例がある）。
- **絶対連続性と特異性**（3 節）：$`θ ↦ Q_θ`$ が単射でボレル可測なら、事前分布について $`μ ≡ ν`$（互いに絶対連続）と $`P_μ ≡ P_ν`$ は同値で、$`μ ⊥ ν`$ と $`P_μ ⊥ P_ν`$ も同値である。したがって、事前分布が互いに特異な場合（ディリクレ事前分布では普通に起こる）には、Blackwell–Dubins の定理は使えない。弱位相での併合は、それでも起こりうる。

## 5. A-0007 への当てはめ（Claude の検算）

第 16 回の最初の報告で挙げた三つの補足を、証明の形で確かめた。原典で確かめた定理（2〜4 節）を使うが、組み合わせ方は Claude の補足である。

**設定**：有限次元 $`d`$ の量子系で、結果が有限個（$`m`$ 個）の情報的に完全な POVM $`\{E_k\}`$ を、各系で独立に繰り返す。状態 $`ρ`$ の結果の分布を $`p_ρ(k) = \mathrm{tr}(E_k ρ)`$ とする。二人の主体の事前分布を $`μ, ν`$（密度作用素の空間 $`𝒟_d`$ の上の確率測度）とする。

### 5.1 KL 台と台は一致する

- 写像 $`ρ ↦ p_ρ`$ は線形で単射（情報的に完全）で連続であり、$`𝒟_d`$ はコンパクトなので、像への同相写像である。
- $`K(p_{ρ_0}, p_ρ) = \sum_{k : p_{ρ_0}(k) > 0} p_{ρ_0}(k) \log\, (p_{ρ_0}(k) / p_ρ(k))`$ は、$`ρ → ρ_0`$ で 0 に収束する（$`p_{ρ_0}(k) > 0`$ の項だけが残り、その項では $`p_ρ(k) → p_{ρ_0}(k) > 0`$）。したがって、KL 近傍は $`ρ_0`$ の近傍を含み、台の点は KL 台に入る。
- 逆に、Pinsker の不等式から KL 情報量が小さければ全変動距離も小さく、同相写像により $`ρ`$ は $`ρ_0`$ に近い。したがって、KL 台の点は台に入る。
- 結果の空間が有限なので、モデルはヘリンガー距離について全有界である。Schwartz の定理（3.2 節）から、$`ρ_0`$ が事前分布の台に入れば、事後分布は $`p_{ρ_0}^∞`$ についてほとんど確実に $`ρ_0`$ に集中する（同相写像で、結果の分布の空間から $`𝒟_d`$ へ移す）。台に入らなければ、事後分布は $`ρ_0`$ のある近傍に確率を置かないので、一致しない。これは `diaconis1986` の「有限次元の滑らかな族では、一致性と台に入ることは同値」（3.3 節。識別可能性などの条件の下で）と合う。
- **第 15 回の論点への答え**：QBism の一致の主張の「データが指す状態の近傍で事前分布が正」という条件は、「真の状態 $`ρ_0`$ が事前分布の台に入る（すべての開近傍に正の確率を置く）」と読むのが正しく、この設定では Schwartz の定理の KL 台の条件と同値である（[第 15 回の調査メモ](2026-09-29_15_qbism-agreement.md)の 2.4 節）。

### 5.2 将来全体の予測の全変動距離は、事後分布の全変動距離に等しい

- 結果の列の空間の上の予測分布を $`U(μ) = \int p_ρ^∞\, μ(dρ)`$ と書く。
- 大数の法則と同相写像の逆から、結果の列から $`ρ`$ を復元する可測な写像 $`f`$ があり、すべての $`ρ`$ について $`p_ρ^∞`$ についてほとんど確実に $`f = ρ`$ となる。これは `diaconis1986` の付録 A の識別可能性の議論（(A.2)）と同じである。
- 同じ核による混合は全変動距離を増やさないので、$`ρ(U(μ), U(ν)) ≤ ρ(μ, ν)`$。逆に、$`U(μ)(f ∈ B) = μ(B)`$ なので、$`ρ(U(μ), U(ν)) ≥ ρ(μ, ν)`$。したがって等号が成り立つ。
- 同じ議論で、$`U(μ) ≪ U(ν)`$ と $`μ ≪ ν`$ は同値になる。これは A-0007 の「注意」の同値（同一の情報的に完全な測定を繰り返す場合）の証明であり、`diaconis1986` の 3 節の記述と、`blackwell1962` の 5 節の Savage の指摘に合う。
- 事後分布 $`μ_n, ν_n`$ についても同じなので、将来全体の予測の全変動距離は、事後分布の全変動距離に等しい。

### 5.3 一致の三つの段階

真の状態 $`ρ_0`$ を固定し、データが $`p_{ρ_0}^∞`$ に従うとする。

| 一致する予測 | 仮定 | 根拠 |
| --- | --- | --- |
| 固定した $`N`$ 個の将来の結果（全変動距離）。$`N`$ を動かせば、将来全体の弱位相での併合と同じ | $`ρ_0`$ が両者の事前分布の台に入る | 5.1 節の一致性と、$`ρ ↦ p_ρ^{⊗N}`$ の連続性。`diaconis1986` の定理 A.1（(i) ⇒ (iv)） |
| 将来全体（全変動距離） | 事後分布どうしが全変動距離で近づく（例えば Bernstein–von Mises 型の条件） | 5.2 節の等式 |
| 将来全体（全変動距離）を、主体自身の予測分布についてほとんど確実に | 予測分布の絶対連続性（A-0007）。この設定では事前分布の絶対連続性と同値 | `blackwell1962` の主定理 |

- 結果の空間が有限なので、結果の列の空間の弱位相での収束は、有限個の座標の周辺分布の収束と同じである。そのため、1 行目の「固定した $`N`$」と「将来全体の弱位相での併合」は同じことになる。
- **2 行目が 1 行目より強いことの例**：$`μ`$ が $`ρ_0`$ に原子を持ち、$`ν`$ が密度を持てば、両者とも $`ρ_0`$ に集中するが、$`μ_n(\{ρ_0\}) → 1`$ で $`ν_n(\{ρ_0\}) = 0`$ なので、全変動距離は 1 に近づく。このとき $`μ`$ は $`ν`$ に絶対連続でないので、3 行目の定理とは矛盾しない。
- **2 行目の条件**：両者の事前分布が $`ρ_0`$ の近傍で正の連続な密度を持ち、$`ρ_0`$ が正則な点（$`𝒟_d`$ の内部にあり、すべての $`k`$ で $`p_{ρ_0}(k) > 0`$）なら、Bernstein–von Mises の定理から、両者の事後分布は同じ正規分布に全変動距離で近づき、互いに近づく（確率収束。Bernstein–von Mises の定理は記憶によるもので、原典で確かめていない）。純粋状態は $`𝒟_d`$ の境界にあるので、この形の条件は当てはまらない。
- **3 行目と固定した $`ρ_0`$ の関係**：$`U(μ)(A) = \int p_ρ^∞(A)\, μ(dρ)`$ なので、「$`U(μ)`$ についてほとんど確実に」は「$`μ`$ についてほとんどすべての $`ρ_0`$ で、$`p_{ρ_0}^∞`$ についてほとんど確実に」と同じである。例外になる $`ρ_0`$ は事前分布で測って零の集合で、Doob の定理と同じ形になる。
