## 要旨（自分の言葉で）

位相空間とロケールの随伴（ストーン双対性）を、前順序を持つ空間に拡張する。
空間の点の上の前順序 $`x ≤ y`$ を、開集合の間の前順序 $`U ⊴ V`$ に持ち上げ、後者を公理化したものを**順序付きロケール**（ordered locale）とよぶ。

### 順序付き空間と開錐条件（2 節）

- **順序付き空間**（ordered space）：位相空間に、点の集合上の前順序を加えたもの。位相と順序の間に条件は課さない（順序のグラフが閉集合であることも要求しない）。
- 部分集合 $`A`$ の上集合 $`↑A`$ と下集合 $`↓A`$ を、因果の言葉で未来錐・過去錐とよぶ。
- **開錐条件**（open cone condition）：開集合 $`U`$ について $`↑U`$ と $`↓U`$ が開集合であること。上向き・下向きの片方だけの版もある。
  - 離散空間や、順序を等号にとった任意の空間は開錐条件を満たす。一方、開錐条件は順序の分離公理（順序のグラフが閉など）とは独立である。
  - 相対論の「押し上げ原理」（push-up principle）の抽象化にあたる（補題 2.10）。
  - **滑らかな時空は、因果関係 $`≼`$ について開錐条件を満たす**（系 2.11）。このとき開集合 $`U`$ について $`I^±(U) = J^±(U)`$ となる。

### 順序付きロケール（3 節）

- **定義 3.1**：ロケール $`X`$ と、その開集合フレーム $`𝒪X`$ 上の前順序 $`⊴`$ の組で、次の公理 (∨) を満たすもの。

```math
∀ i ∈ I : U_i ⊴ V_i \implies ⋁_{i ∈ I} U_i ⊴ ⋁_{i ∈ I} V_i
```

- $`⊴`$ のグラフが $`𝒪X × 𝒪X`$ の部分完備結び半束であることと同値。交わりについては閉じていない。
- 空間から作るときの開集合の順序には、上順序（$`V ⊆ ↑U`$）、下順序（$`U ⊆ ↓V`$）、両方を課す **Egli–Milner 順序**の 3 通りがあり、主に Egli–Milner 順序を使う。

```math
U ⊴ V \iff U ⊆ ↓V \text{ かつ } V ⊆ ↑U
```

  「$`U`$ のどの点も $`V`$ のある点の過去にあり、$`V`$ のどの点も $`U`$ のある点の未来にある」という意味である。
- **局所的な錐**（localic cones）：点を使わない未来錐・過去錐。

```math
↟U = ⋁ \{ V ∈ 𝒪X : U ⊴ V \}, \qquad ↡U = ⋁ \{ W ∈ 𝒪X : W ⊴ U \}
```

  空間から作った順序付きロケールでは $`↟U = (↑U)^◦`$、$`↡U = (↓U)^◦`$（内部）であり、開錐条件のもとでは $`↟U = ↑U`$、$`↡U = ↓U`$ となる（補題 4.3）。(∨) のもとで $`U ⊴ ↟U`$、$`↟↟U = ↟U`$ などが成り立つ（補題 3.8）。
- **射**：ロケールの射 $`f : X → Y`$ は逆向きのフレーム準同型 $`f^{-1}`$ なので、「順序を保つ」をそのままは書けない。関係 $`R_f = \{ (U, V) : U ⊆ f^{-1}V \}`$ を使い、関係の 2-圏 Rel での 2-セルの存在として上単調・下単調を定義する（定義 3.4）。局所的な錐で言い換えると、$`↟ f^{-1}(V) ⊑ f^{-1}(↟V)`$ と $`↡ f^{-1}(V) ⊑ f^{-1}(↡V)`$ である（命題 3.9）。これは点の場合の $`↑ g^{-1}(B) ⊆ g^{-1}(↑B)`$（命題 2.2）の類似である。
- **点を持たない順序付きロケールの例**（例 3.11）：孤立点を持たないハウスドルフな順序付き空間の二重否定部分ロケール $`(𝒪S)_{¬¬}`$ は点を持たないが、部分ロケールに誘導した順序（例 3.10）で順序付きロケールになる。

### 点と随伴（4〜6 節）

- 開集合をとる関手 $`𝒪`$ は、開錐条件を満たす空間の上でちょうど射についてうまく定義される（命題 4.4：開錐条件 ⟺ 任意の連続単調写像 $`g`$ について $`𝒪g`$ が単調）。
- 点（完全素フィルター）の間の順序（定義 5.1、補題 5.2）：

```math
F ≤ G \iff ∀ U ∈ F : ↟U ∈ G \text{ かつ } ∀ V ∈ G : ↡V ∈ F
```

- 点の空間 $`\mathrm{pt}(X)`$ が開錐条件を満たすように、公理 (•) を課す：$`U ⊴ V`$ ならば $`\mathrm{pt}(U) ⊴ \mathrm{pt}(V)`$。これは $`↑\mathrm{pt}(U) = \mathrm{pt}(↟U)`$ などと同値（補題 5.6）。点を持たないロケールは (•) を自明に満たす。
- **定理 6.3（随伴）**：開錐条件を満たし「点が十分にある」（weakly sober：単位 $`η_S`$ が全射）順序付き空間の圏と、(•) を満たす順序付きロケールの圏の間に、随伴 $`𝒪 ⊣ \mathrm{pt}`$ がある。
- **$`T_0`$ 順序**（$`T_0`$-ordered、定義 6.5）：$`x ≰ y`$ なら、$`x`$ のある開近傍 $`U`$ で $`y ∉ ↑U`$ となるか、$`y`$ のある開近傍 $`V`$ で $`x ∉ ↓V`$ となる。点の順序を開集合で見分けられるという分離公理で、「$`T_0`$ かつ順序付き」という意味ではない。
- **定理 6.9（順序付きのストーン双対性）**：随伴は、(•) を満たす空間的な順序付きロケールの圏と、開錐条件を満たすソバーな $`T_0`$ 順序空間の圏の同値に制限される。
- **例 6.6**：滑らかな時空は開錐条件を満たすが、$`T_0`$ 順序とは限らない。一点を除いたミンコフスキー時空がその例で、時空をロケールに移すと、点の間の因果関係の情報の一部が失われる。因果的に単純な（causally simple）時空、とくに大域的双曲的な時空は $`T_0`$ 順序である。
  - **（見立て）** 除いた点を通る光的測地線の両側の 2 点は、因果曲線で結べないので $`x ≰ y`$ だが、どの開近傍の錐をとっても区別できない、という状況だと理解している（論文には図も説明もない）。

### 上順序・下順序、Esakia 双対性（7〜8 節）

- 証明はすべて上向き・下向きに分けられ、上順序・下順序だけを使う随伴と双対性も得られる（定理 7.6、7.10）。
- Esakia 空間（ハイティング代数の双対）は、下向きの開錐条件を満たすプリーストリー空間として特徴づけられ、下向きの随伴の不動点に入る（命題 8.5）。

### 今後の課題として挙げられていること（9 節）

- 公理 (•) は点を使って述べられており、開集合だけで述べた代わりの公理が見つかっていない。「点が十分にある」という仮定も必要とは限らない。
- 内部前順序（ロケール $`X × X`$ の閉部分ロケール）による Townsend の定義との関係。
- 有向代数的位相幾何の基本圏、局所順序空間（stream）、順序付きロケール上の層（文脈依存性の研究への応用）、量子重力の因果構造、**因果の梯子**（causal ladder）の点なし版、クォンタールへの一般化、テンソル位相、双フレーム（biframe）との関係。

## 本プロジェクトとの関係

- **基礎の調査メモ 5 節の記述の訂正**：要旨だけから書いた「空間的な順序付きロケールと、開錐を持つソバー $`T_0`$ 順序空間の圏同値」は、正確には「**(•) を満たす**空間的な順序付きロケール」と「開錐を持つソバーな **$`T_0`$ 順序**（上記の分離公理）空間」の同値である。随伴自体も、空間側は「点が十分にある」、ロケール側は (•) を満たす部分圏の間のものである。
- **基礎の調査メモ 5 節の「点なしの時制論理」との関係**：局所的な錐 $`↟`$ は、調査メモの $`I^+`$（過去の ◇、$`P`$）の点なし版にあたり、滑らかな時空の開集合 $`U`$ では実際に $`↟U = I^+(U) = J^+(U)`$ となる（heunen2026 の系 2.10）。ただしこの論文は $`↟`$ が結びを保つことを一般には要求せず、右随伴（未来の □、$`G`$）も扱わない。**時制論理・様相論理の完全性（Goldblatt の S4.2 など）には触れていない。** 結びを保つ条件と、$`↟`$ と $`↡`$ の関係は heunen2026 で導入される。
- **点がないと表せない因果構造**（調査メモ 7 節の候補 2）：例 6.6 は逆向きの現象、つまり**点のある時空の因果関係のうち、開集合（ロケール）からは復元できない部分がある**ことを示している。候補 2 を考えるときの出発点になる。
- **点を持たない順序付きロケール**が二重否定部分ロケールとして自然に得られる（例 3.11）。基礎の調査メモ 1 節の「完備ブール代数の点はアトムに対応する」と、Lean で形式化する予定の定理を、順序付きの場合に使う場面がある。**（見立て）** 例 3.11 の「点を持たない」ことは、二重否定部分ロケールのフレーム（正則開集合の完備ブール代数）がアトムを持たないことから、この定理で導ける。孤立点がないことが、アトムがないことに対応する。
