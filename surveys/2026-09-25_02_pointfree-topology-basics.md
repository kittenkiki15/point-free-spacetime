## 1. 基本概念

### フレームとロケール

- **フレーム**（frame）：任意の結び $`⋁`$ と有限の交わり $`∧`$ を持つ完備束で、有限の交わりが任意の結びに分配するもの。

```math
a ∧ ⋁_{i ∈ I} b_i = ⋁_{i ∈ I} (a ∧ b_i)
```

- この分配律は第 01 回に Lean で検証した（[`lean/PointFreeSpacetime/Basic.lean`](../lean/PointFreeSpacetime/Basic.lean)）。
- **フレーム準同型**：有限の交わりと任意の結びを保つ写像。
- **ロケール**（locale）：フレームの圏 **Frm** の反対圏 **Loc** の対象。フレーム $`L`$ を「空間」とみなしたもの。
- 位相空間 $`X`$ の開集合全体 $`𝒪(X)`$ はフレームになる。連続写像 $`f : X → Y`$ は逆像により $`f^{-1} : 𝒪(Y) → 𝒪(X)`$ というフレーム準同型を与える。向きが逆になるので、空間の側に合わせて反対圏をとる。

### ロケールの点

- 記法の約束：以下では、ロケールと、それを定めるフレームを同じ記号 $`L`$ で表す。射の向きは、ロケールとしては空間の向き、フレームとしてはその逆向きである。
- ロケール $`L`$ の**点**は、ロケールの圏 $`\mathrm{Loc}`$ で、終対象（一点空間に対応するロケール、そのフレームは $`2 = \{0, 1\}`$）から $`L`$ への射である。フレームの言葉では、逆向きのフレーム準同型 $`L → 2`$ にあたる。次のものと一対一に対応する。
  - **完全素フィルター**（completely prime filter）：$`⋁ S ∈ F`$ ならば、ある $`s ∈ S`$ について $`s ∈ F`$ となるフィルター $`F`$。
  - **素元**（prime element）：$`p ≠ 1`$ で、$`a ∧ b ≤ p`$ ならば $`a ≤ p`$ または $`b ≤ p`$ となる元 $`p`$。
- 点全体に位相を入れた空間 $`\mathrm{pt}(L)`$ が作れ、$`𝒪 : \mathrm{Top} → \mathrm{Loc}`$ と $`\mathrm{pt} : \mathrm{Loc} → \mathrm{Top}`$ は随伴 $`𝒪 ⊣ \mathrm{pt}`$ をなす。
- この随伴は、**ソバー空間**（sober space）と**空間的ロケール**（spatial locale）の圏同値に制限される（Johnstone 1982）。ハウスドルフ空間はソバーなので、通常の物理で使う多様体はロケールとして扱っても情報を失わない。

### 点を持たないロケール

- **完備ブール代数の点はアトムと一対一に対応する。** 以下、$`L`$ を完備ブール代数とする（完備ブール代数はフレームである）。証明は次の 4 段に分ける。
  1. **完全素フィルターと素元の対応**（一般のフレームで成り立つ）。完全素フィルター $`F`$ に対して、補集合の結び $`p = ⋁ (L ∖ F)`$ をとる。$`p ∈ F`$ なら、完全素性から $`L ∖ F`$ のある元が $`F`$ に属することになり矛盾するので、$`p ∉ F`$ である。$`F`$ は上に閉じているので、$`a ∈ F`$ なら $`a ≰ p`$ であり、$`a ∉ F`$ なら $`a ≤ p`$ である。したがって $`F = \{ a : a ≰ p \}`$、すなわち $`L ∖ F = ↓p`$ となる。$`p`$ は素元である：$`1 ∈ F`$ より $`p ≠ 1`$ であり、$`a ∧ b ≤ p`$ のとき $`a, b ∈ F`$ なら $`a ∧ b ∈ F`$ となって矛盾するので、$`a ≤ p`$ または $`b ≤ p`$ となる。逆に素元 $`p`$ から $`F = \{ a : a ≰ p \}`$ を作ると完全素フィルターになり、この二つの対応は互いに逆である。
  2. **素元は余アトム**。素元 $`p`$ について $`p < q`$ とすると、$`q ∧ ¬q = 0 ≤ p`$ と素性から $`q ≤ p`$ または $`¬q ≤ p`$ であり、$`q ≤ p`$ は $`p < q`$ に反するので $`¬q ≤ p < q`$ となる。したがって $`q = q ∨ ¬q = 1`$。よって $`p`$ のすぐ上は $`1`$ だけで、$`p`$ は余アトムである。
  3. **完全素フィルターは $`↑(¬p)`$ の形**。まず $`¬p`$ はアトムである：$`¬p ≠ 0`$（$`p ≠ 1`$ より）で、$`0 < b ≤ ¬p`$ とすると $`b ≰ p`$（$`b ≤ p`$ なら $`b ≤ p ∧ ¬p = 0`$）なので $`p < p ∨ b`$、余アトム性から $`p ∨ b = 1`$、よって $`¬p = ¬p ∧ (p ∨ b) = ¬p ∧ b = b`$。次に、ブール代数では $`a ≤ p \iff a ∧ ¬p = 0`$ であり、$`¬p`$ がアトムなので $`a ∧ ¬p`$ は $`0`$ か $`¬p`$ のどちらかである。したがって $`a ≰ p \iff a ∧ ¬p = ¬p \iff ¬p ≤ a`$ となり、1 の $`F`$ は $`↑(¬p)`$ に等しい。
  4. **逆方向：アトムから点を作る**。アトム $`a`$ について $`↑a`$ はフィルターであり（$`a ≠ 0`$ より $`0 ∉ ↑a`$）、**任意の**部分集合 $`S ⊆ L`$ について完全素である。実際、$`a ≤ ⋁ S`$ なら、分配律から次が成り立つ。

```math
a = a ∧ ⋁ S = ⋁_{s ∈ S} (a ∧ s)
```

（4 の続き）アトム性から各 $`a ∧ s`$ は $`0`$ か $`a`$ である。すべてが $`0`$ なら $`a = 0`$ となって矛盾するので（$`S = ∅`$ のときは $`⋁ S = 0`$ であり、そもそも $`a ≤ ⋁ S`$ にならない）、ある $`s ∈ S`$ で $`a ∧ s = a`$、すなわち $`a ≤ s`$ となる。対応する素元は $`⋁ (L ∖ ↑a) = ¬a`$ である（$`b ∉ ↑a \iff a ∧ b = 0 \iff b ≤ ¬a`$ による）。$`¬¬a = a`$ なので、3 の対応 $`F ↦ ¬p`$ と、ここでの対応 $`a ↦ ↑a`$ は互いに逆であり、点（完全素フィルター）とアトムの一対一対応が得られる。

- 第 03 回に Lean で形式化した（[`lean/PointFreeSpacetime/BooleanPoints.lean`](../lean/PointFreeSpacetime/BooleanPoints.lean)）。Mathlib の点の定義（フレーム準同型 $`L → \mathrm{Prop}`$）を使い、1 段目を `ptEquivPrime`、2 段目を `IsPrimeElement.isCoatom`、3・4 段目をまとめて `ptEquivAtom` とした。
- 系として、**非自明な（$`0 ≠ 1`$ の）完備ブール代数でアトムを持たないものは、自明でないのに点を持たないロケール**を与える（一元ブール代数 $`0 = 1`$ もアトムを持たないが、自明なロケールである）。例：実数直線の正則開集合全体。これは $`ℝ`$ の最小の稠密な部分ロケールにあたる **（未確認：文献で確認する）**。
- 論理の側から見ると、**非自明な**ロケール（$`0 ≠ 1`$）が点を持たないことは、「矛盾はないが、集合論的なモデルを持たない理論」に対応する（3 節）。一元フレーム（$`0 = 1`$）も点を持たないが、これは矛盾した理論に対応する。

### 部分ロケールと核

- フレーム $`L`$ 上の**核**（nucleus）$`j : L → L`$ は、次を満たす写像である。

```math
a ≤ j(a), \quad j(j(a)) ≤ j(a), \quad j(a ∧ b) = j(a) ∧ j(b)
```

- 核は**部分ロケール**（sublocale）と一対一に対応する。点なし位相では、部分空間は部分集合ではなく核で与えられる。

## 2. 直観主義論理：フレームはハイティング代数

- フレームは、順序集合としては**完備ハイティング代数**（complete Heyting algebra）と同じものである（射の定義は異なる）。含意 $`a → b = ⋁\{c : c ∧ a ≤ b\}`$ が定まる。
- ハイティング代数は**直観主義命題論理**の代数的意味論である。開集合で読むと、否定 $`¬U`$ は「$`U`$ の補集合の内部」になり、排中律は**一般には**成り立たない（離散空間のようにすべての部分集合が開集合なら成り立つ）。
  - 例：$`ℝ`$ で $`U = (0, ∞)`$ とすると $`¬U = (−∞, 0)`$ であり、$`U ∪ ¬U = ℝ ∖ \{0\} ≠ ℝ`$。
- McKinsey–Tarski（[mckinsey1944](../references.bib)）は、位相の代数化を与え、直観主義論理・様相論理 S4 が位相空間の意味論に対して完全であることにつながる結果を示した（4 節）。

## 3. 幾何学的論理：開集合は「観測で確かめられる命題」

- **形式的な事実**：フレームの演算（有限の交わり、任意の結び）は、命題的な幾何学的論理の結合子（有限の論理積、任意の論理和）と一致する。
- **解釈（見立て）**：Vickers（[vickers1989](../references.bib)）は、これを「有限回の観測で確かめられる命題」の論理として動機づけている。この解釈は、何を 1 回の観測とし、原子命題をどう確かめるかという前提に依存する。
  - 各原子命題が有限回の観測で確かめられるなら、有限個の観測をすべて行えば、有限の論理積を確かめられる。
  - どれか一つを確かめれば、無限個の論理和も確かめられる。
  - 無限の論理積や否定は、一般に有限回の観測では確かめられない。
  - 物理学への応用では、この前提を物理的に正当化する必要がある。
- この論理を**幾何学的論理**（geometric logic）という。命題的な幾何学的理論のリンデンバウム代数はフレームであり、ロケールは「その理論のモデルの空間」、点はモデルに対応する。
- 例の候補（未検証）：非可算集合 $`X`$（たとえば $`ℝ`$ の台集合）を固定し、各 $`n ∈ ℕ`$ と $`x ∈ X`$ について命題 $`f(n) = x`$ を原子命題とする命題的理論で、「$`f`$ は写像である」「$`f`$ は全射である」を幾何学的な公理で書いたものを考える。この理論は集合論的なモデル（$`ℕ`$ から $`X`$ への全射）を持たないが、対応するロケールは自明でない、と理解している。
  - **（未確認）** 公理の正確な形と、ロケールが自明でない理由（フレームで $`0 ≠ 1`$ となること）を、典拠で確かめてから例として採用する。
- ロケール上の層はトポスをなし、その内部論理は高階の直観主義論理である。ロケールの理論は選択公理なしで展開でき、たとえばチコノフの定理のロケール版は選択公理を使わない（[johnstone1983](../references.bib)）。

### ストーン双対性の階層

| 論理側（代数と準同型） | 空間側（空間と射） |
| --- | --- |
| ブール代数（古典命題論理）とブール代数準同型 | ストーン空間と連続写像 |
| 有界分配束と有界束準同型 | スペクトル空間とスペクトル写像（コンパクト開集合の逆像がコンパクト開集合になる連続写像） |
| フレーム（命題的な幾何学的論理）とフレーム準同型 | ロケールとロケールの射（空間的なものはソバー空間と連続写像に対応） |

いずれも、論理側の圏と空間側の圏の反変な同値（双対）である。フレームとロケールの場合は定義により反対圏であり、空間との対応は 1 節の随伴を通して得られる。

## 4. 様相論理

- **S4 と位相**：様相演算子 $`□`$ を「内部をとる操作」と読むと、S4 は位相空間の論理になる（[mckinsey1944](../references.bib)）。
- **ゲーデル–McKinsey–Tarski 翻訳**：直観主義論理は S4 に埋め込める（直観主義的に $`p`$ が真であることを $`□p`$ と読む）。開集合の論理は、もともと様相論理の一部分である。
- **核は様相**：1 節の核 $`j`$ は、$`p → ○p`$、$`○○p → ○p`$、$`○(p ∧ q) ↔ ○p ∧ ○q`$ を満たす様相 $`○`$ にあたる（遅延論理の様相）。トポスでは**ローヴェア–ティアニー位相**として現れる。
- **ストーン双対性の拡張**：様相論理の代数（演算子付きブール代数）と、関係付きストーン空間の対応は、Jónsson–Tarski（[jonsson1951](../references.bib)）・Esakia による **（Esakia は未登録の文献）**。
- **パワーロケール**：「部分集合の空間」に類する点なしの構成で、上パワーロケール・下パワーロケール・Vietoris パワーロケールなど複数ある。すべての部分集合を点として表すわけではない（たとえば上パワーロケールの点は、コンパクトな飽和部分集合に類するもの）。上パワーロケールは $`□`$、下パワーロケールは $`◇`$ に対応するという見方がある（Vickers、Abramsky の *Domain Theory in Logical Form*） **（未登録の文献・未確認）**。

## 5. 因果構造と時制論理

### 点に基づく結果

- Goldblatt（[goldblatt1980](../references.bib)）：ミンコフスキー時空で、$`□`$ を「いまも、これから先もずっと成り立つ」（因果的未来のすべての点で成り立つ）と読むと、妥当な様相式はちょうど **S4.2** の定理になる。2・3・4 次元のいずれでも同じ。 **（未確認：要旨・書誌データベースの記載による。本文は未読）**
- これはクリプキ意味論（点と関係）に基づく結果である。

### 点なしの定式化（見立て）

- 時空 $`M`$ の開集合 $`U`$ の時間的未来 $`I^+(U)`$ は開集合である。したがって $`I^+`$ はフレーム $`𝒪(M)`$ 上の写像になる。
- $`x ∈ I^+(U)`$ は「$`x`$ の時間的過去のどこかで $`U`$ が成り立った」ことを意味するので、$`I^+`$ は時制論理の**過去の ◇（P）**にあたる。
- $`I^+(S) = ⋃_{x ∈ S} I^+(x)`$ なので、$`I^+`$ は任意の合併を保つ。したがって右随伴 $`G`$ を持つ。

```math
I^+(U) ⊆ V \iff U ⊆ G(V), \qquad G(V) = ⋃ \{ U ∈ 𝒪(M) : I^+(U) ⊆ V \}
```

- $`G(V)`$ は「これから先ずっと $`V`$ が成り立つ」点の集合の内部であり、**未来の □（G）**にあたる。
- 同様に、時間的過去 $`I^-`$ は未来の ◇（F）にあたり、右随伴は過去の □（H）になる。
- この随伴の組（$`P ⊣ G`$、$`F ⊣ H`$）は Prior の**時制論理**（tense logic）の構造である。**因果構造は、フレーム上の随伴な様相演算子の組として、点を使わずに表せる見込みがある。**
- ただし、**随伴であることだけでは足りない**。たとえば二元フレームで $`P`$ を常に $`0`$、$`G`$ を常に $`1`$ としても随伴になるが、$`G`$ は S4 の公理 $`□p → p`$ すら満たさない。時空の時間的関係に由来する性質（反射性にあたる条件、推移性、方向性など）を演算子の条件として課す必要がある。
- また、Goldblatt の意味論は点の上で命題を評価し、ここでの演算子は開集合の上で働く。両者で命題の評価先が一致するか（任意の点集合と開集合の違い）も確かめる必要がある。

### 先行研究

- Christensen–Crane（[christensen2005](../references.bib)）：点の集合の代わりに、有界な領域と、領域間の因果関係から出発する「因果サイト」（causal site）を提案した。 **（未確認：要旨・書誌データベースの記載による。本文は未読）**
- Heunen–van der Schaaf（[heunen2024](../references.bib)）：**順序付きロケール**（ordered locale）を定義し、開錐条件を満たす前順序付き位相空間と順序付きロケールの間の随伴を構成した。正確には、随伴は「開錐条件を満たし、点が十分にある順序付き空間」と「公理 (•) を満たす順序付きロケール」の間のもので、「(•) を満たす空間的な順序付きロケール」と「開錐条件を満たすソバーな $`T_0`$ 順序空間」（$`T_0`$ 順序は論文で導入された分離公理）の圏同値に制限される。詳細は[論文メモ](2026-09-25_03_heunen2024.md)。
- Heunen–van der Schaaf（[heunen2026](../references.bib)）：順序付きロケールに**因果被覆**（causal coverage）を導入し、相対論の因果論を点なし位相で展開した。Christensen–Crane の因果サイトを改良し、因果被覆を一般化されたグロタンディーク位相として、層条件を決定論的な時間発展として解釈している。点なしの依存領域は、曲線による依存領域を常に含み、真に大きくなる例がある。詳細は[論文メモ](2026-09-25_03_heunen2026.md)。
- 上の「点なしの定式化（見立て）」との関係：時空では、順序付きロケールの局所的な錐 $`↟U`$ は $`I^+(U)`$ に等しく、任意の結びを保つ（heunen2026 の系 2.10・命題 3.2）。したがって $`I^+`$ が開集合の上の結びを保つ写像になるという見立ては裏づけられた。

## 6. 量子論

- **伝統的な量子論理**（[birkhoff1936](../references.bib)）：命題をヒルベルト空間の閉部分空間とみなす。閉部分空間の束は**オーソモジュラー束**で、分配律を満たさない。フレームの定義の核心は分配律なので、そのままでは点なし位相の枠組みに入らない。
- **トポス的アプローチ**：
  - Isham–Butterfield（[isham1998](../references.bib)）：可換部分代数（文脈）の順序集合上の前層トポスで量子論を扱い、観測量の代数から**スペクトル前層**を構成した。次元 3 以上のヒルベルト空間では、**コッヘン–シュペッカーの定理がスペクトル前層に大域切断がないことと同値**である。
  - Heunen–Landsman–Spitters（[heunen2009](../references.bib)）：非可換な C\*-代数から、その可換部分代数全体を貼り合わせた一つの**可換** C\*-代数をトポスの内部に構成した。その「スペクトル」はトポス内のロケールとして得られる。これは量子状態の空間そのものではなく、観測量の代数から作る空間である。コッヘン–シュペッカーの定理の仮定を満たす場合（次元 3 以上など）には、大域的な点を持たない **（未確認：論文メモで条件を確認する）**。
  - この枠組みの論理は、分配的な直観主義論理である。前層トポスの内部論理の意味論は、文脈の順序を関係とするクリプキ意味論になる（4 節の様相論理とつながる）。
- **クォンタール**（quantale）：フレームの交わりを非可換な積に置き換えたもの。Mulvey が非可換な C\*-代数のスペクトルを捉えるために導入した **（未登録の文献）**。線形論理と関係する。
