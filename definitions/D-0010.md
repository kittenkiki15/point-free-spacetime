## 目的

- 膨張 $`N`$（[D-0009](D-0009.md)）から、「$`a`$ は $`b`$ に、区別できない幅の余白を残して含まれる」という関係を作り、点なしの言葉で述べるための定義。最小の尺度（型 II）の候補を、この関係が補間的でないこと（$`N ∘ N ≰ N`$。[R-0006](../results/R-0006.md)・[R-0007](../results/R-0007.md)）として述べ、最小の尺度と離散化を区別するという [C-0001](../conjectures/C-0001.md) の主張を述べられるようにする（[G-0003](../goals/G-0003.md)）。
  - ただし、補間的でないことだけでは物理的な最小の尺度を識別できない（通常の実数直線の上でも、固定した正の幅の膨張では $`N ∘ N ≰ N`$ となる。[T-0008](../tasks/T-0008.md) の注意。PR #48 のレビュー）。余白の尺度を実験からどう定めるかなどの追加の条件は、C-0001・[C-0007](../conjectures/C-0007.md) の側で扱う。
- [C-0007](../conjectures/C-0007.md) の候補 B（$`◁`$ を局所的な準備可能性から定める案）でも、この関係を使う。局在の限界から装置の占める領域の上下限を導くことで、実験の側から尺度を定める（[G-0004](../goals/G-0004.md)）。

## 完了の条件

採用済み。この定義に固有の未解決の点はない（$`L`$ の取り方は D-0009 の側の論点）。D-0009 の残る点が [T-0007](../tasks/T-0007.md) で決まれば、この定義の検討は完了する。

## 定義

膨張 $`N : L → L`$（[D-0009](D-0009.md)）について、$`L`$ の元の間の関係 $`◁_N`$ を次で定める。

```math
a ◁_N b \iff N\,a ≤ b
```

$`a ◁_N b`$ を「$`a`$ は $`b`$ に余白付きで含まれる」と読む。$`N`$ が明らかなときは $`◁`$ と書く。

**点の場合**：集合 $`X`$ 上の関係 $`T`$（$`T(x, y)`$ を「$`x`$ と $`y`$ は区別できないほど近い」と読む）について、$`T[a] := \{\, y \mid T(x, y) \text{ となる } x ∈ a \text{ がある} \,\}`$ は $`X`$ の冪集合の上の、結びを保つ写像である（$`T`$ が反射的なら膨張）。このときの $`◁`$ は「$`x ∈ a`$ かつ $`T(x, y)`$ ならば $`y ∈ b`$」である。

## 注意

- $`◁`$ が補間的（$`a ◁ b`$ ならば $`a ◁ c ◁ b`$ となる $`c`$ がある）であることは、$`N ∘ N ≤ N`$ と同値である（[R-0007](../results/R-0007.md)）。点の場合は、$`T`$ が推移的であることと同値である（[R-0006](../results/R-0006.md)）。
- 補間性の破れと「最小の尺度がある」ことは、一般には一致しない（[C-0001](../conjectures/C-0001.md) の「注意」）。

## 未解決の点
