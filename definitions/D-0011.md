## 定義

観測者 $`O`$ の時空の部分 $`M_O`$（[D-0003](D-0003.md)）の上で考える。扱うのは、時空の読みを持つプロトコルの実験だけである。実験 $`e`$ の時空の部分の設定値を $`x_e := τ^O_π(x) ∈ M_O`$ と書く（$`e`$ のプロトコルが $`π`$、設定が $`x`$ のとき）。

1. **実際の実験の記録された占める領域**：実際の実験（[D-0002](D-0002.md)）$`e`$ について、その装置が準備から結果の読み出しまでに占めた点がすべてその中にあることを、記録が保証する範囲（外側の範囲）を $`\mathrm{occ}_{\mathrm{rec}}(e) ⊆ M_O`$ とする。有限の記録から占めた点の全体を特定できるとは限らないので、実際に占めた点の全体ではなく、記録が保証する外側の範囲をとる。
2. **可能な実験の占める領域**：可能な実験（[D-0002](D-0002.md)）$`e = (π, x)`$ について、可能な実験を観測量の時空の中でモデル化できること（[C-0002](../conjectures/C-0002.md)）を前提として、そのモデルの装置が占める点の全体を $`M_O`$ に写したものを $`\mathrm{occ}_{\mathrm{mod}}(e) ⊆ M_O`$ とする（観測における時空から $`M_O`$ への写し方は、[D-0003](D-0003.md) の整合条件による。したがってこの定義は、C-0002 のモデル化とその写し方の両方を与えた場合の条件付きの構成である）。実際の実験は可能な実験でもあるので、実際の実験 $`e`$ には $`\mathrm{occ}_{\mathrm{rec}}(e)`$ と $`\mathrm{occ}_{\mathrm{mod}}(e)`$ の二つがありうる。両者の関係（例えば $`\mathrm{occ}_{\mathrm{rec}}(e) ⊆ \mathrm{occ}_{\mathrm{mod}}(e)`$）は、別の整合条件とする。
3. どちらの場合も、$`x_e ∈ \mathrm{occ}_{\mathrm{rec}}(e)`$、$`x_e ∈ \mathrm{occ}_{\mathrm{mod}}(e)`$（装置は、自分の設定値の点を占める）を課す。
4. **設定値ごとの合併**：$`M_O`$ の各点 $`y`$ について、**装置の占める領域** $`\mathrm{occ}(y) ⊆ M_O`$ を、設定値が $`y`$ の可能な実験のモデルの占める領域の合併 $`\mathrm{occ}(y) := ⋃_{x_e = y} \mathrm{occ}_{\mathrm{mod}}(e)`$ と定める。次を課す。
   - すべての $`y ∈ M_O`$ について、設定値が $`y`$ の可能な実験がある。これがないと、実験のない点で $`\mathrm{occ}(y) = ∅`$ となり、下の $`N_{\mathrm{occ}}`$ は増大的でない。実際の実験は高々可算個（[A-0001](../assumptions/A-0001.md)）なので、この条件は可能な実験でしか課せない。
   - $`\mathrm{occ}(y)`$ は $`M_O`$ の領域（開集合）である。

このとき、$`M_O`$ の領域 $`R`$ について

```math
N_{\mathrm{occ}}\,R := ⋃_{y ∈ R} \mathrm{occ}(y)
```

と定めると、$`N_{\mathrm{occ}}`$ は膨張（[D-0009](D-0009.md)）である。その余白付きの包含（[D-0010](D-0010.md)）$`a ◁ b`$ は、「設定値が $`a`$ にある可能な実験は、装置ごと $`b`$ に収まる」ことを表す。

この定義は**可能な実験についての定義**で、[C-0002](../conjectures/C-0002.md) が成り立つことを前提とする条件付きの定義である（第 13 回にユーザーの指摘で明記した）。

## 注意

- **「区別」の読み方**（C-0001 の見直しで採った候補 A）：実験が領域に「収まる」ことには、設定値が領域に属すること（設定の読み）と、装置の占める領域が領域に含まれること（占有の読み）の二つがある（[D-0008](D-0008.md) の未解決の点）。この定義は、両者のずれを膨張として表す。$`N_{\mathrm{occ}}`$ は、点の場合の関係 $`T(y, z) :\iff z ∈ \mathrm{occ}(y)`$ による近傍 $`T[R]`$ である（D-0010 の点の場合）。
- 局在（[D-0008](D-0008.md)）の $`𝒪(R)`$ を、設定の読み（族のすべての実際の実験 $`e`$ で $`x_e ∈ R`$）で定めたものを $`𝒪_{\mathrm{set}}(R)`$、占有の読み（族のすべての実際の実験 $`e`$ で $`\mathrm{occ}_{\mathrm{rec}}(e) ⊆ R`$。記録された占める領域で判定する）で定めたものを $`𝒪_{\mathrm{occ}}(R)`$ とする。実験と族の許容条件が同じなら、$`x_e ∈ \mathrm{occ}_{\mathrm{rec}}(e)`$ から、実際の実験だけで次が成り立つ。

```math
𝒪_{\mathrm{occ}}(R) ⊆ 𝒪_{\mathrm{set}}(R)
```

  さらに、**追加の条件**として、すべての実際の実験 $`e`$ で $`\mathrm{occ}_{\mathrm{rec}}(e) ⊆ \mathrm{occ}(x_e)`$（記録された占める領域が、モデルの合併に含まれる。整合条件の一部で、$`\mathrm{occ}_{\mathrm{rec}}(e) ⊆ \mathrm{occ}_{\mathrm{mod}}(e)`$ なら成り立つ）を仮定すると、$`\mathrm{occ}_{\mathrm{rec}}(e) ⊆ \mathrm{occ}(x_e) ⊆ N_{\mathrm{occ}}\,R`$ から次も成り立つ。

```math
𝒪_{\mathrm{set}}(R) ⊆ 𝒪_{\mathrm{occ}}(N_{\mathrm{occ}}\,R)
```

  この追加の条件がないと、右の包含は成り立たないことがある（例えば $`ℝ`$ で、モデルが $`\mathrm{occ}(y) = (y - 1, y + 1)`$ を与え、設定値 $`0`$ の実験の記録が $`(-2, 2)`$ なら、$`R = (-1/2, 1/2)`$ について記録は $`N_{\mathrm{occ}}\,R = (-3/2, 3/2)`$ に収まらない）。二つの読みは、この条件の下で、膨張 $`N_{\mathrm{occ}}`$ を使って二つの包含で関係づけられる。右辺では、局在に使える実験の条件が真に緩くなりうる。例えば $`ℝ`$ で $`\mathrm{occ}(y) = B_1(y)`$、$`R = (0, 1) ∪ (2, 3)`$ とすると、$`N_{\mathrm{occ}}\,R = (-1, 4)`$ で、設定値が $`R`$ の外（例えば $`1.5`$）にある実験も、占有の読みでは $`N_{\mathrm{occ}}\,R`$ に収まる。ただし、使える実験が増えても、得られる観測量の集合が真に大きくなるとは限らない（観測量の集合として右の包含が等号でないかどうかは、この例からは従わない）。
- $`M_O`$ は点を持つ（時計や物差しの読みの空間）。点なしの構造が現れるのは、観測における時空（[D-0007](D-0007.md)）の側である。$`N_{\mathrm{occ}}`$ と余白付きの包含が観測における時空にどう移るかは、再構成（ロードマップの T-0009）で扱う。
- $`\mathrm{occ}`$ に最小の尺度を入れる前提の候補が [A-0009](../assumptions/A-0009.md)、それを物理から導く予想が [C-0007](../conjectures/C-0007.md)、共変性との関係が [C-0008](../conjectures/C-0008.md) である。これらも可能な実験の層の上の前提・予想になる。
- 候補 B（「操作的に切り離せる」ことで $`◁`$ を定める、split property 型の定義）は、$`\mathrm{occ}`$ を物理から決める方法の一つとして C-0007 の中で扱う（第 12 回にユーザーと合意）。
- この定義は [C-0002](../conjectures/C-0002.md) に依存するが、C-0002 はこの定義に依存しないので、D-0011 と C-0002 の間には循環はない。一方、可能な観測量（[D-0006](D-0006.md)）は C-0002 を前提とし、C-0002 は D-0006 に依存するので、両者の間には記述の上の循環がある。D-0006 の依存する ID に C-0002 を書いていないのは依存関係の図の上のことで、循環の解消ではない（D-0006 の未解決の点）。

## 未解決の点

- 「装置が占める点」の判定：各実験の装置が占める領域をどう定めるか（[D-0001](D-0001.md) の未解決の点）。装置と環境の境目や、準備・読み出しの信号の経路を含めるか。記録が保証する外側の範囲 $`\mathrm{occ}_{\mathrm{rec}}(e)`$ を、どんな記録からどう定めるか（範囲を広くとるほど、占有の読みでの局在は弱くなる）。
- $`\mathrm{occ}(y)`$ を、可能な実験の全体の合併とする（上の定義。最悪の場合）か、実験ごとの族 $`\mathrm{occ}_{\mathrm{mod}}(e)`$ のまま扱うか。後者では膨張は一つに定まらない。個々の装置の最小の大きさは、合併 $`\mathrm{occ}(y)`$ ではなく実験ごとの占める領域への条件になる（[A-0009](../assumptions/A-0009.md) の注意）。
- $`\mathrm{occ}`$ の観測者への依存（[C-0008](../conjectures/C-0008.md) の論点）。
- 設定の部分（時空の部分以外のパラメータ）が $`\mathrm{occ}`$ にどう効くか。
- 実験の存在の条件（定義で課した）の扱い：設定値の取れる範囲を $`M_O`$ の一部に制限すると、その範囲が長さ空間であるか（[C-0001](../conjectures/C-0001.md) の仮定）や、観測者の取り替えで閉じているか（[C-0008](../conjectures/C-0008.md) の仮定）が、実験できる範囲に依存する（PR #27 のレビュー）。
- 記録とモデルの占める領域の関係 $`\mathrm{occ}_{\mathrm{rec}}(e)`$ と $`\mathrm{occ}_{\mathrm{mod}}(e)`$（整合条件の一部。[D-0003](D-0003.md) の未解決の点）。
- 観測量の時空の中のモデルの占める領域を $`M_O`$ の部分集合に写す対応の向き・定義域と、占める領域に課す条件（PR #28 のレビュー）。C-0002 のモデル化だけでは、この写し方は定まらない。また、同じ可能な実験に複数のモデルがありうる場合、実験ごとにモデルと $`M_O`$ への対応を選ぶのか、許される全モデルの占める領域を合併するのかを決め、[A-0009](../assumptions/A-0009.md) の上下限が何に対する条件かもそろえる（PR #28 のレビュー）。開集合が開集合に写ることと、$`x_e ∈ \mathrm{occ}_{\mathrm{mod}}(e)`$ を保証する条件も特定する。
