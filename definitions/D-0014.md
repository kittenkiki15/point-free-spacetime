## 定義

プロトコル $`π`$（[D-0001](D-0001.md)）を可能な実験に用いるとき、$`π`$ は装置側の物理モデルとして、入力側の観測量の代数 $`𝒜_π^{\mathrm{in}}`$ と出力側の観測量の代数 $`𝒜_π^{\mathrm{out}}`$（どちらも C* 代数）を指定する。C* 代数 $`𝒜`$ の状態の全体を $`S(𝒜)`$ と書く。可能な実験（[D-0002](D-0002.md)）は、この定義の設定の空間を用いて定める（この定義は可能な実験の概念を使わない。PR #48 のレビュー）。

1. **設定の空間**：$`X_π ⊆ S(𝒜_π^{\mathrm{in}})`$。準備の事象（[D-0013](D-0013.md)）で装置の入力側に用意する状態のうち、プロトコル $`π`$ が許すものの集合。
2. **結果の空間**：$`Y_π ⊆ S(𝒜_π^{\mathrm{out}})`$。1 回の観測の後に装置の出力側（補助系を含む）に残る状態のうち、プロトコル $`π`$ が結果とみなすものの集合。
3. **座標による表示**：単射 $`φ : X_π → ℝ^{m}`$ で、$`X_π`$ の中で行える混合（凸結合）を保つもの（アフィンなもの）をプロトコル $`π`$ の一部として固定したとき、$`X_π`$ を $`φ(X_π) ⊆ ℝ^{m}`$ と同一視して、設定を実数の組で書いてよい。結果の空間 $`Y_π`$ についても同様とする。
4. **実際の実験との対応**：実際の実験のプロトコル $`π`$（設定の空間 $`X_π ⊆ ℝ^{n_π}`$（[D-0003](D-0003.md)）、結果の空間 $`Y_π ⊆ ℝ^{m_π}`$（[D-0013](D-0013.md)））に、可能な実験に用いるプロトコル $`π^{\mathrm{pos}}`$ を次で対応させる（両者の設定の空間は型が異なるので、プロトコルを区別する。PR #48 のレビュー）。
   - $`𝒜_{π^{\mathrm{pos}}}^{\mathrm{in}} := C_b(X_π)`$、$`𝒜_{π^{\mathrm{pos}}}^{\mathrm{out}} := C_b(Y_π)`$（有界な連続関数の代数。可換）。$`X_{π^{\mathrm{pos}}} := \{δ_x \mid x ∈ X_π\}`$、$`Y_{π^{\mathrm{pos}}} := \{δ_y \mid y ∈ Y_π\}`$。
   - 設定 $`x`$ に点での値をとる状態 $`δ_x`$ を、結果 $`y`$ に $`δ_y`$ を対応させる（実際の実験から可能な実験を得る [D-0002](D-0002.md) の対応は、設定をこれで写す）。座標による表示 $`φ(δ_x) := x`$ で、もとの実数の組に戻る。

## 注意

- 実際の実験の設定と結果は、実数の有限の組である（[A-0003](../assumptions/A-0003.md)）。可能な実験の設定と結果は、この定義で、量子状態を含んでよいものに広げる。可換な代数を選べば古典的な記録（第 25 回の判断の (a)。記録 $`y`$ には $`δ_y`$ を対応させ、記録の分布には $`Y`$ の上の σ 加法的な確率測度から得られる状態を用いる。$`S(C_b(Y))`$ の一般の状態には、例えば $`Y = ℕ`$ で各点の確率が 0 で全体の確率が 1 のものがあり、記録の分布とは区別する。PR #48 のレビュー）、非可換な代数（$`B(H)`$ など）を選べば出力が量子系のまま残る場合（(b)）、直和やテンソル積（$`C_b(Y) ⊗ B(H)`$ など）を選べば混成の場合になる。古典力学の物理モデル（相空間の上の確率測度）もこの形に入る（第 25 回のユーザーの判断。量子状態に限らない）。
- 4 の対応は、[D-0002](D-0002.md) の定義にある対応（実際の実験から結果・装置・観測者を忘れて可能な実験を得る対応）を、設定と結果の空間の側で明示したものである。「実際の実験が可能な実験に含まれる」は、文字どおりの集合の包含ではなく、この対応の意味で用いる（PR #47 のレビューの論点）。
- 古典的な記録の分布は、可換な代数の状態（記録の空間の上の確率測度）として表す。連続値の記録も区別して扱える（対角の密度行列への埋め込みでは区別しきれないという PR #47 のレビューの論点への答え。第 26 回のユーザーの合意）。
- **設定を実数の組で書ける場合**（第 26 回のユーザーの提案）：装置の物理モデルが準備で許す状態の族が、混合を保つ有限個の実数の座標で表せるなら、3 によって、設定を今までどおり実数の組で書く。例えば、$`d`$ 次元の量子系の状態の全体は、トレースが 0 のエルミート行列の基底を固定すると、$`ℝ^{d^2 - 1}`$ の中のコンパクトな凸集合と同一視できる。無限次元の物理モデルでも、準備で許す状態が有限個の実数で添字づけられる族なら（調和振動子のコヒーレント状態 $`|α⟩`$、$`α ∈ ℂ ≅ ℝ^2`$ など）、実数の組で書ける。そうでない場合は、準備の事象での装置の状態そのものを設定とする。判定の対象は、状態の全体ではなく、プロトコルが準備で許す状態の族である。
- 3 で混合を保つことを課す条件が実効的なのは、$`X_π`$ が混合で閉じている（凸な）場合である。そのときこの条件は、物理的な意味のない座標を除く。例えば、2 次元以上の可分なヒルベルト空間の正規状態（密度作用素）の全体は濃度が連続体なので、集合としては ℝ に単射で写せるが、その写像は混合を保たない。許される二つの状態の非自明な混合が $`X_π`$ に一つも残らない場合（コヒーレント状態の族や、4 の $`\{δ_x\}`$ など）は、単射であることだけが条件になり（一部の混合だけが残る場合は、残る混合についてアフィン性が要る）、座標の物理的な意味は保証されない。そうした族に、連続性や位相への適合（像への同相写像であることなど）を課すかは、未解決の点とする（PR #48 のレビュー）。
- **設定とプロトコルの境界**：設定とする状態は、準備の事象で、それまでの古典的な記録の履歴で条件づけた各場合に、観測対象やそれまでの量子的な出力と独立に（積の形で）用意するものに限る（古典的な記録から次の設定を選ぶ適応的な設定は、これに含まれる。PR #48 のレビュー）。それまでの量子的な出力や補助系と相関した状態を次の装置に渡す場合は、設定ではなくプロトコルの側（観測対象とのつなぎ方。量子コムなど）で表す。適応的な設定（[D-0001](D-0001.md)）も同様に、古典的な記録から設定の状態を選ぶ規則は設定の側で、量子的な出力から次の入力を作る場合はプロトコルの側で表す（第 26 回の Claude の提案。ユーザーと合意）。
- **補助系**：補助系と合成した実験（第 25 回の判断 3）では、補助系も装置に含める。補助系の量子状態が出力として残る場合（(b)）は、補助系も出力側の代数に含め、補助系との結合状態を結果とする。補助系まで測って読み出す場合（(a)）は、補助系を含む同時測定の古典的な記録を結果とする（[D-0001](D-0001.md) の注意と同じ。PR #48 のレビュー）。前者で、装置だけの縮約状態が同じでも、補助系との相関が違えば後の実験で区別できる（PR #47 のレビューの論点）ことは、結合状態を結果とすることで扱う。
- 可能な主体は物理モデルの組である（[D-0012](D-0012.md)。第 25 回のユーザーの整理）ので、量子状態を設定として「選ぶ」ことに問題はない。
- 一般化確率論の凸集合の状態空間で表す案もあるが、観測量の代数から時空を再構成する構想（[C-0002](../conjectures/C-0002.md)）に合わせて、代数の状態で表す（第 26 回の Claude の提案。ユーザーと合意）。一般化確率論との関係（[C-0003](../conjectures/C-0003.md)）は未解決の点に残す。

## 未解決の点

- $`X_π`$ と $`Y_π`$ の位相：一般の C* 代数の状態の集合には、双対ノルムの位相と弱 * 位相などがある。$`B(H)`$ の正規状態に限れば、双対ノルムの位相はトレースノルムの位相になる。これらは無限次元では異なる（有限次元ではどちらもユークリッドの位相に一致する。PR #48 のレビュー）。どれを採るかは、設定の空間の位相を扱うタスク（[T-0004](../roadmap.md) など）で決める。3 の座標 $`φ`$ に、像への同相写像であることを課すか（特に、混合で閉じていない族では、混合を保つ条件が座標の意味を保証しないので、連続性などの別の条件が要る）も、ここで決める。
- どの状態を許すか：$`C_b(Y)`$ の状態には、σ 加法的でない（有限加法的な）ものも含まれる。古典的な記録の分布をボレル確率測度（緊密なもの）に限るか、$`B(H)`$ では正規状態に限るか。
- 1 回の観測の結果の読み方：(a) では 1 回の結果は $`δ_y`$（記録）で、記録の分布はモデルの予測である。(b) では装置側の状態そのものを結果とするので、1 回の観測の結果と結果の分布の区別が (a) と同じ形にならない。混成の場合（記録 $`y`$ と、それに条件づけた量子状態の組）を含めて、結果の族と結果の分布の関係を、可能な観測量（[D-0006](D-0006.md)）の構成に合わせて定める。出力の状態からは、状態の集合の上の結果の分布は一意に決まらない（同じ混合状態にも異なる純粋状態への分解がある）ので、出力を一つの状態として扱う場合と、読み出せる結果のラベルとその分布を instrument などで与える場合を区別する（PR #48 のレビューの詳細化の論点）。状態の集合の可測構造と、較正（[D-0013](D-0013.md)）・結果の分布への接続を併せて定めると、[C-0012](../conjectures/C-0012.md)・[C-0013](../conjectures/C-0013.md) の適用範囲も確かめられる（PR #48 のレビューの詳細化の論点）。
- 準備の事象・登録の事象への較正の写像（[D-0013](D-0013.md)）を、状態を値とする設定と結果の上でどう定めるか（状態の集合の位相・可測構造とあわせて、[T-0004](../roadmap.md) で扱う。較正の段階は [D-0013](D-0013.md) の 4）。
- 同じプロトコルの中で変わる測定の条件（測定の軸など）の表し方：古典的な制御レジスタ（可換な代数）を入力側の代数に含めて、その状態を設定の一部とするか、測定の条件ごとにプロトコルを分けるか（PR #48 のレビューの詳細化の論点）。
- 4 の対応で、装置の物理モデルの入出力の規則をどう移すか：4 は設定と結果の空間の対応だけを述べる。実際の記録の予測分布（応答関数。[D-0004](D-0004.md)）が対応の後も保たれる条件を明示する。例えば、古典的な応答核を $`x ↦ δ_x`$ と $`y ↦ δ_y`$ で押し出す構成（PR #48 のレビューの詳細化の論点）。
- 一般化確率論（[C-0003](../conjectures/C-0003.md)）の状態空間との関係。
