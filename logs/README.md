# 対話ログ

Claude Code のセッション記録を Markdown に変換したものです。判断の根拠のエビデンスと、ツール用のデータベースとして置いており、人が読むことは前提にしていません（読みやすく整理した内容は、同じファイル名で [`summaries/`](../summaries/) にあります）。

- 1 セッション 1 ファイルで、ファイル名は `YYYY-MM-DD_NN_<話題>.md` です。
- 第 29 回から：[`tools/live_log.py`](../tools/live_log.py) で 1 ターンごとに作り直したものです。発言とタイムスタンプ（UTC）だけを残し、ツールの呼び出しと結果は含めません。PR を作った後からマージまでの発言も含みます。残るのは、各回の最後の同期までに記録された発言です（応答の最後の文は、次の同期で入ります）。見出しの「記録 N」は、`/clear` などで分かれたセッション記録の別を示します。
- 第 28 回まで：セッションの終わりに [`tools/export_log.py`](../tools/export_log.py) で書き出したものです。PR を作った後の経緯は、各 PR で追えます。ツールの呼び出しは要約の 1 行だけを残しています（第 32 回に、他者の文章の長い引用を避けるため、呼び出しの中身と結果を除きました。T-0027。除く前の版は非公開リポジトリの `logs/` にあります）。
- メールアドレスなどの個人情報は伏せ字にしています。他者の文章の長い引用は要約に置き換えています。
- [`live.json`](live.json) は、`tools/live_log.py` が使う、今の回の情報（番号、話題、最初の発言の時刻）です。
