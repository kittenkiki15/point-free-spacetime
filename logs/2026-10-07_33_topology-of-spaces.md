#### Q-0001：結果の統計の空間の位相と、等価原理の「近い」の意味

[Q-0001](questions/Q-0001.md) には、D-0004 と A-0006 の箇条をまとめました。問いは次の 2 つです。
- $`\mathrm{Prob}(Y_π)`$ を、弱位相（weak topology）にするか、全変動距離（total variation distance）にするか。
- 等価原理（A-0006）の「近い」を、それと同じものに揃えること。

**案：弱位相にする。** 等価原理は「$`x ↦ p_π(\cdot \mid x)`$ が、$`X_π`$ の位相から弱位相への連続写像である」と述べることになります。言い換えると、有界な連続関数 $`g`$ のどれについても、期待値 $`x ↦ \int g\, dp_π(\cdot \mid x)`$ が連続になる、ということです。これは、応答の核が Feller 型であることに当たります。

**理由**
1. **全変動距離では、素朴な古典的な装置で破れる。** 結果が設定で決まる装置、$`p_π(\cdot \mid x) = δ_{f(x)}`$（$`f`$ は連続）を考えます。$`x ≠ x'`$ で $`f(x) ≠ f(x')`$ なら、$`\left\| δ_{f(x)} - δ_{f(x')} \right\|_{\mathrm{TV}} = 2`$ です。そのため、値が少しずつ連続に変わる針のような読みでも、連続性が成り立ちません。弱位相なら、$`f`$ の連続性からそのまま従います。
2. **量子の場合はどちらでも成り立つ。** $`x ↦ ρ_x`$ がトレースノルムで連続なら、$`p_π(B \mid x) = \mathrm{Tr}(ρ_x E(B))`$ について $`\left\| p_π(\cdot \mid x) - p_π(\cdot \mid x') \right\|_{\mathrm{TV}} ≤ \left\| ρ_x - ρ_{x'} \right\|_1`$ が成り立ちます。この場合は、全変動距離でも連続になります。したがって、弱位相を選んでも量子の例は失われず、緩めた分は古典的な読みのために使われます。
3. **弱位相でも、本当に不連続な装置は除かれる。** 閾値で 0 と 1 を切り替える読み $`f(x) = \mathbf{1}_{\{x ≥ 0\}}`$ の場合、$`f`$ 自体が不連続なので、弱位相でも連続になりません。これは、物理的な不連続を前提が捉えている、と読めます。この扱いは D-0014 の「Feller 型の条件」の論点と同じ問題なので、Q-0003 と Q-0004 でも扱います。

**決めていただきたいこと**
1. $`\mathrm{Prob}(Y_π)`$ を弱位相とし、A-0006 の連続性を、上の Feller 型の形で述べることにしてよいか。
2. 全変動距離による連続性を、より強い、別の前提（または体系を分ける軸）として残しておくか。私の案は、今は置かず、必要になった予想が出てから加える、です。

この 2 点が決まったら、D-0004 と A-0006 の本文に反映し、Q-0001 を「解決」にします。

ご提案のとおり、このセッションでは Q-0001 だけを扱いましょう。5 つの問いに順に答えます。検討してみると、前の説明の 2 と 3 には不正確な点がありました。その訂正も含めて書きます。

#### 1. 「実際の実験」と「可能な実験」で定義を分けるべきか

**結論：定義は分けたまま、同じ原理で位相を揃えるのがよいと考えます。**

- **今の分担**
  - D-0004 と A-0006 の $`p_π : X_π → \mathrm{Prob}(Y_π)`$ は、実際の実験の話です。結果は古典的な記録 $`y ∈ Y_π`$ で、$`\mathrm{Prob}(Y_π)`$ はその上の確率分布の空間です。
  - 可能な実験（D-0014）では、設定と結果が状態です。
- **揃え方**：$`\mathrm{Prob}(Y)`$ の弱位相は、定義により、有界連続関数 $`g ∈ C_b(Y)`$ をすべて使った期待値 $`μ ↦ \int g\, dμ`$ による位相 $`σ(\mathrm{Prob}(Y), C_b(Y))`$ です。
  - 確率測度を $`C_b(Y)`$ の状態とみなせば、これは状態の集合の弱 * 位相を、確率測度の部分に制限したものと同じです。
  - したがって、実際の実験で弱位相を、可能な実験（Q-0002）で弱 * 位相を選べば、D-0014 の 4 の対応 $`y ↦ δ_y`$ の下で、両者は同じ位相の特殊化として揃います。
- **扱いの範囲**：Q-0001 は実際の実験に限って決めます。可能な実験の側は Q-0002 で、「Q-0001 と揃える」という条件を付けて決めるのがよいと考えます。

#### 2. 「論点」の『「近い」と同じものに揃える』の解決になっているか

**位相の意味では解決になります。量の意味では、まだ解決になっていません。**

- **位相の意味**
  - A-0006 の「近い」は、写像 $`p_π`$ の連続性で述べられています。これには、$`X_π`$ の位相と $`\mathrm{Prob}(Y_π)`$ の位相の 2 つが要ります。
  - $`X_π`$ の位相は、$`ℝ^{n_π}`$ の部分空間の位相として決まっています（D-0003）。
  - そのため、$`\mathrm{Prob}(Y_π)`$ の位相を D-0004 で一つに決めて、A-0006 がそれを指すようにすれば、「近い」は D-0004 と同じものになります。
- **量の意味**
  - 位相だけでは、「どのくらい近いか」は表せません。推定や、事後分布の集中（C-0006）で量が必要になれば、弱位相と同じ位相を与える距離を選ぶ必要があります。
  - 例えば、$`Y_π`$ が可分な距離空間なら、Lévy–Prokhorov 距離や bounded Lipschitz 距離は弱位相を与えます。
  - 案：今は位相だけを決め、距離の選び方は「注意」に書き残すにとどめます。

#### 3. $`p_π`$ が δ 分布になるような「結果の統計」を許すか

前の説明の 1 は、この点に依存していました。その範囲を正確にすると、次のとおりです。

- **$`Y_π`$ が有限集合（デジタルの記録）の場合**：弱位相と全変動の位相は一致します。どちらを選んでも違いはありません。
- **$`Y_π`$ が連続体で、統計に雑音がある場合**：例えば $`p_π(\cdot \mid x) = N(f(x), σ^2)`$（$`σ > 0`$、$`f`$ は連続）なら、全変動距離でも連続になります。
- **違いが出る場合**：統計が特異な部分（δ のような点の重み）を持ち、その位置が設定とともに動く場合だけです。例えば、雑音のない針の読み $`δ_{f(x)}`$ がそうです。

**案：許します。ただし理想化した模型として許します。** 実際の装置の統計は、雑音のためにふつうは滑らかです。それでも、決定論的な古典力学の模型など、理想化した模型を枠組みに入れられることは必要だと考えます。

#### 4. 「緩めた分は古典的な読みのために使われます」の数学的な意味

この言い方は不正確でした。数学的に言えるのは次のことです。

- 弱位相は全変動の位相より粗いので、連続写像の集合には包含関係があります。
```math
\{\,p_π \text{ が全変動の位相で連続}\,\} ⊆ \{\,p_π \text{ が弱位相で連続}\,\}
```
- 弱位相を選ぶと、この差の分の応答関数も等価原理を満たすものとして許されます。差に入るのは、3 で述べた「特異な部分の位置が設定とともに動く」応答関数です。
- 量子の例でよく使う形は、POVM $`E`$ を固定し、状態 $`x ↦ ρ_x`$ をトレースノルムで連続に動かすものです。この場合は次の不等式が成り立つので、もともと小さい方の集合に入ります。
```math
\left\| p_π(\cdot \mid x) - p_π(\cdot \mid x') \right\|_{\mathrm{TV}} ≤ \left\| ρ_x - ρ_{x'} \right\|_1
```
  ここで左辺は、符号付き測度の全変動ノルムです。
- 前に「古典的な読み」と書いたのは、差に入る典型例が雑音のない古典的な針の読みだからです。差の分を古典に限る性質があるわけではありません。この部分は取り下げます。

#### 5. 「$`f`$ 自体が不連続」は物理的に可能か

**厳密には、理想化した極限でしか起こらないと考えます。**

- **閾値で切り替わる装置**：比較器や光子の検出器は、有限の利得と雑音を持ちます。そのため、閾値の近くで $`p(1 \mid x)`$ は滑らかに 0 から 1 へ変わります。不連続な $`\mathbf{1}_{\{x ≥ 0\}}`$ は、雑音を 0 にした極限です。
- **相転移**：熱力学的な極限での一次相転移など、統計が設定に対して不連続になる例も、無限系という極限の理想化です。
- **A-0006 との関係**：実際の装置について連続性を仮定する A-0006 は、物理的に妥当だと考えます。不連続になる統計は、「実際の応答関数の極限」として現れるものです。

#### 4・5 から出てくる、弱位相を選ぶ理由

4 と 5 を合わせると、弱位相を選ぶより強い理由が出てきます。

- 雑音を小さくした装置の列 $`N(f(x), σ_k^2)`$（$`σ_k → 0`$）は、$`δ_{f(x)}`$ に弱位相では収束します。しかし、全変動では、各 $`x`$ でも収束しません。
- 本プロジェクトは、観測量を「実験の族の極限」として扱います（D-0005・D-0006）。そのため、極限で統計が収束する位相として、弱位相が自然です。
- 前に挙げた理由 1（素朴な装置で全変動の連続性が破れる）は、理想化した模型を許すかどうかに依存していました。これに対し、この理由は理想化の扱いに依存しません。

#### 解決の案（ご判断をお願いします）

1. $`\mathrm{Prob}(Y_π)`$ は弱位相とし、D-0004 に書く。A-0006 の連続性は、この位相についての連続性と明記する。理由は、上の極限の議論と、理想化した決定論的な模型を許せることです。
2. 定義は、実際の実験と可能な実験で分けたままにする。Q-0002 では、Q-0001 と揃える条件（弱 * 位相）を付けて決める。
3. 量の意味の「近さ」（距離の選び方）は、今は決めない。D-0004 の「注意」に残す。
4. 全変動による連続性は、今は前提として置かない。

この案でよければ、D-0004・A-0006・Q-0001 に反映し、Q-0001 を「解決」にします。
