**設定の空間と応答**

- 標準の意味論：設定の空間は $`X = [-1, 1]`$ で、位相は $`ℝ`$ の部分空間の位相です。結果の空間は $`Y = \{0, 1\}`$ です。$`\mathrm{Prob}(Y)`$ は、$`q = P(1)`$ によって $`[0, 1]`$ と同一視できます。応答は $`p(x) = δ_{𝟙_{x ≥ 0}}`$ です。
- ストーン空間の意味論：読みの列の空間を $`Σ = \{0, 1\}^ℕ`$ とし、積位相を入れます。埋め込みを $`e(d) = \sum_{i ≥ 0} 2 d_i\, 3^{-(i+1)}`$ とし、設定の空間を $`X' = 𝒞 = e(Σ) ⊆ ℝ`$（部分空間の位相）とします。応答は $`p'(e(d)) = δ_{d_0}`$ です。
- 比較の写像：$`h : 𝒞 → [-1, 1]`$ は、C-0016 の主張の 3 のとおりです。

**量化の対象**

C-0016 は「ある一組の意味論と応答で、次が成り立つ」という存在の主張です。存在を言う対象は、上で具体的に作った $`X, X', p, p', h`$ だけです。C-0014 の $`\mathrm{Scl}`$ のように、無限の列の存在を量化する部分はありません。証明に選択公理も要りません。

**実無限と有限の立場（A-0001）との関係**

- A-0001 が制限しているのは、実際の主体・実験・プロトコルの個数です。$`[-1, 1]`$ や $`Σ`$ が無限の点を持つことは、D-0003 の設定の空間（実数の組）と同じく、数学的な道具の側の話です。そのため、C-0016 は A-0001 に触れません。
- ただし、物理的な読みには差があります。$`Σ`$ の点、つまり読みの桁の無限列は、どの有限の記録でも確定しません。実際の記録が確定するのは、有限の接頭辞（シリンダー集合 $`[d_0 ⋯ d_n]`$）までです。
  - $`p'`$ が連続であることは、「結果の確率が有限の接頭辞（ここでは $`d_0`$ だけ）で決まる」ことに当たります。これは有限の立場とよく合います。
  - 一方、標準の意味論の $`p`$ は、$`x = 0`$ の近くでは、どの有限の精度でも値が決まりません。

#### 確認したい点（Claude の気づき）

前回のレビュー（PR #69）で、$`X' = 𝒞`$ を $`ℝ`$ に埋め込むことにしました。その結果、$`X'`$ の位相も「$`ℝ`$ の部分空間の位相」になり、形の上では標準の意味論と同じ規則で位相を入れています。二つの意味論の実際の違いは、次の二点です。

- 同じ集合に別の位相を入れているのではありません。
- 違うのは、**記録（読み）から設定への対応**です。設定を実数そのものとするか、読みの桁の列とするかの違いです。
