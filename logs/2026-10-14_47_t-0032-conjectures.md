依存しません。ご質問で、主張の書き出し「プロトコルを一つ固定し」が誤りだと気づきました。

#### 答え

$`q`$ は一つのプロトコル $`π`$ に属するものではありません。$`q`$ を決めるのは、プロトコルの列 $`(π_k)`$ です。

- D-0004 では、応答関数 $`p_π`$ はプロトコルごとに一つです。プロトコルを一つ固定すると、応答関数の列は同じ $`p_π`$ を並べた定数の列になり、極限も $`p_π`$ 自身になってしまいます。
- ですから、主張の (1) の $`p_k`$ は、本来は異なるプロトコル $`π_k`$ の応答関数 $`p_{π_k}`$ です。固定するのはプロトコルではなく、列の各プロトコルに共通の設定の空間 $`X`$ と結果の空間 $`Y`$ です。
- 主張の (1) の極限 $`q`$ は、列 $`(π_k)`$ によって決まります。異なる列から同じ $`q`$ が得られることもあります。$`q`$ 自体は $`X`$ から $`\mathrm{Prob}(K)`$ への写像で、どのプロトコルの応答関数でもありません。
- 主張の (2) の $`q`$ も、プロトコルとは無関係に与えた写像です。主張の中身は、「共通の空間を持つプロトコルの列 $`(π_k)`$ で、応答関数がそれぞれ A-0006・A-0017 を満たし、各設定で $`q`$ に弱収束するものがある」ということです。

#### プロトコルを取り替えることが要る理由

一つのプロトコルの中だけでは、閾値のような不連続な応答は極限としても得られません。理由は二つあります。

- A-0006 の連続性は、プロトコルごとの条件です。プロトコルをまたぐ共通の度合い（同程度連続性）は課していません。列の各項が別のプロトコルなので、連続性の度合いが項ごとに悪くなることができ、それで不連続な極限が現れます。
- 雑音の大きさ $`σ`$ を同じプロトコルの設定の座標にして $`σ → 0`$ とする案もあります。しかし、A-0006 の注意の 3 により、理想化の値は設定の範囲に含めず、$`σ ≥ σ_{\min} > 0`$ とします。そのため、一つのプロトコルの中では閾値の極限まで届きません。

さらに、実際の実験は全体で有限個（A-0001）なので、無限の列 $`(π_k)`$ には延長の実験が要ります。これは C-0014 の詳細化の論点に書いてあります。

#### 直し方の案

主張の書き出しを、次のように改めたいと思います。

> 設定の空間 $`X ⊆ ℝ^n`$ と結果の空間 $`Y`$（A-0017 の形）を固定し、これらを共通の設定と結果の空間に持つプロトコルの列 $`(π_k)`$ と、その応答関数の列 $`p_k := p_{π_k}`$ を考える。

あわせて、(1)・(2) の $`q`$ は列 $`(π_k)`$ によって決まり、どのプロトコルの応答関数でもないことを、主張の中に一文で書きます。$`K`$ の定義には $`Y`$ の参照測度を使っていますが、参照測度は $`Y`$ だけで決まるので、プロトコルには依りません。この点も明記します。

この直し方でよければ、C-0014 に反映します。続けて、C-0015〜C-0017 にも同じ種類の書き方（プロトコルの固定の仕方）の誤りがないか確かめます。

#### 1. 応答関数の豊富さを予想にする

C-0014 の (2)（ベール第 1 級の写像はどれも極限として得られる）は、近似に使う応答関数が実際にプロトコルとして存在しなければ成り立ちません。ですから、応答関数の集合が十分に豊富であることは、確かめるべき前提条件です。

**注意が要る点が二つあります。**
- 実際の実験は全体で有限個（A-0001）なので、実際のプロトコルの応答関数は有限個しかありません。豊富さを問えるのは、延長で使えるプロトコル（A-0018 の制約を満たすもの）の応答関数の集合です。
- プロトコルの応答関数は、プロトコルを書けば自由に決められるものではなく、自然が決めるものです。豊富さは「どんな応答を実現する装置が作れるか」という物理的な主張になります。

**予想の案（「プロトコルの応答の普遍性」）**

共通の設定の空間 $`X`$ と結果の空間 $`Y`$ を固定します。延長で使えるプロトコルのうち、この $`X`$・$`Y`$ を持つものの応答関数の集合を $`R(X, Y)`$ とします。このとき次が成り立つ、という予想です。

> 計算可能な（計算可能解析の意味で）連続な応答 $`q : X → \mathrm{Prob}(Y)`$ で、各設定で密度を持つものは、どれも $`R(X, Y)`$ の元で近似できる。すなわち、任意のコンパクト集合 $`C ⊆ X`$ と $`ε > 0`$ について、$`C`$ の上で弱位相の距離（レヴィ–プロホロフ距離など）が一様に $`ε`$ 以内になる $`p ∈ R(X, Y)`$ がある。

**この形にした理由**
- 根拠になる構成を書けます。設定 $`x`$ を雑音のある読みとして計算機に取り込み、$`q`$ を計算し、乱数で結果を出し、小さな雑音を加えて密度を持たせるプロトコルです。読みの雑音で応答は連続になり、出力の雑音で密度を持ちます。
- 厳密に $`q`$ に一致させる形ではなく、近似の形にしました。設定の読みは有限の精度なので、厳密な一致は求められないためです。
- これは、物理的なチャーチ–チューリングの提唱の、実験の側の類比です。C-0004（プロトコルを計算可能な手続きとして形式化する予想。第 38 回に、真の乱数を使うプロトコルの扱いを議論しました）と関係が深く、真の乱数源や計算機が装置として使えることを、どこまで前提にするかが論点になります。

#### 2. 参照測度 $`λ_π`$ はプロトコルに依存するか

「参照測度は $`Y`$ だけで決まる」は、不正確でした。
- A-0017 では、$`λ_π`$ は結果の空間の各成分 $`C_{π,a}`$ の上の $`m_{π,a}`$ 次元のルベーグ測度の直和です。つまり、$`λ_π`$ は集合 $`Y_π`$ だけでなく、その成分への分解（添字の集合 $`F_π`$、各成分 $`C_{π,a}`$ と次元 $`m_{π,a}`$）で決まります。

結論から言うと、理想化した応答の全体は $`\mathrm{Prob}(Y)`$ でも $`\mathrm{Prob}(K)`$ でもありません。この二つは、一つの設定での統計がとる値の空間です。応答は設定から統計への写像なので、理想化した応答の全体は写像の空間 $`\mathrm{Prob}(K)^X`$ の部分集合になります。値の空間には $`\mathrm{Prob}(Y)`$ ではなく $`\mathrm{Prob}(K)`$ を使います。$`\mathrm{Prob}(Y)`$ では、境界の点の δ 分布のような極限を含められないためです。C-0014 はこの区別を書いていないので、以下を定義として加えることを提案します。

#### 1. 値の空間 $`\mathrm{Prob}(K)`$

**結果の空間と参照測度**（A-0017 のとおり）

```math
Y = ⨆_{a ∈ F} C_a, \qquad C_a ⊆ ℝ^{m_a}, \qquad λ = ⨁_{a ∈ F} λ_a
```

ここで $`λ_a`$ は、$`m_a ≥ 1`$ なら $`C_a`$ に制限した $`m_a`$ 次元のルベーグ測度、$`m_a = 0`$ なら一点の上の重さ 1 の測度です。

**拡張した空間 $`K`$**

```math
K_a = \overline{\{\, y ∈ ℝ^{m_a} : \text{$y$ のどの開近傍 $U$ についても } λ_a(U ∩ C_a) > 0 \,\}}^{\,ℝ^{m_a}}, \qquad K = ⨆_{a ∈ F} K_a
```

- 各 $`K_a`$ には $`ℝ^{m_a}`$ の部分空間の位相を入れ、$`K`$ にはその直和の位相を入れます。
- $`K_a`$ は $`ℝ^{m_a}`$ の閉集合なので、$`K`$ は可分で完備に距離化できます（ポーランド空間）。
- 括弧の中は $`λ_a`$ の台で、それを $`ℝ^{m_a}`$ の中で閉包をとったものが $`K_a`$ です。台の外は測度 0 なので、密度を持つ統計の質量はすべて $`K`$ に乗ります。
- $`K`$ は二つの点で $`Y`$ と違います。境界の点（$`C_a`$ が開集合のときの端など）を加え、測度 0 の孤立点（$`C = [0, 1] ∪ \{2\}`$ の 2 など）を除きます。

**集合**：$`K`$ の上のボレル確率測度の全体を $`\mathrm{Prob}(K)`$ とします。

**位相**：弱位相、すなわち次の写像をすべて連続にする最も粗い位相です。

```math
μ \;↦\; \int_K g\, dμ \qquad (g ∈ C_b(K))
```

$`C_b(K)`$ は $`K`$ の上の有界な連続関数の全体です。列の収束で言い換えると、次のようになります。

```math
μ_k → μ \;\;\Longleftrightarrow\;\; \int_K g\, dμ_k → \int_K g\, dμ \quad (∀ g ∈ C_b(K))
```

$`K`$ がポーランド空間なので、この位相はレヴィ–プロホロフ距離で距離化でき、$`\mathrm{Prob}(K)`$ もポーランド空間になります。

**$`\mathrm{Prob}(Y)`$ からの埋め込み**：$`λ`$ について密度を持つ $`μ ∈ \mathrm{Prob}(Y)`$ は、$`K`$ のボレル集合 $`B`$ について

```math
ι(μ)(B) := μ(B ∩ Y)
```

とおくことで、$`\mathrm{Prob}(K)`$ の元とみなせます。$`μ`$ の質量は $`K ∩ Y`$ に乗っているので、これで確率測度になります。

#### 2. 応答の空間

**集合**：設定の空間 $`X`$ から $`\mathrm{Prob}(K)`$ への写像の全体です。

```math
\mathrm{Prob}(K)^X = \{\, q \mid q : X → \mathrm{Prob}(K) \,\}
```

**位相**：各点収束の位相（積位相）です。列について言えば、次のとおりです。

```math
q_k → q \;\;\Longleftrightarrow\;\; ∀ x ∈ X :\; q_k(x) → q(x) \;\;(\mathrm{Prob}(K) \text{ の弱位相で})
```

**実際の実験の応答の候補**：A-0006 と A-0017 を満たす応答（を $`ι`$ で写したもの）の全体です。

```math
R(X, Y) = \{\, ι ∘ p \mid p : X → \mathrm{Prob}(Y) \text{ は連続},\; ∀ x ∈ X :\; p(x) ≪ λ \,\}
```

C-0014 の (2a) はこの数学的な集合について述べます。(2b) は、延長のプロトコルの応答関数として実現される部分（C-0018）について述べます。

**理想化した応答**：$`R(X, Y)`$ の列の極限として得られ、$`R(X, Y)`$ には属さない応答です。

```math
\mathrm{Ideal}(X, Y) = \{\, q ∈ \mathrm{Prob}(K)^X \mid ∃ (p_k)_{k ∈ ℕ} ⊆ R(X, Y) :\; p_k → q \,\} \setminus R(X, Y)
```

#### 3. 注意が要る点

- **「列」の極限であって、位相の閉包ではない**：積位相の閉包はネット（有向族）の極限を含み、連続写像の閉包は大きくなりすぎます（値の空間が弧状連結なら、閉包は写像の全体になります）。そのため、理想化した応答の全体は、位相の閉包ではなく「列の極限の全体」（点列閉包）で定めます。可算個の段階を持つ延長の列（A-0001）とも合います。C-0014 の (1)・(2a) は、この点列閉包がちょうどベール第 1 級の写像の全体 $`B_1(X, \mathrm{Prob}(K))`$ になる、という主張です。

- **設定の空間の側**：$`X`$ には D-0003 の部分空間の位相を入れたままです。境界の設定値を加える拡張（C-0014 の詳細化の論点）は、ここには入れていません。

#### 1. 何が実無限か

区別したいのは三つの段階です。

| 段階 | 例 | 無限の扱い |
| --- | --- | --- |
| 実際 | 実際の実験の記録 $`𝓔`$（A-0001 の (a)） | 有限 |
| 可能的無限 | A-0001 の (b) の漸近。「どの $`N`$ についても、その段階までは有限で作れる」 | どの段階も有限で、終わりがない |
| 実無限 | $`\mathrm{Scl}(X, Y)`$ の定義の「$`∃ (p_k)_{k ∈ ℕ}`$」 | 完結した無限の列を一つの対象として扱う |

A-0001 の (b) は、可能的無限の主張に限っています。$`N → ∞`$ の漸近は「任意の $`ε`$ について、十分大きな有限の $`N`$ で…」という形で述べられ、完結した無限の列そのものを存在させません。一方、$`\mathrm{Scl}(X, Y)`$ の定義は、完結した任意の列を量化しています。ご指摘のとおり、これは A-0001 の立場の外です。

#### 2. 選択公理が要るか

要る場合があります。
- 今の (2b) の構成では、各 $`k`$ について C-0018 で「近いプロトコル $`π_k`$ がある」と言い、それを $`k`$ ごとに一つずつ選んで列にしています。存在しか言えないものを可算回選んで列にするので、一般には可算選択公理が要ります。
- (2a) も同様です。任意のベール第 1 級の写像（計算可能でないものを含む）について近似の列があるという古典的な定理は、構成を与えない存在の主張です。

選択公理で存在が保証されるだけの列は、それを作る手順を持ちません。延長の各段階の実験を実際に行うには、次に行うプロトコルを有限の手段で決められなければなりません。ですから、そのような列を「物理的に存在する」と見なすことはできないと考えます。

#### 3. 食い違いを解く書き方の案

列を「完結した無限の対象」ではなく、「有限の規則で生成される可能的無限」として述べ直します。

**(i) 実効的な点列閉包を分けて定義する**

\mathrm{Scl}_{\mathrm{eff}}(X, Y) := \{\, q ∈ \mathrm{Prob}(K)^X \mid ∃ M :\; M \text{ は } k \text{ からプロトコル } π_k \text{ の記述を出力する機械（A-0018 の制約を満たす）で、} ι ∘ p_{π_k} → q \,\}

## Claude（2026-10-15 05:27:40 UTC、記録 2）

TTE の理論だけから、「計算可能な列なら計算可能な収束のモジュラスを持つ」という結論は出ません。TTE はむしろ逆で、計算可能な列の各点極限は一般に計算可能ではなく、不連続にもなり得ることを示しています。ただし、物理的な前提を一つ加えると、極限が連続になる可能性はあります。順に説明します（文献上の事実は記憶に基づくもので、この回には確かめていません）。

#### 1. TTE から言えること

- **計算可能な関数は連続である**：TTE の基本定理です。許容的な表現を持つ空間の間の計算可能な関数は連続です。
- **モジュラスがあれば極限は計算可能**：計算可能な関数の計算可能な列が、計算可能なモジュラスで（各点で、あるいは一様に）収束するなら、極限は計算可能で、したがって連続です。
- **モジュラスがなければ、極限は不連続になり得る**：典型例はヘヴィサイド関数（閾値の関数）です。
  - 各 $`s(kx + \sqrt{k})`$ は計算可能で、列としても一様に計算可能です。それでも、各点極限は $`x = 0`$ で不連続です。
  - 極限の操作 $`\lim`$ は、ワイラウフ（Weihrauch）の還元の理論で、計算できない操作の代表です。ヘヴィサイド関数はこの $`\lim`$ で計算でき（$`\lim`$ に還元でき）、極限計算可能な関数の典型例です。
  - 極限計算可能な関数は、実効的に $`Σ^0_2`$ 可測な関数（実効的なベール第 1 級）と一致する、という結果があったはずです（Brattka）。

ですから、TTE からは逆の結論が出ます。極限が不連続なら、その列には計算可能なモジュラスがありません。

古典的には、各点収束する列には、$`x`$ と $`ε`$ に「十分大きな $`k`$」を対応させるモジュラスの関数がいつでも存在します。しかし極限が不連続なら、その関数は $`x`$ について不連続で、計算できません。

#### 2. 一つ注意：応答関数は機械が計算するものではない

$`M`$ が計算するのは、プロトコルの記述 $`π_k`$ です。応答関数 $`p_{π_k}`$ ではありません。応答関数は自然が決めるもので、記述が計算可能でも、$`p_{π_k}`$ が計算可能であるとは限りません。

C-0018 を構成的な形にしても、言えるのは「$`p_{π_k}`$ が、計算可能な $`q_k`$ に精度つきで近い」ことまでです。ご質問の「$`p_{π_k}`$ が計算可能なとき」は、この近似の意味で読むのがよいと思います。その読みでも、上の結論は変わりません。極限は $`q_k`$ の極限と一致し、それはヘヴィサイド関数のように不連続になり得ます。

#### 3. 極限が連続になる可能性：物理的な前提

TTE からは出ませんが、次のような物理的な前提を置けば、極限は連続になります。

> すべてのプロトコルに共通の雑音の下限がある（すべての応答関数が、プロトコルによらない同じ度合いで連続である。同程度連続性）。

同程度連続な関数の列の各点極限は連続です。この前提の下では、閾値の応答は極限としても近似できず、理想化した応答は存在しなくなります。

この前提には、物理的な根拠の候補があります。熱雑音（有限の温度）、量子的な揺らぎ（不確定性関係による読みの精度の限界）、第 44 回に触れた資源の上限（有限のエネルギーで達成できる精度の限界）などです。

一方で、A-0006 の注意の 2 は、まさにこの同程度連続性を課さないことにしています（追加の制限を課さないという注意）。A-0005・A-0018 も、プロトコルをまたぐ資源の共通の上界を置いていません（第 44 回）。ですから、
- 今の前提の下では、極限は不連続になり得ます。理想化はあり得ます。
- 共通の雑音の下限を前提に加えた体系では、極限は連続で、理想化はありません。

という二つの体系に分かれます。どちらが物理的に正しいかは、前提ではなく問いとして扱うべきことだと思います。言い換えると、「閾値の装置は、極限としても物理的に意味のある理想化なのか、それとも純粋に数学的な虚構なのか」という問いです。
