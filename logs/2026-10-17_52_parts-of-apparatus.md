おおむね自然だと思います。ただ、Turing machine の「状態」には二つの読み方があるので、それを分けると対応がはっきりします。

#### 1. Turing machine の「状態」の二つの意味
- **制御部の状態**（有限個）：狭い意味の「状態」です。
- **機械全体の様相**（configuration）：制御部の状態・テープの内容・ヘッドの位置の三つ組です。状態遷移は、本来はこの様相の上の写像です。ただし、制御部の状態と、ヘッドの下の 1 マスだけから局所的に決まります。

そのため、「状態と状態遷移は物理系の構成要素」と言うときに、どちらの状態を指すかで対応が変わります。

#### 2. Claude の案：制御部を「装置」、テープを「装置の外の物理系」とする
| Turing machine | 装置の定式化での対応（案） |
| --- | --- |
| 制御部の状態（有限個） | 装置の内部の状態（区別できる有限個の状態） |
| 状態遷移（局所的な規則） | 装置の状態遷移（装置の状態と、接している外の部分だけで決まる） |
| テープ | 装置の外の物理系（観測対象と記録の媒体） |
| ヘッド（1 マスだけ読み書きする） | 装置と外の系の相互作用の局所性（ポート） |
| テープの初期の内容と最終の内容 | 準備された入力と、残った記録 |

- この見方では、「状態」と「状態遷移」は、ご指摘のとおり物理系としての装置の構成要素になります。
- テープも物理系ですが、装置の外に置きます。テープは入力と記録の二つの役を担うので、D-0001 の「観測対象」と「結果の記録」に当たります。
- 機械全体の様相は、装置と外の系を合わせた複合系の状態に当たります。

物理的な機構として計算を定式化した先行研究に、Gandy の「Church's thesis and principles for mechanisms」（1980）があります。装置の状態を有限個の部分に分け、遷移の局所性と、因果の伝わる速さの上限を原理として課す形です。記憶によるもので、確かめるなら調査の候補にします。この流儀は、装置の定式化の参考になる見込みです。

#### 3. Turing machine と物理的な装置で違うところ
1. **遷移の性質**
   - Turing machine の遷移は決定的で、仕様として与えられます。
   - 物理系の遷移は一般に確率的（マルコフ核）か、量子的（チャネル）です。
   - さらに、物理系の遷移は、少なくとも一部が実験で調べる対象です。前回の「振る舞いが仕様で与えられる部品」と「使い方だけを与える部品」の区別は、ここに対応します。
2. **状態の離散性**
   - 物理系の状態の空間は、一般に連続です。
   - Turing machine の有限個の状態は、「有限の精度で確実に区別できる状態」への理想化と読めます（Landauer の「情報は物理的」の立場に近い読み方です）。
   - そうすると、装置の状態は、その装置の分解能に相対的な、有限個の区別できる状態の集合になります。
3. **遷移の歩みと時間**
   - Turing machine の歩みは、順序だけを持ちます。
   - 装置の遷移の歩みを観測者の時計でどう読むかは、別に決める必要があります（T-0031 の「添字は時刻ではない」と同じ型の論点です）。

#### 4. ご意見を伺いたいこと
1. 「状態」は、制御部の状態（装置の内部の状態）を指すと考えてよいでしょうか。それとも、外の系を含めた全体の様相を指すお考えでしょうか。
2. テープを「装置の外の物理系（観測対象と記録の媒体）」と読む対応は、ご意図に合っていますか。

## Claude（2026-10-18 14:30:59 UTC）

ご回答ありがとうございます。ご指摘のとおり、重ね合わせを許すかどうかでモデルは大きく変わります。ただ、変わるのは「状態の空間の形」で、決定的・確率的・量子的の三つの遷移は、一つの枠組みにまとめられる見込みです。

#### 1. 重ね合わせを許すと何が変わるか
Claude の見立てでは、変わるのは次の 4 点です。

1. **状態の空間の形**
   - 重ね合わせを許さない場合（古典）、確率的な状態は有限集合 S の上の確率分布です。状態の空間は単体（頂点が S の元）になります。
   - 許す場合（量子）、状態は d 次元のヒルベルト空間の密度行列です。状態の空間は単体でない凸集合になります。
   - どちらの場合も、確実に区別できる状態の個数は有限です（古典では |S|、量子では d）。前回合意した「区別できる有限個の状態」は保てます。違いは、その間に連続的な重ね合わせがあるかどうかです。
2. **内部の状態を読めるか**
   - Turing machine の制御部の状態は、乱さずに読めます。
   - 量子的な状態は、測らなければ読めず、測ると乱れます。複製もできません（no-cloning）。
   - そのため、「装置の状態を記録する」には、必ず測定（量子から古典への変換）が入ります。量子 Turing machine（Deutsch 1985）でも、停止の判定を観測で行うことに伴う問題が議論されていたと記憶しています（確かめていません）。
3. **装置と外の系の境界**
   - 量子的な相互作用で、装置の内部の状態と外の系（テープ）がもつれると、装置だけの純粋な状態は一般になくなります。残るのは、縮約した状態だけです。
   - 「装置の内部の状態」は定義できますが、全体の状態は部分の状態の組からは決まりません。これは、D-0001 に残した「装置とそれ以外の境界の取り方」に直接響きます。
4. **計算可能性**
   - 有限次元の量子的な装置で計算できる関数の範囲は、古典の Turing machine と変わらない、というのが標準的な理解です（変わるのは計算量です）。
   - そのため、C-0004（計算可能なら連続）や Q-0013 の論点は、量子的な遷移を許しても大きくは変わらない見込みです。

#### 2. 三つの遷移をまとめる枠組み：Claude の案
装置の内部の状態の型を、有限次元の C* 代数 $`\mathcal{A} = \bigoplus_k M_{n_k}(ℂ)`$ で与えます。$`M_{n_k}(ℂ)`$ は、$`n_k`$ 行 $`n_k`$ 列の複素行列の代数です。

| 遷移 | 状態の代数 | 遷移の写像 |
| --- | --- | --- |
| 決定的 | 可換（すべての $`n_k = 1`$。ℂ を \|S\| 個並べたもの） | 集合の写像（から誘導される準同型） |
| 確率的（マルコフ核） | 可換 | 完全正値でトレースを保つ写像（可換な場合は、確率的な行列と同じ） |
| 量子的（チャネル） | 非可換（ある $`n_k > 1`$） | 完全正値でトレースを保つ写像 |

- 重ね合わせを許すことは、「状態の代数に非可換な成分を許す」ことに当たります。$`n_k`$ が 1 と 2 以上の成分を混ぜれば、古典と量子の混成（古典の制御レジスタを持つ量子的な装置など）も扱えます。D-0014 で、制御レジスタを可換な代数として入力側の代数に含める案を書いたのと、同じ形です。
- 記録（テープに残る結果）は、[A-0003](assumptions/A-0003.md) のとおり古典（可換な代数）に限ります。量子的な装置でも、最後の読み出しは測定（非可換から可換への写像）になります。
- 前回の「部品の組を主張のパラメータにする」案と合わせると、次のように述べられます。
  - 可換な代数だけを許す部品の組では、古典的な物理理論になります。
  - 非可換な代数を許す部品の組では、量子的な物理理論になります。
  
  「重ね合わせを許すか」は定義で固定せず、部品の組の選び方の一つにできます。ご指摘の「部品に何を含めるかで物理理論が変わる」の、いちばん基本的な例になる見込みです。

#### 3. この案の限界
1. **量子より一般の理論**：C* 代数を使うと、量子と古典の間の理論しか表せません。一般化確率論（GPT）のように、状態の空間を任意の凸集合として許すと、もっと広くなります。代わりに、合成（テンソル積）が一意に決まらなくなります。T-0019 の調査で扱った論点です。
2. **無限次元**：連続変数の系（調和振動子など）は、有限次元では表せません。「有限の精度で区別できる有限個の状態」の立場では、有限次元への切り詰めとして扱うことになります。
3. **状態の代数が既知という前提**：物理系に作用する部品で、内部の状態の代数を仕様として与えてよいかは、前回の「振る舞いを仕様に含めるか」と同じ型の論点です。代数の型（何次元か、可換か）も実験で調べる対象と見る立場もありえます。

#### 4. ご意見を伺いたいこと
1. 装置の内部の状態の型を、有限次元の C* 代数（可換な成分と非可換な成分の直和）で与え、重ね合わせを許すかを部品の組の選び方とする案は、いかがでしょうか。
2. GPT のような、量子より一般の状態の空間も、部品の組の候補に含めたいですか。それとも、当面は古典と量子（とその混成）に限りますか。
3. 記録は古典に限る（A-0003 のまま）でよいでしょうか。

ただ、装置と外の系では、同じ型でも扱いが違うところが 4 点あると考えます。

#### 1. 同じ型でも扱いが違うところ
1. **状態の型と遷移を、所与として置いてよいか**
   - 装置の部品は、状態の代数と（少なくとも一部の）遷移を仕様として与えます。

C* 代数を使う量子物理学（代数的量子論）での標準的な定義をまとめます。教科書（Bratteli–Robinson、Haag『Local Quantum Physics』など）の一般的な内容を、記憶で書いています。この回では原典を確かめていません。

#### 1. 標準的な定義
物理系に、単位元を持つ C* 代数 $`\mathcal{A}`$ を対応させるところから始めます。

| 概念 | 定義 | 有限次元（$`\mathcal{A} = M_n(ℂ)`$）での形 |
| --- | --- | --- |
| **観測量** | $`\mathcal{A}`$ の自己共役な元 $`a = a^*`$ | エルミート行列 |
| **状態** | $`\mathcal{A}`$ の上の正値で正規化された線形汎関数 $`ω`$（$`ω(a^* a) ≥ 0`$、$`ω(1) = 1`$）。$`ω(a)`$ が観測量 $`a`$ の期待値 | 密度行列 $`ρ`$ で $`ω(a) = \mathrm{Tr}(ρ a)`$ |
| **純粋な状態** | 状態の凸集合の端点（ほかの状態の混合で書けないもの） | 階数 1 の射影 |
| **閉じた系の遷移（時間発展）** | $`\mathcal{A}`$ の *-自己同型の 1 パラメータ群 $`α_t`$（C* 力学系 $`(\mathcal{A}, α)`$）。状態は $`ω ↦ ω ∘ α_t`$ と変わる | ユニタリ $`U_t`$ による $`a ↦ U_t^* a U_t`$ |
| **一般の遷移（開いた系、操作）** | 完全正値で単位元を保つ写像 $`T : \mathcal{B} → \mathcal{A}`$（観測量の側。ハイゼンベルク描像）。状態の側では、その双対 $`ω ↦ ω ∘ T`$ | 完全正値でトレースを保つ写像（チャネル） |
| **測定** | 正値作用素値測度（POVM）$`E`$。結果が集合 $`Δ`$ に入る確率は $`ω(E(Δ))`$。測定後の状態まで含めると、インストルメント（Davies–Lewis） | $`0 ≤ E(Δ) ≤ 1`$ の行列の族 |

**補足**
- **GNS 構成**：状態 $`ω`$ からヒルベルト空間の表現が作れます。この枠組みでは、代数と状態が先にあり、ヒルベルト空間は後から導かれます。
- **可換な場合（古典）**：$`\mathcal{A} = C(X)`$（$`X`$ はコンパクト空間）のとき、次のように対応します（ゲルファント双対とリース–マルコフの定理）。可換な場合は、正値な写像は自動的に完全正値です。
  - 観測量は実数値の連続関数です。
  - 状態は $`X`$ の上の確率測度です。
  - 遷移はマルコフ核です。
  - 決定的な遷移は、写像 $`f : X → Y`$ による $`g ↦ g ∘ f`$ です。
- **向き**：ハイゼンベルク描像では、遷移の写像は系の向きと逆に（出口の代数から入口の代数へ）向きます。

#### 2. 局所的な観測量の網（Haag–Kastler）
- 場の理論では、時空の各領域 $`O`$ に、そこで測れる観測量の代数 $`\mathcal{A}(O)`$ を対応させます（観測量の網）。$`O_1 ⊆ O_2`$ なら $`\mathcal{A}(O_1) ⊆ \mathcal{A}(O_2)`$ です（単調性。用語一覧の isotony）。

#### 3. 前回の論点への含み（Claude の見立て）
1. **標準の物理学では、観測量の代数は所与です**

2. **代数を操作的な公理から導く研究もあります**

#### 1. 時計：周期的な事象と、その場での一致
**部品としての時計（Claude の案）**
- **内部の状態**：周期の位相を表す有限集合 $`ℤ_N`$ と、周期を数える計数器（古典のレジスタ）
- **自由な遷移**：位相を一つずつ進め、一周するごとに計数器を 1 増やす（決定的）。観測対象と違い、この遷移は仕様として与える側です。時計は「自由な遷移が既知の部品」と言えます。
- **タイムスタンプ**：事象（結合の部品が働いた瞬間）に、計数器と位相の値を記録に写し取る操作です。読みは「$`n`$ 周目と $`n + 1`$ 周目の間」という有限の精度の命題になり、Q-0015 の記録の命題の、最も基本的な例になります。

**論点**
1. **その場での一致**：タイムスタンプを付けられるのは、事象と時計の読みが同じ場所で一致する場合だけです（Einstein の操作的な定義）。離れた場所の事象に時刻を付けるには、次の 2 節の同時性が要ります。
2. **周期が「一様」か**：外に基準の時間がないので、一つの時計の歩みが一様かどうかは、その時計だけでは決まりません。決まるのは、時計どうしを比べた歩みの比が安定しているかどうかだけです。「時計の仕様」は、時計どうしの比較（較正）に相対的です。A-0013（較正の普遍性）・C-0009 の論点と同じ形です。
3. **量子的な時計の限界**：エネルギーが下に有界な系には、理想的な時刻の演算子がありません（Pauli の議論）。有限の大きさ・有限のエネルギーの時計には、精度の限界があります（Salecker–Wigner）。前回までの「有限の精度で区別できる有限個の状態」は、時計については物理的な限界でもあります。

#### 2. 物差し：離れた事象の同時性
ご指摘のとおり、物差しで長さを測るには、物差しの両端と対象の両端の一致を「同時に」読む必要があります。ただし、ここで一つ制約があります。前々回に「装置の外の系には、テープのマスの並び（空間の構造）を与えない」と決めました。そのため、目盛りの位置を所与とする「剛体の物差し」を部品として置くと、空間を先取りします。

**代案（Claude の案）**：物差しを独立の部品にせず、時計と信号から組み立てます（レーダーの方法）。
- 観測者の時計で、信号を送った時刻 $`t_1`$ と、遠くの事象で反射して戻った時刻 $`t_2`$ を記録します。
- 遠くの事象に、距離 $`(t_2 - t_1)/2`$（信号の速さを単位とする）と、時刻 $`t_1 + ε\,(t_2 - t_1)`$ を割り当てます。
- $`ε = 1/2`$ が Einstein の同期です。$`ε`$ の選び方は、往復の測定だけでは決まりません（Reichenbach の規約性）。

これで、次の 3 点がはっきりします。

1. **同時性の論点は、$`ε`$ の選び方（片道の信号の速さの規約）に集約されます。** これは、部品の組や体系の選び方と同じ「規約の選択」として、明示的に置けます。
2. **必要な部品は、時計・信号の送受信・その場での一致の記録だけになります。** 空間の構造は与えずに済みます。今のメートルの定義が、秒と光の速さから決まっているのと同じ考え方です。
3. **前回の Bell の例で論点になった「信号が伝わらない」という仮定も、同じ道具で述べられる見込みです。** 往復の信号の時刻から、二つの事象の間で信号が間に合うかを判定できます。

#### 3. 全体のまとめ（Claude の見立て）
| 概念 | 必要な部品 | 規約や仮定 |
| --- | --- | --- |
| その場での一致（事象） | 結合の部品（事象が起きた瞬間に記録へ写す） | 基本の操作として置く |
