#### (2) 「計算可能」とする対象：三つの層

| 層 | 対象 | 「計算可能」の意味 |
| --- | --- | --- |
| ① 記述 | プロトコルの記述（有限の文字列） | 列挙できること（[A-0018](assumptions/A-0018.md) の 1 のまま） |
| ② 実行 | 制御のプログラム | 計算機の部品の能力のクラスの中で、設定の名前と部品の出力（有限の記号）から次の操作を選ぶ関数として計算できること |
| ③ 応答 | 公称の応答の核 | 下の写像が計算可能であること |

③で計算可能とする写像は次のとおりです。

```math
(π,\ ω,\ x) \;\longmapsto\; p_π(x \mid ω) ∈ \mathrm{Prob}(Y)
```

入力は、記述 $`π`$、観測対象の状態 $`ω`$ の名前、設定 $`x`$ の名前です。

- **記述 $`π`$ について一様**に計算可能とします。部品の仕様の数値（ゲートの行列要素、許容差など）を、記述の言語の中で計算可能な実数のプログラムとして書けば、一様性は記述の有限性から従います。
- **表現**：実数には Cauchy 表現（許容的な表現）を使います。$`Y`$ は計算可能な距離空間とし、$`\mathrm{Prob}(Y)`$ には、稠密な点の上の有理数の重みの有限和で近似する標準の表現（Prokhorov 距離に関して計算可能。記憶によるもので、未確認）を使います。
- **計算可能と効率は分けます**。量子の部品の公称の応答の計算は、一般に指数の時間がかかります。ここで求めるのは計算可能性だけで、効率は A-0018 の 2 の資源の側で扱います。
- **観測対象の状態 $`ω`$ の表現**：無限次元の代数では、状態の空間に計算可能な表示があるとは限りません。そこで、③の主張は「状態の空間が計算可能な距離空間として表示される観測対象に限る」という条件付きにします。代数をどう表示するかは [Q-0012](questions/Q-0012.md)・[Q-0014](questions/Q-0014.md) に残します。
- **実際の応答**は、第 53 回の案のとおりとします。結合状態・個体の実際のチャネル・相関の名前に相対的に計算可能、とします。

#### (4) 手順の実効性：要件にし、すべての分岐の停止も課す

要件にします。②は、計算機の部品がプログラムを実行することで満たされます。

これに加えて、**すべての分岐が停止すること**を要件にする案です。第 53 回の詳細化の論点（結果を返さない分岐）への答えにもなります。理由は次の二つです。

- 停止しない分岐が残ると、出力の分布は「合計が 1 未満になりうる分布」になり、下からしか近似できません（下半計算可能）。この場合、③の意味での計算可能性は一般に成り立ちません。
- 実験の側から見ても、時計の部品で打ち切って失敗 ⊥ を記録する形（第 53 回の、予算で打ち切る形）にすれば、どのプロトコルも停止するように書き直せます。そこで、A-0004 の 3 の上界は結果を返さない分岐にも及ぶ、と読みます。打ち切りは記述に含めます。

2. (4) で、すべての分岐の停止（打ち切りと ⊥ による）を要件にしてよいか。
3. 状態の変わる観測対象に繰り返し問い合わせるときの扱い。次の三つの案があります。
   - (i) 対象の遷移は理論から既知とし、初期状態の名前だけを入力にする。
   - (ii) 問い合わせの過程の名前（量子の comb や過程テンソルに当たるもの）も入力に含める。
   - (iii) 両方を許す。基本を (i) とし、(ii) を一般の形とする。

## Claude（2026-10-27 23:04:53 UTC、記録 2）

#### 結論の要約

依存関係はあります。P4（装置の構成的な定義）を土台にすると、残りの三つは次のようになると見ています（Claude の見立て）。

| | P4 を決めた後 | 残る部分 |
| --- | --- | --- |
| P3（実行できない手順の除外） | **ほぼ自動的に解決する** | 停止を構文で保証する仕組みを P4 に入れること |
| P1（等価原理を定理に） | **大部分が、組み立てについての帰納法の定理になる** | 観測対象そのものが設定にどう依存するか（自然の側の連続性） |
| P2（応答の豊富さ） | **自動的には解決しない**（P4 の上で証明する定理になる） | 部品の組 𝔅 の選び方、普遍性の証明、許容差の累積、$`K`$・$`ι`$ |

```
P4（装置の構成的な定義：記述の言語・部品の仕様・組み立て・停止）
 ├──→ P3：有効な記述 ＝ 言語の正しいプログラム（停止は構文で保証）
 ├──→ P1：部品の連続性 ＋ 有限の組み立て ⇒ 応答の連続性
 │         ＋ 観測対象の側の連続性（P4 からは出ない）
 └──→ P2：P4 の言語での普遍性の定理（𝔅 の選択に依存）
           ＋ K・ι の表現（C-0014 の側）
```

#### P3：ほぼ自動的に解決する

P4 で、プロトコルの記述を「部品を呼び出す、組み立ての言語のプログラムで、計算機の部品が実行するもの」と定めれば、有効な記述はどれも、定義から実行できます。[A-0018](assumptions/A-0018.md) の穴（有限の記述だが実行できない手順）は、定義の段階でふさがります。

ただし条件が一つあります。計算機の部品を制限のない Turing machine とすると、プログラムが停止するかは構文からは判定できず、「有効な記述か」も判定できなくなります。そこで、**時計の部品による打ち切りを構文に組み込む**（どのプログラムも、打ち切りの上限を明示し、上限に達したら ⊥ を記録する）形にします。こうすれば停止が構文で保証され、有効性も判定できます。前回の判断の 2（すべての分岐の停止）は、P4 の言語の設計として入ることになります。

#### P1：大部分が帰納法の定理になる

P4 で、次の三つを決めたとします。

1. 設定は、設定を与える部品（つまみ、遅延線、移動台などの作動の部品）か、設定を読む部品を通してだけ装置に入る。
2. 制御部が分岐に使うのは、部品の出力の有限の記号だけである。
3. どの分岐も、上限のある回数で停止する。

このとき、各部品の核が設定について連続なら、組み立てた応答の連続性は、組み立てについての帰納法で示せます。有限の記号での分岐は、各記号の確率が設定について連続であれば保たれ、有限回の合成も連続性を保つからです。これは TTE の「計算可能なら連続」の定理を使わない、構造的な証明です。

残るのは、**観測対象そのものの依存**です。設定には、初期状態の条件と測定の条件を定める実数（[D-0001](definitions/D-0001.md)）が入り、例えば待ち時間 $`t`$ なら、観測対象の時間発展が $`t`$ について連続かどうかが効きます。量子論では、時間発展の群の強連続性に当たります（記憶によるもので、未確認）。これは部品の仕様ではなく、観測対象（自然）についての主張なので、P4 からは出ません。

したがって P1 は、次の形に分解されます。

```math
\underbrace{\text{部品の核の連続性}}_{\text{仕様（𝔅 の選択）}} \;+\; \underbrace{\text{観測対象の側の連続性}}_{\text{自然についての前提}} \;+\; \underbrace{\text{有限の組み立て}}_{\text{P4}} \;\Longrightarrow\; \text{A-0006（等価原理）}
```

等価原理の物理的な中身は、真ん中の項に集まります。前回、P1 だけを前提にすると C-0004 が自明になるおそれがあると述べましたが、この分解なら中身のある定理になります。その代わり、[C-0004](conjectures/C-0004.md) の主張の「計算可能性から導く」という形は、「組み立ての構造から導く」形に書き直すことになります。計算可能性が果たす役は、2 の「有限の記号で分岐する」ことに縮みます。

#### P2：P4 の上の定理として残る

P2 は向きが逆です。目標の応答 $`q`$ を与えて、それを近似するプログラムを構成します。P4 は言語を与えるだけで、次は別に要ります。

- **部品の組 𝔅 の選択**：例えば、公平な乱数源、計算機、連続な値を出力する作動の部品が入っていること（[Q-0012](questions/Q-0012.md)）。
- **普遍性の証明**：古典では、公平なコインと計算機から計算可能な分布の標本を作る標準的な構成があります（Knuth–Yao の型。記憶によるもので、未確認）。量子では、普遍的なゲートの組の近似の定理に当たります。
- **許容差の累積の評価**（体系 (a)）。
- **$`K`$・$`ι`$ の表現**：これは C-0014 の側の論点です。

#### 進め方の提案

P4 を先に決めることに賛成です。(2)・(4) の検討を、次の 5 点を決めることとして組み直す案です。

1. 記述の言語（部品の呼び出し、有限の記号での分岐、繰り返し）
2. 停止の保証（打ち切りを構文に組み込む）
3. 部品のインターフェース（制御部に返すのは有限の記号だけか。連続な値の結果は、読みの部品が有限の精度で記号にする）
4. 設定が入る経路（作動の部品と読みの部品に限る）
5. 部品の仕様の数値の与え方（P2 のためだけに要る。後回しにできる）

これらは [Q-0014](questions/Q-0014.md)（組み立ての規則）と重なります。境界を、Q-0013 では「計算機の部品が実行するプログラムの言語と停止」までを決め、組み立ての一般の規則は Q-0014 で決める、と引く案はいかがでしょうか。また、P1 の分解の結果として、C-0004 の主張を書き直すことと、「観測対象の側の連続性」を前提の候補として記録することについても、ご判断をお願いします。
