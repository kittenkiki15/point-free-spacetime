## 内容

### 動機（第 45 回のユーザーの問題提起）

実験の層（層 1）の前提には、二つの種類が混ざっている。

- **(A) 制限の前提**：物理的にありえない実験を除くために、何を本プロジェクトの実験とするかを定めるもの（例：[A-0005](../assumptions/A-0005.md) の予算の有界性、[A-0004](../assumptions/A-0004.md) の 3 の消費量の有界性、[A-0017](../assumptions/A-0017.md) の「実際の実験の結果の統計は密度を持つ」）。
- **(B) 包含の前提**：理想の物理モデルを扱えるようにするために、何を本プロジェクトの実験とするかを定めるもの（例：A-0017 の目的にある「連続体の上の δ 分布や、設定について不連続な応答を、極限として扱えるようにする」）。

(B) は、本来は結論であるべき物理モデルを先に決めることになりやすい。特に「連続体の上の δ 分布を扱えるようにする」は、点あり時空を前提にしているように読める（ユーザー）。$`δ_y`$ は結果の空間の点 $`y`$ を鋭い値として指定するもので、結果の値が一つに確定することを表す。結果が時計や物差しの読みなら、読みの値が確定することになる。ただし、読みの値が確定することと、時空の点が得られることは別のことで、後者には較正の一意性などが別に要る（PR #62 のレビュー）。δ 分布を理想として置くと、少なくとも結果の空間の点を理想として置くことになり、時空の点を得る道筋の先取りにもつながりやすい。点なしの見方では、有限の精度の観測を鋭くしていった極限が点として得られるか（対象とする観測について、点に当たる対象と、そこへの収束が得られるか。空間全体が点を十分に持つかとは別の問い）は、それ自体が問いである。統計の側でも、鋭くしていった列の弱極限が一点に集中する測度になるとは限らない（Claude の補足）。

### 方針（第 45 回にユーザーと合意）

1. A-0017 から、理想化を極限として再現できることを保証する書き方（(B) の要素）を取り除く。密度の条件は制限の前提として残し、結果の空間の位相の指定は、当面の意味論の選択として残す（下の「結果の空間の意味論」。PR #62 のレビュー）。目的・採用の理由・注意から「理想化を極限として扱えるようにする」という書き方を外し、「実際の実験の結果の統計は密度を持ち、連続体の上の δ 分布は実際の実験の統計には含まれない」までを残す（設定について不連続な応答を除くのは、密度ではなく [A-0006](../assumptions/A-0006.md) の連続性である。各設定で密度を持っても、設定の符号で平均が切り替わる正規分布のように、応答は不連続になり得る。PR #62 のレビュー）。
2. 理想化の再現を予想にする（例：「不連続な閾値の応答は、A-0006・A-0017 を満たす応答の列の極限として得られる」、「鋭くしていった統計の極限が、点（あるいは点なし空間の点に当たる対象）に集中する条件」）。扱うべき物理モデルを扱えることは、前提で保証するのではなく、予想として確かめ、確かめられなければ前提を見直す（「目標の ID」の仕組みと同じ向き）。
3. [Q-0007](../questions/Q-0007.md) の (3)（δ 分布のために結果の空間を拡張する条件、理想化の前後で比べる事象、境界の設定値）は、(B) の種類なので層 1 では決めず、2 の予想の側に移す。
4. ほかの前提も同じ観点で点検する（下の一覧。第 45 回に洗い出した）。

### 結果の空間の意味論（第 45 回のユーザーの提案。Claude が同意）

結果の空間の意味は、数理論理学の意味論に当たると読める。結果の空間に具体的な位相空間を割り当てるごとに、結論として得られる物理モデルが満たす物理法則が変わる、という関係があると予想する（ユーザー）。そこで、Q-0007 で結果の空間の意味を確定するのではなく、この型の予想をいくつか立てて検証する。

- 点なし位相の標準的な対応（Claude の補足）：フレームは命題的な幾何学的理論のリンデンバウム代数として読め、その理論のモデルがフレームの点（完全素フィルター）である。フレームが点を十分に持つ（spatial）ことは、フレームを構文の代数として与えたときに、集合値の点のモデルがフレームの異なる元を区別すること（その意味での完全性）に当たる。通常の論理の「完全な理論」とは別の意味である。記録とそこから確かめられる命題の代数を「構文」、結果の空間への位相空間の割り当てを「意味論」と読む。選んだ意味論のすべてのモデルで成り立つ命題は、現段階では「選んだ意味論で妥当な命題」とよぶにとどめる。物理法則との対応は、同じ結果の空間でも許す応答や統計が違えば法則も違うので、設定・応答・統計を含むモデルを定めてから検討する（PR #62 のレビュー）。
- 予想の型の案（登録する数と優先度はユーザーと相談する）：
  1. **依存の型**：結果の空間の意味論（$`ℝ^m`$ の部分空間、離散空間、有限の精度から作るストーン空間など）を取り替えると、極限として得られる観測量の性質（応答の連続性、統計の極限の形など）が変わる。
  2. **不変の型**（健全性・完全性の類比）：許されるすべての意味論で妥当な命題は、記録の構文から導けるものに一致する。
  3. **点の型**：鋭くしていった統計の極限が点（δ に当たるもの）に集中するための条件を、対象とする観測の領域・点・集中の条件に絞って問う（方針の 2 の後者の例）。空間全体のフレームが点を十分に持つ（spatial）かどうかで述べる形は採らない（spatial でなくても一部に点があればそこへの集中はあり得、通常の位相空間の開集合のフレームはもともと spatial なので、例を区別できない。PR #62 のレビュー）。
- 予想を登録するときは、意味論の間で何を固定し何を変えるか（共通に保つ記録の構文、許すモデルの範囲、命題の対応づけ）を明示する。特に、A-0017 の位相を固定した体系と、それを変えた体系を区別する（PR #62 のレビューの詳細化の論点）。
- 方針の 2 の「不連続な閾値の応答を列の極限として得る」は、収束の意味で結論が変わる（連続な応答の一様極限は連続なので、閾値を含む領域での一様収束では得られない）。点ごとの収束か、閾値を除いた領域での収束か、結果の確率測度の弱収束かを、予想の詳細化で指定する（PR #62 のレビューの詳細化の論点）。
- A-0017 の位相（$`ℝ^m`$ の部分空間の直和）は、意味論を一つ選んでいることに当たる。当面は「標準の意味論」として残し、それが一つの選択であることを注意に明記する（Claude の案。方針の 1 とあわせて扱う）。
- Q-0007 は、意味の確定を完了の条件とせず、「層 1 では意味を確定せず、意味論の選択による違いを予想として立てる」と判断して記録したら、解決にできる形に改める（Claude の案）。(1) の「結果は記録の値（物理量そのものではない）」という読みは、構文の側の約束として [Q-0010](../questions/Q-0010.md) に使える候補として残す。

### 較正とトポスの見方（第 46 回。Claude の見立て。ユーザーの依頼で記録した。文献上の事実は記憶によるもので、この回には確かめていない）

区切り 3 の A-0010・D-0013 の段階 1（決定的な較正）の判断と、層 3（[T-0009](T-0009.md)）・層 4〜6（[T-0010](T-0010.md)）の構成の手がかりとして残す。

1. **決定的な較正をロケールの写像として述べる（段階 1）**：今の [D-0013](../definitions/D-0013.md) の較正 $`σ_e : X_π × Y_π ⇀ M_O`$ は連続な部分写像で、定義域を $`D ⊆ X_π × Y_π`$ とすると、逆像は逆向きのフレームの準同型 $`σ_e^{*} : 𝒪(M_O) → 𝒪(D)`$ を与える（$`M_O`$ の逆像は $`D`$ で、全体ではないので、$`𝒪(X_π × Y_π)`$ への準同型にはならない。PR #63 のレビュー）。これは、観測者の座標の各領域 $`U`$ に「事象が $`U`$ の中にある」という記録の側の命題を対応させる翻訳として読める。ただし、記録の側の $`X_π × Y_π`$ と行き先の $`M_O = ℝ^{1+n}`$ を今のまま点を持つ位相空間として与えるなら、このフレームの準同型は、記録の各点に $`M_O`$ の点を対応させる連続写像を再び定めるので、書き換えただけでは点の先取りはなくならない（開集合をすべて使うこと自体も、有限の精度への制限ではない。PR #63 のレビュー）。点を前提にしないためには、どの空間・命題の与え方を変えるか（例えば、記録の側や座標の側を、点から作るのではなく有限の精度の命題の代数として与える）を決める必要があり、それを区切り 3 の問いとする。また、連続でない決定的な較正は、この形には入らないので、別に扱う（部分写像 $`⇀`$ をロケールとしてどう扱うか（定義域を開部分ロケールとするなど）も、別に定める必要がある）。
2. **確率的な較正と、確率の冪ロケール（段階 2）**：段階 2 のマルコフ核 $`κ_e`$（入力は設定と結果の組 $`(x, y)`$。D-0013 の 4）のうち、各開集合の確率が入力全体について下半連続になるもの（設定だけについての下半連続性では足りない。例：$`y < 0`$ なら $`δ_0`$、それ以外なら $`δ_1`$ とする核は、設定については一定だが、$`y`$ について条件を満たさない。PR #63 のレビュー）（開集合の付値についての連続性の条件を満たすもの）は、付値ロケール（確率の冪ロケール、valuation locale。Vickers ら）$`𝒱(M_O)`$ へのロケールの写像として読める見込みである。一般のマルコフ核はこの形にならない（例：実数の設定が 0 以上のときだけ結果 1 を確率 1 で出す核では、結果 1 の確率が設定について下半連続でない。PR #63 のレビュー）ので、条件を満たさない較正は別に扱う。条件を満たす場合、段階 1 は、単位 $`η : M_O → 𝒱(M_O)`$（点を δ に写すもの）と合成した特別な場合に当たり、今の D-0013 の「段階 1 は $`κ_e = δ`$ の特別な場合」という関係が、モナドの単位として保たれる見込みである。
3. **観測者が複数あることが、トポスの構造になる**：観測者を対象、比較の実験で定まる取り替え（[A-0014](../assumptions/A-0014.md)）を射とする場を考えると、その上の前層のトポスで、各観測者の座標のロケールが一つの対象にまとまり、較正は記録の側の対象から座標の側の対象への自然変換になる。較正の普遍性（[A-0013](../assumptions/A-0013.md)）は自然性の条件として、体系 P の群（[A-0015](../assumptions/A-0015.md)）は場が亜群になる場合として読める見込みである。これは、量子論のトポス的な定式化（Isham–Döring、Heunen–Landsman–Spitters の「Bohr 化」）と同じ型である。そこでは、可換部分代数（文脈）の圏の上のトポスで、文脈ごとのスペクトル（観測量の値の割当ての対象）が内部のロケールにまとまり、Kochen–Specker の定理の条件が成り立つ系（ヒルベルト空間の次元が 3 以上など）では、そのロケールが大域的な点（文脈をまたいで整合する値の割当て）を持たない。量子状態が存在しないという主張ではない（PR #63 のレビュー）。
4. **位置づけ**：再構成したい時空（[D-0007](../definitions/D-0007.md)）は、観測者の場の上のトポスの内部ロケールとして読める。「観測者ごとの局所的な時空は点を持つが、すべての観測者に共通の大域的な点があるか」は、内部ロケールが大域的な点を持つかという問いになり、点なし時空の主題と Kochen–Specker の型の「点がない」現象が同じ枠組みに入る。また、上の「結果の空間の意味論」とも合う。幾何学的理論の分類トポスでは、トポス $`𝔈`$ の中のモデルが、$`𝔈`$ から分類トポスへの幾何学的な写像と対応する。集合値のモデルは、集合のトポスからの写像、つまり通常の点（命題的な理論ならロケールの点、一般の理論ならトポスの点）に当たり、一般のトポスの中のモデルは、その相対的・内部的な点に当たる（PR #63 のレビュー）。結果の空間に位相空間を割り当てることは、モデルを取る先のトポス（集合のトポスか、観測者の場の上のトポスか）を選ぶことにも広げられる。
5. **扱い**：区切り 3 で、A-0010・D-0013 の行の選択肢として検討する。トポスの観点（観測者の場の上の前層のトポス）は、予想の候補か、T-0009・T-0010 の手がかりとして登録するかを、区切り 2・3 でユーザーと相談する。参考文献として登録するには、文献を確かめる。

### 理想化の再現の予想へ移す論点（第 46 回に仮置き。区切り 2 で予想の詳細化の論点に移す）

[Q-0007](../questions/Q-0007.md) と [A-0017](../assumptions/A-0017.md) から移した。本文は移す前のままである。

- 極限で表せる不連続な応答の範囲（A-0017 の未解決の点から。第 33 回。PR #42 のレビューの詳細化の論点）：連続な応答関数の設定ごとの極限として得られる不連続な応答は限られる。例えば $`X = [0, 1]`$、$`Y = \{0, 1\}`$ で $`p(1 \mid x) = 𝟙_{ℚ}(x)`$ は、連続関数の各点極限（ベール第 1 級の関数）にならないので、極限としても得られない。どの不連続な模型を極限として扱いたいかと、それで足りるかを確かめる。
- 理想化した極限のための結果の空間の拡張（第 33 回。PR #42 のレビューの詳細化の論点）：$`C_{π,a}`$ が開集合だと、境界の δ 分布は $`\mathrm{Prob}(Y_π)`$ の中の弱極限にならない（例：$`(0, 1)`$ の上の密度 $`n\,𝟙_{(0, 1/n)}`$ は、ℝ の上では $`δ_0`$ に弱収束するが、$`\mathrm{Prob}((0, 1))`$ では弱極限を持たない）。理想化の際に結果の空間を（閉包などへ）拡張する条件を決める。
- どの点の δ 分布まで理想化として必要か（第 33 回。PR #42 のレビューの詳細化の論点）：$`C_{π,a}`$ がルベーグ測度 0 の孤立点を含むと（例：$`C = [0, 1] ∪ \{2\}`$）、密度を持つ分布はその点に質量を持たず、$`𝟙_{\{2\}}`$ が $`C`$ の上で連続なので、$`δ_2`$ に弱収束できない。すべての点の δ 分布を対象にするなら、参照測度の台と $`C_{π,a}`$ の関係（例：$`C_{π,a}`$ を開集合の閉包に限る）も決める。
- 理想化の前後で比べる事象（第 33 回。PR #42 のレビューの詳細化の論点）：弱収束は、任意の可測な結果の事象の確率の収束までは保証しない（例：$`N(0, σ_k^2) → δ_0`$ でも、事象 $`[0, ∞)`$ の確率は各 $`k`$ で $`1/2`$、極限では 1）。閾値の判定などの後処理を理想化の前後で比べるときに、どの事象の確率に収束を求めるか（例：極限の分布の連続集合に限る）を決める。
- 境界の設定値の扱い（第 44 回。PR #60 のレビューの詳細化の論点）：[A-0005](../assumptions/A-0005.md) は予算の値域が閉じていることを求めないので、設定の列が範囲の境界（$`X_π`$ の外）へ近づくことがある。この極限は、[A-0017](../assumptions/A-0017.md) の極限（共通の空間の各設定を固定した、応答関数の列の弱極限）とは別の操作である。境界の設定値を、理想化した模型の設定として含めるために、設定の空間の拡張や写像を定めるかを、理想化の前後で比べる事象とあわせて決める。

### 詳細化の論点（PR #62 のレビュー）

- [A-0013](../assumptions/A-0013.md)・[A-0015](../assumptions/A-0015.md) を予想の「目標の ID」にしていることだけでは、結論の先取りが解消したとは限らない。目標を導く経路で、目標自身を直接・間接に仮定していないかを、[C-0010](../conjectures/C-0010.md)・[C-0011](../conjectures/C-0011.md) と関連する導出の依存関係で点検する。
- 依存の型の予想は、「どの取り替えでも必ず変わる」という全称の主張にすると強すぎる（結果の値域を同相写像で移し、応答と統計も写し替えれば、法則は同じ形に保てる）。登録するときは、同型な意味論の扱いを決め、差が現れる意味論の組と、比べる法則を指定する。
- [T-0004](T-0004.md) の本文に残る「極限で表せる不連続な応答の範囲」（A-0017 の未解決の点）と、予想へ移す理想化の再現・Q-0007 の (3) との境界を、書き換えのときに T-0004 の本文にも反映する。
