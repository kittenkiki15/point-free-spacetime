# 全体の目的

本プロジェクト全体の目的（goal）を、1 件 1 ファイル（`goals/G-NNNN.md`）で管理します（第 56 回にユーザーと決めた。[T-0035](../tasks/T-0035.md)）。

- **最上位の目的は [G-0000](G-0000.md)（個人または人間社会の幸福の追求）です。** 本プロジェクトでは「幸福」を「生きること（系としての存続）」と同義として用い、幸福の追求は自己保存・進化・多様性の 3 つの側面を持ちます。目的の受益者は個人または人間社会だけとし、AI を含めません（研究の主体には AI を含みます）。各目的のファイルには、主にどの側面に資するかを書きます（第 58 回のユーザーの提案。[T-0037](../tasks/T-0037.md)）。
- **研究目的は仮説の形で書きます。** 研究において「研究目的」とは「仮説を検証すること」そのものとする（第 56 回のユーザーの定義）。仮説の形で書くのは研究目的だけで、G-0000 のような一般の目的は対象外です（第 58 回のユーザーの判断）。各ファイルには、仮説、検証の方法、現在の信念（仮説に対する確信の度合い）を書きます。これは、人と AI の協働による研究で重要な 3 つ（[G-0001](G-0001.md) の 1〜3：仮説と研究目的の共有、合意した方法での検証、更新した信念の合意）に対応します。
- 種類は「一般」（研究目的ではない目的。今は G-0000 だけ）、「進め方」（人と AI の協働による研究の進め方）、「研究テーマ」（点なし時空による物理学）の三つです。今は「進め方」の目的が優先します（第 56 回のユーザーの判断。[G-0001](G-0001.md) の「方針」）。
- 状態は、合意・候補・廃止のどれかです。候補の段階で削除したものは、ファイルを置かずに欠番とします（下の「削除した候補と欠番」）。「合意」にするのは、ユーザーと合意したときに限ります。
- 書式は [`_template.md`](_template.md) です。
- 各項目（D・A・C・Q・R）の「## 目的」は箇条書きにし、それぞれの箇条に、関係する全体の目的の ID を書きます（[T-0036](../tasks/T-0036.md)。第 57 回にすべての項目を書き換えた。どの全体の目的ともつながらない箇条は、明文化されていない全体の目的の手がかりとして洗い出す）。但し書きやレビューの経緯は下位の箇条に置き、G のリンクを要しません。すべての項目の目的の節が箇条書きで、すべての箇条にリンクがあることを `tools/tests/test_framework.py` で検査します。一覧とファイルの一致、上位の目的の循環がないことも検査します。
